### Verified End-to-End Flows

1. **Flow A (Hierarchy & Task Management):** Project -> Milestone -> Task CRUD -> Reparenting -> Inline controls -> Safe cascade deletion.
2. **Flow B (Capacity & Ledger):** Weekly capacity rules -> Date overrides -> 7-day grid -> Minute allocations -> Dual-encoded status badges.
3. **Flow C (Feasibility Engine):** Task estimate -> Feasibility calculation -> Surplus/deficit -> Earliest feasible date -> Deterministic lowest-load candidate distribution -> User review -> Atomic commit.
4. **Flow D (Dashboard Forecasting):** Overdue/urgent attention list -> 7d/14d/30d forecast cards -> Deep link navigation `/#/planner?date=YYYY-MM-DD` -> Planner focused date.
5. **Flow E (Safe Local Backup):** Versioned JSON export -> Zod schema & referential validation -> Comparison preview -> Pre-import snapshot -> Atomic restore / one-click rollback.
6. **Flow F (PWA & Lifecycle Safety):** PWA install prompts -> Offline caching -> UpdateBanner -> FormGuardContext check -> ActiveFormGuardModal preventing reload data loss.
7. **Flow G (Encrypted GitHub Sync):** Transient auth -> PBKDF2/AES-GCM encryption -> Remote push -> SHA conflict detection -> Pull & decrypt -> Preview & restore -> 100% offline autonomy.
