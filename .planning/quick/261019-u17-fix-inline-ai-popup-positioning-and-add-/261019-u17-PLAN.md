    Refactor popup coordinate calculation in InlineAISelectionBar:
    1. Store selection bounding rect in state (`selectionRect: { top: number; bottom: number; left: number; right: number; width: number } | null`) when mouseup detects a valid text selection.
    2. Implement a positioning calculation function:
       - Define GAP = 8.
       - Measure popup height and width using `containerRef.current?.getBoundingClientRect()` with fallback estimates: collapsed toolbar height ~38px, width ~320px; asking inline view height ~280px, width ~380px.
       - Vertical positioning:
         If `rect.top >= popupHeight + GAP + 10` (sufficient clearance above viewport top):
           `y = rect.top - popupHeight - GAP` (strictly above selection rect, bottom edge of popup is 8px above top of text).
         Else:
           `y = rect.bottom + GAP` (flip strictly below selection rect, top edge of popup is 8px below bottom of text).
       - Horizontal positioning:
         Center horizontally relative to selection: `x = rect.left + rect.width / 2 - popupWidth / 2`.
         Clamp to viewport margins: `Math.max(16, Math.min(window.innerWidth - popupWidth - 16, x))`.
       - Add scroll offsets `y + window.scrollY` and `x + window.scrollX` for absolute positioning.
    3. Ensure recalculation runs when `isAskingInline` toggles or when popup height changes (via `useEffect` or `useLayoutEffect` on `isAskingInline`, `visible`, and `selectionRect`), so transitioning into the taller question/answer view recalculates and shifts the popup up or down to avoid covering the selected text.
    4. Rename button from "Hỏi Chat Drawer" to "Mention vào Chat" with tooltip "Mention đoạn trích vào khung chat để chỉnh sửa trước khi gửi". In the inline query panel footer, rename "Mở trong Chat Drawer" to "Mention vào Chat".
