<objective>
Cho phép mở nhiều tab độc lập cho cùng một utility tool trong Tool Explorer và đổi tên từng tab đó,(scope) không đụng tab editor khác.

Purpose: hiện `ToolExplorerPanel.openTool` dùng `id = tool.id` nên click lần hai chỉ focus tab cũ; hai tab cùng tool còn dùng chung buffer input/output trong `utilityToolContentStore` (key theo `viewType`). Sếp cần mở song song hai phiên bản của cùng công cụ để so sánh/gõ liệu khác nhau mà không ghi đè nhau, và cần đặt tên tab có ý nghĩa.

Output: id tab duy nhất, buffer nội dung tách theo instance, action `renameTab` + UI double-click inline, guard reopen chỉ cho tab utility, và focused regression tests. Không thêm dependency, không đổi schema Dexie, không đụng PWA/GitHub Pages.

Quyết định (Claude's discretion): dùng `crypto.randomUUID()` theo convention ID của dự án, prefix `utility-` để đọc log dễ; dùng chính `tab.id` làm instance key thay vì thêm param mới. Giữ fallback về key `viewType` để tab utility đã persist từ trước vẫn đọc được nội dung cũ. Chọn double-click + input inline thay vì context menu modal — ít code hơn, không thêm component AntD mới; vẫn có Enter/Escape và aria-label.
</objective>
