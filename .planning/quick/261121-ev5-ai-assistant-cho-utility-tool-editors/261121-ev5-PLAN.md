# AI assistant inline cho utility tool editors

## Mục tiêu

Mỗi editor trong Tool Explorer (JSON Formatter, XML Formatter, Text Compare, Markdown Viewer)
có nút **AI**. Mở ra 2 chế độ:

1. **Sửa nội dung** — nhập yêu cầu, stream kết quả, xem so sánh/xem trước, chỉ ghi vào editor
   sau khi bấm **Áp dụng**. Hủy hoặc đóng = không đổi nội dung.
2. **Hỏi về nội dung** — stream câu trả lời dạng Markdown, **không** có nút áp dụng, không sửa editor.

Mỗi tool nhớ riêng model đã chọn. Mặc định lấy `config.defaultModel` của NineRouter hiện hữu.

**Giới hạn cứng:** không thêm dependency; không sửa `AiChatWidget`, `useChatTurn`,
`chatTurnRuntime`, `AIChatDrawer`, `InlineAISelectionBar`, `patchProposal`; không dùng full-chat
path; không mạng ngoài luồng NineRouter có sẵn; giữ Tauri/local-first.

## Thiết kế dùng chung (bắt buộc)

### Component dùng chung

Tạo `src/workbench/toolwindows/UtilityToolAIAssistant.tsx` — MỘT component cho cả 4 tool.

Props (exact): `open: boolean`, `toolId: string` (một trong `json_formatter | xml_formatter |
text_compare | markdown_viewer`), `content: string`, `contextContent?: string`, `contextLabel?: string`,
`onApply: (next: string) => void`, `onClose: () => void`, `db?: TaskPlannerDatabase` (default `db`
từ `../../db`). Modal tự quản lý mode/prompt/model/stream — editor chỉ truyền nội dung và nhận lại
chuỗi đã sửa qua `onApply`.

- `contextContent` chỉ dùng cho `text_compare`: truyền pane A, nhãn `A — GỐC (tham khảo)`.
  Assistant luôn sửa pane `B — MỚI`; pane A chỉ là ngữ cảnh cho chế độ hỏi.

### Model picker — state riêng từng tool, lưu ở Dexie

- Key duy nhất: `utility_tool_ai_models`, value = `Record<string, string>` map `toolId -> modelId`.
- Load khi mở: đọc record đó + `getNineRouterConfig(db)`; model của tool = `map[toolId] ?? config.defaultModel`.
- Danh sách chọn: `['ninerouter_cached_models']` nếu có; nếu rỗng thì `Select` chỉ có 1 option là
  model hiện tại. Không fetch mạng.
- Khi đổi model: đọc lại record, ghi `db.settings.put({ key: 'utility_tool_ai_models', value: { ...map, [toolId]: model } })`.
  Tool khác đọc map same key nhưng nhánh khác → không bị ảnh hưởng. Không dùng localStorage.
- Thêm 4 dòng khai báo key vào `PROFILE_KEY_CATALOG` (mỗi tool một key) **hoặc** một dòng
  `utility_tool_ai_models: 'portable'` — chọn một dòng key duy nhất cho ngắn.

### Prompt shape

- Chung: system message ngắn, tiếng Việt, bọc nội dung người dùng trong delimiter rõ ràng
  (`NỘI DUNG HIỆN TẠI:` / `CÂU HỎI:`), nhắc "không bịa dữ liệu, giữ nguyên nội dung gốc khi không
  được yêu cầu sửa", "không xuất thẻ `<think>`".
- **Edit** (`mode: 'edit'`): system nhấn "trả về TOÀN BỘ nội dung đã sửa, chỉ nội dung, không lời dẫn;
  nếu kết quả là code/JSON/XML/Markdown thì bọc trong đúng MỘT fenced code block". User message =
  yêu cầu của người dùng + `NỘI DUNG HIỆN TẠI` (có `contextContent` thì thêm phần nhãn).
- **Ask** (`mode: 'ask'`): system nhấn "chỉ trả lời câu hỏi, KHÔNG trả bản sửa, KHÔNG thực hiện thay đổi".
  User message = câu hỏi + nội dung (+ context nếu có).

### Trích xuất output

Hàm pure export `extractProposedContent(raw: string): string` (test trực tiếp):
1. `stripThinkingBlocks(raw)` rồi `.trim()`.
2. Nếu có cặp fence ```` ``` ```` → lấy nội dung block cuối cùng, bỏ dòng mở/đóng, giữ nguyên
   indent và nội dung bên trong (regex `/```[^\n]*\n([\s\S]*?)```/g`, lấy `match[1]` cuối).
3. Không có fence → trả nguyên chuỗi đã strip.
4. Kết quả rỗng → trả `''` (nút Áp dụng bị disable).
Chế độ ask KHÔNG gọi hàm này — render trực tiếp `renderSafeMarkdown(stripThinkingBlocks(accumulated))`.

### Xác nhận / UI

- `Modal` (rộng ~960), `destroyOnClose`. Header: icon `RobotOutlined` + "AI · {tên tool}" +
  `Select` model (compact) + `Segmented` [Sửa nội dung | Hỏi về nội dung].
- `Input.TextArea` cho yêu cầu/câu hỏi + nút **Tạo** (disabled khi đang stream hoặc prompt rỗng).
- Khi stream: `Spin` + text "AI đang phản hồi..."; hiện text tích lũy theo thời gian thực.
- Edit: `Segmented` [So sánh 2 cột | Xem trước | Chỉnh sửa].
  - So sánh: grid 2 cột, trái = nội dung gốc (`whiteSpace: 'pre-wrap'`, mono), phải = đề xuất.
  - Xem trước: `renderSafeMarkdown(proposed)` (với JSON/XML/Markdown đều dùng được, class
    `markdown-rendered-view` nếu muốn style sẵn).
  - Chỉnh sửa: `Input.TextArea` cho phép sửa đề xuất trước khi áp dụng.
  - Footer: **Hủy** (abort + đóng), **Tạo lại** (disabled khi streaming), **Áp dụng** (primary,
    disabled khi `isStreaming || !proposed.trim()`) → `onApply(proposed)` rồi `onClose()`.
- Ask: chỉ khung Markdown answer + **Đóng**; **không** render nút Áp dụng / Tạo lại dạng apply.
- Error: `Alert type="warning"` hiện `err.message` (đã được client redact key), giữ nội dung gốc.
- Abort/dọn: `AbortController` ref; `handleCancel` abort + đóng; `useEffect` cleanup abort khi
  `open` chuyển false **và** khi unmount; bỏ ref nếu chính controller đó kết thúc (pattern dòng
  140-145 của NormalizeDocModal). Không setState sau unmount.
