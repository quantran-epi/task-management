## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Telegram API -> Rust Gateway | Untrusted user input enters via getUpdates polling |
| Inbound Text -> HTML Converter | User input & AI output translated to HTML tags |
| Whitelist -> TaskMate DB | Authorization barrier preventing unauthorized data exfiltration |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-TG-01 | Tampering | telegramHtml.ts | mitigate | XML entity escape all raw text before applying markdown formatting tags to prevent HTML injection |
| T-TG-02 | Information Disclosure | telegramHeadlessWorker.ts | mitigate | Enforce dataScope restrictions and filter retrieval strictly to authorized scopes; /reset wipes conversational memory |
| T-TG-03 | Denial of Service | telegramHeadlessWorker.ts | mitigate | Enforce dailyLimit quota checks before LLM invocation; cap maxHistoryTurns to 20 to avoid token blowups |
| T-TG-04 | Elevation of Privilege | telegramSettingsService.ts | mitigate | Reject any inbound chat_id not explicitly whitelisted with status 'active' |
</threat_model>
