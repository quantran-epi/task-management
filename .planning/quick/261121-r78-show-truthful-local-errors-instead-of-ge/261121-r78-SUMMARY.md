## What changed

- `src/services/ai/office/teamRunCoordinator.ts`
  - Added `LOCAL_ERROR_CODE_PREFIXES` / `LOCAL_ERROR_PHRASES`, pinned only to throw sites in app code (`WORKTREE_NOT_AVAILABLE`, `Tính năng SSH worktree chỉ hoạt động`, `Không tìm thấy SSH config`). No fabricated `SSH_NOT_AVAILABLE` / `DB_NOT_AVAILABLE` / `CONFIG_NOT_AVAILABLE` markers — those have no app throw site and matching them would let provider text into `content` (T-r78-01).
  - Added `truthfulLocalReport(err)`: returns a 300-char-bounded `Không thể chuẩn bị môi trường làm việc: ...` string for app-local errors, `undefined` otherwise. No stack, no IDs, no hosts.
  - Thrown-exception catch now computes it once and replaces all three `SANITIZED_TURN_ERROR` report slots with `truthfulReport ?? SANITIZED_TURN_ERROR`. `stopReason: 'provider'` kept (union has no local member); `diagnosticDetail` unchanged. `onError` and `reportContentFor` untouched.
  - Direct-mention turns (no assignment row) get a persisted report bubble on the local-error path only, so the truthful message is visible in the transcript. Provider throws get no bubble from this path.
- `tests/services/ai/office/teamRunCoordinator.test.ts`
  - `HarnessOptions.agentDeveloperWorktree` seam; creates a real `Agent Developer` employee (`agentKind: 'developer'`) at construction.
  - Strengthened existing provider-throw test to assert the report row content is exactly `SANITIZED_TURN_ERROR` and contains no raw text.
  - Added 2 tests: local provisioning error on dispatched assignment; local error on direct mention with no assignment row.

## Decisions

- Did not widen `AiTeamAssignmentStopReason`. Ledger keeps `'provider'`; report text carries the truth. Avoids backup schema/UI mapping churn.
- Did not add `SSH_NOT_AVAILABLE` / `DB_NOT_AVAILABLE` / `CONFIG_NOT_AVAILABLE` markers from the plan's example list: grep confirms no app throw site. A provider string containing them must stay sanitized.
- The direct-mention bubble write is a Rule 2 (missing critical functionality) fix: without it, must-have "Direct-mention turns with no assignment row also show the truthful local message" is unachievable.
