<objective>
Fix Ghost-Dev Claude Code CLI process invocation and interaction protocol when operating under `--input-format stream-json`.

Purpose:
Claude Code CLI with `--input-format stream-json` expects messages streamed over standard input (`stdin`) rather than a positional command-line prompt argument. Passing the prompt as a CLI argument alongside `--input-format stream-json` causes CLI errors or prompt truncation. In addition, user feedback in `send_agent_feedback` and worker tool execution results must be formatted in standard stream-json user envelopes (`{"type":"user","message":{"role":"user","content":[...]}}`) so Claude Code can parse them without stream corruption.

Output:
- `src-tauri/src/agent_manager.rs`: Updated spawn arguments (removing `&payload.initial_prompt`), helper functions for stream-json user and tool envelopes, sending initial prompt via `stdin_tx`, wrapping user feedback and worker tool results.
</objective>
