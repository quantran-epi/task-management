# Quick Task Summary: 261006-i22 Fix Ghost-Dev Stream-JSON Initial Prompt and Stdin Framing

## One-liner
Framed Claude Code CLI initial prompt, user feedback, and worker tool results in stream-json user envelopes over process stdin.

## Context
When running Claude Code CLI with `--input-format stream-json`, passing an initial prompt as a command-line positional argument causes argument parsing errors or prompt truncation. Stream-json mode requires messages sent over standard input (`stdin`) framed with `{"type":"user","message":{...}}`. In addition, user feedback strings and worker subtask execution results must adhere to this stream-json envelope format.

## Key Changes
- `src-tauri/src/agent_manager.rs`:
  - Added `format_user_text_envelope(text: &str) -> serde_json::Value` helper generating standard Claude stream-json user message payload.
  - Added `format_tool_result_envelope(tool_use_id: &str, content: &str, is_error: bool) -> serde_json::Value` helper generating standard Claude stream-json tool result payload.
  - Removed `&payload.initial_prompt` positional argument from `claude` command invocation in `start_ghost_dev_session`.
  - Dispatched initial prompt immediately after `stdin_writer` spawn via `stdin_tx.send(format_user_text_envelope(&payload.initial_prompt).to_string())`.
  - Updated `send_agent_feedback` to frame user feedback with `format_user_text_envelope`.
  - Updated `dispatch_subtask` worker concurrency limit, worker spawn failure, and worker completion responses to send via `format_tool_result_envelope`.

## Verification
