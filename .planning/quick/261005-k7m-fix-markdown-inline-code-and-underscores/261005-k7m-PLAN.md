<objective>
Fix inline code corruption and intra-word underscore italic rendering in `renderSafeMarkdown`.

Purpose: When AI returns identifiers like `T_TRANS_TYPE` inside backticks or plain text, the underscore italic parser incorrectly matches intra-word underscores, converting `_TRANS_` into `<em>TRANS</em>` and removing the underscores so it renders as `TTRANSTYPE`.
Output: Fixed `src/utils/markdown.ts` with tokenized inline code protection and CommonMark boundary checks for underscores, plus unit tests in `tests/utils/markdown.test.ts`.
</objective>
