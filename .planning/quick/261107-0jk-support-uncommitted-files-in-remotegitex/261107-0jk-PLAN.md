       - Update `getRemoteFileContent` to catch git show errors or check if ref is working copy/untracked and fallback gracefully to `getRemoteWorkingFileContent`.

    - Pressing Enter or clicking outside (blur) commits the new title (if non-empty, trimmed).
    - Pressing Escape cancels editing and restores the original title.
    - Updated titles persist in component state for the lifetime of the tab session.
  </behavior>

       - Render an inline `<Input size="small" autoFocus />` when `editingTabId === tab.id`.
       - Handle `onKeyDown`: Enter commits (`handleRenameSubmit`), Escape cancels (`handleRenameCancel`).
