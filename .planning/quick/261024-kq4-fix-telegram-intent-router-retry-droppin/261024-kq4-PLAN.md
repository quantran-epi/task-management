<objective>
Fix Telegram/AI intent router retry dropping MCP routing fields.

Root cause (proven by HAR captures, do not re-investigate):

2. `IntentResultSchema` uses `.default(false)` / `.default([])`, so the incomplete retry payload validates and silently disables MCP retrieval in `groundedTurn.ts`.

Purpose: Make the router contract self-consistent so a retry can never silently disable MCP retrieval.
Output: Schema-derived repair prompt, required MCP fields, regression tests covering the real timeout+retry failure.

Scope guard: do NOT modify `src/services/ai/groundedTurn.ts`. Its MCP gate logic is correct; it must not compensate for a broken router contract.
</objective>
