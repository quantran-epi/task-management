Ghi chú · hành vi được mô phỏng
  1. Cây worktree SSH là dữ liệu tĩnh. Search, collapse/expand, scope Diff/Tất cả chạy bằng JS local; không kết nối SSH hay đọc filesystem.
  2. Nội dung file là sample. Gutter số dòng và tô màu keyword/string/comment làm bằng span, không dùng syntax-highlight library.
  3. Copy Path / Copy Content / Reveal / Reload chỉ hiện toast "Mô phỏng — không có tác dụng thật"; không ghi clipboard thật.
  4. Diff Accept/Reject/Accept All/Revert All chỉ đổi state trong trang. Bộ đếm +/− phản ánh số dòng của các hunk chưa quyết định; không sửa file hay repository.
  5. Popout Coding Zone không phải cửa sổ thật. Đây là div nổi chứa tree, tab/diff và chat strip nhỏ, dùng chung biến messages, activeTabId, hunkStates, treeScope với modal; không dùng window.open, IPC hay Tauri.
  6. Team chat không gửi đi đâu. Tin thêm vào chỉ nằm trong bộ nhớ trang, mất khi reload.
  7. Light/Dark chỉ đổi attribute data-theme trên <html> để swap palette CSS; không lưu cài đặt.
  8. Góc nhìn "Team chat + agent activity" chỉ đổi bố cục của cùng modal, vẫn dùng chung state tab/chat.
  9. Tab pinned "Tổng quan" không có nút ×. Đóng tab active chuyển sang tab kề; kéo thả để sắp xếp lại (pinned luôn đứng đầu).
