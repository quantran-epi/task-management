## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| model tool args → chat history handler | Model-generated `turnId` / injected `threadId` is untrusted; thread ownership must come from request context |
| transcript text → model prompt | Message bodies are user-authored and may contain prompt injection |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-Q7J-01 | Information disclosure | `executeChatHistoryTool` cross-thread read | mitigate | `getTeamTurn(threadId, turnId, db)` guard using request-bound threadId; refusal before any content is serialized; scoped test + UAT with foreign turnId |
| T-Q7J-02 | Tampering / privilege | `dispatchAiToolCall` threadId resolution | mitigate | `threadId` only from `ChatTurnRequest.threadId` set by drawer; `args.threadId` ignored; missing context returns `THREAD_CONTEXT_MISSING` |
| T-Q7J-03 | Injection | search excerpts + read content | mitigate | `wrapUntrusted` on every returned excerpt/content (nonce delimiters), mirroring team tools |
| T-Q7J-04 | DoS | unbounded BM25 scan | accept | Personal single-user transcript; existing `limit` clamp 1..20; same ceiling as team tools |
| T-Q7J-SC | Tampering | npm/install step | mitigate | No new packages installed; no install task in this plan |
</threat_model>
