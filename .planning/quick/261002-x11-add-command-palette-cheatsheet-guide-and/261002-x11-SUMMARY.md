# Quick Task 261002-x11: Command Palette Cheatsheet Guide & Prefix Filters Summary

Added interactive syntax cheatsheet and prefix filters (`>`, `@`, `#`, `!`, `+`, `?`) to Command Palette.

## What Was Done

1. **Prefix Filters**:
   - `> `: Only search views/screens
   - `@ `: Only search tasks
   - `# `: Only search projects
   - `! `: Only search notes
   - `+ `: Create task directly
   - `? `: Open syntax cheatsheet guide

2. **Interactive Cheatsheet Guide**:
   - Question mark button `<QuestionCircleOutlined />` in search bar and footer link "Xem phím tắt (?)".
   - Typing `?` immediately opens the cheatsheet panel.
   - Clickable prefix badges under search input (`> Màn hình`, `@ Tác vụ`, `# Dự án`, `! Ghi chú`, `+ Tạo việc`) for instant 1-click filter selection.

3. **Targeted Tests**:
   - Added unit test cases for cheatsheet guide rendering and prefix filtering.
   - All 6 tests in `tests/components/palette/CommandPaletteModal.test.tsx` pass.
