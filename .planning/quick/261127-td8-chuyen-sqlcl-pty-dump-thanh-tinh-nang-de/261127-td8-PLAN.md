# Quick Task 261127-td8: Đưa SQLcl PTY dump thành tính năng debug trong app

## Goal

Thay instrumentation phụ thuộc env/file bằng in-memory ring buffer bounded, có Tauri command export và UI nút "Xuất nhật ký PTY SQLcl" trong Settings → Remote SSH, dùng `saveFileWithPicker` để lưu file `.log` trên Windows. Cập nhật hướng dẫn build Windows installer.

## Tasks

1. Convert `sqlcl_pty_debug.rs` sang in-memory buffer + export command
   - Files: `src-tauri/src/sqlcl_pty_debug.rs`, `src-tauri/src/lib.rs`
   - Action: Giữ `dump(label, bytes)` nhưng ghi vào `Mutex<Vec<u8>>` bounded 64 KiB (ring/drop-oldest hoặc truncate head — chọn bounded an toàn, không vượt cap). Thêm `#[tauri::command] pub fn sqlcl_pty_dump_export(clear: bool) -> Result<String, String>` trả nội dung đã escape/redact. Register trong `generate_handler!`. Bỏ file/env path.
   - Verify: `cargo check` + 3 unit test scoped + test export command nếu gọn.
   - Done: dump luôn có sẵn trong process, export được qua IPC, không ghi file tự động.

2. Thêm UI debug card
   - Files: `src/components/settings/SqlclPtyDebugCard.tsx` (new), `src/views/SettingsView.tsx`
   - Action: Card với Button "Xuất nhật ký PTY SQLcl (debug)" gọi `invoke('sqlcl_pty_dump_export', { clear: false })`, dùng `saveFileWithPicker` lưu `sqlcl-pty-debug.log`. Hiện Alert hướng dẫn: repro xong mới bấm xuất; nội dung đã redact nhưng vẫn rà tay. Thêm vào tab `ssh`.
   - Verify: `npx tsc --noEmit` scoped / vitest nếu có test component; không chạy full suite.
   - Done: xuất hiện trong Settings → Remote SSH, bấm được, file download/save dialog chạy trên Windows.

3. Update guide + Windows build instructions
   - Files: `.planning/quick/261127-td8-.../WINDOWS-GUIDE.md`, cập nhật guide cũ nếu cần
   - Action: Hướng dẫn CI build installer từ workflow `windows-installers.yml`, tải artifact, cài trên Windows, repro, bấm nút export, gửi log về. Nêu rõ không cần env var.
   - Verify: đọc lại guide, đủ bước.
   - Done: sếp có thể phối hợp trên Windows mà không cần `tauri dev`.

## Constraints

- Không đổi protocol SQLcl/PGID/marker/session reuse.
- Dump bounded 64 KiB, redact keyword, không auto-write file.
- Không commit secret; không chạy full vitest.
- Giữ ngôn ngữ tiếng Việt, identifier/path/lệnh nguyên gốc.
