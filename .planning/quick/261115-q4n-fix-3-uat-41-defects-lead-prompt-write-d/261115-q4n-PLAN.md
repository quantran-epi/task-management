# Fix 3 UAT-41 defects

Three verified defects from `41-UAT.md` (tests 12, 14, 7). Root causes are already diagnosed by probe — do not re-investigate.

- **A (test 12):** the lead prompt never says an EMPLOYEE writes with `write_doc`, so the lead delegates `create_note`, which the employee read-only gate refuses → turn `cancelled` → `stopped`.
- **B (test 14):** `send()` awaits `ensureDocsReady` + `refreshMcpTools` before `saveTeamMessage`; `graphiti_mcp_request`'s reqwest client has no timeout, so an unreachable MCP endpoint leaves the await pending forever and the user's own row never lands.
- **C (test 7):** `ensureDocsReady`'s bare `catch` hides the backfill failure, so a missing tree is undiagnosable.

Out of scope (deliberate): `delegate_batch`'s tool description in `teamTools.ts` — the diagnosed fix is the lead prompt block only. PWA/GitHub Pages untouched (Tauri is the only supported runtime).
