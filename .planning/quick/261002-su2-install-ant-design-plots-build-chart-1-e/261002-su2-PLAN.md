## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-quick-01 | Information Disclosure | `src/views/AnalyticsView.tsx` | mitigate | All calculations occur entirely client-side in browser memory without sending data to external endpoints. |
| T-quick-02 | Denial of Service | `src/utils/analytics.ts` | mitigate | `aggregateEstimateVsActual` restricts output to top N (default 15) tasks sorted by effort, and `aggregateProductivityHeatmap` caps data to a static 7x24 grid to prevent chart rendering slowdowns. |
| T-quick-SC | Tampering | npm install `@ant-design/plots` | mitigate | Install official `@ant-design/plots` package with cache isolated to `/tmp/.npm-cache`. |
</threat_model>
