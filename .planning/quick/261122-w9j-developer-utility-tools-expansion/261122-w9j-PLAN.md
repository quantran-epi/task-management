    Encoder/Decoder — `encodeText(input: string, kind: 'base64'|'url'|'html'): string` và `decodeText(input: string, kind): string`. base64 phải UTF-8-safe: encode bằng `TextEncoder` → binary string → `btoa`; decode bằng `atob` → `Uint8Array` → `TextDecoder`, throw `Error` rõ nghĩa khi base64 sai. url dùng `encodeURIComponent`/`decodeURIComponent`. html dùng bảng thay thế `& < > " '` (decode chiều ngược bằng replace theo thứ tự `&lt;` trước, `&amp;` cuối). Test bắt buộc có roundtrip tiếng Việt có dấu để chứng minh không mojibake.

    Regex — export `REGEX_MAX_INPUT = 100000`, `REGEX_MAX_MATCHES = 200`, và `runRegex(pattern: string, flags: string, input: string): { matches: { index: number; value: string; groups: string[] }[]; count: number; truncated: boolean; error: string | null }`. Chỉ cho phép flag `gimsuy` (lọc flag lạ, báo lỗi). Wrap `new RegExp` + vòng lặp `matchAll`/`exec` trong try/catch trả `error` thay vì ném. Các phép case chuyển theo token từ; `sort-lines`/`dedupe-lines`/`reverse-lines` giữ thứ tự ổn định, bỏ dòng trống khi dedupe; `count` trả chuỗi tóm tắt "N ký tự · M từ · K dòng · B byte" với B đếm bằng `TextEncoder`.     Cron — `parseCron(expr: string): { valid: boolean; fields: string[]; description: string; error: string | null }` tự implement, KHÔNG thêm `cron-parser`.
