<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Popout opener -> browser/Tauri navigation | App constructs a navigation URL consumed by browser popup or Tauri WebviewWindow. |
| Popout UI -> native/window close API | User click closes current script-opened browser popout or current Tauri webview/window. |
| Jira REST API -> local settings UI | Jira status catalog from network becomes display labels for local mapping config. |
| IndexedDB Jira cache -> task drawer UI | Cached Jira status ID/name drives local mismatch warning. |
| IndexedDB task notes -> task list UI | Private task note text affects list indicator visibility. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-JM1-01 | Tampering | popout URL builder | mitigate | Only add numeric `popoutVersion` before an existing whitelisted hash route; keep entity params URL-encoded. |
| T-JM1-02 | Denial of Service | popout close action | accept | Close occurs only on explicit user click; no timers or repeated close attempts. |
| T-JM1-03 | Information Disclosure | TaskTable note indicator | mitigate | Render only compact indicator for non-empty notes; do not render task note body in list. |
| T-JM1-04 | Spoofing | Jira status mapping labels | mitigate | Persist Jira status IDs as values; names are display labels and optional semantic comparison tokens only. |
| T-JM1-05 | Tampering | Jira mismatch comparison | mitigate | Match exact ID first, then normalized configured name token; no broad category-only equality for mismatch. |
| T-JM1-06 | Denial of Service | controlled pagination | mitigate | Use Ant Design page sizes only and clamp current page when data shrinks. |
| T-JM1-SC | Tampering | package supply chain | accept | No package installs; use existing React, Ant Design, Tauri API, and Vitest only. |
</threat_model>
