<objective>
Fix the `#/agents` route reload issue, add custom prompt review/editing to `RunGhostDevModal`, and implement local session audit history tracking for Ghost Dev sessions.

Purpose:
1. Reloading the browser while on `#/agents` currently drops back to `#/dashboard` because `'agents'` is missing from `VALID_ROUTES` in `useHashRoute.ts`.
2. Users currently cannot inspect or modify the generated prompt before launching Ghost Dev. Adding prompt customization and extra instructions gives users direct control over agent instructions.
3. Ghost Dev sessions lack persistence: once stopped or after app reload, session context, initial prompts, and user feedback logs are lost. A persistent audit repository preserves complete execution logs and mid-run feedback history.

Output:
- Updated route validator and tests
- Interactive prompt customization in `RunGhostDevModal`
- `agentSessionHistoryRepo` with full audit metadata and mid-run feedback tracking
- Session audit inspection in `AgentSessionList` and `AgentControlView`
</objective>

| Browser Hash → Router | Untrusted user navigation input in window.location.hash |
| User Input → Agent Prompt | Free-form prompt text provided in modal and feedback |
| Client Storage → Memory | LocalStorage audit history parsed at runtime |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-QUICK-01 | Tampering | agentSessionHistoryRepo.ts | mitigate | Validate parsed JSON with safe typing and fallback to empty array on malformed storage |
| T-QUICK-02 | Information Disclosure | localStorage ('planner:ghost_dev_session_history') | mitigate | Restrict to origin-isolated browser storage; sanitize display of local paths |
| T-QUICK-03 | Denial of Service | agentSessionHistoryRepo.ts | mitigate | Enforce 100-record cap ring buffer to prevent unbounded localStorage growth |
| T-QUICK-04 | Tampering / Spoofing | useHashRoute.ts | mitigate | Whitelist route string strictly against VALID_ROUTES array |
| T-QUICK-05 | Injection | RunGhostDevModal.tsx | mitigate | Prompts passed directly via CLI arguments and stream-json without shell string interpolation |
</threat_model>
