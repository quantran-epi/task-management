# Quick Task 261126-r13: Sửa thiết kế SSH attach theo phong cách Claude Code

## Tóm tắt

Quick task này thay thế thiết kế `261126-qag` bằng một thiết kế khả thi hơn cho tính năng đính kèm file SSH trong chat standalone. Không có mã production nào bị sửa; output là hai file documentation.

Năm quyết định được giữ nguyên:

1. `ATTACH-PERSIST-IN-MESSAGE` — attachment là field của `ChatMessage`, không phải transient tab state. Chip sống sau reload và sau backup/restore; composer thêm/xoá chip trước gửi, chip tin nhắn cũ chỉ đọc.
2. `DOC-PROGRESSIVE-READ` — DOCX/XLSX/PDF đọc theo kiểu Claude Code: `info` rồi `read` theo vùng (PDF `pageStart/pageCount <= 20`, XLSX sheet+row/col, DOCX block index qua JSZip `word/document.xml`). Không đọc toàn file rồi cắt 24k.
3. `SSH-BROWSER-SEARCH` — browser SSH có tree `listRemoteDir` và tìm tên file `find -iname | head -n 201` với `shellQuote` + `callId` cancel; multi-select lưu full normalized path; attach chỉ lưu danh tính.
4. `UNIFIED-ATTACH-TOOL-FAMILY` — `ssh_attached_file_info/search/read` thay `ssh_read_attached_file`; mọi tool validate path thuộc attached set sau `resolveRemoteToolPath`, sanitize + `wrapField`.
5. `GATING-STANDALONE-ONLY` — mọi affordance đi qua `isStandaloneChat`; dock chat không nút, không tool; không knowledge daemon, không network service mới.

Ba điểm thiết kế cũ bị thay:

- Attach chỉ là `references` trong runtime tab → chỉ lưu path tạm, mất sau reload; giờ copy vào `ChatMessage.attachments` lúc `saveMessage` và khai báo optional trong `BackupChatMessageRecordSchema` (`src/validation/backupSchemas.ts:291`). Phát hiện bổ sung: `attachments` cũng nằm trong `FORBIDDEN_BACKUP_KEYS` (`:198`), nhưng forbidden-key check chỉ chạy trên tab record (`:251`) — thiết kế nêu rõ ranh giới này để implement không vô tình chặn message record.
- `parseSshDocument` đọc toàn file rồi cắt `DEFAULT_MAX_CHARS = 24000` → thay bằng phân trang theo định dạng, dùng thư viện có sẵn (`exceljs`, `jszip`, `mammoth`, `pdfjs-dist`), không cài package mới.
- Tool đơn `ssh_read_attached_file` chỉ delegate text/code cho docs → thay bằng family 3 tool có validate attached set, range theo extension, và từ chối thay fallback.
