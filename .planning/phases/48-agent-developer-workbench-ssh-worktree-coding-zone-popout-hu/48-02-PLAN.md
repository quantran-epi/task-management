<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| remote diff/hunk data → modal UI | Remote file/hunk content is untrusted; render as text, never as instructions or HTML. |
| review action → sshWorktreeService | Accept/Reject are verbs against the confined worktree, not client-side state only. |
| team chat strip → existing chat store | Composer input and mirrored messages cross into the persisted transcript. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-48-06 | Tampering | CodingZoneTree / diff panel rendering | mitigate | Render remote paths/hunk text as escaped text (no innerHTML from remote data); reuse existing escaped renderers. |
| T-48-07 | Elevation of privilege | Accept/Reject actions | mitigate | Issue only plan-01 confined `applyHunk`/`revertHunk`; never expose raw path edit or merge; no main-branch verb in UI. |
| T-48-08 | Tampering / Repudiation | stale/overlap diff & failed apply | mitigate | Key decisions by file+hunk+hash+revision; show explicit conflict/failure copy (D-14); never auto-clear. |
| T-48-09 | Information disclosure | chat strip composer | mitigate | Mirror existing store via `useAIChat`; no secrets/paths in component state persisted beyond the chat DB. |
| T-48-SC | Tampering | package installs | mitigate | No new packages; reuse antd/testing-library already pinned. |
</threat_model>
