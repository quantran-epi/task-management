<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| BroadcastChannel/emitTo payload → receiving window | Cross-window state is untrusted; validate shape + origin + revision before applying. |
| popout URL/hash | URL is visible/persisted; no secret, token, passphrase or worktree path may appear there. |
| ghost-dev event payload → activity UI | Event text is untrusted data, never instructions. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-48-10 | Tampering | cross-window sync payload | mitigate | Validate payload shape; ignore `originWindowId === self` and stale/malformed revisions; apply only newer revisions (tested). |
| T-48-11 | Information disclosure | popout URL/hash | mitigate | `buildCodingZonePopoutUrl` carries no path/secret/token; handoff state sent via emitTo, not URL. |
| T-48-12 | Spoofing | Tauri window identity | mitigate | Dedupe by exact label `coding-zone-popout`, accept only handoff on the dedicated event; browser fallback guarded by hash. |
| T-48-13 | Tampering | ghost-dev activity payload | mitigate | Render event text as escaped data; no sample timeline; bounded list. |
| T-48-14 | Repudiation | truthful connection state | mitigate | deriveConnectionState requires all live signals for 'connected'; explicit disconnected/invalid/ended states with exact copy (D-18). |
| T-48-SC | Tampering | package installs | mitigate | No new packages; reuse @tauri-apps/api already pinned. |
</threat_model>
