## Typography

Exactly four roles, matching draft + workbench tokens:

| Role | Size | Weight | Line Height | Family / Usage |
|------|------|--------|-------------|----------------|
| Body | 13px | 400 | 1.5 | Inter; base body text, chat message text (11px in compact strip), toolbar labels |
| Label | 11px | 400/600 | 1.45 | Inter; tree rows, tabs, buttons, msg meta, hunk headers, segmented; small UI (`.tag`, `.msg-time`, `.scope-hint`, `.compose-hint`) 9-10px |
| Heading | 13px | 650 (≈700) | 1.2 | Inter; modal title (13px/650), chat head (11px/600), perspective label, overview h2 (16px) |
| Code | 11.5px | 400 | 19px fixed | IBM Plex Mono; code rows, diff lines, line-number gutter 10px, `path`/`hdr` 10.5-11px |

Rules:
- Weights limited to 400 (regular) and 600-700 (semibold/bold) — two effective weights, consistent with draft (`600`, `650`, `700`) and loaded Fontsource weights.
- Body line-height 1.5 recommended baseline; chat strip 1.45; code/diff fixed 19px per line (no wrap; horizontal scroll).
- Vietnamese labels render offline via bundled Fontsource subsets — no network font fetch.
- Do not shrink below 9px (draft's smallest tag/hint); keep accent/contrast per palette tokens.

Source: draft CSS lines 96-99, 104-126, 138, 145, 183-203, 230-250, 271-304, 307-332; workbench-tokens.css:67-72.

## Interaction & Layout Contract (draft-derived, prescriptive)

These are hard rules from the approved draft and locked decisions, included so executor/auditor have one visual source of truth.

### Shell
- Fullscreen modal: backdrop `position: fixed; inset: 0; background: var(--bg); padding: 16px`; modal fills it, `border-radius: 11px`, `box-shadow: var(--shadow)`, `overflow: hidden`, flex column.
- Header 48px: title + perspective segmented + spacer + `Light / Dark`, `Popout Coding Zone`, `Ghi chú` (production: omit), close `×`. Footer 26px shows live branch / connection state (production replaces sample placeholders).
- Two perspectives share ONE state object: `messages`, `activeTabId`/tabs, `hunkStates`, `treeScope`, `treeQuery`, `activeFile`. Switching perspective only swaps layout (D-04). Chat perspective: left = active-file card + live agent activity timeline; right = wide transcript + composer.

### Left — SSH worktree tree
- Target card: `SSH` label + mono `profile · /remote/path`; branch line: branch tag + `read-only` marker (read-only applies to file viewer; hunk accept/reject still worktree-local per D-12 — clarify copy so `Read-Only` refers to direct file editing, not review actions).
- Controls: 26px search input (`⌕`), scope segmented `Diff`/`Tất cả`, hint text.
- Tree rows 24px, 12px indent/level, folder/file glyph + status badge + `+N −N` delta; selected row = accent-soft bg + accent fg; hover = bg-hover. Click folder toggles collapse; click file opens/focuses tab. Search auto-expands ancestors; diff scope hides subtrees without changes.

### Center — tabs / file / diff
- Tab bar 30px, scrollable; pinned `Tổng quan` tab (no `×`, always first), code tabs (file glyph), diff tabs (green `Δ`). Active tab: surface bg + 2px accent top rule. Close button hover = danger bg. Drag to reorder; pinned stays first. Active close falls to adjacent tab.
- Code view: toolbar shows `remote` tag + mono path + branch + `Read-Only` tag + actions (Copy Path / Copy Content / Reveal / Reload — real behavior where D-05 applies; toast only in draft). Body: 52px line-number gutter, 19px rows, target initial line highlighted via `--accent-soft`, syntax colors (keyword/string/comment/function/number), Mermaid handling reused from `RemoteFileViewer`.
- Diff view: second toolbar with `Unified`/`Side-by-side` segmented, live `+N −N dòng chưa quyết định` counters, `Accept All`/`Revert All`. Hunks are bordered cards: head (mono `@@` header + state tag + per-hunk `+N −N` + Accept/Reject buttons), body (unified: old/new no columns + marker + text with add/del backgrounds; split: OLD/NEW halves), foot. Accepted → `dimmed-old` (old lines struck), state-accept border/green tag; Rejected → `dimmed-new`, state-reject border/red tag, body opacity .72. Clicking same decision toggles back to pending. Decisions are worktree-local verbs, mirrored to popout (D-12/D-13).

### Right — compact chat strip
- Head 38px: `Team chat · N online` + sync chip (truthful, D-18) + `⤢` popout icon button. Transcript scrolls to bottom on new message; compact message grid 24px avatar + meta (name/time/kind chip) + text (11px, 1.45). `agent` messages get cyan avatar/kind styling; synthesis kind gets success chip. Composer: 50px textarea, `Gửi` primary, Enter to send / Shift+Enter newline. Mirrors existing team store (D-16).

### Popout (real Tauri `WebviewWindow`)
- Label `coding-zone-popout`, hash route `#/coding-zone-popout`, dedupe via `getAllWebviewWindows`, targeted `emitTo` handoff + `BroadcastChannel` sync with `{originWindowId, revision}` for echo suppression (D-15). Geometry ~1200×800 default; window title `Coding Zone`.
- Popout renders the SAME three panes at narrower widths (`210px | 1fr | 230px`), its own tree search, tab bar, content, active-file label, chat strip transcript + composer. State (tree/tabs/active file/hunk decisions/chat/activity) shared and revision-guarded; decision made in either window appears in the other (D-13).
- Browser fallback safe (same-origin BroadcastChannel; no secrets/paths in URL/hash). If popout closed, main modal keeps working and chip reflects reality (D-18).
- Draft note "Popout Coding Zone (mô phỏng)" and the floating-div `.popout` are replaced by the real window; keep visual language identical.

### Responsive & accessibility
- ≤900px: hide right chat pane in modal; two-column layout persists. Popout ≤760px: stack explorer + center rows, hide chat pane.
- Focus rings on inputs, tab close, tree rows; `role="dialog"`/`aria-label` on modal + popout, `role="tablist"`/`role="tab"`/`aria-selected` on tabs, `aria-label` on icon buttons, `role="status"` toast. Escape closes notes → popout → modal. Keyboard focus visible with accent outline.
- Theme: toggling `data-theme` swaps both palette sets; no layout shift, no network fonts.
