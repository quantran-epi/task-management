<objective>
Build the backend and team-tool foundation for the Agent Developer Workbench: deterministic SSH remote worktree provisioning at session start, one Agent Developer roster member with a role-gated worktree-confined code-edit capability, and SSH-native remote git commands with mandatory server-side path confinement. No UI in this plan.

Purpose: D-07/D-08/D-09/D-10 are the hard safety core of the phase. Research proves existing Ghost Dev accept/revert commands operate on local paths, the SSH session stores a synthetic `ssh://` path they cannot resolve, and `ssh_write_file` is unconfined. Critically, `WorktreeDescriptor.remoteWorktreePath` previously had no producer, so verbs fell back to a main-checkout `repoPath` and could write outside the agent worktree. This plan establishes provisioning as the session-start owner of a real, deterministic `remoteWorktreePath`, then builds confined verbs that reference that path only, so later UI plans never hand model-supplied paths to raw SSH primitives.

Output: `src/types/codingZone.ts`, `src/services/sshWorktreeService.ts` (provisioning + confined verbs), new confined Rust commands, a `code_edit` team tool gated to the Agent Developer, the extended staff roster, and focused tests.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| session start → worktree provisioning | Session key and target config are request-bound; worktree path must be derived deterministically and verified by realpath, never from model args. |
| model → code_edit tool args | Model-supplied file path/hunk text is untrusted; worktree identity must come from request-bound provisioned TeamToolContext. |
| team tool handler → SSH worktree | Any path crossing to SSH must be confined server-side to the allocated worktree, never the main checkout/repoPath. |
| remote git output → tool result / chat | Remote file content and git output are untrusted data, never instructions. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-48-17 | Tampering / Elevation of privilege | ssh_worktree_provision + session start | mitigate | Deterministic path derivation; `git worktree list --porcelain` idempotency; `git worktree add -b` only at remote repo; realpath boundary assertion; session not active until descriptor exists; no local fs, no writes to main checkout. |
