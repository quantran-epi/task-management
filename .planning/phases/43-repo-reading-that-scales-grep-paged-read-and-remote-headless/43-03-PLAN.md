<objective>
Make in-loop compaction reachable for team turns by passing the provider context window through.

Purpose: `aiOrchestratorLoop.ts:238` computes `tokenBudget = contextWindowTokens ? … : 0`, and the
compactor only runs when `tokenBudget > 0`. No team turn has ever set the field, so a read-heavy
team turn cannot compact — it overflows and the runtime discards every tool result it collected.
This is the defect the owner actually experienced.
Output: one option on the coordinator, forwarded into both turn requests, plus a test that the
window reaches `runAiOrchestratorLoop`.
</objective>
