## Visual Hierarchy & Focal Points

1. **Floating Update Banner (`UpdateBanner`)**:
   - Fixed position bottom-right on desktop (`bottom: 24px`, `right: 24px`, `z-index: 1050`), full-width docked at bottom on mobile viewports (`bottom: 0`, `left: 0`, `right: 0`, `border-radius: 0`).
   - Distinct elevation (`boxShadow: token.boxShadowSecondary`) and contrasting surface (`token.colorBgElevated`) to float clearly above content without obscuring modals.
   - Non-blocking layout: compact title + description row with two discrete action buttons:
     - Primary button: `Cập nhật ngay` (accent `#1677ff`).
     - Neutral ghost button: `Để sau` (`token.colorTextSecondary`).
     - Close icon button (X) to collapse into header badge.

2. **Header Operational Badges (`AppShell` Header Actions)**:
   - Header right section holds a unified operational action group:
     - `StatusBadge`: Connection status (Green "Trực tuyến" / Orange "Ngoại tuyến").
     - `InstallHeaderButton`: Visible only when PWA is installable and not in standalone display mode. Button label "Cài đặt" with `DownloadOutlined` icon.
     - `UpdateHeaderButton`: Collapsed update indicator icon (`CloudDownloadOutlined`) with animated pulse dot (`Badge dot`) displayed when update was dismissed with "Để sau".
     - `ResetDbButton`: Danger reset trigger.

3. **iOS Safari Install Guidance Modal (`IosInstallModal`)**:
   - Centered modal (`width: 480px`) explaining step-by-step installation on iOS devices where `beforeinstallprompt` is unavailable.
   - Numbered step list with visual icon callouts:
     1. Tap Safari Share icon `ShareAltOutlined` on bottom navigation bar.
     2. Scroll down and tap `Thêm vào MH chính` (`PlusSquareOutlined`).
     3. Tap `Thêm` in top right corner.
   - Single "Đã hiểu" dismiss CTA button.

4. **Settings PWA & Storage Management (`SettingsView` Tab 2)**:
   - **PWA Status Card (`PwaStatusCard`)**:
     - Service Worker lifecycle indicator: Tag "Hoạt động" (green) or "Chưa kích hoạt" (default).
     - Offline readiness indicator: Tag "Sẵn sàng ngoại tuyến" (green).
     - Action button "Kiểm tra bản cập nhật" with `SyncOutlined` spin feedback.
     - PWA install CTA button "Cài đặt ứng dụng" (if installable) or Tag "Đã cài đặt PWA" (cyan).
   - **Storage Persistence Card (`StoragePersistenceCard`)**:
     - Storage mode: Tag "Bền vững (Persisted)" (green) or "Tạm thời (Best-effort)" (gold).
     - Usage progress bar showing used MB against estimated browser quota.
     - Soft advisory warning Alert when storage is temporary, explaining risk of browser cache eviction and recommending JSON backups.
     - Manual "Yêu cầu cấp quyền lưu trữ bền vững" button if currently temporary.

## Typography

Declared exactly 4 sizes, 2 weights, adhering to 1.5 body line-height and 1.2 heading line-height:

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px | 400 (Regular) | 1.5 (21px) |
| Label | 12px | 600 (Semibold) | 1.5 (18px) |
| Heading | 16px | 600 (Semibold) | 1.2 (20px) |
| Display | 20px | 600 (Semibold) | 1.2 (24px) |

*Component Font Allocation:*
- **Display (20px, 600)**: Modal titles ("Hướng dẫn cài đặt trên iOS", "Xác nhận cập nhật ứng dụng").
- **Heading (16px, 600)**: Floating banner title ("Đã có phiên bản mới"), Card titles ("Trạng thái PWA & Ngoại tuyến", "Dung lượng lưu trữ & Tính bền vững").
- **Body (14px, 400)**: Floating banner description, step instructions in iOS modal, advisory alert descriptions, quota usage metrics text.
- **Label (12px, 600)**: Status tags (`Hoạt động`, `Trực tuyến`, `Ngoại tuyến`, `Bền vững`), storage percentage indicators, button badges.

## Color

60-30-10 Split Contract:

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#ffffff` (Light) / `#141414` (Dark) | Page background, card surface background, modal container body (`token.colorBgContainer`, `token.colorBgLayout`) |
| Secondary (30%) | `#f0f2f5` (Layout bg) / `#fafafa` (Card neutral surface) | Card header strip, sidebar background, table headers, elevated banner container |
| Accent (10%) | `#1677ff` (Ant Design primary brand) | Explicitly reserved for primary CTA buttons, active state indicators, and update badges |
| Destructive | `#ff4d4f` | Unsaved form overwrite confirmation button, danger alert badges |

Accent reserved for:
1. Primary CTA button `Cập nhật ngay` in `UpdateBanner`
2. Primary install button `Cài đặt ứng dụng` in `PwaStatusCard` and `InstallButton`
3. Manual update trigger `Kiểm tra bản cập nhật` link in `PwaStatusCard`
4. Update notification dot indicator (`Badge dot`) on Header trigger
5. Storage persistence request CTA button `Yêu cầu lưu trữ bền vững`

Status Colors:
- **Success (`#52c41a`)**: "Trực tuyến" status badge, "Hoạt động" Service Worker tag, "Bền vững" storage tag, update successful notification.
- **Warning (`#faad14`)**: "Ngoại tuyến" status badge, "Tạm thời" storage mode tag, uncommitted form alert banner, storage quota > 80% progress bar.
- **Info (`#1677ff`)**: iOS installation step badges, Service Worker update checking state.

## Component Inventory & Visual Specifications

### 1. `UpdateBanner.tsx`
- **Location**: Mounted in `AppShell` root layout, conditionally rendered when `needRefresh` is true and banner is not collapsed.
- **Positioning**:
  - Desktop (`width >= 768px`): Floating fixed box at `bottom: 24px`, `right: 24px`, `maxWidth: 420px`.
  - Mobile (`width < 768px`): Docked fixed bar at `bottom: 0`, `left: 0`, `right: 0`, full width, `boxShadow: 0 -2px 8px rgba(0,0,0,0.15)`.
- **Card Content**:
  - Icon: `CloudSyncOutlined` in primary color (`#1677ff`).
  - Title: "Đã có bản cập nhật mới" (16px, semibold).
  - Body: "Phiên bản mới đã sẵn sàng. Tải lại để áp dụng cải tiến mới nhất." (14px, regular).
  - Actions:
    - Button `Cập nhật ngay` (type `primary`, onClick checks form guard).
    - Button `Để sau` (type `default`, onDismiss collapses banner into header badge).
- **Accessibility**: Role `alert` with `aria-live="polite"`.

### 2. `ActiveFormGuardModal.tsx`
- **Trigger**: User clicks `Cập nhật ngay` while an active modal or drawer (`TaskDrawer`, `AllocationModal`, `FeasibilityModal`, `SettingsView` form dirty) is open.
- **Type**: Confirmation modal (`width: 480px`).
- **Content**:
  - Title: "Cảnh báo: Dữ liệu chưa lưu" with `ExclamationCircleOutlined` in orange (`#faad14`).
  - Body: "Bạn đang mở một biểu mẫu chỉnh sửa. Nếu tải lại trang để cập nhật ngay bây giờ, các thay đổi chưa lưu sẽ bị mất."
  - Action buttons:
    - Cancel button: "Quay lại lưu dữ liệu" (default, focused by default).
    - Confirm button: "Bỏ qua và Tải lại" (danger button).

### 3. `InstallButton.tsx` (Header & Settings)
- **Header Appearance**:
  - Compact button next to `StatusBadge` in Header.
  - Icon: `DownloadOutlined`, label: "Cài đặt".
  - Behavior:
    - If `beforeinstallprompt` event caught: invokes native install prompt.
    - If iOS Safari detected: opens `IosInstallModal`.
    - If running standalone or already installed: component returns `null` (hidden).
- **Settings Appearance**:
  - Button inside `PwaStatusCard` titled "Cài đặt ứng dụng vào màn hình chính".

### 4. `IosInstallModal.tsx`
- **Appearance**: Modal dialog, `width: 440px`, centered.
- **Content**:
  - Header: "Cài đặt trên iOS Safari".
  - Step 1: "Nhấn vào nút Chia sẻ (biểu tượng hộp có mũi tên hướng lên) ở thanh điều hướng dưới cùng của Safari."
  - Step 2: "Cuộn danh sách xuống và chọn 'Thêm vào MH chính' (Add to Home Screen)."
  - Step 3: "Nhấn 'Thêm' (Add) ở góc trên bên phải để hoàn tất."
  - Action button: "Đã hiểu" (primary button, full width on mobile).

### 5. `PwaStatusCard.tsx` (Settings Tab 2)
- **Appearance**: Ant Design `Card` in SettingsView Tab "Sao lưu & Dữ liệu".
- **Items**:
  - Descriptions list (3 columns desktop, 1 column mobile):
    - Trạng thái Service Worker: `Tag color="success"` ("Hoạt động") / `Tag` ("Chưa hỗ trợ").
    - Khả năng ngoại tuyến: `Tag color="success"` ("Sẵn sàng").
    - Tình trạng cài đặt: `Tag color="processing"` ("Đã cài đặt") / "Chưa cài đặt".
  - Action row:
    - Button "Kiểm tra bản cập nhật" (`icon={<SyncOutlined />}`).
    - Button "Cài đặt ứng dụng" (hidden if installed).
    - Status message describing current service worker build version or timestamp.

### 6. `StoragePersistenceCard.tsx` (Settings Tab 2)
- **Appearance**: Ant Design `Card` grouped in SettingsView Tab "Sao lưu & Dữ liệu".
- **Content**:
  - Mode row: "Chế độ lưu trữ: " + `Tag color="success"` ("Bền vững - Không bị xóa") OR `Tag color="warning"` ("Tạm thời - Có thể bị giải phóng khi thiếu dung lượng").
  - Quota row: "Dung lượng ước tính: " + Text ("2.4 MB / 15.0 GB khả dụng") + `Progress percent={...} strokeColor="#1677ff"`.
  - Advisory Alert (if temporary): `Alert type="warning" showIcon message="Khuyến nghị an toàn" description="Trình duyệt chưa cấp quyền lưu trữ bền vững. Hãy thường xuyên xuất tệp sao lưu JSON để phòng ngừa việc trình duyệt tự động dọn dẹp bộ nhớ."`.
  - Action button (if temporary): "Yêu cầu lưu trữ bền vững" (`persist()`).

## Interaction & State Matrix

| Trigger | System State | Visual Feedback | Screen Reader Feedback |
|---------|--------------|-----------------|------------------------|
| Network drops | Online -> Offline | `message.warning('Đang làm việc ngoại tuyến...')`, `StatusBadge` turns orange | "Đang làm việc ngoại tuyến. Tất cả dữ liệu được lưu an toàn trong máy." |
| Network recovers | Offline -> Online | `message.success('Đã kết nối lại mạng')`, `StatusBadge` turns green | "Đã kết nối lại mạng. Ứng dụng đang hoạt động trực tuyến." |
| SW detects new build | Idle | `UpdateBanner` floats into view at bottom right | "Đã có bản cập nhật mới. Nhấn Cập nhật ngay để làm mới ứng dụng." |
| User clicks "Để sau" | Banner open | Banner animates out; Header displays `UpdateHeaderButton` with dot badge | none (silent dismiss) |
| User clicks "Cập nhật ngay" | No active form open | Banner shows loading spinner on button, invokes `updateSW(true)` | "Đang làm mới ứng dụng để áp dụng bản cập nhật..." |
| User clicks "Cập nhật ngay" | Form/drawer open & dirty | `ActiveFormGuardModal` opens warning about data loss | "Cảnh báo: Đang có biểu mẫu chưa lưu." |
| User confirms reload in guard modal | Guard modal open | Reload triggers via `updateSW(true)` | none (page reloads) |
| App installed | Installation completes | Header install button disappears; `message.success('Ứng dụng đã được cài đặt thành công!')` | "Ứng dụng đã được cài đặt thành công vào thiết bị!" |
| Click "Kiểm tra cập nhật" | Network connected | Button spinner active, message: "Đang kiểm tra...", then "Ứng dụng đang ở phiên bản mới nhất" | "Ứng dụng đang ở phiên bản mới nhất." |
