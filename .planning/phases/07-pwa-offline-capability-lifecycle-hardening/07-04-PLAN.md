<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client UI ↔ Service Worker Lifecycle | Untrusted/asynchronous service worker update events trigger destructive application reloads across UI boundaries |
| Client User Input ↔ Browser Prompt Dialog | Native OS/browser BeforeInstallPromptEvent lifecycle transitions can reject or consume events unpredictably |
| Client Draft State ↔ Reload Dispatch | In-flight, uncommitted form inputs in modals and drawers cross reload lifecycle boundaries |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-05 | Denial of Service | src/hooks/usePWAInstall.ts | mitigate | Wrap prompt() in try/catch and clear installPrompt reference in finally block so second click cannot crash with DOMException: InvalidStateError |
| T-07-06 | Information Disclosure / Data Loss | src/context/FormGuardContext.tsx & UpdateBanner.tsx | mitigate | Connect useRegisterActiveForm to TaskDrawer, ProjectModal, MilestoneModal, AllocationModal, CapacitySettingsModal, and FeasibilityModal so hasActiveForm guards uncommitted user inputs |
| T-07-07 | Denial of Service / Resource Exhaustion | src/context/ServiceWorkerContext.tsx | mitigate | Lift useRegisterSW into singleton ServiceWorkerProvider to eliminate duplicate SW event listeners and un-cleared interval timers |
| T-07-SC | Tampering | npm/pip/cargo installs | mitigate | No new npm packages installed; reuse existing vite-plugin-pwa and virtual:pwa-register/react |
</threat_model>
