<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Service Worker → Main Thread | Incoming messages and update triggers must not corrupt active IndexedDB transactions. |
| UI Reload Action → Uncommitted State | Reload events must not cause user data loss while editing forms. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | Denial of Service | Service Worker Cache | mitigate | Enable `cleanupOutdatedCaches: true` in Workbox and `registerType: 'prompt'` to prevent stale cache lockouts per D-10. |
| T-07-03 | Tampering | Update reload trigger | mitigate | Intercept reload in `UpdateBanner` using `useFormGuard().hasActiveForm` and display `ActiveFormGuardModal` before executing `updateSW(true)` per D-02. |
</threat_model>
