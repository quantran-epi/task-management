# Phase 25.1.2 Plan 02: Dedicated Project SDLC View and Step 1/Step 2 User Flow Summary

- Built dedicated `ProjectSdlcView` with 2-column IDE layout: Left sidebar (`SdlcSidebar`) with CR selector, New CR button, progress indicator, and 6 vertical steps; Right workspace (`SdlcWorkspace`) with step view and isolated AI chat (`StepChatPanel`).
- Wired `ProjectsView` to mount `ProjectSdlcView` on `onOpenSdlcStudio` callback and return via back button.
- Implemented `Step1IntakeView` with metadata form, PL01/PL02 input text areas, and Note picker modal.
- Implemented `Step2SolutionView` with two-way Document Editor (Write, Preview, Split modes), resilient manual editing, and one-click "Duyệt & Lưu SOLUTION.md" saving directly to Note v1/v2.

## Key Changes

1. **Dedicated View & IDE Layout (`ProjectSdlcView.tsx`, `SdlcSidebar.tsx`, `SdlcWorkspace.tsx`)**:
   - Two-column full workspace replacing overcrowded drawer modals.
   - Stepper provides 6 distinct steps with clear labels, icons, and status indicators.
   - SdlcSidebar supports switching between steps freely without disrupting running state.

2. **StepChatPanel (`StepChatPanel.tsx`)**:
   - Each step automatically resolves and binds to its dedicated `ChatThread` (`sdlc:${projectId}:${crId}:${stepId}`).
   - Grounded context injected specifically for the active step.

3. **Step 1 Intake & Step 2 Solution Views (`Step1IntakeView.tsx`, `Step2SolutionView.tsx`)**:
   - `Step1IntakeView`: Allows typing raw text or selecting existing Notes for PL01 & PL02.
   - `Step2SolutionView`: Segmented control for Write/Preview/Split. Preview sanitized via `renderSafeMarkdown`. Approval commits versioned Note via `saveHubSolution`.

4. **ProjectsView Navigation (`ProjectsView.tsx`, `ProjectTable.tsx`)**:
   - Added `⚙️ SDLC Studio` action button in `ProjectTable`.
   - `ProjectsView` conditionally renders `ProjectSdlcView` when `activeSdlcProjectId` is set.
