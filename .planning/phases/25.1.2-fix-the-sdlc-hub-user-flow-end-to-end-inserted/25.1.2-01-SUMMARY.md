2. **Decoupled AIChatDrawer (`src/components/ai/AIChatDrawer.tsx`)**:
   - Removed `<SdlcWorkflowHub`, `StepInputDocsModal`, and all step panels.
   - Removed SDLC workflow state variables, coordinator hooks, and handler functions.
   - Purged over 1,000 lines of coupled SDLC code while maintaining full multi-tab general chat capabilities.

3. **Clean Tab Repository (`src/db/repositories/chatTabRepo.ts`)**:
   - `getOrCreateSdlcTab` now defaults `active: false`.
   - Project scope initialization creates standard chat tabs for drawer conversations without forced SDLC tab creation.
