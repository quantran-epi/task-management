# Phase 51 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Scope:** second Tauri bundle "TaskMate Chat" — chat full-bleed, one gear in titlebar, right-side settings drawer with 7-group side nav + accordion. No task UI, no workbench, no TaskMate context grounding.

**Source priority:** 51-CONTEXT.md D-01..D-15 (locked) > sketch 007 winner A + sketch 008 winner C > `src/styles/tokens.ts` (locked by 49-UI-SPEC) > defaults chosen here under `--auto` ("khỏi discuss, cứ tốt nhất mà làm"). Deferred ideas ignored.

## Design System

| Property | Value |
|----------|-------|
| Tool | none — shadcn not initialized |
| Preset | not applicable |
| Component library | Ant Design 6.6.5 **through TaskMate wrappers in `src/components/ui/`** (56 wrappers). Direct `antd` / `@ant-design/icons` imports outside that folder are forbidden (GUARD-01). |

Initializing shadcn would break GUARD-01 and add a second system. Registry safety gate: not applicable. No third-party registries, no third-party blocks.

## Spacing Scale

Inherited from `src/styles/tokens.ts` (`sharedTokens.spacing`); do not invent new values. Declared values (all multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing |
| md | 16px | Default element spacing, drawer header/body padding |
| lg | 24px | Section padding, message list horizontal padding |
| xl | 32px | Layout gaps |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Exceptions (already locked in `tokens.ts` / `workbench-tokens.css`, not new):
- `--island-gap: 6px` — island separation.
- `--gap-1..14` = 1, 2, 3, 5, 6, 7, 10, 12, 14px — legacy control gaps, mapped 1:1, allowed only where a wrapped legacy card already uses them.
- Fixed structural metrics: titlebar 40px, tab bar 36px, row 24px, control 28px (`ui-tokens.css` overrides 30px token to 28px for wrapped inputs/selects/buttons), tree indent 12px.
- Drawer width 460px; side nav 190px. Gear hit target 28×28 wrapped IconButton (do not shrink below 28px; desktop, not touch-only).

## Typography

Sizes declared: **3** (11, 12, 13px — the locked `--font-size-xs/small/ui`). Weights declared: **2** (400 regular, 600 semibold). No new size steps; the chat-only shell has no display role.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 13px | 400 | 1.5 (chat message bubbles 1.55 per sketch 007 A) |
| Label | 12px | 400 | 1.5 |
| Heading | 13px | 600 | 1.2 |
| Display | — | — | No display role in this shell; chat title and drawer title use Heading 13px/600. |

Fonts: UI `--font-ui` Inter; URLs, paths, token counts, model ids use `--font-mono` 12px. Never hardcode `font-size` in a new view — use the role tokens / wrapper defaults.

## Color

Values from `src/styles/tokens.ts`. Both modes must ship; no new hex introduced. 60/30/10 refers to visual area, not to number of tokens.

| Role | Value (light / dark) | Usage |
|------|-------|-------|
| Dominant (60%) | `--bg-app` `#ffffff` / `#171d27` | Chat canvas, message list background, window body |
| Secondary (30%) | `--bg-island` `#ffffff` / `#1c2330`, `--bg-elev` `#f7f8fa` / `#171d27`, `--surface-sunken` `#e8ecf3` / `#111720` | Titlebar, chat header, composer strip, settings drawer surface, side nav, accordion headers, AI/assistant bubbles |
| Accent (10%) | `--accent` `#2f62d8` / `#6a9bff` | Primary "Gửi" button, gear hover/focus, active side-nav item (text + 3px left border), active tab pill, accordion/focus rings, selected scope chip border |
| Destructive | `--danger` `#d1484f` / `#ff8289` | Destructive actions only (delete MCP server / Oracle profile / SSH config / clear conversation) |

Accent reserved for: primary send action; gear hover/active/focus; active side-nav item; active chat tab; focus-visible outline; selected/active accordion header. Never use accent for static text, borders of inactive controls, or decorative fills.

Inherited semantic tokens (not accent): `--success` `#338555` / `#4ade80` for connection pills and successful tool lines; `--warning` `#a56906` / `#e8a13a`; `--info` `#22d3ee` with accessible foreground `--info-fg` `#0e7490` / `#22d3ee`. Use only through `StatusTag`/wrapped status components. Destructive text on light surfaces must use `--danger`, never accent.

Status copy must be truthful: show "Knowledge · MCP sẵn sàng" only when both are actually reachable; otherwise render the specific degraded state (e.g. "Knowledge Server chưa kết nối — mở Cài đặt AI") with `aria-live="polite"`.

## Copywriting Contract

Vietnamese for all user-facing copy (project convention). Code identifiers, setting field labels from the real cards, and the 7 group names stay in their source form.

| Element | Copy |
|---------|------|
| Primary CTA | **Gửi** (composer send, wrapped primary Button). Enter sends; Shift+Enter inserts newline. Disabled while a turn is busy. |
| Empty state heading | **Chưa có hội thoại** |
| Empty state body | **Nhập tin nhắn bên dưới để bắt đầu. Enter để gửi, Shift+Enter để xuống dòng.** |
| Error state | **Không gửi được tin nhắn.** → **Kiểm tra API Endpoint / API Key trong Cài đặt AI rồi thử lại.** Reuse existing `InlineApiErrorCard` action label verbatim: **Mở Cài đặt AI**. Retry action: **Thử lại**. |
| Destructive confirmation | **Xóa cuộc hội thoại**: "Xóa cuộc hội thoại này? Hành động này không thể hoàn tác." Buttons: **Xóa** / **Hủy**. Card-level deletes (MCP server, Oracle profile, SSH config) reuse each existing card's confirmation copy — do not author a second confirmation string. |

Fixed shell copy:
- Window/titlebar: **TaskMate Chat**; titlebar gear accessible name **Mở Cài đặt AI**, native tooltip **AI settings**.
- Chat header title: **AI Chat**. Scope chip: **Global · không có ngữ cảnh TaskMate** (D-08; not clickable, no scope picker).
- Drawer header: **AI Settings · tất cả**; close button accessible name **Đóng Cài đặt AI**.
- Side nav, exactly 7 labels in this order (D-09): **Provider**, **Knowledge Server**, **MCP**, **Graphiti**, **Oracle SQLcl**, **SSH File System**, **Tool Catalog**.
- Provider field labels from `NineRouterConfigCard`: **API Endpoint**, **API Key**, **Default Model**, **Context window**, **Global conventions**. Stored key renders masked (`••••••••`), never in clear text, never in `VITE_*`.
- Other real field labels retained: **URL Graphiti Memory**, **URL SVNG Source**, **Base Path**. Do not translate or rename locked field labels.
- First-run (no key): inline composer prompt **Chưa có API Key. Mở Cài đặt AI → Provider để nhập key.** with a **Mở Cài đặt AI** button.

## Interaction Contract

Layout (sketch 007 A, locked D-05..D-08):
1. Window 1280×800, min 900×600, resizable; url `index.html#ai-popout`; chat-only from first paint — no workbench flash, no route to task views on reload/deep link.
2. Titlebar 40px: app name left; truthful connection status; **one** gear IconButton right. No left rail, no top menu, no workbench, no tool buttons on main surface.
3. Chat header: title, tab pills (existing tab bar), scope chip. **No** close / pin / popout / "return to main app" controls; no parent-window scope or draft listeners; no popout geometry restore or always-on-top.
4. Message list flex:1, scrollable, padding 24px; bubbles max-width 74%; tool status lines use `--success`. Composer pinned bottom, textarea min-height 52px, send button right.
5. Drawer (sketch 008 C, D-06/D-09/D-10/D-11): wraps right, width 460px (`min(460px, 100% - 64px)` at narrow widths), overlay — chat stays mounted and preserves tab/draft/scroll state. Header + close; body splits into 190px side nav and scrollable right pane. Clicking a nav item shows only that group; each group renders its own accordion with the group open by default. Exactly 7 groups, no eighth.
6. Cards are mounted from existing components, not reimplemented: `NineRouterConfigCard`, `KnowledgeServerConfigCard` (needs `KnowledgeConfigProvider`), `McpConfigCard`, `GraphitiSqlConfigCard`, `OracleAiToolConfigCard` (OracleProfileManager is already a card — no separate modal needed), `SshFsAiToolConfigCard`, `AiToolCatalogCard`. All writes go to the same Dexie `settings` store and OS keyring `service: 'task-planner'`, key `ninerouter_api_key` (D-12).
7. Context suppression (D-08): force `activeScope = { type: 'global' }` ignoring persisted scope/remote targets. At turn assembly, do **not** call `buildGlobalContextPrompt(db)`, do **not** emit `<global_context>`, do **not** inject global conventions, and do **not** ground task/CR/system/document mentions or expose task actions (`handleAddToChecklist`, `handleSaveStickyNote`, `handleRunClaudeCode`). Knowledge, MCP, Graphiti, Oracle SQLcl and SSH FS grounding stay fully enabled.
8. Resolved discretion point: **Global conventions** field is visible and editable in Provider (D-10 literal) but is **not injected into standalone prompts** — D-08 "no TaskMate context" governs turn assembly. Treat the stored value as shared config only.
9. Keyboard / a11y: gear and every icon-only control has an accessible name (CTRL-02); side nav items are buttons with `aria-current="true"` on the active item; accordion headers expose `aria-expanded`; Esc and backdrop close the drawer and restore focus to the gear; Tab order = gear → tabs → composer → drawer when open; focus-visible ring uses accent; send disabled + busy state during a turn; connection status `aria-live="polite"`.
10. Use only wrapped components (`Button`, `IconButton`, `Drawer`, `Collapse`, `Tabs`/wrapped menu, `Input`, `Select`, `InputNumber`, `Tooltip`, `Tag`/`StatusTag`). No inline token-valued styles in new views (ADOPT-01/02); no direct AntD import.
