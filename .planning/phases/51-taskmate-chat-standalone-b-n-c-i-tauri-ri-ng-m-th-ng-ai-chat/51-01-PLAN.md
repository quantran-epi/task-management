<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Tauri config → bundle identity | Untrusted/incorrect config merge can overwrite TaskMate's app identity or drop window fields. |
| Build marker → runtime behavior | `VITE_CHAT_STANDALONE` is build-time input compiled into the bundle; it must never carry secrets or a value that leaks into TaskMate's normal build. |
| npm scripts → CLI arguments | Script arguments are attacker-adjacent only through repository edits; guard against accidental cross-config builds. |
