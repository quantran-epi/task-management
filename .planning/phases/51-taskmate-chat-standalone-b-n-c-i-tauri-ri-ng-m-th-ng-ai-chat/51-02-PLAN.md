<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Parent window → standalone chat events | `AI_SCOPE_EVENT`/`AI_DRAFT_EVENT` and postMessage are untrusted parent input; standalone has no parent (D-07). |
| Persisted scope / layout store → chat scope | localStorage and layout store are client-controlled; must not override forced global scope (D-08, pitfall 5). |
| Window geometry storage → main window | Popout geometry clamp (360-560×480-800) is wrong for a 1280×800 main window and must not run. |
| Drawer → chat state | Drawer is UI composition only; must not remount chat or re-read/replace chat state. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-51-05 | Tampering | Parent scope/draft listeners | mitigate | In standalone, skip entire listener effect and postMessage registration; test asserts zero registrations. |
| T-51-06 | Tampering | Hash scope params / customScope | mitigate | Force `{ type: 'global' }` in standalone; skip remote-target registration; test asserts global with malicious hash params. |
| T-51-07 | Tampering (geometry) | `planner:ai_popout_geometry` read/write | mitigate | Early-return effect in standalone; no setSize/setPosition/setAlwaysOnTop, no localStorage access to that key. |
| T-51-08 | Information disclosure | TaskMate affordances leaking into chat-only app | mitigate | Gate pin/close/popout/scope-picker on absent `onOpenSettings`/standalone flag; legacy path untouched. |
| T-51-SC | Tampering | npm/cargo installs | mitigate | No installs; no new dependency (D-15). |
