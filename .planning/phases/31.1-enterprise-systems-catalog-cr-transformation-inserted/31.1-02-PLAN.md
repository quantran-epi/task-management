<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User Form Input → System Model | Validating remote repository paths and system codes to prevent invalid shell arguments |
| System Deletion → Dependent Subsystems & CRs | Preventing broken foreign keys when a parent system or subsystem is deleted |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-31.1-04 | Tampering | SystemModal remoteRepoPath input | mitigate | Validate absolute path format with regex; sanitize when invoking SSH git operations |
| T-31.1-05 | Denial of Service | Deleting parent system with active subsystems | mitigate | Block deletion if child subsystems exist; require reparenting or cascade confirmation |
| T-31.1-06 | Information Disclosure | SshConfig display in table | mitigate | Only display sanitized username@host and alias; never display credentials or keys |
</threat_model>
