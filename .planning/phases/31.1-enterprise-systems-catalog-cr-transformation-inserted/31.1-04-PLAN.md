<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Multi-Repo SSH File Reading | Probing multiple remote servers over SSH must not leak secrets or block on hanging connections |
| Prompt Composer Multi-Convention Injection | Untrusted Markdown from multiple repositories must remain strictly framed inside untrusted delimiters |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-31.1-09 | Denial of Service | loadMultiRepoConventions SSH timeout | mitigate | Apply per-system 5s timeout on SSH probe commands; one failing system must not fail the entire turn |
| T-31.1-10 | Elevation of Privilege | Malicious CONVENTIONS.md prompt injection | mitigate | Enforce SHARED_EVIDENCE_POLICY and CONVENTIONS_CONFLICT_POLICY; wrap all convention content inside untrusted data tags |
</threat_model>
