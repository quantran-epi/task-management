# Phase 31.1 Plan 03: Change Request (CR) Management UI Summary

**One-liner:** Overhauled project-facing UI to Change Request (CR) management with 3 explicit colored type tags (`New Feature`, `Enhancement`, `Bugfix`), multi-subsystem targeting via TreeSelect, filterable table view, and ProjectExplorer tree integration.

## Key Changes

1. **Target Systems Selector & CR Modal (`Task 1`)**:
   - `src/components/changeRequests/TargetSystemsSelector.tsx`: Reusable Ant Design `TreeSelect` grouping deployable subsystems under logical parent systems with badges, monospace system codes, and orphaned subsystem fallback.
   - `src/components/changeRequests/ChangeRequestModal.tsx`: Modal supporting full CRUD for Change Requests. Enforces CR title and at least 1 target subsystem, upper-cased CR codes, and radio selection for 3 explicit CR types:
     - New Feature (`#1677ff`, "Tạo mới tính năng")
     - Enhancement (`#52c41a`, "Nâng cấp / Cập nhật")
     - Bugfix (`#faad14`, "Sửa lỗi")
     - Binds Jira Epic creation and link attachments.

2. **Change Request Table, Management View, and ProjectExplorer (`Task 2`)**:
   - `src/components/changeRequests/ChangeRequestTable.tsx`: Ant Design table with CR code badges, type tags, target subsystem chips (`#13c2c2` cyan), task completion progress bars, and action menus (Edit, SDLC Studio, Delete).
   - `src/views/ChangeRequestsView.tsx`: Full-page view with PageHeader, toolbar filters (search by name/code, filter by CR type, filter by target subsystem), empty state per UI-SPEC, and destructive cascade confirmation modal.
   - `src/views/ProjectsView.tsx`: Re-exports `ChangeRequestsView` for smooth backward-compatibility.
   - `src/workbench/toolwindows/ProjectExplorer.tsx`: Tree explorer displaying CR items with colored type icons (`#1677ff`, `#52c41a`, `#faad14`), CR codes, target subsystem chips, and intact child milestones and tasks.
