# Phase 31.1 Plan 04: Multi-System SDLC Studio and AI Assistant Integration Summary

**One-liner:** Multi-system convention aggregation across CR target subsystems with prompt layering, SDLC Studio subsystem switcher, and active CR pills integration.

## Key Changes

1. **Multi-System Convention Service & Prompt Composer (`Task 1`)**:
   - `src/services/conventionService.ts`:
     - Added `loadRepoConventionsForSystem(systemId, db)`: Probes remote server over SSH using system's own `sshConfigId` and `remoteRepoPath` to discover `CONVENTIONS.md`.
     - Added `loadMultiRepoConventions(systemIds, db)`: Resiliently aggregates repository conventions across multiple system IDs using `Promise.allSettled`.
     - Extended `loadRepoConventions(projectIdOrCrId, db)`: Resolves target subsystems when given a Change Request ID and delegates to multi-system probe.
   - `src/services/ai/sdlcPromptComposer.ts`:
     - Extended `buildConventionsSegment` with `repos` array parameter.
     - Layers each target repository's conventions under distinct delimited headers `[REPOSITORY CONVENTIONS - {systemCode} ({repoPath})]`.
     - Preserves `CONVENTIONS_CONFLICT_POLICY` and untrusted framing.
   - `tests/services/multiSystemConventionService.test.ts`:
     - 9 unit tests verifying probe behavior, multi-repo aggregation, graceful failure fallback, and prompt formatting.

2. **SDLC Studio and AIChatDrawer Wiring (`Task 2`)**:
   - `src/components/sdlc/SdlcSidebar.tsx`:
     - Displays active Change Request type badge (`New Feature` blue, `Enhancement` green, `Bugfix` orange) and target subsystems pills in cyan (`#13c2c2`) with monospace codes.
     - Displays fallback warning tag "Chưa gán subsystem" if none assigned.
   - `src/components/sdlc/steps/Step3CodeGuideView.tsx`:
     - Added Subsystem Switcher (`Segmented`) when CR targets multiple subsystems.
     - Dynamically rebinds active SSH profile, remote repo path, and base branch when user toggles between subsystems.
   - `src/views/ProjectSdlcView.tsx`:
     - Resolves `crTargetSystems` from DB for active CR and passes them to Step 3.
   - `src/components/ai/AIChatDrawer.tsx`:
     - Imported `loadMultiRepoConventions` for multi-system resolution.
   - `tests/views/ProjectSdlcViewMultiSystem.test.tsx`:
     - Integration tests verifying SdlcSidebar pills, Step 3 subsystem switcher, and multi-system prompt composition.
