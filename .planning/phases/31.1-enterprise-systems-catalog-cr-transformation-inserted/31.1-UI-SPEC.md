## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, tag inline padding, badge spacing |
| sm | 8px | Compact element spacing, form item gaps, button inline padding |
| md | 16px | Default card body padding, modal padding, column gaps |
| lg | 24px | Section padding, modal content margins, drawer header padding |
| xl | 32px | Layout panel gaps, page section breaks |
| 2xl | 48px | Empty state vertical padding, major container margins |
| 3xl | 64px | Page-level spacing and full-height view wrappers |

Exceptions:
- 6px: Workbench island gap (`--island-gap`) and tab border radius
- 26px: Workbench StatusBar fixed height (`--statusbar-height`)
- 30px: Ant Design compact control height (`controlHeight: 30`) for Button, Input, Select
- 36px: Tool Window Stripe width (`--stripe-width`) and Editor tab bar height (`--tabbar-height`)
- 40px: Workbench TitleBar fixed height (`--titlebar-height`)

|------|-------|-------|
| Dominant (60%) | #ffffff | Primary canvas, card backgrounds, modal content, island surfaces |
| Secondary (30%) | #e9eaee | Borders, tool window dividers, neutral badges, secondary sidebars |
| Accent (10%) | #3871e1 | Primary CTA buttons, selected tree node highlight, focus rings |

Accent reserved for:
1. Primary CTA buttons ("Tạo hệ thống", "Lưu cấu hình", "Tạo Change Request", "Lưu thay đổi")
2. Selected tree node background and active tab indicator (`--bg-selected: #d0dffe`, text `#3871e1`)
3. Active link / navigation text in Left Explorer and Breadcrumbs
4. Focus rings and borders on active text inputs and dropdown selects

Semantic Status & Type Colors:
- CR Type "New Feature" (Tạo mới tính năng): Tag color `#1677ff` / `processing`

## Component Inventory & Interactions

### 1. Enterprise System Catalog (`SystemCatalogView.tsx` / `SystemsExplorer.tsx`)
- **Structure**: Hierarchical Tree Table / Tree View (`Parent System` -> `Child Subsystems`).
- **Parent System node**: Logical/Virtual group (e.g. "SmartCard System", "SVNG System"), displays name, description, subsystem count. No direct SSH configuration.
- **Child Subsystem node**: Deployable unit (e.g. "accounting-service", "cardappdb", "svng-gui"), displays deployable type tag (Service, DB Schema, Frontend UI, Worker), bound SSH Host (`username@host:port`), remote repository path (`/data/...`), and git branch (`origin/main`).
- **Actions**:
  - `Tạo hệ thống` (Top header action): Modal opens with form (Name, Description, Parent System selector [optional]).
  - `Thêm subsystem` (Context menu / Row action): Pre-selects parent system, prompts for Subsystem Name, Type, SSH Profile, Remote Repo Path, Default Branch.
  - `Sửa`: Edit metadata, reassign parent system, update SSH profile or path.
  - `Xóa`: Triggers cascade confirmation check (warns if CRs currently target this subsystem).

### 2. CR (Change Request) Management (`ChangeRequestTable.tsx` / `ProjectExplorer.tsx`)
- **Terminology**: "Dự án / Project" terminology completely transformed to "Change Request (CR)".
- **CR Badges**:
  - `New Feature`: Tag `#1677ff` ("Tạo mới")
  - `Enhancement`: Tag `#52c41a` ("Nâng cấp")
  - `Bugfix`: Tag `#faad14` ("Sửa lỗi")
- **Target Systems Multi-Select**: Form field `targetSystemIds` using Ant Design `TreeSelect` or grouped `Select` allowing selection of 1 or more Child Subsystems across Parent Systems.
- **Hierarchy in Explorer**: CR Name -> Target Subsystems Pills -> Milestones -> Tasks/Checklists.

### 3. SDLC Studio Multi-System Resolution
- **Context Banner**: Top of SDLC Studio displays selected CR code, CR type badge, and active Target Systems tag list.
- **SSH & Repo Config Integration**: When switching CR, SDLC Studio Step 3 and AI Chat Drawer automatically read SSH connection and repo path from the first targeted subsystem (with subsystem switcher dropdown if CR impacts multiple subsystems).
- **Conventions Integration**: Auto-loads `CONVENTIONS.md` from each targeted subsystem's repository path via SSH.
