<objective>
Turn remote text selection into an inline AI action and make `path:line` citations navigate back into the remote file, closing the loop from browsing to asking to verifying an answer in code.

Purpose: D-09/D-10/D-11/D-12 are the user-facing payoff — highlight any code in a readonly remote file, get a short Explain/Ask answer in place or carry the selection into the existing remote chat, then click a cited `path:line` to land on that line. The anchor contract from plan 01 and the explicit-target tools/grounding from plan 03 make this glue work; the popover positioning, inline tool loop and tab-open param helpers all already exist.

Output: remote-aware `InlineAISelectionBar` (toolbar + popover + Open in Chat with structured anchor), per-line anchor attributes on `RemoteFileViewer` plus auto scope activation, and a remote-citation activation path in `AIChatDrawer`; focused tests.

**Artifacts this phase produces (from plan 04):** remote inline toolbar (Explain/Ask/Open in Chat), popover answer beside selection, structured-anchor mention to remote composer, remote `path:line` citation chip navigation, auto remote-scope activation on file open/selection.

<user_decisions>
- **D-08:** Opening/selecting a remote file auto-activates that target's remote scope; manual switch still possible.
- **D-09:** Remote files stay readonly; selection shows an inline toolbar with Explain, Ask, Open in Chat.
- **D-10:** Explain/Ask answer briefly in a popover; Open in Chat puts the mention into the remote composer.
- **D-11:** Selection mention is a structured anchor (target identity, path, start/end line, text).
- **D-12:** Answers may cite `path:line`; clicking opens the remote file and highlights that line.
</user_decisions>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| remote text selection → inline prompt | Selected remote code is untrusted content that crosses into an AI prompt as a structured anchor |
| chat answer citation → tab navigation | A model-produced `path:line` citation crosses into a navigation action that opens a remote file |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-47-09 | Information disclosure | Remote selection anchor in inline prompt | high | mitigate | Anchor uses the active target identity (targetUuid + config/repo/branch) from the viewer metadata; no fake doc entity, no cross-target path; D-11 shape pins path/line to the selected file |
| T-47-10 | Tampering | Remote citation click target | high | mitigate | Citation chip uses the active remote scope's target, never a model-supplied host/path; path flows through `remote:<path>` tab id + confined viewer; read-only open only |
| T-47-11 | Denial of Service | Inline Explain/Ask loop | low | mitigate | Reuse `READ_ONLY_AI_TOOLS` with `MAX_LOOPS = 3` and `calculatePopupPosition` bounds; no new unbounded tool loop |

</threat_model>
