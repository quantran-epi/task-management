<objective>
Give the SSH Remote Explorer a name search and a ripgrep-style content search that are scoped to the currently open target, with bounded `path:line:text` results that open the matching remote file at the right line in the existing readonly tab.

Purpose: D-02/D-03/D-04 are the user's first visible capability — find anything in the repo they are already browsing, then jump straight to the hit without losing the readonly viewer. Reusing `getRemoteTree` and `grepRemoteRef` keeps the work confined to presentation plus one tab-param contract; no new filesystem walker, no whole-file fetch into the renderer (Pitfall: unbounded context), and no new write surface (D-14).

Output: search controls and result list in `RemoteGitExplorer.tsx`, one-shot `initialLine` param handling in `layoutStore.ts`, an `initialLine` highlight/scroll prop in `RemoteFileViewer.tsx`, and extended focused component tests.

**Artifacts this phase produces (from plan 02):** explorer name/content search modes, `initialLine` tab param with one-shot clear, `path:line:text` result rows, click-to-open-at-line.

<user_decisions>
- **D-02:** Search defaults to the active SSH config + repoPath + branch; reuse the explorer's existing target state, no new target picker.
- **D-03:** Two modes — file/folder name and ripgrep-style content; both return relative paths and open the remote file tab.
- **D-04:** Content results show `path:line:text`, bound hit count, open at that line.
- **D-14:** Read-only, confined, escaped, bounded; no writes.
</user_decisions>

|----------|-------------|
| explorer → remote git (SSH) | User-authored search pattern and repo-relative path cross into a remote shell command; untrusted file hits cross back into the renderer |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-47-04 | Tampering | Content search pattern/path into `grepRemoteRef` | high | mitigate | Pass pattern as data to the existing service only (`-e`, `--end-of-options`, `escapeShellArg`); no new command string, no client-side shell quoting; hit cap 200 keeps output bounded (D-04/D-14) |
| T-47-05 | Denial of Service | Rendered search result list | low | mitigate | Cap both content hits (200 in service) and rendered name results so a large tree cannot flood the DOM |
