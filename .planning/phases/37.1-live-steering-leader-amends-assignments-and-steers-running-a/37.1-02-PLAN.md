<objective>
Change the loop's round-boundary hook from a fire-and-forget `Promise<void>` that skips round 1 into a return-value hook that fires on EVERY round and appends whatever it returns (D-09/D-10). This is the delivery channel a steer message travels through: without it an agent that answers without calling a tool never sees a mid-run instruction.

Purpose: SC3 — a steering message reaches a running agent at its next tool round.
Output: the loop contract, the runtime forwarding, and the two inverted/extended test suites.
</objective>
