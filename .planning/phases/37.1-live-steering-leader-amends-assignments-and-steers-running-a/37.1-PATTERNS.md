## Shared Patterns

### Abort-aware park (every wait in this phase)
**Source:** `src/services/ai/office/budgetGate.ts:44-60`, composed in `teamRunCoordinator.ts:960-968`
**Apply to:** `beforeToolRoundFor`'s gate composition, any steer-turn park, the ledger poll in `runBatch`.
```ts
      await gateFor(agentId).wait(signal);
      await teamGate.wait(signal);
      signal.throwIfAborted();
```

### Single `runStatus` writer
**Source:** `src/db/repositories/aiTeamRunRepo.ts:165-180` (`transitionAssignment`) and `teamRunCoordinator.ts:572-674` (`finalizeAttempt`)
**Apply to:** every amend. Never `db.aiTeamAssignments.update({ runStatus })`. Non-status field writes (`steerMessageIds`, `reportMessageId`, `instructionMessageId`) are exempt — precedent at `:798-800` and `:1072-1074`.

### Terminal write must insert a report row
**Source:** `teamRunCoordinator.ts:572-674` (`finalizeAttempt` → `reportMessageId` at `:646`)
**Apply to:** cancel (`stopped`) and rewrite (`skipped`). A bare `transitionAssignment` leaves `listInterruptedAssignments` (`teamTranscriptRepo.ts:288-310`) showing "Lượt trước bị gián đoạn" forever.

### Per-assignment `AbortController`, never `scheduler.cancel`
**Source:** `teamRunCoordinator.ts:1913-1955` (`stopAgent`), `scheduler.ts:32-37` (the comment explaining why)
**Apply to:** amend-cancel and any queued-assignment teardown.

### Spread-only-when-defined optional fields
**Source:** `teamTranscriptRepo.ts:108-122`, `teamRunCoordinator.ts:1776`
**Apply to:** every new optional field write — the project runs `exactOptionalPropertyTypes`, so `{ x: undefined }` is a type error.
```ts
    ...(input.batchId ? { batchId: input.batchId } : {}),
    ...(input.attemptNo !== undefined ? { attemptNo: input.attemptNo } : {}),
```

### Sanitized user-facing error
**Source:** `chatTurnRuntime.ts:143-144` (`SANITIZED_TURN_ERROR`), `teamRunCoordinator.ts` `STOPPED_REPORT_COPY` / `AMENDED_REPORT_COPY`
**Apply to:** every steer/amend failure. Raw detail → `diagnosticDetail` only (never transcript, never a backup key).

### `disposed` re-check after every await
**Source:** `teamRunCoordinator.ts:1257`, `:1378`, `:1431`, `:1750`, `setPhase` gate `:491-492`
**Apply to:** the steer turn, `drainSteerInbox`, the ledger poll. Criterion 5 depends on it.

### Fire-and-forget error routing in the component
**Source:** `TeamWorkspace.tsx` `runAction` + `actionError` Alert
**Apply to:** amend refusals, dispose failures. Never a bare `void promise`.
