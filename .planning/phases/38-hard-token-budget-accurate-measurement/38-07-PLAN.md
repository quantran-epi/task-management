<objective>
Plumb real provider usage through the runtime into split ledger columns, charge every attempt including retries and aborts, and reconcile live counters with persisted rows when a turn ends.

Purpose: `handleUsage` today collapses usage with `normalizeUsageTotal` and writes a single scalar through a get-then-update. ROADMAP criteria 2 and 3 are unmet because the split is thrown away before it is stored and because a no-usage response costs nothing. This plan makes the funnel lossless, adds the estimation fallback (the tokenizer arrives in plan 10 — until then the fallback is chars÷4 and is still marked estimated), and closes the live-vs-DB gap D-22 describes.
Output: cache-aware usage mapping, `handleUsage` writing split deltas through a chained promise, per-attempt usage rows, `tokenEstimate.ts`, and reconcile inside `finalizeAttempt`.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| provider response → runtime accumulator | untrusted numeric fields (`usage`) and arbitrary text (`streamingText`) |
| runtime → Dexie ledger | the split numbers a user's budget is charged against |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-38-14 | Tampering | `splitUsage` inputs | high | mitigate | Every component is `?? 0` and the sum is compared to `> 0`; a negative or non-numeric provider field cannot decrease a counter because the write path adds only non-negative deltas from `incrementMemberUsage`'s validated shape (plan 06 adds the backup-level guard) |
| T-38-15 | Denial of service | estimation on the hot path | medium | mitigate | Estimation runs at settle time only, chained off the write chain, never per delta; a failure is swallowed and the turn is unaffected |

| T-38-SC | Tampering | npm/pip/cargo installs | high | mitigate | This plan installs nothing; `js-tiktoken` install is gated behind plan 10's blocking checkpoint |
