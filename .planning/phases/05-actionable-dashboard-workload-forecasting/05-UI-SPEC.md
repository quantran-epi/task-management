## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline tags, badge padding, compact metric offsets |
| sm | 8px | Mini day card internal padding, list item gaps, chip margins, button icon spacing |
| md | 16px | KPI card body padding, section headers, grid gutters, alert internal margins |
| lg | 24px | Major tier vertical gap (Today tier to Forecast tier), card layout padding |

| 2xl | 48px | Page-level view separation |
| 3xl | 64px | Maximum page-level vertical gutters |

Exceptions:
- Mobile touch targets: 44px minimum height/width for interactive triggers, chip buttons, and quick action icons on viewports `< 768px`.

## Visual Hierarchy & Focal Points

1. **Primary Focal Anchor (Landing View)**:
   - **Today Summary KPI Card**: Top-left position. Features large display statistics showing `Planned / Capacity` (`Xh Ym / Zh Wm`), utilization percentage progress bar, dual-encoded load status badge, and prominent primary CTA `Open Today in Planner`.
2. **Secondary Interactive Anchor**:
   - **Attention Today List**: Top-right position (stacked beside Today KPI on desktop, stacked below on mobile). Constrained scrollable container (~360px max height) with priority grouping: Overdue (red alert banner/badges) -> Due Today -> Scheduled Today. Each task has direct mark-done checkbox, inline status tag, and clickable title opening `TaskDrawer`.
3. **Tertiary Projection Anchor**:
   - **Workload Forecasting Section**: Bottom tier. Begins with interactive `Segmented` horizon switch (`Next 7 Days` | `Next 14 Days` | `Next 30 Days`), dynamic Overload Alert banner with clickable date chips (`+Xh Ym`), followed by responsive Mini Day Cards Grid (`180px` min-width per card, horizontal scroll or wrap).

## Typography

Declared exactly 4 sizes, 2 weights, adhering to 1.5 body line-height and 1.2 heading line-height:

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px | 400 (Regular) | 1.5 (21px) |
| Label | 12px | 600 (Semibold) | 1.5 (18px) |
| Heading | 16px | 600 (Semibold) | 1.2 (20px) |
| Display | 20px | 600 (Semibold) | 1.2 (24px) |

*Rules:*
- Display (20px, 600): Today KPI primary statistic numbers, dashboard view title.
- Heading (16px, 600): Section titles ("Hôm nay cần chú ý", "Dự báo khối lượng công việc"), KPI card titles, alert titles.
- Body (14px, 400): Task titles, alert descriptions, empty state messages, segmented control labels.
- Label (12px, 600): Day card weekday headers, status badges, priority tags, metric labels (`Sức chứa`, `Phân bổ`, `Còn lại`, `Vượt`).

## Color

60-30-10 Split Contract:

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#ffffff` (Light) / `#141414` (Dark) | Page background, dashboard canvas, primary card bodies (`token.colorBgContainer`, `token.colorBgLayout`) |
| Secondary (30%) | `#fafafa` (Light) / `#1f1f1f` (Dark) | Attention list container, mini day card surfaces, table/panel headers, metric background fills (`token.colorFillAlter`, `token.colorBgElevated`) |
| Accent (10%) | `#1677ff` | Primary CTA buttons, active segmented horizon tab, task title hover link, current day ring indicator |
| Destructive | `#ff4d4f` | Overdue status tag, overloaded day card border and progress fill, deficit text indicator (`+Xh Ym` overload) |
| Warning / Neutral | `#fa8c16` / `#52c41a` | Busy load status (`#fa8c16`), high context switching warning (`#fa8c16`), available capacity status (`#52c41a`) |

Accent reserved strictly for:
1. Primary CTA button ("Open Today in Planner" / "Mở Hôm nay trong Lịch")
2. Active segment selection indicator on Horizon Switcher (`Next 7 Days` / `Next 14 Days` / `Next 30 Days`)
3. Task title link click/hover state in Attention Today list
4. Primary link "View all in Tasks" ("Xem tất cả tác vụ") in Attention list header
5. Today indicator tag / ring in mini day cards

### Semantic 4-State Load Palette (PLAN-04, DASH-02, DASH-03)

| Status | Color | Tag Token | Icon | Criteria |
|--------|-------|-----------|------|----------|
| Available | `#52c41a` | `success` | `CheckCircleOutlined` | Active allocations < 80% effective capacity |
| Busy | `#fa8c16` | `warning` | `ClockCircleOutlined` | Active allocations 80% to 100% capacity |
| Overloaded | `#ff4d4f` | `error` | `ExclamationCircleOutlined` | Active allocations > 100% capacity OR >0m on 0m capacity day |
| No Capacity | `#8c8c8c` | `default` | `MinusCircleOutlined` | Effective capacity = 0m and allocations = 0m (Rest day / Holiday) |

## Component Inventory & Interaction Contracts

### 1. View Shell & Route Integration (`AppRoute = 'dashboard'`)
- **Default Route**: App navigates to `'dashboard'` upon initial visit (`/#/` redirects to `/#/dashboard`).
- **Sidebar Menu**: `Dashboard` item inserted as top entry with `<DashboardOutlined />` icon.
- **Deep Linking Query Support**: `useHashRoute` extended to parse and maintain URL query parameters (e.g. `/#/planner?date=2026-09-27`).

### 2. Today Summary KPI Card (`TodaySummaryCard.tsx`)
- Container: Ant Design `Card` with responsive header displaying current calendar date (`dddd, D MMMM YYYY`).
- Main Metric: Large `Statistic` displaying `Planned / Capacity` (`Xh Ym / Zh Wm`).
- Utilization Progress Bar: Ant Design `Progress` component dual-encoded with semantic status colors (green < 80%, orange 80-100%, red > 100%).
- Status Row:
  - Dual-encoded load state Tag (`Khả dụng`, `Bận`, `Quá tải`, `Nghỉ`).
  - Scheduled task count pill (`N tác vụ hôm nay`).
- Action:
  - Primary button `Mở Hôm nay trong Lịch` (`<CalendarOutlined />`) immediately routes to `/#/planner?date={today}`.
  - Zero-capacity rest day context: Muted badge with explanation and quick link to Settings overrides.

### 3. Attention Today List (`AttentionTodayList.tsx`)
- Container: Ant Design `Card` with title `"Tác vụ cần chú ý"` and badge count.
- Header Action: Link button `"Xem tất cả tác vụ"` routing to `/#/tasks`.
- Max Height & Scrolling: `maxHeight: 360px`, `overflowY: 'auto'` to keep forecast grid visible on desktop viewports.
- Grouping & Sorting Hierarchy (D-09, D-10):
  1. **Overdue Tasks**: Red danger tag `"Quá hạn X ngày"`, sorted by overdue days descending.
  2. **Due Today Tasks**: Blue tag `"Đến hạn hôm nay"`, sorted by Priority (`Urgent` -> `High` -> `Medium` -> `Low`).
  3. **Scheduled Today Tasks**: Purple/Cyan tag `"Lên lịch Xh Ym"`, sorted by allocated minutes descending.
- Task Item Layout:
  - Left: Mark Done `Checkbox` (instantly marks task as `Done` via `taskRepo.updateStatus`).
  - Middle: Clickable Task Title (opens `TaskDrawer` in-place on Dashboard without navigation). Priority pill + Project/Milestone breadcrumb.
  - Right: `InlineStatusTag` dropdown for instant status change.

### 4. Workload Forecasting Section (`WorkloadForecast.tsx`)
- **Horizon Switcher (D-05, D-08)**:
  - Ant Design `Segmented` options:
    - `Next 7 Days` (`7 ngày tới` — rolling `today` to `today + 6`) [Default]
    - `Next 14 Days` (`14 ngày tới` — rolling `today` to `today + 13`)
    - `Next 30 Days` (`30 ngày tới` — rolling `today` to `today + 29`)
- **Overload Alert Banner (D-07)**:
  - Displayed if and only if any dates in the selected horizon have `loadState === 'overloaded'`.
  - Type: Ant Design `Alert` with `message="Phát hiện quá tải công suất"` and `type="warning"`.
  - Body contains interactive clickable Tag chips for each overloaded date (e.g. `[2026-09-29: +2h 15m]`).
  - Clicking any date chip immediately navigates to `/#/planner?date=YYYY-MM-DD`.
- **Mini Day Cards Grid (D-06, D-13)**:
  - Responsive container (`display: grid`, `gridTemplateColumns: repeat(auto-fill, minmax(180px, 1fr))`, `gap: 12px`).
  - Horizontal overflow scrolling enabled on ultra-wide horizons (e.g., 30 days) to prevent extreme vertical stretching.
  - Each Day Card includes:
    - Header: Date string (`D/M`), Weekday name (`Th 2`, `Th 3`), Today tag if applicable.
    - Capacity & Allocated metrics (`Phân bổ: Xh Ym`, `Sức chứa: Zh Wm`).
    - Mini `Progress` bar with load color.
    - Balance indicator: Green `+Xh Ym` if remaining, Red `+Xh Ym vượt` if overloaded.
    - 4-state dual-encoded badge (`Khả dụng`, `Bận`, `Quá tải`, `Nghỉ`).
    - Card Click Action: Whole card is interactive (hover border highlight, cursor pointer). Clicking navigates directly to `/#/planner?date=YYYY-MM-DD` and synchronizes `WeekNavigator`.

### 5. In-Place Drawer Inspection (`TaskDrawer.tsx` on Dashboard)
- `DashboardView` embeds `TaskDrawer` instance.
- Clicking any attention item opens drawer with full tabs (Details, Planning).
- Closing drawer restores focus to task row on Dashboard without losing scroll position.
