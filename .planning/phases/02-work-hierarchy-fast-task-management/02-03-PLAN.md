| Boundary | Description |
|----------|-------------|
| User Action -> Cascade Deletion Modal | Permanent multi-record deletion request from UI |
| Hash Routing -> View Containers | Route switching in App.tsx rendering corresponding view tree |
| Batch Operations -> Repository Updates | Simultaneous mutation of multiple tasks across projects/statuses |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-08 | Denial of Service / Accidental Deletion | src/components/projects/CascadeDeleteModal.tsx | mitigate | Present explicit modal with choice between 'Delete All' and 'Keep Tasks' (D-13, D-14); default button preserves tasks |
| T-02-09 | Tampering / Consistency | src/components/tasks/BatchActionBar.tsx | mitigate | Execute batch modifications within Dexie atomic transactions to prevent partial failure states |
| T-02-10 | Denial of Service / UI Freezing | src/components/projects/ProjectTable.tsx | mitigate | Limit nested table re-renders by memoizing row expansion renders and using live query reactive subscriptions |
| T-02-SC | Tampering | Package dependencies | mitigate | Zero external package additions; native Ant Design 6 components only |
</threat_model>
