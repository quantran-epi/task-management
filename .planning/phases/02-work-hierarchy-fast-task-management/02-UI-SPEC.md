## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline tag padding, status dot margins |
| sm | 8px | Compact element spacing, filter bar element gap, popover internal padding |
| md | 16px | Default layout margins, card padding, table cell vertical padding, header horizontal padding |
| lg | 24px | Section padding, drawer body gutter, modal content padding |
| xl | 32px | Major container breaks, empty state vertical spacing |
| 2xl | 48px | Page-level view separation |
| 3xl | 64px | Maximum page-level vertical gutters |

Exceptions:
- Mobile interactive touch targets: 44px minimum height/width for hamburger button, mobile action buttons, and touch tap zones (`AppShell.tsx` and mobile table action triggers).

## Typography

Declared exactly 4 sizes, 2 weights, adhering to 1.5 body line-height and 1.2 heading line-height:

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px | 400 (Regular) | 1.5 (21px) |
| Label | 12px | 600 (Semibold) | 1.5 (18px) |
| Heading | 16px | 600 (Semibold) | 1.2 (20px) |
| Display | 20px | 600 (Semibold) | 1.2 (24px) |

Rules:
- Standard body text, table row contents, inputs, dropdown items: 14px Regular (weight 400, line-height 1.5).
- Badges, status tags, column labels, metadata timestamps, breadcrumb chips: 12px Semibold (weight 600, line-height 1.5).
- Card titles, modal titles, drawer headers, section subtitles: 16px Semibold (weight 600, line-height 1.2).
- View headers, main page titles (`AppShell` title / View title): 20px Semibold (weight 600, line-height 1.2).
- No unlisted font sizes or font weights permitted in Phase 2 components.

## Color

60-30-10 Split Contract:

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#ffffff` (Light) / `#141414` (Dark) | Page background, table canvas, layout surfaces (`token.colorBgLayout`, `token.colorBgContainer`) |
| Secondary (30%) | `#fafafa` (Light) / `#1f1f1f` (Dark) | Sider menu, filter bar container, drawer surface, modal cards, table header backgrounds (`token.colorFillAlter`, `token.colorBgElevated`) |
| Accent (10%) | `#1677ff` | Reserved strictly for interactive action elements listed below |
| Destructive | `#ff4d4f` | Permanent deletion buttons, destructive modal confirmations, error states |

Accent reserved strictly for:
1. Primary CTA buttons (`+ New Task`, `Create Project`, `Save Changes`)
2. Active navigation menu item indicator in sidebar
3. Focused input / select border highlights
4. Progress bar fill indicator
5. Table row selection checkboxes in checked state
6. Batch action bar primary triggers

Accent is NEVER used for passive text, non-interactive headers, or background shading.

Status & Priority Semantic Palette (Ant Design standard tokens):
- Task Status:
  - `Open`: `#8c8c8c` (Default / Gray)
  - `In Progress`: `#1677ff` (Processing / Blue)
  - `Resolved`: `#faad14` (Warning / Amber)
  - `In Review`: `#13c2c2` (Cyan)
  - `Done`: `#52c41a` (Success / Green)
  - `Cancelled`: `#8c8c8c` (Muted with strikethrough text style)
- Priority:
  - `Low`: `#8c8c8c` (Default / Gray)
  - `Medium`: `#1677ff` (Blue)
  - `High`: `#fa8c16` (Orange)
  - `Urgent`: `#ff4d4f` (Red)

## Component Inventory & Interaction Contracts

### Visual Hierarchy & Focal Points
- **Primary Focal Anchor (`/#/tasks`)**: `QuickAddBar` input field at top of page, highlighted with subtle border focus on initial load / `c` shortcut.
- **Secondary Content Anchor**: `TaskTable` structured tabular view displaying current task horizon.
- **Accessibility & ARIA**: All icon-only triggers declare explicit `aria-label` attributes (`aria-label="Quick edit task"`, `aria-label="More task actions"`, `aria-label="View attachments"`).

### 1. Fast Task Creation Bar (`QuickAddBar.tsx`)
- Placed directly above the Tasks table on `/#/tasks`.
- Single input field with placeholder: `"Add a task (e.g. 'Review pull request ~1h 30m'). Press Enter to save..."`.
- Optional inline project dropdown selector prepended/appended.
- Syntax parser extracts `~Xh Ym` into integer minutes (e.g. `~2h` -> 120m, `~45m` -> 45m).
- Hitting `Enter` immediately calls `taskRepo.create()` with status `Open`, priority `Medium`, and clears input.
- Global shortcut: Pressing `c` (when not in an input/textarea) focuses this input bar.

### 2. Tasks Table (`TaskTable.tsx`)
- Columns:
  1. Selection: Checkbox for batch actions.
  2. Status: `InlineStatusTag` with click dropdown.
  3. Priority: Priority Tag with color coding (`Low`, `Medium`, `High`, `Urgent`).
  4. Title & Hierarchy:
     - Project/Milestone Breadcrumb Tag (e.g., `[Project Alpha > Sprint 1]`). Clicking breadcrumb sets project filter.
     - Task Name (Click opens details Drawer).
     - Subtitle row: truncated 1-line notes preview + Document link count badge (`[🔗 N]`, hover shows popover links).
  5. Estimate: Displayed as formatted `Xh Ym` (e.g., `2h 30m`).
  6. Progress: `InlineProgress` showing percentage bar; click opens Popover slider + numeric input.
  7. Deadline: Calendar date (`YYYY-MM-DD`). Highlighted in red `#ff4d4f` if overdue (`deadline < today`).
  8. Actions: Quick edit icon (opens Drawer) and More dropdown (`Reparent`, `Delete`).
- Keyboard navigation: Arrow Up/Down to navigate rows, `Enter` to open Drawer, `Space` to toggle row selection.

### 3. Inline Controls
- **InlineStatusTag (`InlineStatusTag.tsx`)**:
  - Displays Ant Design `Tag` with arrow `▾`.
  - Click opens `Dropdown` menu with all 6 statuses (`Open`, `In Progress`, `Resolved`, `In Review`, `Done`, `Cancelled`).
  - Selecting an item immediately updates Dexie via `taskRepo.updateStatus(id, status)` and fires success notification (`message.success({ content: 'Status updated', duration: 1.5 })`).
  - Visual: `Cancelled` renders text with line-through and muted gray color.
- **InlineProgress (`InlineProgress.tsx`)**:
  - Compact Ant Design `Progress` bar (width 80px).
  - Click opens `Popover` containing a `Slider` (0-100) and paired `InputNumber`.
  - Updates save to Dexie on popover close/blur with success toast.

### 4. Task Drawer (`TaskDrawer.tsx`)
- Slide-out panel from right (`width: 520px` desktop, `100%` mobile).
- Closes on `Esc` key or close button.
- Form fields:
  - Name: `Input` (required, trimmed, max 120 chars).
  - Parent Assignment: Cascading `Select` (Project -> Milestone). Selecting project clears milestone if incompatible. Standalone option clearly available (`None / Standalone`).
  - Status & Priority: Paired `Select` inputs.
  - Estimate: Dual `InputNumber` (Hours, Minutes) with quick preset buttons (`+30m`, `1h`, `2h`, `4h`, `8h`). Persists strictly as integer minutes.
  - Dates: `DatePicker` for Deadline, Actual Start Date, Actual End Date (persists `YYYY-MM-DD`).
  - Progress: `Slider` + `InputNumber` (0-100%).
  - Document Links: Dynamic form list (`Input` with URL validation, `Add Link`, `Remove Link`). Links render `target="_blank" rel="noopener noreferrer"`.
  - Notes: `Input.TextArea` with `autoSize: { minRows: 4, maxRows: 10 }`.
- Save CTA: Sticky footer button `Save Task` (Accent `#1677ff`).
- Focus restoration: Tracks active trigger ref and restores focus upon close.

### 5. Filter & Search Bar (`TaskFilterBar.tsx`)
- Top-level toolbar above table:
  - Search Input: Search icon, placeholder `"Search tasks (Press '/' to focus)..."`, 200ms debounce.
  - Segmented View: `All` | `Projects` | `Standalone`.
  - Project Dropdown: Filter by specific project.
  - Status Multi-select: Default shows active statuses (`Open`, `In Progress`, `Resolved`, `In Review`). Quick toggle `Include Done & Cancelled`.
  - Priority Filter: Multi-select dropdown.
  - Horizon Quick Filter: Radio tags (`All`, `Overdue`, `Today`, `This Week`).
- Sort controls: Default sorted by `Deadline asc, Priority desc`. Sortable table headers.

### 6. Batch Action Bar (`BatchActionBar.tsx`)
- Floating toolbar at bottom of screen, visible only when `selectedRowKeys.length > 0`.
- Text: `"${selectedRowKeys.length} tasks selected"`.
- Actions:
  - `Batch Status`: Dropdown to set status for all selected tasks.
  - `Batch Move`: Modal/Dropdown to assign Project/Milestone.
  - `Batch Delete`: Danger button with confirmation popconfirm/modal.
  - `Clear Selection`: Text button to deselect all.

### 7. Cascade Deletion Modal (`CascadeDeleteModal.tsx`)
- Custom Ant Design `Modal` triggered when deleting a Project or Milestone that contains child items.
- Structure:
  - Warning icon + Title: `"Delete Project '${project.name}'"`.
  - Description: `"This project contains ${milestonesCount} milestones and ${tasksCount} tasks."`.
  - Two explicit action buttons:
    1. `Delete All`: Permanently deletes project, milestones, tasks, and allocations in atomic Dexie transaction (Destructive `#ff4d4f`).
    2. `Keep Tasks (Move to Standalone)`: Deletes project and milestones, but resets child tasks to standalone (`projectId = undefined`, `milestoneId = undefined`) (Default button).
  - Cancel button: Closes modal with zero data mutation.
