<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User Form Input -> TaskDrawer | Unvalidated text, dates, numbers, and URLs enter component state |
| Document Links -> DOM Anchor | User-provided URLs rendered as clickable links in table/drawer |
| Global Keyboard Shortcuts -> Input Fields | Keydown events must not intercept user typing inside text inputs |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-04 | Denial of Service / Usability | src/hooks/useKeyboardShortcuts.ts | mitigate | Check event target tagName (INPUT, TEXTAREA) and isContentEditable before triggering '/' or 'c' hotkeys (D-29) |
| T-02-05 | Tampering / XSS | src/components/tasks/TaskDrawer.tsx | mitigate | Validate document links with regex /^https?:\/\// to reject javascript: URIs; pair target="_blank" with rel="noopener noreferrer" (D-25) |
| T-02-06 | Information Disclosure / Spoofing | src/utils/filter.ts | mitigate | Calculate date horizons using local calendar dates (YYYY-MM-DD strings) to prevent timezone drift across UTC midnight |
| T-02-07 | Denial of Service / Accessibility | src/utils/focus.ts | mitigate | Store and restore trigger element focus upon drawer/modal close with setTimeout to prevent focus trapping |
| T-02-SC | Tampering | Package dependencies | mitigate | Zero external package additions; Ant Design and Dayjs used exclusively |
</threat_model>
