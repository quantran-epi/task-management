<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller to retrieval DTO | Untrusted query, limits, turns, URNs, and flags enter strict Zod validation. |
| daemon to remote provider | Query/chunk content may leave host only through explicit opt-in adapters. |
| planner output to graph execution | Untrusted model JSON must become a validated logical plan, never Cypher. |
| retrieval to active projections | Reads must stay on one leased snapshot generation. |
| package/model artifact to Node process | Third-party code and model artifacts require pinning and integrity evidence. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-18-01 | Information Disclosure | retrieval DTOs/provider contracts | mitigate | Strict response schemas exclude secrets/endpoints/vectors; remote calls remain opt-in and host-allowlisted in Plan 02. |
| T-18-02 | Tampering/Elevation | `LogicalQueryPlanSchema` | mitigate | Closed ontology schemas, resolved URNs, max 5 entries, depth 1–3, and explicit rejection of raw/interpolated Cypher. |
| T-18-03 | Denial of Service/Repudiation | modality contracts/status | mitigate | AbortSignal-aware contracts, mandatory status for every modality, bounded values, and explicit degraded reason codes. |
| T-18-04 | Tampering | citation/snapshot fields | mitigate | Every item and response carries snapshotId; downstream lease contract pins once and reports stale reads. |
| T-18-05 | Tampering | embedding metadata contract | mitigate | Provider/model/revision/dimensions/policy/integrity metadata is typed; mismatches become unavailable. |
| T-18-SC | Tampering | npm/model supply chain | mitigate | Plan 02 requires slopcheck attempt plus blocking human legitimacy checkpoint before `[ASSUMED]` package install. |
</threat_model>
