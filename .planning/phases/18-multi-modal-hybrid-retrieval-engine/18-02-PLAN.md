<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| daemon to npm/native artifacts | Third-party JS, `sharp`, ONNX runtime, and model weights execute locally. |
| daemon to remote embedding host | Published chunk or query content plus Authorization header leaves host. |
| environment to startup config | URLs, host allowlists, dimensions, model IDs, and keys are untrusted configuration. |
| adapter to logs/DTO | Errors and metadata must not leak content, vectors, endpoints with credentials, or secrets. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-18-01 | Information Disclosure/Spoofing | remote adapter and startup config | mitigate | Default off; explicit flags; exact HTTPS hostname allowlists; server-only distinct keys; bounded query/chunk boundary; redacted logs and metadata tests. |
| T-18-02 | Tampering | provider responses | mitigate | Strict Zod, output-count/index/finiteness/dimension validation; no provider response controls Cypher. |
| T-18-03 | Denial of Service | model load/inference/fetch | mitigate | Lazy warmup, AbortSignal/timeout, bounded batches, typed failures consumed as degraded semantic status. |
| T-18-04 | Tampering | provider/index identity | mitigate | Immutable revision, dimensions, policy and integrity metadata feed snapshot generation checks in Plan 03. |
| T-18-05 | Tampering/Elevation | npm/native/model supply chain | mitigate | Blocking human legitimacy gate, exact dependency pin, Node 24 spike, immutable model revision, cache integrity manifest. |
| T-18-SC | Tampering | `@xenova/transformers` install | mitigate | slopcheck attempt plus mandatory npm/repository human review; `[SLOP]` forbidden and `[SUS]` blocks execution. |
</threat_model>
