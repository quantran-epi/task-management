<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| request to orchestrator | Query/limits/history control workload and optional egress. |
| orchestrator to three modalities | Independent network/DB/model operations can timeout or fail differently. |
| modality candidates to final envelope | Stale/mismatched/partial data must not masquerade as complete. |
| request lease to snapshot cleanup | Release must happen once on every exit. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-18-01 | Information Disclosure | orchestration diagnostics | mitigate | Enumerated content-free reasons and provider metadata; final Zod/secret tests exclude keys, prompts, endpoints, vectors, raw errors. |
| T-18-02 | Injection | planner to modalities | mitigate | Consumes only Plan 04 validated plans and Plan 05 static traversal; no Cypher path in service. |
| T-18-03 | Denial of Service/Repudiation | modality fan-out | mitigate | Validated timeouts, independent AbortControllers, allSettled, bounded candidates, explicit status/duration, no silent omission. |
| T-18-04 | Tampering | snapshot pin/citations | mitigate | One lease at start, item snapshot consistency check, stale discard, finally release exactly once. |
| T-18-05 | Tampering | embedding model/index | mitigate | Exact provider metadata match before vector query; mismatch unavailable. |
| T-18-SC | Tampering | dependencies | mitigate | No installs; consumes prior approved adapters. |
</threat_model>
