<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| query/history to resolver | User text and prior-turn URNs may be ambiguous or malicious. |
| resolver to remote planner | Bounded query/context may leave daemon only under Plan 02 opt-in. |
| model JSON to traversal | Untrusted structured output attempts to control graph execution. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-18-01 | Information Disclosure | planner input/logging | mitigate | Last 3 turns, typed URNs, ontology only; remote default off/allowlisted; no raw output or secret logging. |
| T-18-02 | Injection/Spoofing | logical planner output | mitigate | Strict Zod, seed allowlist, frozen ontology registry, max 5 entries/depth 3, no Cypher field, one bounded repair. |
| T-18-03 | Denial of Service | planner call/history | mitigate | Request/history limits, AbortSignal, exactly one repair, deterministic fallback, explicit modality statuses. |
| T-18-04 | Tampering | entity resolution | mitigate | All resolution scoped to pinned snapshot; ambiguity never guessed and stale candidate rejected. |
| T-18-05 | Tampering | planner provider | transfer | Concrete provider not selected; optional adapter remains outside core, with provider-neutral deterministic tests. |
| T-18-SC | Tampering | dependencies | mitigate | No package installs; native/Zod/existing code only. |
</threat_model>
