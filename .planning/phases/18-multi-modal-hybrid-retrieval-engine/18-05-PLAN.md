<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| validated logical plan to query binder | Model-controlled relation/direction/depth attempts to select query behavior. |
| Cypher execution to Neo4j | Seeds, snapshot IDs, classes, and limits cross DB boundary. |
| Neo4j records to retrieval candidates | Large/cyclic/partial results require validation and caps. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-18-01 | Information Disclosure | graph errors/results | mitigate | Content-free stable error/status mapping; only citation/evidence fields enter output. |
| T-18-02 | Injection/Elevation | static traversal binder | mitigate | Closed registry, resolved seeds, finite template catalog, parameterized values, no raw/interpolated model Cypher. |
| T-18-03 | Denial of Service | 1–3 hop traversal | mitigate | Simple paths, max 5 entries, depth 3, path/node/edge caps in query and mapper, cancellation/transaction timeout. |
| T-18-04 | Tampering | snapshot traversal | mitigate | Every pattern filters pinned graphSnapshotId; missing generation maps stale, never switches to latest. |
| T-18-05 | Tampering | evidence class | mitigate | OBSERVED/BUSINESS_APPROVED default; explicit inferred opt-in; response edge carries class. |
| T-18-SC | Tampering | dependencies | mitigate | No package installs; static native Neo4j driver use only. |
</threat_model>
