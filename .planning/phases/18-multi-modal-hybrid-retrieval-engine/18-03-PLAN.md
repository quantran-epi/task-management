<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| published Markdown to Neo4j projections | Canonical chunks become rebuildable text/vector nodes. |
| request query/vector to Neo4j procedures | Untrusted search data crosses database boundary. |
| candidate to active pointer | Failed or stale generation must not become visible. |
| retrieval lease to cleanup | In-flight requests retain superseded generation references. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-18-01 | Information Disclosure | Neo4j chunk projection | mitigate | Only already-published Markdown enters daemon Neo4j; no secret/env/key fields persisted or returned. |
| T-18-02 | Injection/Tampering | full-text/vector Cypher | mitigate | Static Cypher, parameterized values, Lucene escaping, digest-only DDL identifiers, exact dimension checks. |
| T-18-03 | Denial of Service | index build/query/cleanup | mitigate | Await timeout, top-K bounds, dimension/count validation, cleanup outside activation, failure isolation. |
| T-18-04 | Tampering | activation/retention | mitigate | Pin metadata once, atomic ACTIVE_GRAPH swap, lease refcount plus 600000 ms grace, stale status on missing generation. |
| T-18-05 | Tampering | model artifact metadata | mitigate | Persist immutable revision/policy/integrity/dimensions and reject query mismatch. |
| T-18-SC | Tampering | package/model installs | mitigate | No new install in this plan; consumes Plan 02-approved exact dependency and metadata. |
</threat_model>
