<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser/client to Fastify | Origin, bearer, URL params, and JSON body are untrusted. |
| route to service | Only parsed bounded request may invoke retrieval. |
| env/startup to external services | Neo4j/provider credentials must remain server-only and validated. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-18-01 | Spoofing/Information Disclosure | retrieval route/startup | mitigate | Existing exact-origin + timing-safe bearer; body/auth redaction; fixed errors; server-only env; host allowlists. |
| T-18-02 | Injection | route DTO to service | mitigate | Strict params/body Zod; service receives logical query text only, never raw Cypher. |
| T-18-03 | Denial of Service | HTTP request | mitigate | Existing 1 MB body limit plus stricter query/history/limit schemas and service deadlines. |
| T-18-04 | Tampering | service/repository composition | mitigate | Shared repository/pointer instance; strict response parse; safe close lifecycle. |
| T-18-05 | Tampering | startup dependencies | mitigate | Exact Plan 02 package/model metadata and Plan 03 schema initialization; no client secrets. |
| T-18-SC | Tampering | dependencies | mitigate | No new package install in route wiring. |
</threat_model>
