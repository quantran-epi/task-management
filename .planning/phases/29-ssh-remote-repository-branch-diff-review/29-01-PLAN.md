<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client UI → Shell Exec over SSH | Remote repo path, branch names, and file paths pass to remote shell |
| DB / Memory → Remote SSH Daemon | SSH credentials (password / private key passphrase) loaded from OS Keyring |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-29-01 | Tampering | `runGitCommand` in `gitRemoteService.ts` | high | mitigate | Wrap all arguments in `escapeShellArg` (POSIX single-quote escaping) to prevent command injection. |
| T-29-02 | Information Disclosure | `gitRemoteService.ts` | medium | mitigate | Only execute read-only git queries (`rev-parse`, `log`, `diff`, `status`, `for-each-ref`). Restrict command list. |
| T-29-03 | Elevation of Privilege | Keyring resolution in `sshService.ts` | high | mitigate | Passwords/keys retrieved from native OS Keyring on demand; never stored plaintext in Dexie or logs. |
| T-29-SC | Tampering | npm installs | high | mitigate | Zero new third-party npm packages added; relies strictly on existing in-tree dependencies. |
</threat_model>
