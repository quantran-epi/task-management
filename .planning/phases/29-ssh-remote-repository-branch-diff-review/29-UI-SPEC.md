# Phase 29 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Scope of this phase's UI:** SDLC Step 3 (`Step3CodeGuideView`) UI overhaul from a static instruction card into an interactive Git Branch & Diff Review workbench over native Tauri SSH. Includes SSH profile & repository configuration bar, uncommitted/dirty working tree alert banner, resizable 2-column review pane (commit timeline & changed files tree on left, Unified/Split `RemoteDiffViewer` on right), fullscreen modal diff toggle, 5000-line diff capping safety, snapshot approval CTA, and non-destructive remote HEAD drift handling.

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px | 400 | 1.5 |
| Label | 12px | 600 | 1.4 |
| Heading | 16px | 600 | 1.3 |
| Display | 20px | 600 | 1.2 |

Declared sizes: exactly 4 — 12px, 14px, 16px, 20px.
Declared weights: exactly 2 — Regular (400) and Semibold (600).

Hard rule (carried from Phase 26 & 27): **no text below 12px in any touch point.** This includes commit SHAs, file status tags, line counts, and diff line numbers.

Declared exceptions:
- Diff code lines & line numbers: 12px monospace (`ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas, "Liberation Mono", "Courier New", monospace` — consistent with `DiffHunkView`), line-height 20px, `whiteSpace: 'pre'`.
- Commit SHA badge: 12px monospace, weight 600.

- Snapshot approval wording states: `Đã lưu snapshot nhánh thành công` (Branch snapshot saved) — never "đã merge", "đã push", "đã commit".

- Re-inspection updates the snapshot without erasing existing CR data.

## UI Component Contract Specifications

### 1. Top Configuration Bar (`RemoteRepoConfigBar`)
- Container: compact `Card` with `padding: 12px 16px`, `backgroundColor: token.colorFillAlter`, `borderRadius: 8`, border `1px solid token.colorBorderSecondary`.
- Layout: flex row with wrapping:
  - SSH Profile selector: `Select` (min-width 180px), lists profiles from `sshService.getSshConfigs()`.
  - Remote Repo Path: `Input` with monospace font, placeholder `/home/user/workspace/repo`.
  - Base Branch: `Select` or `Input` (default `origin/main` with fallback `origin/develop`).
  - Target Branch: `Select` with search filter (`showSearch`), populated dynamically via `gitRemoteService.getRemoteBranches()`.
  - Refresh CTA: `Button icon={<ReloadOutlined />}` with tooltip `Làm mới danh sách nhánh`.

### 2. Status & Alert Banners
- **Dirty Working Tree Banner:**
  - `Alert type="warning" showIcon`, collapsible file list for untracked/modified working files.
  - Text: `Thư mục làm việc remote có {count} tệp chưa commit. Kết quả review bên dưới chỉ hiển thị các commit đã tạo giữa {base} và {target}.`
- **Remote HEAD Drift Alert Banner:**
  - `Alert type="warning" showIcon`, action button `Button size="small" type="primary"` with label `Kiểm tra lại & Cập nhật snapshot`.
  - Text: `Remote HEAD đã thay đổi so với snapshot đã duyệt ({oldSha} → {newSha}). Nhấn "Kiểm tra lại" để cập nhật.`
- **SSH Connection / Git Error Banner:**
  - `Alert type="error" showIcon closable`, displays detailed error message and suggested remedy.

### 3. Resizable 2-Column Review Pane
- Container: flex row, `height: 600px`, `border: 1px solid token.colorBorderSecondary`, `borderRadius: 8`, `overflow: hidden`.
- **Left Panel (Commit Timeline & File Tree):**
  - Default width: 320px (min 260px, max 480px), managed by `ResizeSplitter`.
  - Background: `token.colorFillAlter` (light: `#f7f8fa`).
  - Sub-section 1: Commit Log Timeline — scrollable list (`maxHeight: 220px`), each item shows commit short SHA (12px monospace tag), author, relative date, and commit subject (ellipsis).
  - Sub-section 2: Changed Files Tree — quick-search input filter (`Input.Search` placeholder `Lọc tệp...`), scrollable file list (`flex: 1`).
  - File row: status badge (`[A]` green, `[M]` orange, `[D]` red, `[R]` blue), file path relative to repo root, additions/deletions counts (`+N / -M`). Selected row highlighted with `var(--bg-selected)`.
- **Divider:**
  - `ResizeSplitter` (side="left", currentWidth={leftWidth}, minWidth={260}, maxWidth={480}, onResize={setLeftWidth}).
- **Right Panel (`RemoteDiffViewer`):**
  - Background: `token.colorBgContainer` (`#ffffff`).
  - Toolbar Header: flex row with selected file path in bold 14px, diff stats (`+N / -M`), view mode switcher (`Segmented` with options `Unified` / `Split`), and fullscreen toggle button (`FullscreenOutlined`).
  - Diff Body:
    - Unified mode: stacked diff hunks with old/new line numbers gutter and color-coded line rows.
    - Split mode: 2-column side-by-side view (left: base, right: target) with synchronized vertical scroll.
    - Safety cap: if file lines > 5000 or size > 1MB, render first 5000 lines followed by alert card with button `Tải toàn bộ nội dung diff ({count} dòng)`.

### 4. Fullscreen Review Modal
- Invoked via fullscreen toggle button.
- Ant Design `Modal` with `width: "95vw"`, `centered`, footer=null, body style `height: "85vh", padding: 0`.
- Renders `RemoteDiffViewer` at full dimensions with internal split pane or full-width diff body.

### 5. Action & Approval Footer
- Fixed bottom container inside `Step3CodeGuideView`: flex row, `justifyContent: space-between`, `alignItems: center`, `padding: 16px 0`.
- Left: Snapshot approval status (`Approved: {timestamp} (HEAD: {headSha})` or `Chưa duyệt`).
- Right:
  - `Button type="primary" size="large" icon={<CheckCircleOutlined />}` with label `Chấp thuận kết quả review`. Clicking commits `BranchSnapshot` to CR state in Dexie.
  - `Button size="large" icon={<ArrowRightOutlined />}` with label `Chuyển sang Bước 4: Change Pack`. Enabled after snapshot approved; triggers `onProceedToStep4()`.
