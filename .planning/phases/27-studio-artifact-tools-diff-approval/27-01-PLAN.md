## Interface contract

Keep contracts in `src/services/ai/sdlcArtifactTools.ts`, not a new type-only module. Export `ArtifactToolContext`, `ArtifactToolSnapshot`, `ArtifactPatchProposal`, `ArtifactToolRefusal`, and `ArtifactToolResult`.

- `ArtifactToolContext` carries trusted `scopeKey`, `projectId`, `crId`, `stepId`, live `getAccess()` returning readOnly/CR status/scope validity, `getDraft(kind): string | undefined`, and optional `getWorkflowState()`. No singleton current-context registry. Two simultaneous scopes must remain isolated.
- `readArtifactSnapshot(db, context, kind)` uses live host state when supplied, otherwise validated `db.settings[workflowStorageKey(projectId, crId)]`. An explicitly supplied but unavailable host state is unavailable, not permission to read another snapshot. Undefined draft falls back to committed content; empty string does not.
- Snapshot fields: `kind`, `version`, `approvedAt`, `approvalState`, `markdown`, `baseHash`, `sectionIndex`. Committed approval metadata describes committed version only; changed draft is explicitly unapproved. No invented version increment.
- `get_artifact` arguments: `kind` in SOLUTION/PL03B/PL07/CAB. `patch_artifact_section` arguments: `kind`, `sectionId`, `expectedHeading`, `baseHash`, `operation` in append/replace, `newContent` string. Model arguments never select project, CR, or scope.
- Proposal fields: runtime-generated `proposalId`, trusted scope identity, `kind`, `version`, `sectionId`, `sectionTitle`, `baseHash`, `baseMarkdown`, `diffText`, `addedLines`, `removedLines`, `patchedMarkdown`. Refusals carry `refused: true`, `code`, Vietnamese `message`, and current index/count/navigation metadata where applicable.
- Hash identity uses `defaultSha256(markdown.trim())`, matching coordinator call-site `hashText(markdown.trim())`. Preserve original text for reads and splice operations; hashing is not permission to trim Unicode/body content. Include exact base Markdown identity or a monotonic draft revision in each runtime proposal as a secondary compare-and-apply check; whitespace-only edits must not be overwritten merely because normalized hashes match. Normalized hashes govern staleness semantics, while exact-base changes require a new proposal before replacing text. Store this runtime-only field as baseMarkdown on ArtifactPatchProposal; do not persist it in decision rows.
