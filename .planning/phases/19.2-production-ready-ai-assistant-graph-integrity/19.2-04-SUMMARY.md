# Phase 19.2 Plan 04: Server Startup Validation, Two-Phase Snapshot Rebuild, and Safe Rollback Summary

Explicit dependency injection at server startup, two-phase candidate snapshot publication with atomic compare-and-swap activation, authenticated rollback endpoint, and lease-safe deferred cleanup for knowledge graph integrity.

## Tasks Executed

### Task 1: Implement validated DI configuration in main.ts and server.ts
- Added `ProseExtractionServerConfig` and strict env validation in `readKnowledgeServerOptions` (`PROSE_EXTRACTION_*` and `ROLLBACK_GRACE_PERIOD_MS`).
- Required explicit `GraphBuildService`, `AttemptService`, and `SnapshotStore` injection into `buildKnowledgeServer`.
- Mandated explicit `repository` and `snapshotStore` when `productionMode: true` in `GraphBuildService`.
- Created test suite in `knowledge-server/tests/graphBuildRuntime.test.ts`.
- **Commit:** `471320f` (initial)

### Task 2: Implement two-phase candidate build and atomic compare-and-swap activation
- Separated `prepareCandidate`, `validateCandidate`, and `activateCandidate` in `GraphBuildService`.
- Added atomic compare-and-swap verification on `expectedPriorSnapshotId` throwing `GraphCASConflictError`.
- Extended `GraphStatusDTO` in `routes/graph.ts` with `candidateSnapshotId`, `candidateStatus`, `priorSnapshotId`, `rollbackExpiresAt`, and `canRollback`.
- Added route `POST /api/v1/sets/:setId/graph/activate`.
- **Commit:** `255c219`

### Task 3: Implement authenticated rollback endpoint and lease-safe cleanup
- Implemented `rollbackCandidate(setId)` checking rollback grace expiration, atomically swapping active pointer back to `priorSnapshotId`, clearing window, and logging structured `[PUBLISH]` audit event.
- Implemented `cleanupExpiredSnapshots(setId)` asserting expired rollback grace window and zero active query leases before invoking generation cleanup.
- Added route `POST /api/v1/sets/:setId/graph/rollback`.
- Extended `InMemoryGraphRepository.cleanupSupersededGenerations` with configurable grace period.
- **Commit:** `1c3a1f8`
