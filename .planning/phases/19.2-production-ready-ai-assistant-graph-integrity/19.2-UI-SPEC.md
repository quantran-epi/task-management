# Phase 19.2 — UI Design Contract: Production-Ready AI Assistant & Graph Integrity

> Visual and interaction contract for frontend components in Phase 19.2. Defines exact UI states for LLM-first intent classification, model clarification prompts, AI unavailable fail-closed views, daemon-down local fallback, confidence and speculation visual separation, citations and source preview, multi-hop graph path visualization, TaskMate-to-knowledge entity linking, mutation confirmation gates, and two-phase candidate build/activation/rollback in Document Set management. Built exclusively on existing Ant Design 6 components and design tokens without adding new UI frameworks.

| Property | Value |

## 2. Spacing Scale

Declared values (strictly multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Inline citation chip gap, badge icon gap, hop arrow margin |
| sm | 8px | Button icon spacing, chip padding-y, tag gaps in lists, compact card row margin |
| md | 16px | Card body padding, section margin between answers, banner inner padding |
| lg | 24px | Outer padding of drawer header/body when width >= 480px, modal container padding |
| xl | 32px | Major section divider spacing inside document set drawer |
| 2xl | 48px | Reserved for full-height empty state vertical centration |
| 3xl | 64px | Page-level spacing (reserved) |

Exceptions:

- **Drawer mobile body padding:** Collapses from 24px to 12px horizontal padding when drawer width < 384px to maximize text reading area on mobile screens.
- **Citation chip inline height:** Fixed at 20px with inline baseline alignment (matches 14px body text line-height). Touch target inflated via invisible pseudo-element `::before` to minimum 32px x 32px (44px on touch devices).

## 3. Typography

Declared typography scale (strictly 4 font sizes and 2 font weights):

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Label | 12px | 600 | 1.4 (17px) | Badges (`OBSERVED`, `INFERRED`, `LOCAL`, `GIẢ THUYẾT`), citation chip index `[1]`, metadata timestamps |
| Body | 14px | 400 | 1.5 (21px) | Message prose, conclusion sentences, explanation bullets, input text, dialog content |
| Heading | 16px | 600 | 1.4 (22px) | Section headings ("Trả lời", "Giả thuyết", "Đường dẫn suy luận", "Xác nhận thao tác") |
| Display | 20px | 600 | 1.3 (26px) | Drawer header title, modal title ("Xây dựng đồ thị", "Kích hoạt ứng viên") |

Typography rules:

- **Two weights only:** Regular (400) for all reading prose; Semibold (600) for headings, labels, tags, and interactive buttons. No third weight.
- **Monospace identifier styling:** Code identifiers (e.g. `MAIN1.FCL_CYCLE_COUNTER`, `PRC_PROCESS:60000006`), snapshot hashes, and Cypher relation tokens use 13px monospace with `colorFillTertiary` background, `colorBorderSecondary` 1px border, and `borderRadius: 4px`.
- **Verbatim quotes:** Source text excerpts inside preview drawers or quotes must never be translated, summarized, or restyled; they display in verbatim 13px monospace or 14px blockquote with exact casing.

## 4. Color Contract

Follows the 60/30/10 spatial color distribution rule:

| Role | Proportion | Semantic Token | Light Mode Hex | Dark Mode Hex | Usage |
|------|------------|----------------|----------------|---------------|-------|
| Dominant | 60% | `colorBgContainer` | `#ffffff` | `#141414` | Chat drawer background, message bubble background, card surfaces |
| Secondary | 30% | `colorFillTertiary` / `colorBgElevated` | `#f5f5f5` | `#262626` | Collapsible panels, diagnostic surfaces, hop cards, candidate chip container |
| Accent | 10% | `colorPrimary` | `#4f46e5` | `#6366f1` | Specific reserved elements only (see below) |
| Destructive | Action-gated | `colorError` | `#ff4d4f` | `#dc4446` | Mutation decline button, rollback execution button, hard error banners |

Semantic status colors:

- `colorWarning` (`#faad14`): Local authority BM25 banner, degraded modality warning, mutation confirmation alert box, hypothesis warning badge.
- `colorInfo` (`#1677ff`): Clarification question bubble accent, knowledge link pills, candidate selection chips.
- `colorSuccess` (`#52c41a`): `OBSERVED` fact tags, verified content hash badge, active snapshot status tag.

### Accent Reserved-For List (Strict 10%)

The accent color (`colorPrimary`) is reserved strictly for:

1. Server citation chips `[1]`, `[2]` text and border.
2. Active graph path connector lines and direction indicator arrows.
3. Candidate activation primary button (`Kích hoạt đồ thị`).
4. Primary mutation confirmation CTA button (`Xác nhận`).
5. Keyboard focus rings on interactive pills and list items.

All other interactive elements use neutral or semantic token borders. Specifically, **local citations `[LN]` must use `colorFillSecondary` background and neutral border**, visually distinguishing local BM25 citations from server-verified GraphRAG citations.

## 6. Component Inventory & UI State Specifications

### 6.1 Clarification Flow (`ChatMessageBubble` & `AIChatDrawer`)

**Problem addressed:** In prior phases, low-confidence intent triggered generic route chips (`Tra cứu tài liệu` / `Thao tác PlannerMate`) or discarded model clarification text.

**Specification:**
- **No Route Chips:** Completely remove `IntentRoutingPrompt.tsx` route buttons. The assistant must never present manual intent bypass chips.
- **Render Model Question:** When intent routing returns `intent: 'clarify'`, the UI renders an assistant message bubble containing:
  1. Header tag: `InfoCircleOutlined` with text `Cần làm rõ yêu cầu`.
  2. The exact `clarify_question` generated by the model in 14px semibold prose.
  3. Context badge showing original query excerpt: `"Dựa trên câu hỏi: ..."`
- **Free-Text Answer Input:** The chat input bar placeholder switches to `Nhập câu trả lời làm rõ của bạn...`. User types natural free text.
- **Composite Resubmission:** When submitted, the client preserves the original query and appends the user answer into a structured composite context:
  ```text
  [Yêu cầu gốc]: {originalQuery}
  [Làm rõ của người dùng]: {clarificationAnswer}
  ```
- **Re-enter Intent State Machine:** This composite text re-enters `routeIntent()` through the normal LLM pipeline.
- **Clarification Loop Prevention:** Allow at most 2 user clarification answers. If routing still returns `clarify` after the second answer (`turnCount >= 2`), break the loop and render: `"Chưa thể xác định rõ ý định sau 2 lần hỏi. Vui lòng đặt câu hỏi cụ thể hơn hoặc chọn tác vụ cụ thể trong giao diện."` with a `Làm mới hội thoại` button.

### 6.2 AI Unavailable Fail-Closed State (`InlineApiErrorCard`)

**Problem addressed:** When LLM is unconfigured, unreachable, or returns invalid schema after repair, the system must fail closed without running tools, mutations, or unrequested fallbacks.

**Specification:**
- **Visual Container:** An alert card rendered in place of the streaming assistant bubble using `colorErrorBg`, `colorErrorBorder`, and `colorError` accents.
- **Layout:**
  - Header: `ExclamationCircleFilled` icon + Title `Trợ lý AI tạm thời không khả dụng` (16px/600).
  - Body: Clear explanation that no database operations or knowledge queries were executed.
  - Action row (bottom right):
    - `Mở Cài đặt AI` (`Button` with `SettingOutlined`): Opens the 9router configuration modal.
    - `Thử lại` (`Button` type `primary` with `ReloadOutlined`): Resends the last user turn.
- **Safety Guarantee:** No tool loading indicators, no fake synthesis bubbles, and no mutation dialogs appear while in this state.

### 6.3 Daemon-Down Local Fallback View (`GroundedBanner` & `GroundedAnswerCard`)

**Problem addressed:** When 9router is alive but Knowledge Server (or Neo4j) is down, the assistant must continue functioning using local IndexedDB BM25 search without misleading the user regarding graph provenance.

**Specification:**
- **Banner Indicator:** A persistent top banner inside the answer card with `variant="local"`:
  - Background: `colorWarningBg` (`#fffbe6`), border: `colorWarningBorder`.
  - Icon: `SafetyCertificateOutlined` with `colorWarning`.
  - Title: `Đang sử dụng tìm kiếm cục bộ (Quyền hạn cục bộ)` (13px/600).
  - Body: Explains that answers derive solely from local Markdown docs via BM25; vector search and graph relations are inactive.
- **Local Citations:** Citations render as `[L1]`, `[L2]` tags in neutral gray with a small `Local` tag. They open `QuickPreviewDrawer` referencing local Dexie `notes` table.
- **Omission of Graph Paths:** The `GraphPathCard` and "Đường dẫn suy luận" collapsible panel are completely hidden (or display an empty state stating `Đồ thị tri thức ngoại tuyến`).

### 6.4 Answer Truthfulness, Confidence & Speculation Separation (`GroundedAnswerCard`)

**Problem addressed:** Model hallucination, unsupported claims claiming citations, and mixed speculation confusing the user.

**Specification:**
- **Answer Confidence Badge:** Rendered at top-right of the conclusion card:
  - `HIGH`: Green tag (`colorSuccess`) + "Độ tin cậy: Cao" (all claims directly cited).
  - `MEDIUM`: Blue tag (`colorInfo`) + "Độ tin cậy: Trung bình" (inferred or partial evidence).
  - `LOW`: Orange tag (`colorWarning`) + "Độ tin cậy: Thấp" (sparse evidence or hypotheses present).
  - `UNKNOWN`: Gray tag (`colorTextSecondary`) + "Độ tin cậy: Chưa xác định" (no evidence).
  - Tooltip: Displays concise rationale derived from evidence coverage (e.g. `2 dẫn chứng trực tiếp, 1 dẫn chứng suy luận, không có mâu thuẫn`).
- **No-Evidence Card (`NO_EVIDENCE`):**
  - Card style: Neutral border, clean typography.
  - Title: `Không tìm thấy bằng chứng trong tri thức đã xuất bản` (16px/600).
  - Body: Honest statement that indexed knowledge lacks this domain. Zero invented claims.
  - Refinement suggestions: Up to 3 clickable chips (e.g. `Thử tìm kiếm với từ khóa khác`, `Mở rộng sang tác vụ TaskMate`) that populate the input bar upon click.
- **Explicit Speculation Block (`HypothesisBlock`):**
  - **Condition:** Rendered IF AND ONLY IF `speculation_requested: true` was detected in the prompt/intent and model returned hypotheses.
  - **Visual Separation:** Hypotheses are strictly rendered in a dedicated bordered box *below* the cited conclusion, separated by a dashed divider.
  - **Visual Badging:** Uses amber border (`colorWarningBorder`), a prominent label `Giả thuyết (Chưa có bằng chứng xác thực)` (14px/600), and a disclaimer text.
  - **Citation Prohibition:** Hypotheses must NEVER display citation chips `[N]`. They are pure model reasoning and visually marked as ungrounded.

### 6.5 Citations & QuickPreview Contract (`CitationChip` & `QuickPreviewDrawer`)

**Specification:**
- **Server Citation Chip `[N]`:**
  - Visual: Compact pill (height 20px), `colorPrimary` text and border, background `colorBgContainer`.
  - Interaction: Hover shows tooltip with Document Title, Section Anchor, Line Range, and Snapshot ID (first 8 chars).
  - Click/Keydown: Opens `QuickPreviewDrawer`.
- **Local Citation Chip `[LN]`:**
  - Visual: Compact pill with `colorBorder` outline, subtle gray fill, and a small `LOCAL` badge. Verify at least 3:1 graphical-object contrast against both light and dark container surfaces.
- **`QuickPreviewDrawer` Highlighting & Snapshot Verification:**
  - Scrolls smoothly to `lineStart`..`lineEnd`.
  - Target text highlighted with `colorPrimaryBg` background for 1600ms (or static highlight if `prefers-reduced-motion` is active).
  - **Snapshot Mismatch Alert:** If the document's current local content hash differs from `publishedContentHash` associated with the citation, display a warning banner at top of preview:
    `"Tài liệu cục bộ đã được chỉnh sửa sau thời điểm xuất bản đồ thị. Đoạn trích hiển thị theo bản chụp tại thời điểm lập chỉ mục."`

### 6.6 Multi-Hop Graph Paths Card (`GraphPathCard`)

**Specification:**
- **Container:** Collapsible panel titled `Xem đường dẫn suy luận ({N} bước)`.
- **Path Row Layout:**
  - Vertical step visualization.
  - Step hop format:
    `[Nguồn: Entity] ───( Mối quan hệ: REL_TYPE )──► [Đích: Entity]`
  - Hop metadata:
    - Direction indicator: Forward `──►` or Reverse `◄──`.
    - Relationship classification badge: `OBSERVED` (green), `INFERRED` (blue dashed), or `BUSINESS_APPROVED` (primary).
    - Hop citation chip: Clickable `[N]` linking to the exact evidence chunk proving that specific edge.
  - Snapshot closure indicator: Displays pinned snapshot ID tag at bottom of path card.

### 6.7 TaskMate ↔ Knowledge Links (`LinkedKnowledgeSection`)

**Specification:**
- **Placement:** Displayed inside Task Details, Project Overview, and Milestone details drawers/views.
- **Entity Link Pills:**
  - Document Link: Purple tag with `FileTextOutlined` icon, document title, and click action to open `QuickPreviewDrawer`.
  - Graph Entity Link: Indigo tag with `DeploymentUnitOutlined` icon, Entity Canonical Name + Kind tag (e.g. `MAIN1.FCL_CYCLE_COUNTER [DATA_OBJECT]`), and stable URN tooltip.
- **Link Creation & Deletion:**
  - Add button: `+ Liên kết tri thức` opens modal with entity search (auto-suggest from Neo4j active snapshot entities or local documents).
  - Unlink action: Clicking `CloseOutlined` (x) on a tag triggers confirmation modal: `"Gỡ liên kết tri thức này khỏi tác vụ?"`.
- **Chat Scope Hinting:** When the active chat scope is attached to a task/project with linked entities, `AIChatDrawer` renders a subtle hint bar below scope indicator:
  `"Đã gắn 2 thực thể tri thức: {Entity 1}, {Entity 2}"` and includes these URNs in retrieval seeds.

### 6.8 Mutation Confirmation Dialog (`MutationConfirmationCard`)

**Specification:**
- **Trigger:** Intercepted whenever `isMutationTool(toolName, args)` is true. Phase 19.2 provides no auto-approve bypass; every proposed mutation requires explicit confirmation.
- **In-Chat Confirmation Box:** Rendered directly above the chat input bar in `ChatMessageList`:
  - Background: `colorWarningBg` with `colorWarningBorder`.
  - Icon: `WarningFilled` with warning color.
  - Title: `Xác nhận thay đổi dữ liệu: {Tên hành động}` (14px/600).
  - Diff / Context Summary: Table or list of planned modifications (e.g. `Cập nhật tiến độ: 50% -> 100%`, `Thêm liên kết tri thức mới`).
  - Action buttons:
    - `Xác nhận thực hiện` (`Button` type `primary`, Enter shortcut).
    - `Từ chối thao tác` (`Button` danger ghost, Escape shortcut).

### 6.9 Candidate Build, Activation & Rollback (`DocumentSetDrawer`)

**Specification:**
- **Two-Phase Rebuild Flow in UI:**
  1. **Phase 1: Build Candidate:**
     - User clicks `Chuẩn bị đồ thị ứng viên`.
     - Active graph remains untouched and serves queries normally.
     - Indeterminate progress indicator shows actual server-reported stage (`Preparing`, `Structured extraction`, `Prose extraction`, `Validation`, `Retrieval generation`, `Candidate Ready`). UI must not invent numeric percentages unless server reports measured progress.
  2. **Phase 2: Review & Compare-and-Swap Activation:**
     - Once candidate status reaches `Ready`, UI shows comparison card:
       - Current active snapshot vs Candidate snapshot stats (Thực thể, Sự kiện, Dẫn chứng, Vector embeddings).
       - Acceptance smoke results: Tag `Đạt kiểm tra truy xuất` (green) or `Chưa đạt` (red).
     - Action button: `Kích hoạt đồ thị ứng viên` (`Button` type `primary`).
  3. **Phase 3: Rollback Grace Window:**
     - Immediately upon activation, a server-configured grace timer countdown begins.
     - Rollback alert bar appears using server-returned `rollbackExpiresAt`:
       `"Đồ thị mới đã kích hoạt. Bạn có thể khôi phục phiên bản trước trong vòng {phút:giây} nếu phát hiện sự cố."`
     - Action button: `Khôi phục đồ thị trước đó (Rollback)` (`Button` danger).
     - Clicking Rollback prompts for confirmation and atomically restores the prior active snapshot pointer.

## 8. Accessibility & Responsive Contract

### 8.1 Accessibility (WCAG 2.1 AA)

- **Live Announcements:** Clarification prompts and AI unavailable cards must mount with `role="status"` and `aria-live="polite"`. Mutation confirmation alerts use `role="alert"` and `aria-live="assertive"`.
- **Keyboard Navigation:**
  - Citation chips (`[N]`, `[LN]`) are keyboard focusable (`tabIndex={0}`) and activate via `Enter` or `Space`.
  - Candidate chips and refinement tags respond to `Enter` and `Space`.
  - Mutation confirmation supports `Enter` to approve, `Esc` to decline.
- **Focus Management:** Opening `QuickPreviewDrawer` from a citation chip programmatically moves focus to the highlighted text anchor (`tabIndex={-1}`) with `.focus({ preventScroll: true })`. Closing the preview returns focus to the triggering citation chip.
- **Screen Reader Clarity:** Classification badges and confidence indicators provide explicit `aria-label`s (e.g. `aria-label="Độ tin cậy cao, dựa trên bằng chứng quan sát thực tế"`).
- **Color Contrast:** All text tokens maintain minimum 4.5:1 contrast against their card backgrounds in both light and dark algorithms. Badges maintain 3:1 contrast against surface fills.

### 8.2 Responsive Layout

- **Desktop (>= 768px):** Drawer is resizable between 320px and 650px (stored in `localStorage['planner:ai_chat_width']`). Side-by-side layout for comparisons inside `DocumentSetDrawer`.
- **Tablet / Small Desktop (480px - 767px):** Default drawer width 400px. Hop rows wrap gracefully without text clipping.
- **Mobile (< 480px):** Drawer takes `100vw` full screen. Padding collapses to 12px. Action buttons stretch to full width in stacked layout. Minimum touch targets enforced at 44px.

## 9. Acceptance Scenarios

The following scenarios test the visual and interaction contracts against Phase 19.1 gaps and Phase 19.2 specifications:

### Scenario 1: Natural-Language Intent & Technical Identifier Fast-Path
1. User enters `MAIN1.FCL_CYCLE_COUNTER` into Chat Drawer.
2. UI displays status `Đang tra cứu cơ sở tri thức...` (no intent prompt chips appear).
3. Response renders `GroundedAnswerCard` with conclusion citing `02-data-objects.md`.
4. Citation chip `[1]` is visible in `colorPrimary` accent.
