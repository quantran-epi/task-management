<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Operator -> Knowledge Server API | Untrusted HTTP requests for rebuild, activation, and rollback crossing bearer auth boundary |
| Knowledge Server -> Remote Prose / LLM Endpoint | External HTTP calls with API keys |
| Knowledge Server -> Neo4j Bolt | Database queries for candidate creation, pointer swap, and deletion |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-19.2-04-01 | Tampering | Graph Pointer CAS | mitigate | Atomic compare-and-swap enforces expected prior snapshot ID; prevents race conditions during activation |
| T-19.2-04-02 | Elevation of Privilege | Rollback Endpoint | mitigate | Require valid KNOWLEDGE_SERVER_TOKEN bearer authentication; enforce strict setId parameter validation |
| T-19.2-04-03 | Denial of Service | Snapshot Deletion | mitigate | Enforce read lease checks and grace expiry before deletion; prevent deletion of active or in-flight snapshot |
| T-19.2-04-04 | Information Disclosure | Prose Config | mitigate | Redact API keys from logs and error traces; enforce exact-host allowlist for remote endpoints |
</threat_model>
