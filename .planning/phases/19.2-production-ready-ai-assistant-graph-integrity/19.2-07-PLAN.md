<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client Dexie Storage | IndexedDB database storing personal tasks, notes, and first-class knowledge links. |
| AI Tool Execution | LLM proposing function calls to create or remove links to knowledge entities. |
| Scoped Retrieval Gateway | Client sending context hints (URNs, docIds) to knowledge-server or local BM25. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-19.2-LINK-01 | Tampering | Dexie SCHEMA_V11 migration | mitigate | Version check in `schema.ts`, transaction isolation, and upgrade verification in `tests/db/knowledgeLinkMigration.test.ts`. |
| T-19.2-LINK-02 | Elevation of Privilege | AI link tools | mitigate | Mark `link_taskmate_to_knowledge` and `unlink_taskmate_knowledge` as mutation tools in `MUTATION_TOOLS`, requiring explicit user modal confirmation before writing to Dexie. |
| T-19.2-LINK-03 | Information Disclosure | Backup export/import | mitigate | Validate exported/imported link objects strictly with Zod `uuidSchema` and `linkKey` regex; encrypt in existing Web Crypto backup artifact. |
| T-19.2-LINK-04 | Denial of Service | Stale graph URN hints | mitigate | Server validates hinted URNs against pinned snapshot; missing URNs log a warning and degrade gracefully without aborting retrieval. |
| T-19.2-LINK-05 | Tampering | Orphaned links on entity delete | mitigate | Cascade deletion transactions in `cascadeRepo.ts` purge all `knowledgeLinks` matching `taskMateEntityId`. |
</threat_model>
