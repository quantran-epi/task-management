# Phase 29.1 Plan 02: Remote Git Explorer Tool Window & Read-Only Remote File Viewer Summary

Implemented Remote Git Explorer Left Tool Window and Read-Only Remote File Viewer in the IntelliJ ExpUI Workbench.

## Core Accomplishments

1. **Stripe & Left Tool Window Registration (Task 1)**:
   - Added `remote_explorer` tool window button to `Stripe.tsx` on the left stripe, positioned below Diagram Explorer with `CloudServerOutlined` icon.
   - Docked `RemoteGitExplorer` in `LeftToolWindow.tsx` matching layout store activation.

2. **Remote Git Explorer Tree Component (Task 2)**:
   - Implemented `RemoteGitExplorer.tsx` with SSH config selector dropdown, repo path input with enter/blur trigger, branch dropdown selector, and refresh button.
   - Built lazy-loading directory tree with Ant Design `Tree` leveraging `getRemoteTree`.
   - Wired file node click events to open `remote_file` editor tabs in `layoutStore`.
   - Created comprehensive unit tests in `RemoteGitExplorer.test.tsx`.

3. **Read-Only Remote File Viewer (Task 3)**:
   - Built `RemoteFileViewer.tsx` displaying remote file contents fetched via `getRemoteFileContent`.
   - Included header bar with file path, branch indicator, "Read-Only" badge, formatted byte size, Copy Path, Copy Content, and Reload buttons.
   - Enforced 2MB size cap guard displaying an Alert warning with "Load anyway" button to prevent performance degradation on large/binary files.
   - Integrated `remote_file` viewType into `EditorArea.tsx`.
   - Created unit tests in `RemoteFileViewer.test.tsx` verifying file content loading and 2MB override behavior.
