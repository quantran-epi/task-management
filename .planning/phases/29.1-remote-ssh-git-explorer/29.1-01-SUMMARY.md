# Phase 29.1 Plan 01: Remote Git Tree & Tauri SSH PTY Streaming Backend Summary

Built read-only remote git tree inspection and native SSH PTY streaming session backend for TaskMate desktop runtime.

## Core Accomplishments

1. **Read-Only Git Tree Service (`gitRemoteTreeService.ts`)**:
   - `getRemoteTree`: runs `git ls-tree -l` with strict `escapeShellArg` escaping; parses output into sorted `RemoteGitTreeNode[]` (directories first, files with sizes).
   - `getRemoteFileContent`: retrieves exact blob content using `git show <ref>:<filePath>`.
   - Guaranteed invariant: remote working copy is never mutated (no `git checkout`, no index changes).

2. **Native Rust Tauri SSH PTY Streaming Backend (`ssh_pty_service.rs`)**:
   - Implemented `SshPtyRegistry` managing active sessions in `Mutex<HashMap<String, SshPtySession>>`.
   - `ssh_pty_start`: opens `channel_session()`, requests PTY (`request_pty("xterm-256color")`), merges extended data, starts remote shell, and navigates to `working_dir` if specified.
   - Dedicated OS reader thread reads channel data chunks and emits Tauri event `ssh-pty:data:<sessionId>`; emits `ssh-pty:exit:<sessionId>` upon termination.
   - Dedicated OS writer thread reads from `tokio::sync::mpsc::channel` and writes to SSH stdin.
   - `ssh_pty_write`, `ssh_pty_resize`, and `ssh_pty_close` commands registered in `src-tauri/src/lib.rs`.

3. **TypeScript SSH PTY Client Bindings (`sshPtyService.ts`)**:
   - Typed interfaces `PtySessionConfig`, `PtyResizePayload`, and `PtySessionStatus`.
   - Client functions `startPtySession`, `writePtyInput`, `resizePty`, `closePtySession`, `subscribePtyData`, and `subscribePtyExit`.
   - Comprehensive Vitest unit tests covering Tauri IPC invocations and non-Tauri fallback behavior.
