<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Remote File Viewer ← Remote Host | File content from untrusted remote git repositories rendered in DOM |
| Tree Node Clicks → Tab Management | Arbitrary remote file paths passed to editor tabs |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-29.1-04 | Tampering | `RemoteFileViewer.tsx` | medium | mitigate | Enforce read-only tab contract; no edit textarea or git write actions present in viewer. |
| T-29.1-05 | Denial of Service | `RemoteFileViewer.tsx` | medium | mitigate | Enforce 2MB size cap guard before fetching/rendering large binary or minified files into DOM. |
| T-29.1-06 | Elevation of Privilege | `RemoteFileViewer.tsx` | low | mitigate | Render code as plain text nodes inside syntax spans; never use `dangerouslySetInnerHTML` for file content. |
| T-29.1-SC | Tampering | npm dependencies | high | mitigate | Zero new dependencies added; uses existing Ant Design and Workbench tokens. |
</threat_model>
