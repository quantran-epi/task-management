## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Keystrokes → PTY Stdin | Raw keyboard inputs piped over SSH to remote shell |
| Terminal Output → DOM | VT100 / ANSI escape sequence output rendered on client |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-29.1-07 | Tampering | `RemoteTerminalPanel.tsx` | medium | mitigate | Xterm.js terminal emulator sanitizes raw escape sequences, avoiding DOM XSS injection from untrusted remote output. |
| T-29.1-08 | Denial of Service | `RemoteTerminalPanel.tsx` | medium | mitigate | Dispose `ResizeObserver`, terminal event listeners, and PTY sessions on unmount to prevent memory leaks and zombie SSH channels. |
| T-29.1-09 | Information Disclosure | `diagramSaveBridge.ts` | low | mitigate | Strips ANSI sequences and shell prompts before saving extracted Mermaid code blocks to IndexedDB. |
| T-29.1-SC | Tampering | npm packages | high | mitigate | Installed packages `@xterm/xterm` and `@xterm/addon-fit` verified against npm official registry (per Package Legitimacy Audit in RESEARCH.md). |
