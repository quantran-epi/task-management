## User Constraints (from CONTEXT.md & Phase Readme)

### Locked Decisions
1. **100% Read-Only Remote Git Operations for Explorer**: No `git checkout`, no changing index/working tree in the Explorer view. Strictly use `git ls-tree` for directory tree listing and `git show <ref>:<path>` for file content retrieval.
2. **Headful Claude Code via Remote SSH PTY**: Full interactive terminal session using `@xterm/xterm` + `@xterm/addon-fit` and Tauri SSH PTY streaming channel (`request_pty`), supporting user prompts, cursor navigation, ANSI escape sequences, arrow keys, and arbitrary commands in the repo directory.
3. **Repository Working Directory Anchor**: When user opens a remote repo, working directory is anchored to that repository root for both Explorer and Terminal.
4. **Mermaid & File Inspection Bridge**: User can open any generated files in the Explorer, inspect them in read-only editor tabs, and copy/save Mermaid blocks to Diagram Studio (`type: 'diagram'`).
5. **Clean ExpUI Integration**: Left Stripe icon below Diagram Explorer (`remote_explorer`), docked Left Tool Window panel, read-only center editor tabs (`viewType: 'remote_file'`), and docked Bottom Terminal panel (`slot: 'bottom'`, `id: 'terminal'`).
6. **Runtime Focus**: Desktop Tauri only (`isTauriApp()`); use existing `ssh2` Rust dependency and OS keyring credentials.
7. **No Full Test Suite**: Vitest full suite is slow; run focused tests only.
8. **Minimal Dependencies**: `@xterm/xterm` and `@xterm/addon-fit` for the frontend terminal; backend uses existing `ssh2` crate already present in `src-tauri/Cargo.toml` without new external native crates.

### Claude's Discretion
- SSH PTY streaming protocol between Rust and frontend (Tauri Events: `ssh-pty:data:<sessionId>`, `ssh-pty:exit:<sessionId>` and Tauri commands: `ssh_pty_start`, `ssh_pty_write`, `ssh_pty_resize`, `ssh_pty_close`).

- Diagram extraction & save action: Action bar in `RemoteFileViewer` or context menu to extract and bridge to Diagram Studio.

### Deferred Ideas (OUT OF SCOPE)
- Remote file editing or writing via SSH in the explorer (strictly read-only).
- Multi-agent parallel trace runs on multiple worktrees simultaneously.

### Pattern 1: Tauri SSH PTY Session Backend (`request_pty`)
**What:** Allocate pseudo-terminal over SSH2 channel, launch interactive shell in repository working directory, and bridge stdin/stdout to Tauri IPC & Events.  
**Example (Rust):**
```rust
// [VERIFIED: ssh2 0.9.6 API in Cargo.lock]
use ssh2::{Channel, ExtendedDataMode, Session};
use std::sync::atomic::{AtomicBool, Ordering};
use std::sync::Arc;
use tokio::sync::mpsc;
use tauri::{AppHandle, Emitter};

pub struct SshPtySession {
    pub session_id: String,
    pub stdin_tx: mpsc::Sender<Vec<u8>>,
    pub is_closed: Arc<AtomicBool>,
}

pub fn start_ssh_pty(
    app: AppHandle,
    session: &Session,
    session_id: String,
    working_dir: Option<String>,
    cols: u32,
    rows: u32,
) -> Result<SshPtySession, String> {
    let mut channel = session.channel_session()
        .map_err(|e| format!("Failed to open channel: {}", e))?;

    // Request PTY with xterm-256color terminal mode
    channel.request_pty("xterm-256color", None, Some((cols, rows, 0, 0)))
        .map_err(|e| format!("Failed to request PTY: {}", e))?;

    channel.handle_extended_data(ExtendedDataMode::Merge)
        .map_err(|e| format!("Failed to configure extended data: {}", e))?;

    // Start user's default shell
    channel.shell().map_err(|e| format!("Failed to start shell: {}", e))?;

    // If working directory specified, immediately cd into it
    if let Some(dir) = working_dir {
        use std::io::Write;
        let cd_cmd = format!("cd {}\n", dir);
        let _ = channel.write_all(cd_cmd.as_bytes());
        let _ = channel.flush();
    }

    let (stdin_tx, mut stdin_rx) = mpsc::channel::<Vec<u8>>(128);
    let is_closed = Arc::new(AtomicBool::new(false));
    let is_closed_reader = is_closed.clone();
    let is_closed_writer = is_closed.clone();

    let mut writer_channel = channel.clone();
    let app_clone = app.clone();
    let event_data_key = format!("ssh-pty:data:{}", session_id);
    let event_exit_key = format!("ssh-pty:exit:{}", session_id);

    // Stdin writer thread
    std::thread::spawn(move || {
        use std::io::Write;
        while let Some(bytes) = stdin_rx.blocking_recv() {
            if is_closed_writer.load(Ordering::Relaxed) {
                break;
            }
            if writer_channel.write_all(&bytes).is_err() {
                break;
            }
            let _ = writer_channel.flush();
        }
    });

    // Stdout reader thread
    std::thread::spawn(move || {
        use std::io::Read;
        let mut buf = [0u8; 4096];
        loop {
            if is_closed_reader.load(Ordering::Relaxed) {
                break;
            }
            match channel.read(&mut buf) {
                Ok(0) => break, // EOF
                Ok(n) => {
                    let text = String::from_utf8_lossy(&buf[..n]).to_string();
                    let _ = app_clone.emit(&event_data_key, text);
                }
                Err(_) => break,
            }
        }
        is_closed_reader.store(true, Ordering::Relaxed);
        let _ = app_clone.emit(&event_exit_key, ());
    });

    Ok(SshPtySession {
        session_id,
        stdin_tx,
        is_closed,
    })
}
```

### Pattern 2: Interactive Frontend Terminal Panel (`@xterm/xterm`)
**What:** Mount an xterm terminal inside the Workbench Bottom Panel, pipe keystrokes to `ssh_pty_write`, listen to `ssh-pty:data:<id>`, and fit layout on resize.  
**Example (TypeScript):**
```typescript
import React, { useEffect, useRef } from 'react';
import { Terminal } from '@xterm/xterm';
import { FitAddon } from '@xterm/addon-fit';
import { listen } from '@tauri-apps/api/event';
import { writePtyInput, resizePty } from '../../services/sshPtyService';
import '@xterm/xterm/css/xterm.css';

export function RemoteTerminalPanel({ sessionId }: { sessionId: string }) {
  const containerRef = useRef<HTMLDivElement>(null);
  const termRef = useRef<Terminal | null>(null);

  useEffect(() => {
    if (!containerRef.current) return;

    const term = new Terminal({
      cursorBlink: true,
      fontFamily: 'JetBrains Mono, Menlo, Monaco, monospace',
      fontSize: 13,
      lineHeight: 1.2,
      theme: {
        background: '#1e1f22',
        foreground: '#bcbec4',
        cursor: '#3871e1',
      },
    });

    const fitAddon = new FitAddon();
    term.loadAddon(fitAddon);
    term.open(containerRef.current);
    fitAddon.fit();
    termRef.current = term;

    // Send initial size
    resizePty(sessionId, term.cols, term.rows);

    // Keystroke stream -> backend
    const onDataDisposable = term.onData((data) => {
      writePtyInput(sessionId, data);
    });

    // Backend output stream -> terminal
    let unlistenData: (() => void) | undefined;
    listen<string>(`ssh-pty:data:${sessionId}`, (event) => {
      term.write(event.payload);
    }).then((unlisten) => {
      unlistenData = unlisten;
    });

    // Resize observer
    const ro = new ResizeObserver(() => {
      fitAddon.fit();
      resizePty(sessionId, term.cols, term.rows);
    });
    ro.observe(containerRef.current);

    return () => {
      ro.disconnect();
      onDataDisposable.dispose();
      unlistenData?.();
      term.dispose();
    };
  }, [sessionId]);

  return <div ref={containerRef} style={{ width: '100%', height: '100%', background: '#1e1f22' }} />;
}
```

### Pattern 3: Strictly Read-Only Git Tree Listing (`git ls-tree`)
**What:** Query directory structure without modifying or checking out anything in the remote working tree.  
**Command:** `git -C <repo> ls-tree -l <ref>[:<dir_path>]`  
**Format:** `<mode> <type> <object> <size>\t<file>`  
**Example:**
```typescript
// [VERIFIED: src/services/gitRemoteService.ts:13-29]
export interface RemoteGitTreeNode {
  key: string;       // relative path e.g. "src/index.ts"
  title: string;     // file/folder name e.g. "index.ts"
  isLeaf: boolean;   // true if blob, false if tree
  size?: number;     // byte size for blobs
  sha: string;       // git object SHA
}

export async function getRemoteTree(
  config: SshConfig,
  repoPath: string,
  ref: string,
  dirPath: string = '',
  secret?: string
): Promise<RemoteGitTreeNode[]> {
  const target = dirPath ? `${ref}:${dirPath}` : ref;
  const output = await runGitCommand(
    config,
    repoPath,
    ['ls-tree', '-l', escapeShellArg(target)],
    secret
  );
  
  const entries: RemoteGitTreeNode[] = [];
  for (const line of output.split('\n')) {
    if (!line.trim()) continue;
    const tabIdx = line.indexOf('\t');
    if (tabIdx === -1) continue;
    const meta = line.slice(0, tabIdx).trim().split(/\s+/);
    const name = line.slice(tabIdx + 1).trim();
    const type = meta[1]; // 'tree' | 'blob'
    const sha = meta[2] ?? '';
    const sizeStr = meta[3] ?? '0';
    const isLeaf = type === 'blob';
    const key = dirPath ? `${dirPath}/${name}` : name;
    entries.push({
      key,
      title: name,
      isLeaf,
      size: isLeaf ? parseInt(sizeStr, 10) || 0 : undefined,
      sha,
    });
  }
  return entries.sort((a, b) => {
    if (a.isLeaf === b.isLeaf) return a.title.localeCompare(b.title);
    return a.isLeaf ? 1 : -1; // folders first
  });
}
```

## Common Pitfalls

### Pitfall 1: Remote Working Tree Modification
**What goes wrong:** Calling `git checkout <branch>` changes files on the user's remote machine or WSL worktree, creating merge conflicts, breaking uncommitted edits, or interfering with active development.  
**Why it happens:** Habit of using working-copy git commands instead of ref-based queries.  
**How to avoid:** Enforce invariant: NEVER use `git checkout`. Always use `git ls-tree <ref>` and `git show <ref>:<path>`.

### Pitfall 2: Blocking Rust Async Runtime with Sync SSH Channels
**What goes wrong:** `ssh2` operates with synchronous TCP streams. Running long-lived PTY read/write loops directly in async tokio tasks blocks the tokio thread pool and freezes Tauri UI.  
**Why it happens:** `ssh2` is not an async crate.  
**How to avoid:** Spawn dedicated OS threads (`std::thread::spawn`) or `tokio::task::spawn_blocking` for SSH PTY streaming, using `mpsc` channels to communicate with async Tauri commands.

### Pitfall 3: Terminal Resize Mismatch
**What goes wrong:** Claude Code CLI renders broken line wrapping or garbled status spinners because the remote PTY row/column size doesn't match the client's DOM container.  
**Why it happens:** PTY defaults to 80x24 unless resized.  
**How to avoid:** Attach `ResizeObserver` with `@xterm/addon-fit` and call `channel.request_pty_size(cols, rows, None, None)` whenever the panel dimensions change.

### Pitfall 4: Shell Escaping Bugs with Remote Paths
**What goes wrong:** Paths with spaces, parentheses, or quotes (e.g. `src/My File (1).ts`) break the SSH bash execution or cause command injection vulnerabilities.  
**Why it happens:** String concatenation (`"git -C " + repo + " ..."`) instead of strict shell escaping.  
**How to avoid:** Always wrap arguments with `escapeShellArg(arg)` from `gitRemoteService.ts` [VERIFIED: src/services/gitRemoteService.ts:13-15].
