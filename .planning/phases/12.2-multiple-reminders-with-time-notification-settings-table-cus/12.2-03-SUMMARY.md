# Phase 12.2 Plan 03: Table Column Customization, 3-State Header Sorters & Desktop Sidebar Persistence Summary

Delivered column visibility popover control, 3-state Ant Design Table header sorters, and persistent desktop Sider collapsed state across browser reloads per NOTIF-09, NOTIF-10, and D-13 through D-20.

## What Was Done

### Task 1: Column visibility popover and localStorage persistence in TaskTable
- Defined `STORAGE_COLUMNS_KEY = 'planner:task_table_columns'`, `ALL_CUSTOMIZABLE_COLUMNS`, and `DEFAULT_VISIBLE_COLUMNS`.
- Implemented synchronous `visibleColumns` state initialization with mandatory enforcement of the `name` (Tác vụ & Phân cấp) column.
- Added Popover with Checkbox list and "Mặc định" reset action button in `TaskTable` toolbar alongside "Sao chép Standup".
- Filtered active columns rendered in `<Table>` based on `visibleColumns` selection.
- Commit: `1cb5e5e`

### Task 2: 3-state column header sorters on TaskTable and automated tests
- Added 3-state header sorting (`sortDirections: ['ascend', 'descend']`) for:
  - `name`: Vietnamese alphabetical locale comparison
  - `priority`: Weight map `Urgent (4) > High (3) > Medium (2) > Low (1)`
  - `status`: Lifecycle weight map `Open (1) < In Progress (2) < Resolved (3) < In Review (4) < Done (5) < Cancelled (6)`
  - `estimateMinutes`: Numeric comparison on estimate minutes
  - `deadline`: Calendar string comparison
- Authored test suite `tests/components/tasks/TaskTable.test.tsx` verifying column toggles, mandatory column protection, localStorage persistence, and 3-state sorting.
- Commit: `5069d33`

### Task 3: Persistent desktop sidebar collapse state in AppShell
- Defined `SIDEBAR_COLLAPSED_KEY = 'planner:sidebar_collapsed'`.
- Initialized `collapsed` state synchronously from `localStorage.getItem('planner:sidebar_collapsed') === 'true'`.
- Updated `handleCollapse` to save state changes to `localStorage` on user triggers while ignoring responsive `type === 'responsive'` overrides from viewport adjustments.
- Created `tests/components/shell/AppShell.test.tsx` validating default expanded state, initial collapsed state from localStorage, and trigger toggles.
- Commit: `44523d9`

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] exactOptionalPropertyTypes compliance on Checkbox disabled prop**
- **Found during:** Task 1 build
- **Issue:** `col.fixed` was typed `boolean | undefined`, causing TypeScript error TS2375 under `exactOptionalPropertyTypes: true`.
- **Fix:** Converted `col.fixed` to strict boolean `Boolean(col.fixed)`.
- **Files modified:** `src/components/tasks/TaskTable.tsx`
- **Commit:** `1cb5e5e`

**2. [Rule 1 - Bug] Sider responsive handler overriding persisted collapsed state**
- **Found during:** Task 3 test run
- **Issue:** Ant Design Sider with `breakpoint="lg"` emitted `handleCollapse(false, 'responsive')` on desktop screens, overriding the persisted collapsed preference.
- **Fix:** Ignored `type === 'responsive'` calls in `handleCollapse` so user-persisted preference remains authoritative.
- **Files modified:** `src/components/shell/AppShell.tsx`
- **Commit:** `44523d9`
