**Test:** Navigate to Settings -> Thông báo, enable "Bật thông báo màn hình" (allow browser permission when prompted) and ensure "Giữ thông báo trên màn hình" is ON. Ensure at least one active alert exists (or wait for a scheduled reminder time).

### 2. Interactive Multi-Reminder Creation in Task, Milestone, and Project Modals
**Test:** Open a task in `TaskDrawer`, a project in `ProjectModal`, and a milestone in `MilestoneModal`. Click "+ Thêm nhắc nhở", select a date with `DatePicker`, an exact clock time with `TimePicker`, enter a note, and save. Add up to 5 reminders to test the limit.
**Expected:** All inputs accept data cleanly, the button displays "+ Thêm nhắc nhở (x/5)" and becomes disabled at 5 reminders. Saved items reload accurately.
**Why human:** Ant Design TimePicker dropdown selection and user keyboard/mouse flows require real browser inspection.

### 3. TaskTable Column Customization and 3-State Sorter UX
**Test:** Open the Tasks view. Click "Tùy biến cột" in the table toolbar, uncheck non-essential columns (e.g., "Loại việc", "Ops Owner"), verify the columns disappear immediately. Reload page and check preferences persist. Click "Hạn chót" header 3 times (ascend -> descend -> reset).
**Expected:** Table reflects column selections instantly and retains state after reload. Column header cycles through ascending, descending, and unsorted states, keeping items without deadlines at the bottom.
**Why human:** Visual layout, table column reflow, and sorting visual cues need manual validation.

### 4. AppShell Desktop Sidebar Collapse Persistence
**Test:** On a desktop viewport (>= 992px), click the Sider collapse trigger chevron at the bottom of the navigation menu. Confirm the sidebar collapses to icon-only mode. Reload the page (Cmd+R / F5).
**Expected:** The sidebar immediately loads in collapsed state without flashing open or shifting layout.
**Why human:** Visual flash-of-uncollapsed-content (FOUC) and CSS transition aesthetics require human observation.
