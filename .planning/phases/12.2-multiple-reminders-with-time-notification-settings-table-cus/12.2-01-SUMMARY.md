# Phase 12.2 Plan 01: Multi-Reminder Data Model, Dexie V6 Migration & Dynamic Form UI Summary

Delivered Dexie Schema V6 upgrade, Zod validation boundaries, time-aware multi-reminder alert evaluation, and reusable Ant Design dynamic Form.List for Tasks, Milestones, and Projects.

## What Was Done

### Task 1: ReminderItem types, Dexie SCHEMA_V6 migration, and Zod validation schemas
- Defined `ReminderItem` interface with `id`, `date`, optional `time` (`HH:mm`), and optional `note`.
- Added `reminders?: ReminderItem[]` to `Project`, `Milestone`, and `Task` entities while preserving legacy `reminderDate` and `reminderNote` properties.
- Defined `SCHEMA_V6` in `src/db/schema.ts` and registered version 6 upgrade in `src/db/index.ts` with non-destructive transformation of legacy date/note into array elements.
- Implemented `reminderTimeRegex`, `reminderItemSchema`, and `remindersArraySchema` (capped at max 5) in runtime and backup schemas.
- Created `tests/db/schemaV6.test.ts` verifying v5 -> v6 migration and multi-reminder persistence.
- Commit: `f3c2e42`

### Task 2: Time-aware multi-reminder evaluation in notifications utility
- Exported `isReminderTriggered` helper function evaluating calendar dates, optional clock times (`HH:mm`), and wall clock time.
- Extended `evaluateNotifications` with optional `currentTime` parameter (defaults to `dayjs().format('HH:mm')`).
- Evaluated `reminders` arrays across projects, milestones, and tasks with discrete alert IDs (`reminder:${entityType}:${entityId}:${reminder.id}`).
- Maintained backwards-compatible fallback for legacy `reminderDate` / `reminderNote` entities.
- Added comprehensive unit tests in `tests/utils/notifications.test.ts` verifying past-date triggers, future-time suppression, elapsed-time triggers, discrete alert IDs, and single-reminder dismissal.
- Commit: `9d0228a`

### Task 3: RemindersFormList component and wiring into drawers and modals
- Created `src/components/common/RemindersFormList.tsx` using Ant Design `Form.List` with `DatePicker`, `TimePicker`, note input, delete icon, and dynamic item counting (`+ Thêm nhắc nhở (x/5)`).
- Provided `formatRemindersForForm` and `formatRemindersForSave` conversion utilities.
- Integrated `RemindersFormList` into `TaskDrawer`, `ProjectModal`, and `MilestoneModal`.
- Updated repositories (`projectRepo`, `milestoneRepo`, `taskRepo`) to persist `reminders` arrays while maintaining synchronized primary `reminderDate` / `reminderNote` values.
- Commit: `0a909a0`
