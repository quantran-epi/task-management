## Multiple Reminders: Data Model & Storage

| Option | Description | Selected |
|--------|-------------|----------|
| Array trong entity (Recommended) | Thêm mảng reminders: ReminderItem[] vào Task/Project/Milestone. Tự động chuyển reminderDate/reminderNote cũ vào mảng trong Dexie schema upgrade. | ✓ |
| Bảng Dexie riêng | Tạo table reminders riêng trong Dexie với foreign key (entityType, entityId). | |

**User's choice:** Array trong entity (Recommended)
**Notes:** Lưu trực tiếp trong Task, Milestone, Project đảm bảo atomic write và backup nhanh gọn.

## Multiple Reminders: Dismiss Mechanism & Limit

| Option | Description | Selected |
|--------|-------------|----------|
| Từng reminder có ID riêng (Recommended) | Mỗi reminder có UUID id riêng. Alert ID dạng reminder:${entityType}:${entityId}:${reminderId}. Bấm dismiss chỉ ẩn đúng reminder đó trong ngày. | ✓ |
| Giữ cảnh báo tới khi xử lý (Recommended) | Giữ nguyên cảnh báo trong Drawer cho đến khi user dismiss, sửa/xóa reminder, hoặc đổi status task sang Done. | ✓ |
| Tối đa 5 reminders (Recommended) | Giới hạn tối đa 5 reminders cho mỗi item (đủ dùng thực tế, giữ form gọn gàng). | ✓ |
| Mặc định để trống (Recommended) | Mặc định để trống (empty/undefined). Nhắc nhở kích hoạt từ đầu ngày. Người dùng chỉ nhập giờ khi thực sự cần. | ✓ |

**User's choice:** Từng reminder có ID riêng, Giữ cảnh báo tới khi xử lý, Tối đa 5 reminders, Mặc định để trống time.

## Notification Settings: Persistent Alerts & UI

| Option | Description | Selected |
|--------|-------------|----------|
| requireInteraction + Switch (Recommended) | Áp dụng requireInteraction: true cho Web Notification, kèm nút Switch trong Settings để người dùng có thể bật/tắt hành vi giữ thông báo này. | ✓ |
| Tab riêng trong Settings (Recommended) | Tạo Tab thứ 4 riêng biệt "Thông báo" (Notifications) trong SettingsView, bên cạnh Chung, Công suất, và Jira. | ✓ |
| Bộ cài đặt toàn diện (Recommended) | Gồm: Master Desktop Toggle, Persistent Banner Switch, Số ngày báo trước Deadline, Số ngày tính Ứ đọng, Checkbox bật/tắt từng nhóm cảnh báo. | ✓ |
| Tổng quan + Đúng giờ (Recommended) | Phát 1 thông báo tổng quan khi mở app; đồng thời phát thông báo riêng ngay lập tức khi đến đúng giờ của một Reminder cụ thể. | ✓ |

**User's choice:** requireInteraction + Switch, Tab riêng trong Settings, Bộ cài đặt toàn diện, Tổng quan + Đúng giờ.
**Notes:** Người dùng yêu cầu cụ thể trình duyệt không tự biến mất thông báo (`requireInteraction: true`).
