## Accomplishments

- **Unified Desktop Notification Utility (`sendDesktopNotification`):** Standardized cross-browser dispatching through `navigator.serviceWorker.ready` with a 500ms race timeout, falling back gracefully to `new window.Notification()`, respecting `requireInteraction`, and safely handling permission gates.
- **Reactive Clock Ticker in `useNotifications`:** Added 10-second clock ticker updating `currentTime` and `todayDate` directly in `useLiveQuery` dependencies, guaranteeing scheduled reminders trigger immediately when wall-clock time reaches reminder targets without requiring database writes or manual page reloads.
- **Multi-Category Desktop Alert Dispatch (`useDesktopNotification`):** Unified desktop alerts across all active categories (reminders, overdue, overload, due-soon, stale), honoring user category toggles in settings, preserving initial startup summary aggregation, and deduplicating alerts using `notifiedAlertIdsRef`.
- **Timer Monitor Settings Harmonization (`useTimerAlertMonitor`):** Replaced legacy settings query with unified `NOTIFICATION_SETTINGS_KEY`, honoring `enabledCategories.timer` and `requireInteractionEnabled`.
- **Settings Test Notification & Feedback (`NotificationSettingsCard`):** Added dedicated "Gửi thông báo thử nghiệm" button and automated confirmation alert on enabling desktop notifications.
