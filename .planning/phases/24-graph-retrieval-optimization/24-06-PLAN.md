<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| persisted grounding → React components | Stored entity identity and diagnostics become DOM content |
| reason code → tooltip | Server enum maps to fixed local explanatory copy |
| seed card → drawer callback | User gesture requests broader retrieval |
| drawer → retrieval pipeline | Fixed query starts a new server-validated turn |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-24-12 | Information disclosure | Diagnostics components | mitigate | Render only typed enum codes, fixed labels, timings, counts, and booleans; no arbitrary-object iteration or free-text stage prop. |
| T-24-13 | Tampering | Entity labels/message rendering | mitigate | Use parsed URN/kind/snapshot identity and React text/`code`; tests forbid `dangerouslySetInnerHTML`. |
| T-24-15 | Elevation of privilege | `handleFindRelated` | mitigate | Fixed query template starts normal validated new turn; callback cannot alter original scope or bypass server validation. |
| T-24-28 | Repudiation | Chat history mutation | mitigate | Tests snapshot original message ID/text/grounding and assert equality after new turn append. |
| T-24-29 | Denial of service | Repeated CTA clicks | mitigate | Per-source pending state disables CTA and suppresses duplicate turns/requests until completion/abort. |
| T-24-SC | Tampering | npm/pip/cargo installs | mitigate | No new packages; any proposed dependency stops task and is escalated. |
</threat_model>
