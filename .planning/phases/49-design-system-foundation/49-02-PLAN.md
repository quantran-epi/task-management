<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| localStorage → theme mode | user-controlled string must be validated to the two-value enum |
| cross-window event → popout | IPC/storage payload must be validated before it reaches `data-theme` |
| tokens.ts → CSS custom properties | generated values must never carry user input |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-49-05 | Tampering | `localStorage['taskmate_theme']` | mitigate | Accept only exactly `'light'` or `'dark'`; anything else falls back to OS then light; never write raw value into DOM/CSS |
| T-49-06 | Tampering | `emitTo` / `storage` broadcast payload | mitigate | `subscribeToThemeBroadcast` checks exact `{ mode: enum }` shape; ignore malformed events; unsubscribe on teardown |
| T-49-07 | Tampering | `applyCssVariables` target | mitigate | Values come only from typed `as const` token objects; function takes an HTMLElement ref, not arbitrary user input |
| T-49-08 | Denial of service | OS `change` listener after explicit override | mitigate | Listener removed as soon as a valid localStorage override exists; no listener accumulation across toggles |
| T-49-SC | Tampering | npm packages already installed | accept | No new packages in this plan; no install step |

</threat_model>
