## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, `--find-gap-xs` |
| sm | 8px | Compact element spacing, `--find-gap-sm`, Button `paddingInline` |
| md | 16px | Default element spacing, `--find-gap-md` |
| lg | 24px | Section padding, tree row height (`--row`) |
| xl | 32px | Layout gaps |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Exceptions: `--island-gap: 6px` (khoảng cách island workbench — giá trị đã khóa trong `workbench-tokens.css`, giữ nguyên). Các dimension token sau là kích thước cố định, KHÔNG phải spacing: `--control-height` 30px, `--titlebar-height` 40px, `--statusbar-height` 26px, `--stripe-width` 36px, `--tabbar-height` 36px, `--find-field-height` 34px, `--tree-indent` 12px, `--tree-icon-size` 16px. Nguồn: `workbench-tokens.css` + `AntdThemeAdapter.tsx`.

## Typography

Chỉ 4 kích thước được phép; mọi `font-size` inline lẻ/fractional (ví dụ `13.5px` hiện có trong `AntdThemeAdapter.tsx`) phải migrate về token (D-10).

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| XS / meta | 11px (`--font-size-xs`) | 400 regular | 1.4 |
| Label / compact | 12px (`--font-size-small`, `--font-mono`) | 400 regular | 1.4 |
| Body / UI | 13px (`--font-size-ui` / `--font-size-base`) | 400 regular | 1.5 |
| Heading | 16px | 600 semibold | 1.2 |

Weights (đúng 2): regular 400, semibold 600. Font family: UI `var(--font-ui)` = Inter fallback hệ thống; mono `var(--font-mono)` = IBM Plex Mono. Giữ nguyên giữa light và dark (D-08). Nguồn: `workbench-tokens.css:67-72`, `AntdThemeAdapter.tsx:46-47`; phase 25.5 WB-TYPO.

## Color

Giá trị lấy trực tiếp từ `workbench-tokens.css` (light `:root` / dark `:root[data-theme="dark"]`) và `AntdThemeAdapter.tsx` — phase này thống nhất chúng thành một nguồn, không đổi hex.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | Light: frame `#e9eaee`, app `#ffffff` · Dark: frame `#11151d`, app `#171d27` | Nền frame, nền app, surface chính |
| Secondary (30%) | Light: island `#ffffff`, elevated `#f7f8fa` · Dark: island `#1c2330`, elevated `#171d27` | Island/card, tool window, sidebar, popup, input |
| Accent (10%) | Light: `#2f62d8` · Dark: `#6a9bff` | Xem "Accent reserved for" bên dưới |
| Destructive | Light: `#d1484f` · Dark: `#ff8289` | Chỉ destructive action (xóa, reject, bulk revert) |

Accent reserved for (danh sách cụ thể — không phải "mọi interactive element"):
- Primary Button (nền accent, chữ `--accent-fg`).
- Link text và link hover (`--link` / `--link-hover`).
- Active editor tab: thanh trên cùng 2px + chữ active (`workbench-expui-tab.active::after`).
- Selected tree row / selected chip: nền `--accent-soft`, chữ/viền accent.
- Resize handle hover/drag indicator và focus ring 2px.
- Status dot/badge ở trạng thái "modified"/"in-progress" (xem map bên dưới).

Không dùng accent cho: nền island, border thường, disabled control, nội dung text thường, decoration thuần túy.

### Shared Status Color Map (D-12 — một map cho Tag/Badge/StatusDot mọi domain)

| Status | Light | Dark | Slot |
|--------|-------|------|------|
| success / done | `#338555` | `#4ade80` | `--success` |
| warning / pending | `#a56906` | `#e8a13a` | `--warning` |
| danger / error / deleted | `#d1484f` | `#ff8289` | `--danger` |
| info / in-progress | `#22d3ee` | `#22d3ee` | `--info` |
| accent / modified | `#2f62d8` | `#6a9bff` | `--accent` |

Ba CR type badge (`STATE` D-17) map vào cùng map này — không giữ map rời: New Feature → `info/accent` `#1677ff`, Enhancement → `success` `#52c41a`, Bugfix → `warning` `#faad14`. File-status token hiện có (`--status-untracked`, `--status-added`, `--status-deleted`, `--status-modified`) được gom vào cùng nguồn, giữ giá trị light/dark đã duyệt. Mọi giá trị trên phải được sinh từ `tokens.ts`, không hardcode trong view (TOKEN-04).
