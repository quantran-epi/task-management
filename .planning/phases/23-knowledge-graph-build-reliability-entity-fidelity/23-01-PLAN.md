<objective>
Eliminate Vietnamese entity name mutilation across URN generation, Cypher queries, FactSummaryDTO, and UI display per ENTITY-FIDELITY-01.

Purpose: Prevent non-ASCII Vietnamese characters from turning into chains of underscores (`X__l__merchant_b__t__ch_i`) in URNs and restore original human-readable Vietnamese names (`Xử lý merchant bị từ chối`) on graph fact views without string-splitting sanitized URN segments.
Output: Unicode NFD slugification in `identity.ts`, node canonical name joins in `neo4jRepository.ts` & `graphRepository.ts`, clean DTO mapping in `graphBuildService.ts`, concise entity prompt rules in `llmExtraction.ts`, and regression tests in `graphIdentity.test.ts` and `graphBuildService.test.ts`.
</objective>
