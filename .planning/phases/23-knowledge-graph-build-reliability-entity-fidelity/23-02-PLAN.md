<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Process File I/O → Local Disk | Cache files written and read under `EXTRACTION_CACHE_DIR`. |
| LLM Response → Serialized Cache | Untrusted LLM output serialized to JSON on disk. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-23-02 | Tampering / Traversal | `ChunkExtractionStore.loadDiskCache` | mitigate | Cache key is strictly validated as a 64-char hex string (`[0-9a-f]{64}`). SetId is validated as UUID. Paths are resolved using `path.join(cacheDir, setId, cacheKey + '.json')`. |
| T-23-03 | Denial of Service | `saveDiskCache` | mitigate | Use atomic write (`.tmp` file followed by `fs.rename`) to prevent corrupted cache files upon abrupt process shutdown. |
| T-23-SC | Tampering | npm dependencies | mitigate | Zero new runtime dependencies; uses standard Node.js `node:fs/promises` and `node:crypto`. |
</threat_model>
