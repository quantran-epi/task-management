<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user-selected JSON file → preview | An untrusted file is parsed and inspected before any db write. |
| preview confirm → applyConfigProfile | The gate is the only path from reviewed data into the canonical store. |
| applied envelope → post-import checklist | The checklist must reflect exactly the blank/flagged fields without re-reading secrets. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-46-06 | Tampering | ImportProfilePreviewModal confirm gate | high | mitigate | Exact `IMPORT` confirm text plus valid-payload requirement in okButtonProps.disabled; invalid/backup payload cannot enable apply; zero db writes during preview. |
| T-46-07 | Denial of service | ConfigProfileImportCard file size guard | medium | mitigate | 50 MB limit in beforeUpload with Upload.LIST_IGNORE and notification before JSON.parse. |
| T-46-11 | Tampering | ImportProfilePreviewModal → applyConfigProfile db prop | medium | mitigate | db prop threaded card → modal → applyConfigProfile(envelope, db); no defaultDb import; test asserts the injected db is the one written. |
| T-46-12 | Information disclosure | ImportProfilePreviewModal / PostProfileImportChecklist Telegram leakage | low | mitigate | No Telegram field or checklist item is rendered; invalid telegramSettings payloads are rejected by the strict schema; test asserts no Telegram item appears. |

</threat_model>
