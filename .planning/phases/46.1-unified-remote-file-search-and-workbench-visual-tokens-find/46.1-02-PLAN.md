<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| shortcut event → action dispatch | A global keydown crosses into a workbench action while focus may be in a text input. |
| layoutStore seed → dialog | Active remote identity crosses into the dialog; a second target picker must not be invented. |
| remote grep/tree/file content → React rows and preview | Remote-controlled bytes cross into DOM rendering. |
| preview fetch → 256 KB cap | An oversized or binary remote file crosses into the renderer and must be bounded. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-46.1-05 | Tampering | useGlobalKeymap shortcut handler | low | mitigate | Handler placed before the isInput guard with explicit ctrl/meta+shift+F checks; a plain Ctrl+F is not intercepted. |
| T-46.1-06 | Information disclosure | FindInRemoteFiles seed from layoutStore | medium | mitigate | Reuse activeRemoteConfigId/repoPath/branch only; no new target store, no implicit network target. |
| T-46.1-07 | Tampering | parts.tsx HighlightedText / CodePreview | high | mitigate | Range-based slicing into React text nodes with <mark>; never dangerouslySetInnerHTML on remote content. |
| T-46.1-08 | Denial of service | preview fetch and VirtualizedList | medium | mitigate | 256 KB preview cap + truthful notice + open-full-file action; rows windowed by VirtualizedList. |
| T-46.1-SC | Tampering | npm installs (none this plan) | high | mitigate | No new packages; all UI uses locked antd 6.6.5 / @tanstack/react-virtual 3.14.26. |
