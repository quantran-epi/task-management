# Phase 46.1 — UI Design Contract

> Visual and interaction contract for the unified remote search surface and shared workbench visual tokens. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> **Primary visual source of truth:** the approved `remote-find-draft.html`. Where this spec gives a value, it is taken from that draft or from locked decisions D-01..D-13 in `46.1-CONTEXT.md`.

## Design System

| Property | Value |
|----------|-------|
| Tool | none (no shadcn/Tailwind; shadcn init gate not applied — Ant Design is locked by CLAUDE.md) |
| Preset | not applicable |
| Component library | Ant Design 6.6.5 (`antd`, locked UI decision in CLAUDE.md) |
| Icon library | `@ant-design/icons` 6.3.4 — import icons individually |
| Font | Inter (UI) + IBM Plex Mono (code/data), each bundled locally with the Google Fonts Vietnamese subset (`U+1EA0-1EF9`), offline-capable in Tauri |
| Styling | CSS custom properties in `src/styles/workbench-tokens.css` consumed by components; AntD theme mirrored in `src/workbench/AntdThemeAdapter.tsx` |

**Hard rule (D-02):** the shared token file is the single source of truth. Touched surfaces (Remote Git Explorer shell/tree/rows, Find in Remote Files dialog, adjacent global search result rows) must consume `var(--token)` values and contain **no literal hex colors or one-off row/control sizes**. Changing one token in `workbench-tokens.css` must propagate to every migrated surface without editing a component literal.

**Palette conflict resolved (D-01):** the approved draft palette wins. Set `--accent: #2f62d8` (dark `#6a9bff`) in BOTH `workbench-tokens.css` and `AntdThemeAdapter.tsx` (`colorPrimary: '#2f62d8'`) in the same change. Do not leave the current purple `#5b4fe8` behind; do not layer a second token set on top.

## Typography

Fonts are locally bundled; import the **default per-weight CSS** (e.g. `@fontsource/inter/400.css`) from `src/main.tsx`, never the subset-only CSS — per-subset files lack `unicode-range` and would break Latin glyphs. Vite hashes the woff2 assets into `dist/assets` for offline use. If the strict "no new npm dependency" reading applies, vendor the woff2 into `public/fonts/` with hand-written `@font-face` blocks that include `unicode-range` for both latin and vietnamese subsets. Visual result is identical; the contract is route-agnostic.

Font stacks (tokenized): `--font-ui: "Inter", -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif;` and `--font-mono: "IBM Plex Mono", "SFMono-Regular", Consolas, monospace;`

| Role | Size | Weight | Line Height | Family |
|------|------|--------|-------------|--------|
| Body | 13px | 400 | 1.5 | Inter |
| Label / meta | 11px | 400 | 1.4 | Inter |
| Heading (dialog title) | 13px | 600 | 1.2 | Inter |
| Code / data | 12px | 400 | 19px fixed | IBM Plex Mono |

Supporting roles taken verbatim from the draft (chrome around the dialog and compact readouts). These extend the four-role core above; they are part of the contract, not suggestions:

| Element | Size | Weight | Family |
|---------|------|--------|--------|
| Page display `h1` | clamp(26px, 3vw, 38px), lh 1.1 | 700 | Inter |
| Eyebrow | 12px, letter-spacing .14em, uppercase | 700 | Inter |
| Led / descriptive text | 15px, lh 1.6 | 400 | Inter |
| Result row / tree / code editor | 12px | 400 | IBM Plex Mono |
| Preview source | 11.5px, lh 19px | 400 | IBM Plex Mono |
| Footer / status / legend chip | 10.5–11px | 400 | Inter / IBM Plex Mono |
| Active preview line number | inherited | 600 | IBM Plex Mono |

Weights loaded (draft `Inter:wght@400;500;600;700`, `IBM Plex Mono:wght@400;500;600`): 400 regular (body, code), 500 medium (emphasized mono), 600 semibold (dialog title, active labels), 700 bold (display + eyebrow). This is intentionally wider than a typical two-weight system because D-01 locks the draft's multi-weight typographic identity.

Vietnamese requirement: any UI label or search pattern containing diacritics (e.g. `Tìm trong tệp`, `toàn bộ nhánh`) must render with the bundled Vietnamese glyphs offline — no system-font fallback, no network request.

| Role | Value | Usage |

| Accent (10%) | `--accent: #2f62d8` (dark `#6a9bff`), `--accent-soft: #e4ecff` (dark `#1e3156`), `--accent-fg: #ffffff` (dark `#071224`) | See reserved list below |

| Token | Light | Dark | Usage |

| `--fg-subtle` | `#64748b` | `#9aa8bd` | Secondary text, labels, statuses |
| `--fg-faint` | `#94a3b8` | `#71819a` | Line numbers, file paths, twisty, chain prefix |
| `--border` | `#d8dee9` | `#2c3646` | Standard borders |
| `--border-strong` | `#b9c3d3` | `#3d4a5f` | Dialog border, focus/handle line, dashed hint |
| `--match` | `#ffe08a` | `#a97c16` | Search-match highlight background |
| `--match-ink` | `#2b2100` | `#fff8e1` | Search-match highlight text |
| `--shadow` | `0 24px 70px rgba(23,35,58,.24), 0 3px 12px rgba(23,35,58,.12)` | `0 24px 70px rgba(0,0,0,.55), 0 3px 12px rgba(0,0,0,.35)` | Dialog elevation |
| folder icon | `#c98614` | `#c98614` | Folder glyph in tree |

Match highlight is a distinct semantic color, not accent: `<mark>` uses `--match`/`--match-ink`. Do not substitute accent for match highlighting.

**Accent reserved for:** focused pattern-input border and focus ring; active tree row background (`--accent-soft`) and text; active result row file-path text; active toggle/tab (`on`) background, border, and text; active preview line background tint (`color-mix(in srgb, var(--accent) 10%, transparent)`) and line number; code-type icons in tree; spinner top arc; eyebrow text. Nothing else — not every button, not the destructive badge, not the match highlight.

Dark mode: extend `workbench-tokens.css` with a dark block keyed on `prefers-color-scheme: dark` plus `:root[data-theme="dark"]`, matching the draft's dual strategy and the app's `useThemeMode` (`prefers-color-scheme`). The Find dialog consumes variables only, so it must switch with the token block. Flag the hardcoded `data-theme="light"` in `AntdThemeAdapter.tsx` for the planner to align; the dialog must remain readable under a dark OS setting.

## Dialog Layout (two-pane)

Structure, top to bottom, matching the draft:

1. **Drag/title bar** (`.drag`, 38px): grip glyph (decorative, `aria-hidden`), title "Find in Remote Files" (13px/600), inline status (`aria-live="polite"`), right-side icon buttons: File mask, Pin (toggle), Close.
2. **Fields** (`.fields`, padding 10px 16px 8px): focused pattern input row (34px, border accent + soft outer ring, mono 13px, search glyph) with inline toggles `Aa` / `Word` / `.*` (22px, `on` state = accent-soft bg + accent border/text). Below it the file-mask line (11px): label "File mask", a `<code>` chip, and mono context text "search tracked content on ref `<ref>`".
3. **Scopes** (`.scopes`, 11px): mode tabs Content/Files/Folders, a 12px spacer, scope tabs Whole ref/Directory, and a right-aligned `--scopeval` showing `repo / ref`.
4. **Split** (`.split`, CSS grid rows `210px / 7px / 246px`, `min-height: 0`):
   - **Results pane** (`.results`, scrollable): flat virtualized rows.
   - **Resize handle** (`.handle`, 7px, `cursor: row-resize`, decorative `aria-hidden`).
   - **Preview pane** (`.pane`): header 30px (filename strong + path + `line N` right-aligned) over a scrollable code area.
5. **Footer** (`.footer`, 38px): keyboard hints `↑↓ navigate`, `Enter open at line`, `Esc close`, a flex spacer, and `preview follows selection · 256 KB cap`.

Dialog frame: `position: absolute; top: 22px; left: 50%; transform: translateX(-50%); width: min(820px, calc(100% - 32px)); max-height: calc(100% - 44px); border: 1px solid var(--border-strong); border-radius: 11px; box-shadow: var(--shadow); overflow: hidden;` Modeless and resizable near the top of the workbench, above the Remote Git Explorer tree (which stays visible behind it). Under 760px viewport width, the draft's responsive rules apply: dialog becomes full-width relative, sidebar/editor chrome hidden.

**Result row anatomy** (`.rrow`, 24px, gap 12px, padding 0 16px, mono 12px, nowrap): `.rcode` flex:1 with ellipsis containing highlighted code (`<mark>` on match ranges) + `.rfile` right-aligned faint 11px `relPath:line` (11px). On the active row (`.rrow.on`): background `--accent-soft`, `.rfile` turns `--accent`. Files/Folders rows substitute an icon + path + count for the code snippet.

**Preview anatomy** (`.code`, mono 11.5px/19px): each `.cline` is a flex row with a 52px right-aligned, user-select-none gutter `.lno` and a `white-space: pre` source span. All matches in the file are wrapped in `<mark>`. The active line (`.cline.cur`) gets the accent tint background and an accent/600 line number. Preview scrolls the active line to vertical center (`block: 'center'`).

## Interactions & Input Contract

| Interaction | Behavior |
|------------|----------|
| Open | `Ctrl/Cmd+Shift+F` (both `ctrlKey` and `metaKey`, with `shiftKey` and `key === 'F'|'f'`) dispatches `find.inPath`. Place the handler beside the existing `Ctrl+K` handler **before** the input guard so it works while typing in the query input. Dialog seeds from active SSH config / repo path / branch in `layoutStore`. |
| Query input | Live search, **150 ms debounce** using `setTimeout`/`clearTimeout` in an effect. Pattern is DATA: never interpolated raw into a shell command; pass through `escapeShellArg`/`-e`. |
| Modes | One input drives Content, Files, Folders. Content = scoped `git grep -I`; Files/Folders = cached `git ls-tree` filtered client-side by query + mask. |
| Scope | Whole ref vs Directory. Directory uses a repo-confined pathspec via `confineRepoPath`. |
| Options | Match Case (`Aa`), Words (`Word`), Regex (`.*`) toggles; file mask chip. |
| Keyboard nav | Arrow Up/Down and PageUp/PageDown move the active result (wrap/clamp at bounds); preview follows the active result immediately. |
| Enter | Opens the remote file in a readonly tab at the exact match line via `layoutStore.openTab` with one-shot `initialLine`. |
| Shift+Enter | Opens a second readonly tab (distinct id) — side-target fallback, since no side API exists. |
| Esc | Closes the dialog unless pinned. |
| Ctrl/Cmd+Enter | Toggles pinned state (matches draft hint `⌘ Enter` pin). |
| Pin | Pin icon toggles the same pinned state; pinned dialog ignores Esc, Close button still closes. |
| Stop / cancel | Cancels the in-flight request via `cancelToolCall(callId)` using a stable per-request `callId`; **partial results are kept**. A query change marks current results stale immediately; late responses with a mismatched sequence never overwrite current results. |
| Reveal | Selecting "Reveal in Explorer" maps the result path through the compact chain's `keyOfPath` map before `setSelectedKeys`/`setExpandedKeys`, so reveal still highlights the merged node. |

## UI Considerations

Applicable state considerations resolved: 9 covered, 0 unresolved.

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| empty | Result pane | ✅ covered | No matches render the documented empty copy plus next-step guidance; preview pane shows a muted placeholder. |
| loading | Dialog status, result pane | ✅ covered | Spinner + "Searching…" in `aria-live` status while `status: searching`; results area shows a subtle progress treatment, not blank. |
| error | Dialog status | ✅ covered | Truthful error notice with retry guidance (see Copywriting). |
| stale | Result pane | ✅ covered | Query change sets `stale: true` immediately: results dim/annotated "Results out of date"; late seq-guarded responses ignored. |
| partial | Result pane after Stop | ✅ covered | Cancelled runs keep the matches collected before cancellation with a "Stopped — partial results" note. |
| overflow | Result rows, tree rows, preview | ✅ covered | `nowrap` + ellipsis on `.rcode`/`.label`; long `relPath:line` and dotted chains truncate; status badges preserved via Tooltip. |
| long-text | File paths, dotted chain labels | ✅ covered | Terminal segment kept; dotted prefix uses `--fg-faint` and may ellipsize; full path available in Tooltip. |
| zero-one-many | Result set | ✅ covered | 0 (empty), 1 (single row + preview follows it), many (virtualized list, bounded at 2000). |
| truncation | Result set / preview | ✅ covered | Result cap 2000 → "results truncated" notice; preview 256 KB / binary → truthful notice + "Open full file". |
