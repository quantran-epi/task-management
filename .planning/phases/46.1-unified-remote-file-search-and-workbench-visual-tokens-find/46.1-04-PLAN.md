<objective>
Turn the approved draft's visual identity into a shared, offline-capable token system and migrate only the surfaces this phase touches: Remote Git Explorer shell/tree/rows, the Find dialog, and adjacent global search rows. Bundle Inter and IBM Plex Mono locally with Vietnamese subsets and verify that a single token change propagates without component edits.

Purpose: D-01/D-02/D-03 are a costly single-source-of-truth commitment. The research flagged a concrete conflict — draft accent `#2f62d8` vs current `#5b4fe8`, and a likely partial-migration failure if tokens and component literals diverge. UI-SPEC resolved the accent in favor of the draft. Doing this last (after the dialog and tree render exist) means there is one migration pass over real components, not speculative ones.

Output: locally bundled fonts, a single token source with light/dark blocks, AntD theme aligned to it, migrated touched components with no literal hex colors, and a source-level test proving token usage.
</objective>
