<objective>
Establish the correctness backbone for Find in Remote Files as a vertical tracer: a raised grep limit ceiling proven end to end, and a pure FindSession state machine that proves stale and cancelled results cannot overwrite current results. This is the first layer every later plan depends on — the dialog (plan 02) drives this session, and the preview consumes its rows.

**Why a tracer first:** D-08 cancellation/stale semantics and D-09 escaping are one-way trust-boundary decisions. Proving them with a runnable test on the smallest possible path catches a broken contract before UI is layered on. `grepRemoteRef` already ships escaped, confined, byte-capped grep parsing; this plan extends it (not duplicates it) and adds the genuinely new session module.

Purpose: Per 46.1-RESEARCH.md, the expensive correctness is already paid for in `gitRemoteService.ts` — the only service gap is the 200 limit vs D-10's 2000. The other new piece is the session state machine (OpenIdea `FindSession` shape). Both must be green before any component wires them.

Output: `grepRemoteRef` accepting 2000 with escaping intact, a pure `FindSession` module, and focused tests proving the limit, stale guard, cancel-keeps-partial and injection safety.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| query input → git command builder | Untrusted search pattern, mask and directory cross into a remote `git grep` command. |
| renderer → Tauri SSH process | A cancel request crosses from renderer to Rust `callId` -> process map. |
| remote grep stdout → session state | Remote-controlled bytes (paths, line text) cross into renderer state and later into React text nodes. |

| T-46.1-01 | Tampering | grepRemoteRef / query.ts command construction | critical | mitigate | Every user value via `escapeShellArg`; pattern via `-e`, ref after `--end-of-options`, directory after `--` with `confineRepoPath`; whole-command `toBe` injection test; no command string built in renderer. |
