## End-of-Phase Human-Check UAT (Plan 05, Task 2)

Chạy trên app Tauri thật với SSH config / repo / branch thật. Không xác nhận bằng đọc code — mỗi mục cần app đang chạy. Báo "all confirmed" hoặc nêu mục fail.

1. Nhấn `Ctrl/Cmd+Shift+F` từ ô query và từ cây — dialog Find mở gần đỉnh, resize được; Search Everywhere vẫn chạy local.
2. Gõ pattern có dấu tiếng Việt — hiển thị đúng khi app offline (không gọi mạng).
3. Đổi Content/Files/Folders, mask, scope Whole ref/Directory, Match Case/Words/Regex — kết quả đổi; dòng Content có `relPath:line`.
4. Arrow/PageUp/PageDown đổi dòng active — preview dưới cập nhật, cuộn tới dòng active, highlight mọi match.
5. Enter mở tab readonly đúng dòng; Shift+Enter mở tab thứ hai; Reveal chọn file trong cây compact.
6. Search rồi nhấn Stop — giữ kết quả một phần; đổi query nhanh không để response trễ ghi đè dòng hiện tại.
7. File >256 KB hoặc binary — hiện thông báo cắt ngắn trung thực, Open full file chạy được.
8. Dependency single-child sâu — nhãn dotted, badge trạng thái còn thấy, reveal vẫn chọn node compact.
9. Sửa thử một token (vd. `--match`) trong `workbench-tokens.css` — dòng Find, explorer đã migrate và global search đổi cùng, không sửa component; hoàn tác.
