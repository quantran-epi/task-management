## Remote Search UX

| Option | Description | Selected |
|--------|-------------|----------|
| Keep three inline search inputs | Preserve current RemoteGitExplorer UI and improve styles only | |
| One unified modal with result/preview panes | Add Ctrl/Cmd+Shift+F Find in Remote Files modeled on OpenIdea/IntelliJ | ✓ |
| Extend Search Everywhere only | Make local Search Everywhere search remote files without a new dialog | |

**User's choice:** One unified modal with result/preview panes.
**Notes:** User explicitly described OpenIdea Ctrl+Shift+F: results with `file:line` above, preview with surrounding lines below, arrow navigation updates preview.

## Visual Tokens

| Option | Description | Selected |
|--------|-------------|----------|
| Keep draft styling only in the search dialog | Fastest, but no app-wide benefit | |
| Promote draft palette/fonts/controls to shared tokens | Central CSS tokens consumed by new and migrated workbench surfaces | ✓ |
| Introduce a new UI framework/design system | Broader rewrite with new dependency | |

**User's choice:** Promote draft palette/fonts/controls to shared tokens.
**Notes:** User asked whether changing one token propagates everywhere; answer is yes only if literals are removed. CONTEXT.md locks removal of hardcoded colors in touched surfaces.

---

## Fonts

| Option | Description | Selected |
|--------|-------------|----------|
| Use system fonts | No bundled font assets | |
| Use Google Fonts CDN at runtime | Simpler, but breaks offline Tauri behavior | |
| Bundle Inter + IBM Plex Mono locally with Vietnamese subsets | Offline-capable and preserves approved draft look | ✓ |

**User's choice:** Bundle locally with Vietnamese subsets.
**Notes:** Verified Google Fonts serves `vietnamese` subsets for both families, covering `U+1EA0-1EF9`.
