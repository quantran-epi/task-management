### WR-01: Regex mode could not use ERE constructs (git grep ran BRE)
**Files modified:** `src/services/gitRemoteService.ts`, `src/services/__tests__/gitRemoteService.test.ts`
**Commit:** `68aa975a`
**Applied fix:** `grepRemoteRef` now pushes `-E` in regex mode (`literal === false`) so `foo|bar`, `+`, `?`, `{n}` work and agree with the JS regex used by the client highlighter. Added a whole-command assertion test for `-E` with pattern `foo|bar`.

### WR-02: "Words" checkbox was a no-op in literal mode
**Files modified:** `src/services/gitRemoteService.ts`, `src/services/__tests__/gitRemoteService.test.ts`, `src/workbench/search/find/query.ts`, `src/workbench/search/find/__tests__/query.test.ts`
**Commit:** `6e08ea6e`
**Applied fix:** Added `words?: boolean` to `GrepRemoteRefOptions` and push git's `-w` flag in both literal and regex modes. `buildGrepOptions` now passes `words: query.words` through and drops the hand-written `\b` wrapping (which literal `-F` treats as text and which double-bounded in regex mode). Tests updated: query contract asserts no option value carries `\b`; service test asserts `-w` in both modes.

### WR-03: Stale in-flight search leaked into a reopened/reseeded dialog; no Stop path
**Files modified:** `src/workbench/search/find/FindInRemoteFiles.tsx`, `src/workbench/search/find/store.ts`, `src/workbench/search/find/__tests__/FindInRemoteFiles.test.tsx`
**Commit:** `da77d94d`
**Applied fix:** Added an effect that calls `session.cancel()` when the dialog closes (`open === false`) and cancels the *previous* session when `seedKey` changes (tracked via a ref, since `useMemo` builds a new session on reseed). Added a Stop icon button (single-source label `FIND_CONTROL_LABELS.stop`) bound to `session.cancel()`, shown while `status === 'searching'`; the existing `FindSession.cancel()` already emits `status: 'partial'` so `FIND_STATUS_COPY.partial` is now reachable. Added component tests: cancel on close (late response cannot commit), Stop cancels + keeps partial + rejects late response, and cancel of previous session on reseed.

### WR-04: Files/Folders with empty pattern fetched nothing and rendered an empty list

Added single-source `FIND_STATUS_COPY.emptyPrompt` ("Type to search files/folders.") rendered as a `find-empty-prompt` element in the results pane. Added a test asserting no remote call + prompt in both Files and Folders modes with an empty pattern.

### WR-05: getRecentCommits interpolated limit into the shell unnormalized
**Files modified:** `src/services/gitRemoteService.ts`, `src/services/__tests__/gitRemoteService.test.ts`
**Commit:** `b0b24945`
**Applied fix:** Normalize at the service boundary with `Math.min(Math.max(1, Math.floor(Number(limit)) || 20), 100)` and pass through `escapeShellArg(String(safeLimit))`, matching `grepRemoteRef`'s convention. Added tests: a limit of 500 clamps to `'100'` in the command; a non-numeric injection string cannot inject shell syntax and falls back to `'20'`.
