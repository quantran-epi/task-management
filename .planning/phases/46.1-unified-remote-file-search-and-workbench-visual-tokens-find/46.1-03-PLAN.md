  <behavior>
    - A folder with exactly one visible child folder merges into one node with label `parent.child`, key = parent path, path = last folder, chain = all merged paths.
    - Compaction stops at a branch point (two or more visible children), a file child, a source root (e.g. src/main/java), a reveal target path, and any node carrying a gitStatus badge.
    - keyOfPathFor maps every path in a merged chain to the compact node's stable first-path key.
    - A status badge node is never merged away; its gitStatus survives on the compacted output.
    - A single child chain of length 1 is unchanged (no dotted label).

|----------|-------------|
| raw getRemoteTree nodes → compact tree render | Remote-controlled paths and status labels cross into tree nodes and tooltips. |
| reveal target path → key mapping | A result path crosses into explorer selection; it must resolve to a compact node key. |
| Folders-mode reveal → layoutStore | A search result crosses into one-shot reveal state consumed by the explorer. |

</threat_model>
