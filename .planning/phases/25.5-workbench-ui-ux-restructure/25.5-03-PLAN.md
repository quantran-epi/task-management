# Plan 25.5-03: Left Tool Windows Restructure: Dual Explorer for Projects & Docs

## Goal
Tái cấu trúc Left Tool Window thành 2 Explorer độc lập, chuyên biệt và giàu tính năng:
1. `Project Explorer` (`Alt+1`): Cây Project → Milestone → Task, click vào mở trực tiếp tab tương ứng ở Center.
2. `Docs Explorer` (`Alt+2`): Cây danh mục Docs / Markdown Notes, click vào mở view tài liệu ở Center.

## Scope & Target Files
- `src/workbench/toolwindows/LeftToolWindow.tsx` (điều hướng linh hoạt theo `activeId` của slot trái: `'projects'` hoặc `'docs'`)
- `src/workbench/toolwindows/ProjectExplorer.tsx` (tạo mới: cây phân cấp hoàn chỉnh Project → Milestone → Task kèm action mở tab)
- `src/workbench/toolwindows/DocsExplorer.tsx` (tạo mới: cây tài liệu Notes kèm action mở note trong Editor)
- `src/workbench/toolwindows/Stripe.tsx` & `src/workbench/WorkbenchLayout.tsx` (cấu hình icons `Alt+1: Projects`, `Alt+2: Docs`)

## Tasks
1. **Xây dựng `ProjectExplorer`**:
   - Sử dụng Ant Design `Tree` hiển thị cây phân cấp 3 tầng:
     - Level 1: Project (icon folder / màu sắc dự án).
     - Level 2: Milestone (icon flag / target).
     - Level 3: Task (icon checkbox / status / priority).
   - Click Project: `openTab` mở `Project Overview` tab.
   - Click Milestone: `openTab` mở `TasksView` lọc theo Milestone.
   - Click Task: `openTab` mở `Task Detail` tab ở Center Editor.
   - Quick search input ở trên đầu cây để lọc nhanh Project/Milestone/Task.
2. **Xây dựng `DocsExplorer`**:
   - Truy vấn danh sách ghi chú từ `db.notes` bằng `useLiveQuery`.
   - Phân cấp theo tags hoặc thư mục logic.
   - Click Document: `openTab` mở `NotesView` với `params: { doc: noteId }`.
   - Nút "New Note" nhanh ở header của panel.
3. **Refactor `LeftToolWindow` & `Stripe`**:
   - Dựa vào `leftActiveId` (`'projects'` hoặc `'docs'`), render đúng component Explorer.
   - Nút toggle trên Left Stripe chuyển đổi mượt mà giữa 2 views hoặc đóng/mở panel.
   - Xóa bỏ các navigation buttons chắp vá trước đây khỏi panel trái.
4. **Validation**:
   - Click từng node trong ProjectExplorer mở đúng tab tương ứng ở Center.
   - Click note trong DocsExplorer mở đúng tài liệu để soạn thảo.

## Verification Criteria
- [ ] Left Stripe có 2 icons: Projects (`Alt+1`) và Docs (`Alt+2`).
- [ ] Ấn icon Projects mở Project Explorer; ấn icon Docs mở Docs Explorer.
- [ ] Nhấp đúp hoặc nhấp chọn Task trong cây Project mở đúng chi tiết Task ở Center Editor.
- [ ] Nhấp chọn Note trong Docs Explorer mở đúng tài liệu ở Center Editor.
