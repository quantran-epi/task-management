# Phase 25.5: TaskMate Workbench UI/UX Comprehensive Restructure & Precision Layout — Context

## Objective
Tái cấu trúc toàn diện bố cục và trải nghiệm người dùng (UI/UX) của TaskMate Workbench theo chuẩn JetBrains ExpUI Islands Layout:
- Sửa triệt để cơ chế resize handle của `react-resizable-panels` (phân cách rõ ràng, hover highlight xanh, kéo mượt mà, không kẹt).
- Nâng scale cỡ chữ (typography) từ 12px lên 13.5px–14px, xóa bỏ chữ li ti khó đọc.
- Bỏ cụm nút điều khiển cửa sổ vô nghĩa trên TopBar; đưa Quick Views Navigation lên TopBar.
- Tái cơ cấu Left Explorer chuyên biệt thành 2 cây dữ liệu thực thụ: Project Explorer (Project → Milestone → Task) và Docs Explorer (Thư mục → Markdown Notes), nhấp chuột mở trực tiếp tab tương ứng ở Center.
- Chuyển AI Assistant và Item Inspector sang Right Tool Window dockable; bãi bỏ Bottom Tool Window để giải phóng tối đa chiều dọc cho Center Editor.
- Tinh giản StatusBar (26px), tích hợp Active Timer Widget chạy thực tế kèm nút Play/Pause nhanh.

## Key Decisions & Architecture

### 1. Panel Resize Handle Fix
- Vấn đề: `PanelResizeHandle` trong `WorkbenchLayout.tsx` đang dùng `style={{ width: 6, background: 'transparent' }}`, không có visual indicator, khó bắt trúng chuột và xung đột layout khi panel con unmount/mount.
- Giải pháp: Tạo component `WorkbenchResizeHandle` chuyên dụng:
  - Hiển thị divider line mảnh (1px border), hit-box 6-8px.
  - Hover state: đổi màu sang `var(--accent, #3871e1)` với transition mượt mà.
  - Active dragging state: giữ highlight xanh dương và con trỏ `col-resize` / `row-resize`.
  - Phối hợp chặt chẽ với `layoutStore.ts` để lưu và khôi phục panel sizes mà không xung đột `autoSaveId`.

### 2. Typography & Spatial Density
- Vấn đề: Cỡ chữ 10–12px quá nhỏ, line-height dày đặc gây mỏi mắt.
- Giải pháp:
  - Nâng `--font-size-ui` lên `13.5px`.
  - Body text đạt `14px`, subtext/captions tối thiểu `12px`.
  - Tăng nhẹ chiều cao tab bar (36px), title bar (40px) để tỷ lệ cân đối với cỡ chữ mới.

### 3. TopBar Refinement
- Xóa bỏ các nút `handleMinimize`, `handleMaximize`, `handleClose`.
- Bố trí 3 khu vực rõ ràng:
  - Trái: Project Avatar + Project Switcher Dropdown.
  - Giữa: Search Everywhere Button (`Double Shift` / `Ctrl+K`).
  - Phải: Quick Views Pill/Segmented (`Dashboard`, `Planner`, `Analytics`), nút trigger AI Chat, nút Settings.

### 4. Left Explorer: Dual Specialized Trees
- `projects` slot (`Alt+1`):
  - Cây phân cấp Project → Milestone → Task.
  - Click Project: Mở tab Project Overview.
  - Click Milestone: Mở tab Tasks lọc theo Milestone.
  - Click Task: Mở tab Task Detail.
- `docs` slot (`Alt+2`):
  - Cây danh mục Docs / Notes phân cấp theo thư mục/tag.
  - Click Document: Mở tab NotesView soạn thảo ngay lập tức.
- Giữ thanh Stripe 34px bên trái với tooltip và active indicator thanh lịch.

### 5. Right Tool Window (AI Assistant & Inspector)
- Chuyển `AIChatDrawer` / chat widget vào Right Tool Window (`Alt+3`).
- Tích hợp `Item Inspector` vào Right Tool Window (`Alt+4`).
- Thu hồi hoàn toàn Bottom Tool Window, cho phép Center Editor Area chiếm trọn vẹn 100% chiều cao màn hình còn lại.

### 6. StatusBar Streamlining
- Chiều cao cố định: 26px.
- Cánh trái: Status chip (`Ready` / `Task: ...`), `IndexedDB` indicator, `Knowledge Daemon` indicator.
- Cánh phải: `Active Timer Widget` (thời gian nhảy giây, nút Stop/Pause trực tiếp), `Backup Sync` status, phiên bản ứng dụng.
