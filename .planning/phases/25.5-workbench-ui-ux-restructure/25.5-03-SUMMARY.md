# Summary Plan 25.5-03: Left Tool Windows Restructure: Dual Explorer for Projects & Docs

## Accomplished
- **Project Explorer (`Alt+1`)**: Built hierarchical tree showing Project → Milestone → Task with instant search filtering, priority tags, and status icons. Clicking a Project opens the project overview tab; clicking a Milestone opens tasks filtered by milestone; clicking a Task opens the task detail tab.
- **Docs Explorer (`Alt+2`)**: Built Markdown Notes explorer with search filter, pinned vs. all documents grouping, and quick "New Document" button. Clicking any document immediately opens the note in the Editor Area.
- **LeftToolWindow Specialization**: Dynamically switches between `ProjectExplorer` and `DocsExplorer` based on active stripe selection. Replaced legacy navigation links with native dockable IDE trees.
