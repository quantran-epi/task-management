# Plan 25.5-04: Right Tool Window Integration, Bottom Window Retirement & Full Navigation Verification

## Goal
Đưa AI Assistant và Item Inspector vào Right Tool Window dockable; bãi bỏ hoàn toàn Bottom Tool Window để tối ưu 100% diện tích cho Center Editor Area; đồng thời kiểm thử toàn diện luồng điều hướng giữa các thành phần.

## Scope & Target Files
- `src/workbench/toolwindows/RightToolWindow.tsx` (hỗ trợ 2 views: `'ai_chat'` và `'inspector'`)
- `src/workbench/WorkbenchLayout.tsx` (gỡ bỏ Bottom Tool Window và Bottom Stripe, tích hợp Right Tool Window mượt mà)
- `src/workbench/store/layoutStore.ts` (loại bỏ bottom panel state, chuẩn hóa right slot state)
- `src/workbench/EditorArea.tsx` (tối ưu chiều cao hiển thị 100%, render trơn tru các views)
- `src/workbench/__tests__/WorkbenchLayout.test.tsx` (cập nhật test suite cho layout mới)

## Tasks
1. **Right Tool Window Nâng Cấp**:
   - Tích hợp `AIChatDrawer` (hoặc `AiChatWidget`) vào Right Panel khi `rightActiveId === 'ai_chat'`.
   - Tích hợp `Item Inspector` vào Right Panel khi `rightActiveId === 'inspector'`.
   - Cung cấp nút Collapse ở góc trên cùng của Right Tool Window.
2. **Retire Bottom Tool Window**:
   - Xóa bỏ `BottomToolWindow.tsx` khỏi render tree trong `WorkbenchLayout.tsx`.
   - Xóa bỏ vertical split trong Center Column (Center Column giờ đây là một Panel duy nhất chứa `EditorArea`).
   - Cập nhật `layoutStore.ts` để loại bỏ các trường thừa hoặc đặt default phù hợp.
3. **Right Stripe Icons**:
   - Cung cấp các nút: `Alt+3: AI Assistant` (icon Robot) và `Alt+4: Inspector` (icon Info).
4. **End-to-End Navigation & Usability Verification**:
   - Kiểm tra mở tab, đóng tab, chuyển đổi giữa các tab không gây lag giật.
   - Kiểm tra mở AI Assistant ở panel phải: chat mượt mà, không che khuất tài liệu đang soạn thảo hay danh sách task.
   - Chạy test suite `npm run test:unit -- src/workbench` để đảm bảo 0 regression.

## Verification Criteria
- [ ] AI Assistant mở và đóng mượt mà ở bên phải (`Alt+3`).
- [ ] Không còn Bottom Tool Window, Center Editor Area chiếm trọn chiều cao từ TopBar đến StatusBar.
- [ ] Mọi nút bấm trên giao diện đều có hành động rõ ràng (mở tab, toggle tool window, mở search, mở settings), không còn bất kỳ nút nào bấm vào không có tác dụng.
- [ ] Toàn bộ test suite liên quan đến Workbench pass 100%.
