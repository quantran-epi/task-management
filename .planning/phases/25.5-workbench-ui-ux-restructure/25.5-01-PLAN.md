# Plan 25.5-01: Resizable Panels Fix & Theme/Typography Scale Overhaul

## Goal
Khắc phục triệt để lỗi resize handle không hoạt động trên `react-resizable-panels`, hiển thị thanh kéo phân cách rõ ràng, trực quan với hover highlight và con trỏ chuẩn; đồng thời nâng cấp toàn bộ scale typography và spacing để giao diện thoáng đãng, dễ đọc.

## Scope & Target Files
- `src/workbench/WorkbenchResizeHandle.tsx` (tạo mới: custom resize handle với visual indicator, hit-box và hover/active state)
- `src/styles/workbench-tokens.css` (cập nhật font sizes, line heights, handle colors, dimensions)
- `src/workbench/AntdThemeAdapter.tsx` (đồng bộ token font size với Ant Design 6)
- `src/workbench/WorkbenchLayout.tsx` (áp dụng `WorkbenchResizeHandle` vào horizontal group, xóa bỏ conflict layout)
- `src/workbench/store/layoutStore.ts` (đảm bảo persistence cho panel sizes mượt mà)

## Tasks
1. **Typography & Spatial Tokens Upgrade**:
   - Trong `workbench-tokens.css`, tăng `--font-size-ui` lên `13.5px`, `--font-size-base: 14px`, `--font-size-sm: 12px`, `--font-size-xs: 11px`.
   - Cập nhật `--titlebar-height: 40px`, `--tabbar-height: 36px`, `--statusbar-height: 26px`, `--stripe-width: 38px`.
   - Bổ sung CSS tokens cho resize handle: `--handle-width: 6px`, `--handle-hitbox: 10px`, `--handle-color: var(--border-strong)`, `--handle-color-hover: var(--accent)`.
2. **Build `WorkbenchResizeHandle`**:
   - Nhúng `PanelResizeHandle` từ `react-resizable-panels` bọc component thanh chia:
   - Line phân cách ở giữa dày 1.5px, hit area xung quanh 8px để dễ bắt chuột.
   - Hover state: hiển thị highlight xanh dương `var(--accent)`.
   - Cursor: `col-resize` cho horizontal split, `row-resize` cho vertical split.
3. **Mount and Fix Resizing in `WorkbenchLayout`**:
   - Thay thế các `PanelResizeHandle` trần trụi bằng `WorkbenchResizeHandle`.
   - Kiểm tra kéo thả resize panel trái (Left Panel) và panel phải (Right Panel) phản hồi ngay lập tức, không giật lag hay kẹt chuột.
4. **Validation**:
   - Chạy test headless / component test cho layout resizing.

## Verification Criteria
- [ ] Kéo thả thanh phân cách giữa Left Panel và Center Editor mượt mà, kích thước thay đổi liên tục.
- [ ] Resize handle có visual bar rõ ràng, hover đổi màu xanh dương, con trỏ đổi thành `col-resize`.
- [ ] Font chữ toàn bộ app hiển thị to rõ (13.5px–14px), không còn chữ li ti 10px.
