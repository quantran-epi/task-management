| Boundary | Description |
|---|---|
| Tool loop → resources | Unbounded rounds could consume provider quota/CPU |
| Loop result → persistence | Partial/limited answer must never become history |
| Runtime status → UI | Terminal state must differ from approval/error |

| T-26-04c | Information Disclosure | Terminal copy | mitigate | Static message uses only round count; no provider error, prompt, or raw tool output in alert. |
| T-26-04d | Repudiation | Tool audit trail | mitigate | Existing callbacks retain call/result events; widget renders after limit. |
