       - `ensure_git_worktree(repo_root: &Path, task_id: &str) -> Result<PathBuf, String>` per D-07: Branch `pm-agent/task-<id>`, path `.plannermate/worktrees/task-<id>`. Ensure `.plannermate/` is appended to `.git/info/exclude` so it does not dirty git status. If worktree exists, reuse it (resume capability per D-18).
       - `get_worktree_diff(worktree_path: &str) -> Result<String, String>`: Run `git diff HEAD` and `git diff --cached` inside worktree directory to return full raw unified diff string.
       - `accept_all_diff(worktree_path: &str, commit_message: &str) -> Result<String, String>` per D-14: Stage all changes (`git add -A`) and commit with given message, returning commit sha.
       - `revert_all_diff(worktree_path: &str) -> Result<(), String>` per D-12: Run `git reset --hard HEAD` and `git clean -fd`.
       - `revert_file_diff(worktree_path: &str, file_path: &str) -> Result<(), String>`: Run `git checkout HEAD -- <file>` and delete untracked file if newly added.
    3. Headless Process Orchestration:
       - `spawn_master_agent`: Spawn `claude` executable via `tokio::process::Command` with arguments `["-p", "--output-format", "stream-json", "--input-format", "stream-json", "--permission-mode", "acceptEdits", "--model", &master_model, &initial_prompt]` in worktree directory.
       - Configure piped stdin/stdout/stderr. Read lines asynchronously, parse JSON chunks, and batch events at 50ms intervals before emitting `ghost-dev:stream-chunk` to AppHandle per D-06 and research recommendations.
       - Enforce Global Concurrency Cap per D-08: Max 1 Master + 2 Workers per task, max 6 processes globally. Queue or reject when limit exceeded.
    4. Safety & Permission Handling per D-15, D-16, D-17:
       - Whitelist check: If a shell command starts with any safe prefix (`git status`, `git diff`, `npm test`, `npx vitest`, `cargo check`, `cargo test`, `pytest`, `go test`), allow automatically.
       - If outside whitelist, emit `ghost-dev:permission-request` to frontend and pause asynchronously on an `oneshot::Receiver<bool>` channel without blocking OS thread. Write response back into Claude's stdin.
    5. Hard Kill per D-10:
       - `stop_session(task_id: &str)`: Terminate process group (Master + Workers) via SIGTERM/SIGKILL on Unix or `taskkill /F /T /PID` on Windows, drenching buffers and marking status `'interrupted'`.
