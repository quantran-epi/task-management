    Create `src/utils/gitDiffParser.ts` exporting `parseGitDiff(rawDiff: string): DiffFile[]`:
    - Process unified diff headers (`diff --git a/path b/path`, `--- a/path`, `+++ b/path`)
    - Detect file status: added (`/dev/null` in old path or `new file mode`), deleted (`/dev/null` in new path or `deleted file mode`), otherwise modified
    - Parse hunk headers (`@@ -oldStart,oldCount +newStart,newCount @@ [header]`)
    - Walk lines: lines starting with `+` are additions (`type: 'add'`), incrementing new line pointer; lines starting with `-` are deletions (`type: 'delete'`), incrementing old line pointer; lines starting with space or empty context increment both pointers
    - Aggregate additions and deletions counts per file

    Create `tests/agents/gitDiffParser.test.ts` verifying all behaviors above.
