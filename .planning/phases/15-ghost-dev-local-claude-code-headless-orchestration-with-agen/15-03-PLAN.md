## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Terminal Log XSS & Ingestion | Raw text chunks emitted from child CLI processes rendered in React DOM |
| Shell Permission Gate | User interaction granting execution of non-whitelisted commands |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-15-06 | Information Disclosure | `src/components/agents/AgentTerminalLog.tsx` | mitigate | Render stream chunks as text content within React elements (no `dangerouslySetInnerHTML`) to prevent script execution from CLI outputs |
| T-15-07 | Tampering | `src/components/agents/DiffInlineCommentModal.tsx` | mitigate | Sanitize user comment and escape code snippet fences to avoid markdown prompt injection |
| T-15-08 | Elevation of Privilege | `src/components/agents/ShellPermissionModal.tsx` | mitigate | Require explicit user click on "Cho phép"; do not auto-advance or timeout-accept unwhitelisted commands |
</threat_model>
