## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge padding, inline status tag margins |
| sm | 8px | Button gaps, list item spacing, tree node indentation |
| md | 16px | Card body padding, pane gutters, form item vertical gaps |
| lg | 24px | Modal body padding, control center header spacing |
| xl | 32px | Major column boundaries, split pane separators |
| 2xl | 48px | Empty state canvas padding, terminal placeholder gutter |
| 3xl | 64px | Page boundary vertical padding |

Exceptions:
- Mobile touch targets: minimum 44px height for icon-only action buttons.
- Form controls: 36px standard `controlHeight` matching existing Ant Design theme configuration.
- Terminal log / Diff viewer code lines: 22px fixed line height for terminal output and diff row comparison.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#ffffff` (Light) / `#141414` (Dark) | Primary canvas, Agent Control page background, Terminal background (`#1e1e1e` in dark/terminal zone) |
| Secondary (30%) | `#fafafa` (Light) / `#1f1f1f` (Dark) | Session list sidebar (Column 1), Diff file tree list, card containers, table headers |
| Accent (10%) | `#4f46e5` | Interactive highlights reserved strictly for items declared below |
| Destructive | `#ff4d4f` | Stop Agent, Revert File, Revert All, Hard Kill process |

Accent reserved for:
1. Primary action buttons: "Run Ghost Dev", "Accept All", "Gửi phản hồi"
2. Active session card highlight in Session List (Left Column)
3. Agent running count badge in Sidebar navigation (`/agents` menu item)
4. Inline comment target highlight on selected Diff row
5. Active toggle state for Diff view mode ("Unified" / "Side-by-side")

Semantic Colors:
- Success (`#52c41a`): Agent task completed, Git file additions (`#e6ffed` / `#23452b` in Diff), Accept File button
- Warning (`#faad14`): Agent awaiting shell permission confirmation, paused session state
- Info / Blue (`#1677ff`): Master Lead Agent badge, Worker dispatch notification
- Purple (`#722ed1`): Opus model badge (`claude-3-opus` / `claude-3-5-sonnet`)
- Neutral Tag (`#8c8c8c`): Finished session state, commit sha badge, execution duration timestamp

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | Run Ghost Dev |
| Secondary CTA | Accept All |
| Empty state heading | Chưa có phiên Ghost Dev nào |
| Empty state body | Chọn một tác vụ bất kỳ và bấm "Run Ghost Dev" để khởi động Master Agent tự động phân rã và viết code. |
| Error state | Phiên làm việc bị gián đoạn: Tiến trình Agent gặp lỗi hoặc bị đóng đột ngột. Thư mục Git Worktree vẫn được bảo toàn. Bấm "Thử lại" để khôi phục. |
| Destructive confirmation | Dừng Ghost Dev: Dừng ngay lập tức Master Agent và các Worker đang chạy cho tác vụ này? Tiến trình chưa commit sẽ được giữ lại trong worktree. |
| Shell permission alert | Cấp quyền chạy lệnh Shell: Agent yêu cầu thực thi lệnh `{command}` trong thư mục worktree. Bạn có muốn cho phép không? |
| Revert confirmation | Hủy bỏ thay đổi: Hoàn tác toàn bộ thay đổi mã nguồn trong file `{fileName}` về trạng thái ban đầu? |
