<decisions_made>
- Fix at the state owner, not in the handler. Path confinement belongs in
  `gitRemoteTreeService`, which is why `confineRepoPath` lives there and is applied in
  both entry points.
- `--end-of-options` is required at every revision-arg call site, in BOTH layers
  (handler rejects leading `-`, service places the terminator). Verified against git
  2.50.1 that it blocks `--output` for log/show/diff.
- `rev-parse` needs `--verify --end-of-options` — plain `rev-parse --end-of-options`
  echoes the terminator back as a revision and would corrupt `headSha`.
- No `node:path` import anywhere in `src/` (browser/Tauri renderer bundle), so
  `confineRepoPath` inlines the normalize+confine subset. Do not add the import.
- Refusal codes carry meaning: `GIT_READ_FAILED` = infrastructure, `INVALID_ARGUMENT`
  = the model's argument was wrong. Getting this backwards makes the model retry
  forever (this is why round 1 CR-03 and round 2 WR-05 both mattered).
- WR-10 (AIO-READ-06 Oracle gate) was already covered at
  `tests/services/ai/office/teamRunCoordinator.test.ts:1610-1645` — do not duplicate it.
</decisions_made>
