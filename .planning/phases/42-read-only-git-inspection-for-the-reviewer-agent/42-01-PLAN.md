<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| model → git_read args | `systemId`, `branch`, `base`, `target`, `filePath`, `dirPath` are model-authored strings |
| app → remote shell (SSH) | every argument reaches a POSIX shell on the remote host |
| remote repo → model | branch names, commit messages, diffs, file contents are written by third parties |
| team links → repo selection | the linked-system set is the only legal repo scope |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-42-01 | Tampering | `gitRead` args → `runGitCommand` | mitigate | The handler never builds a command string. Every value is passed to a `gitRemoteService`/`gitRemoteTreeService` function that applies `escapeShellArg` per argument (`getFileDiff:252`, `getRemoteFileContent:165`, `getRecentCommits`). Plan 42-03 asserts the exact escaped command string for a `'; rm -rf /; echo '` payload on `filePath`, `branch`, and `base`. |
| T-42-02 | Elevation of privilege | repo selection | mitigate | `resolveGitRepo` filters `listTeamLinks` to `itemType === 'system'` and requires `sshConfigId` + `remoteRepoPath`; a model `systemId` is only an index into that set. Unlinked id → `SYSTEM_NOT_LINKED`; repo-less or empty set → `NO_LINKED_REPO`. No arg can name a repo path. |
| T-42-03 | Tampering | write path reachable through `git_read` | mitigate | The action enum is fixed at seven read verbs; no property accepts a command string, `-c`, `--output`, or `--ext-diff`. The tool is absent from `MUTATION_TOOLS`, so no approval card is ever minted for it. `ssh_exec_command` is never imported. |
| T-42-04 | Spoofing | diff/log/file content as instructions | mitigate | Every action wraps at least one leaf: `wrapUntrusted` for commit messages, diff text and file content; `wrapField` for branch names, paths and authors. Every label carries action + repo path (D-11). Nonce-tagged delimiters (`untrustedData.ts:59-72`) make a forged closing tag impractical. |
| T-42-05 | Information disclosure | SSH secret handling | accept | `getSshSecret` reads the OS keyring and returns `null` outside Tauri; the secret is passed straight to `execRemoteCommand` and never returned, logged, or stored. No new storage. |
| T-42-06 | Denial of service | oversized `read_file` / `diff_file` | accept | No cap added, matching the Phase 31 D-12 no-truncation precedent. The Phase 38 hard token budget already parks an over-budget turn, and the reviewer is the only intended caller. |
| T-42-SC | Tampering | npm/pip/cargo installs | mitigate | No package is added by this plan. If any task is tempted to add one, stop — the phase forbids new dependencies. |
</threat_model>
