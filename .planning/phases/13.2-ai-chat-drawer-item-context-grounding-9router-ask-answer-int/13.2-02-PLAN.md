<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User Prompt → Chat Stream | User input submitted to AI stream |
| AI Response → DOM | AI output markdown parsed and rendered in HTML |
| AppShell Layout → Drawer Docking | Screen width and margins adjusted dynamically |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13.2-04 | Denial of Service | `AppShell.tsx`, `AIChatDrawer.tsx` | mitigate | On mobile screens (`screens.md === false`), force overlay mode with mask and disable marginRight margin push to prevent horizontal overflow and layout breakage. |
| T-13.2-05 | Tampering / Elevation of Privilege | `ChatMessageBubble.tsx` | mitigate | Sanitize AI markdown output using existing safe markdown parser; reject raw HTML execution or unsanitized script tags. |
| T-13.2-02 | Denial of Service | `AIChatDrawer.tsx` | mitigate | Always attach AbortController to streaming request; trigger abort on component unmount, thread switch, or user stop action. |
</threat_model>
