## Overview

Plan 13.2-02 delivers the user interface for the AI assistant in the Personal Task & Workload Planner:

1. **Chat Message Stream & Input Experience:**
   - Built `ChatMessageBubble` supporting distinct user (#1677ff accent) and assistant styling, safe HTML/Markdown rendering with link target protection, copy-to-clipboard, and streaming cursor indicator (`▋`).
   - Implemented `ChatMessageList` with automatic scroll anchoring to bottom and `--- Ngữ cảnh đã được đặt lại ---` context reset boundary dividers (D-06).
   - Created `ChatInputBar` with auto-resizing textarea, `Cmd+Enter` / `Enter` submission, `/clear` shortcut interception, and dynamic Stop generation button during SSE streaming.
   - Built `InlineApiErrorCard` surfacing 9router connection errors with inline retry and settings shortcut (D-19).

2. **AIChatDrawer & ChatHeader:**
   - Implemented `ChatHeader` containing entity scope badge (`[Tác vụ: ...]`), compact model dropdown selector (`gpt-4o`, `claude-3-5-sonnet`, `deepseek-chat`), clear context button, pin/unpin toggle button, and close button with full `aria-label` accessibility.
   - Built `AIChatDrawer` with mouse drag-resizing clamped between 320px and 650px.
   - Wired `useLiveQuery` to Dexie `chatThreads` and `chatMessages`.
   - Connected `streamChatCompletion` with token delta streaming and graceful abort handling.

3. **AppShell Docked Layout Integration:**
   - Integrated `AIChatDrawer` into `AppShell.tsx`.
   - Implemented dynamic `marginRight: aiChatWidth + 16` with smooth CSS transition when pinned on desktop.
   - Mounted `<RobotOutlined />` trigger button in AppHeader.
   - Handled `Cmd+J` / `Ctrl+J` global keyboard shortcuts.
   - Maintained `z-index` layering ensuring `TaskDrawer` and `NotificationDrawer` cleanly overlay the docked chat panel.

- **Found during:** Task 1 test run

- **Fix:** Added type check `typeof bottomRef.current?.scrollIntoView === 'function'` before invoking in `ChatMessageList.tsx`.
- **Files modified:** `src/components/ai/ChatMessageList.tsx`
- **Commit:** `c75ce99`

- **Found during:** Task 3 build verification
