# Phase 13.2: AI Chat Drawer, Item Context Grounding & 9router Ask-Answer Integration - Context

**Gathered:** 2026-10-03
**Status:** Ready for planning

<domain>
## Phase Boundary

Phase 13.2 cung cấp trợ lý AI tương tác trực tiếp với hệ thống quản lý công việc cá nhân thông qua: (1) AI Chat Drawer bên phải có thể ghim (Docked Side-by-Side) trên toàn bộ ứng dụng; (2) tích hợp 9router API (OpenAI-compatible) với streaming thời gian thực và quản lý key an toàn; (3) tự động gắn ngữ cảnh (Context Grounding) từ Task, Project, Milestone, Sticky Notes và file cục bộ; (4) tích hợp điểm kích hoạt chạy tác vụ sâu bằng Claude Code CLI ngoài hệ điều hành.

Phase không bao gồm việc nhúng trực tiếp terminal giả lập xterm.js PTY trong browser, không tự động cào trang web từ các URL bên ngoài, và không bổ sung dependency SDK bên ngoài (sử dụng native `fetch` và `ReadableStream`).

</domain>

<decisions>
## Implementation Decisions

### Drawer Layout & Docking
- **D-01:** Drawer hiển thị theo cơ chế **Docked Side-by-Side** khi pinned: `Content` của AppShell tự động co hẹp chiều rộng (`marginRight = drawerWidth`), không che khuất bảng biểu hay nội dung làm việc chính.
- **D-02:** Chiều rộng drawer có thể kéo giãn tùy ý bằng chuột (**Resizable**) từ 320px đến 650px qua thanh chia viền trái (drag handle). Độ rộng mặc định 380px và được lưu vào `localStorage` (`planner:ai_chat_width`).
- **D-03:** Các drawer khác (`TaskDrawer`, `NotificationDrawer`) hoạt động với **z-index cao hơn (overlay)** đè lên AI Chat Drawer khi được mở; đóng lại thì AI Chat Drawer vẫn duy trì trạng thái docked.
- **D-04:** Điểm kích hoạt mở/đóng drawer: Nút icon AI trên Header chính (kế bên Notification Bell) và hỗ trợ phím tắt toàn cục `Cmd+J` (macOS) / `Ctrl+J` (Windows).

### Scoping & Session Lifecycle
- **D-05:** Cơ chế liên kết ngữ cảnh là **Auto-follow Focus**: Chat Drawer tự động chuyển scope sang Task/Project/Milestone đang active gần nhất, hiển thị chip định danh scope trên header chat. Có nút bấm "Detach / Standalone" để quay về phiên chat toàn cục.
- **D-06:** Mỗi scope duy trì **Single Thread** duy nhất trong IndexedDB. Hỗ trợ lệnh `/clear` hoặc nút "Clear Context": chèn vạch ngăn ngữ cảnh `--- Ngữ cảnh đã được đặt lại ---`, transcript cũ vẫn hiển thị trên UI nhưng prompt gửi lên LLM chỉ lấy các tin nhắn sau vạch `/clear` (kèm trần an toàn tối đa 20 tin nhắn).
- **D-07:** Khi xóa vĩnh viễn Task/Project/Milestone, hệ thống tự động **Cascade Delete** toàn bộ thread và messages liên kết của entity đó trong IndexedDB để chống rác dữ liệu.
- **D-08:** Trạng thái mở/đóng và trạng thái Ghim (Pinned) của Drawer được lưu vào `localStorage` (`planner:ai_chat_open`, `planner:ai_chat_pinned`) để duy trì sau khi tải lại trang F5. Ô nhập liệu (Draft text) không persist để tránh gửi nhầm sau reload.

### Context Grounding & Document Depth
- **D-09:** Cấu trúc thông tin Task/Project/Milestone được tuần tự hóa theo định dạng **XML Tags `<item_context>` + Markdown có cấu trúc** (Headings, Checklist, Tags, Dates, Estimates, Status, Priority, Owners, BA).
- **D-10:** Trích xuất toàn bộ trường `task.notes` + toàn bộ nội dung Markdown của tất cả Sticky Notes gắn với task (kèm caption của ảnh chụp màn hình đính kèm nếu có), áp dụng trần an toàn tối đa 12.000 ký tự.
- **D-11:** Xử lý file đính kèm cục bộ (`documentLinks`): Áp dụng chuẩn **Claude Code**: Trên Tauri đọc tối đa 2.000 dòng đầu tiên đối với các file văn bản thuần (.txt, .md, .json, .log, source code); file nhị phân chỉ trích xuất metadata (tên file, kích thước, định dạng). Trên Web/PWA hiển thị metadata đường dẫn tham chiếu.
- **D-12:** Xử lý URL web bên ngoài (`https://...`): Gửi URL và domain làm metadata tham chiếu trong prompt; không tự động cào trang web để tránh lỗi CORS hoặc trang yêu cầu xác thực.
- **D-13:** **Claude Code CLI Integration:** Hỗ trợ nút "Chạy với Claude Code" (Open in Claude Code) trên Desktop Tauri (tự động mở Terminal.app / iTerm2 / cmd của hệ điều hành với lệnh `claude "..."` đã nhúng sẵn ngữ cảnh task); trên Web/PWA cung cấp nút "Copy CLI Command" để người dùng dán vào terminal ngoài.

### 9router API & Message UX
- **D-14:** Kết nối 9router qua endpoint chuẩn OpenAI-compatible `/v1/chat/completions` bằng native browser `fetch()` (zero new npm dependencies).
- **D-15:** Phản hồi hiển thị theo cơ chế **Streaming SSE (Server-Sent Events)** thời gian thực thông qua `ReadableStream` và `TextDecoderStream`. Có nút "Dừng sinh phản hồi" (Stop Generation) sử dụng `AbortController`.
- **D-16:** Cấu hình 9router trong Settings (`NineRouterConfigCard`): Endpoint, API Key, Model name. Nút "Kiểm tra kết nối" (Test Connection) gọi `GET /v1/models` để xác thực key và nạp danh sách model vào cache.
- **D-17:** Dropdown đổi nhanh Model ngay trên Header của Chat Drawer, cho phép người dùng linh hoạt đổi model AI cho từng câu hỏi mà không cần vào Settings.
- **D-18:** Render tin nhắn AI bằng Markdown đầy đủ (syntax highlight, copy code) kèm các nút hành động nhanh (**Action Chips**) như "Thêm vào Checklist của Task", "Lưu vào Sticky Notes".
- **D-19:** Hiển thị lỗi kết nối API bằng thẻ thông báo trực tiếp trong dòng chat (**Inline Error Card**) giải thích nguyên nhân rõ ràng kèm nút "Thử lại" (Retry) và lối tắt "Cấu hình AI Settings".
- **D-20:** Quản lý lưu trữ khóa bí mật: Tauri Desktop lưu API Key trong OS Keychain qua `keyringService` (`KEYRING_KEYS.NINEROUTER_API_KEY`); Web/PWA lưu trong Dexie IndexedDB `db.settings`.

### Claude's Discretion
- Cơ chế parse Server-Sent Events (SSE): Xử lý đệm dòng (line buffering) để phân tách các chunk `data: {...}` dở dang khi stream từ network.
- Visual styling của Action Chips trong message bubble: Dùng Ant Design `Button` size `small` với icon tương ứng (`CheckSquareOutlined`, `FileAddOutlined`).
- Mẫu câu lệnh khởi chạy Claude Code: Định dạng chuỗi CLI escaping tương thích cả macOS/Linux (zsh/bash) và Windows (cmd/PowerShell).

<code_context>
## Existing Code Insights

### Reusable Assets
- `src/services/keyringService.ts`: Tái sử dụng `storeKeyringCredential`, `getKeyringCredential` để lưu trữ 9router API key trên OS Keychain.
- `src/utils/documentLinks.ts`: Tái sử dụng `isLocalPath`, `normalizeLocalPath` và `tauriInvoke` để trích xuất hoặc mở tệp cục bộ.
- `src/components/common/AriaLiveRegion.tsx`: Tái sử dụng để thông báo trạng thái streaming hoàn tất cho trợ năng (a11y).
- `src/utils/markdown.ts`: Tái sử dụng bộ parse Markdown an toàn để render nội dung câu trả lời của AI.

### Established Patterns
- **Storage Dual-Tier Pattern:** Secrets lưu tại OS Keychain khi chạy Tauri Desktop, fallback về IndexedDB `db.settings` khi chạy Web/PWA.
- **Local Storage Key Convention:** Sử dụng tiền tố `planner:*` (ví dụ `planner:ai_chat_open`, `planner:ai_chat_width`, `planner:sidebar_collapsed`).
- **Cascade Deletion Pattern:** Quản lý giao dịch nguyên tử trong Dexie transaction tại `cascadeRepo.ts`.
- **Zero-Dependency Native APIs:** Ưu tiên native `fetch`, `ReadableStream`, `TextDecoder` thay vì cài thêm các SDK bên ngoài.

### Integration Points
- `src/components/shell/AppShell.tsx`: Chèn `AIChatDrawer` vào layout, bổ sung nút kích hoạt trên Header, cập nhật style margin co giãn của `Content`.
- `src/db/schema.ts` & `src/db/index.ts`: Nâng cấp `SCHEMA_V8` bổ sung 2 bảng `chatThreads` và `chatMessages`.
- `src/views/SettingsView.tsx`: Thêm thẻ cấu hình `NineRouterConfigCard`.
- `src-tauri/src/lib.rs` (hoặc commands tương đương): Bổ sung Tauri command `launch_claude_terminal` để mở terminal hệ điều hành khi người dùng bấm "Chạy với Claude Code".

</code_context>

<specifics>
## Specific Ideas
- Lệnh `/clear`: Khi người dùng gõ `/clear` trong ô chat, chèn một vạch ngăn ngang trực quan `--- Ngữ cảnh đã được đặt lại ---`. Tin nhắn phía trên vẫn giữ nguyên để người dùng tra cứu; chỉ các tin nhắn phía sau vạch mới được gửi vào ngữ cảnh của lượt gọi LLM tiếp theo.
- Nút "Mở trong Claude Code" (Launch External OS Terminal): Tự động gom tên task, mục tiêu checklist và đường dẫn file, mở Terminal ngoài máy chạy lệnh `claude "..."`.

</specifics>

<deferred>
## Deferred Ideas

- **Embedded xterm.js PTY inside Drawer:** Nhúng trực tiếp giao diện dòng lệnh xterm.js và Rust PTY bên trong tab của Chat Drawer (để dành cho Phase tương lai khi mở rộng tính năng terminal chuyên sâu).
- **Bidirectional AI auto-edits:** Cho phép AI tự động gọi tool cập nhật trạng thái Task, đổi deadline, hoặc tự gán Ops Owner/BA thông qua function calling.
- **Voice input / Audio transcription:** Ghi âm giọng nói trực tiếp để chuyển thành văn bản câu hỏi trong Chat Drawer.

</deferred>
