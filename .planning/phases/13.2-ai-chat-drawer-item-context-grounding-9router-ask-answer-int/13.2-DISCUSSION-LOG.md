## Scoping & session lifecycle

| Option | Description | Selected |
|--------|-------------|----------|
| Auto-follow Focus + nút Detach | Tự động cập nhật scope theo entity đang mở/chọn gần nhất, kèm chip hiển thị rõ ràng trên đỉnh chat và nút 'Tháo gỡ / Về Standalone' | ✓ |
| Explicit Attach | Mặc định luôn là Standalone (toàn cục). Chỉ gắn ngữ cảnh khi người dùng bấm nút 'Hỏi AI' từ TaskDrawer/Project/Milestone | |
| 2 Tab riêng | Tách biệt 2 tab rõ ràng trong Drawer: Tab 'Trợ lý chung' và Tab 'Ngữ cảnh mục' | |

**User's choice:** Auto-follow Focus + nút Detach (Recommended)
**Notes:** Giúp AI luôn bám sát theo tác vụ người dùng đang thao tác, tiết kiệm thao tác đính kèm thủ công.

| Option | Description | Selected |
|--------|-------------|----------|
| Single Thread + Nút Clear | 1 thread duy nhất cho mỗi scope (Task/Project/Milestone/Standalone), có nút 'Bắt đầu phiên mới' (Clear/Archive) | ✓ |
| Multi-thread History per Scope | Hỗ trợ nhiều thread riêng biệt cho từng scope, kèm danh sách lịch sử phiên chat để chọn lại | |
| Persistent Standalone + Ephemeral Item Chat | Chỉ lưu lịch sử cho Standalone; còn đối với Task/Project/Milestone thì phiên chat là tạm thời | |

**User's choice:** Single Thread + Nút Clear (Recommended)
**Notes:** Đơn giản hóa mô hình CSDL và giao diện người dùng.

| Option | Description | Selected |
|--------|-------------|----------|
| Cascade Delete tự động dọn rác | Tự động xóa sạch thread và tin nhắn liên kết khi Task/Project/Milestone bị xóa vĩnh viễn (tối ưu dung lượng) | ✓ |
| Detach chuyển sang Standalone thread | Chuyển đổi các tin nhắn chat quan trọng thành Standalone chat thread | |
| Soft retention | Giữ nguyên trong IndexedDB, không xóa cứng để nếu khôi phục từ backup cũ vẫn khớp dữ liệu | |

**User's choice:** Cascade Delete tự động dọn rác (Recommended)
**Notes:** Tương tự như cơ chế dọn dẹp workSessions và allocations trong `cascadeRepo.ts`.

| Option | Description | Selected |
|--------|-------------|----------|
| Persist Open/Pinned State | Lưu trạng thái Open & Pinned vào localStorage; lịch sử tin nhắn lưu IndexedDB; ô gõ tin nhắn không persist | ✓ |
| Persist đầy đủ cả Draft Text | Persist toàn bộ: cả Open, Pinned và văn bản nháp đang gõ dở trong textarea | |

**User's choice:** Persist Open/Pinned State (Recommended)
**Notes:** Không giữ draft text dở dang qua reload để tránh trường hợp gửi nhầm nội dung cũ.

| Option | Description | Selected |
|--------|-------------|----------|
| Lệnh /clear + Vạch ngăn ngữ cảnh | Hỗ trợ lệnh /clear và nút bấm 'Clear Context': chèn vạch ngăn trên UI, giữ lại transcript cũ để đọc nhưng chỉ gửi tin nhắn sau vạch cho LLM (kèm trần an toàn 20 tin nhắn) | ✓ |
| /clear xóa trắng toàn bộ dữ liệu cũ | Lệnh /clear sẽ xóa sạch hoàn toàn tin nhắn cũ khỏi màn hình và IndexedDB | |

**User's choice:** Lệnh /clear + Vạch ngăn ngữ cảnh (Recommended)
