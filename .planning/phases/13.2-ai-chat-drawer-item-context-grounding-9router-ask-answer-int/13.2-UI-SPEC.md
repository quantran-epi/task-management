## Spacing Scale

Declared values (multiples of 4 only):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, message action chip gaps, inline tag padding, drag handle baseline |
| sm | 8px | Message bubble margin, input action spacing, model selector gap |
| md | 16px | Chat message container padding, drawer body padding, input container padding |
| lg | 24px | Drawer header padding, Settings card section gaps |
| xl | 32px | Major section breaks in AI Settings |
| 2xl | 48px | Empty state vertical centering padding |
| 3xl | 64px | Page-level boundary padding |

Exceptions:
- Drawer width range: resizable between `320px` (minimum) and `650px` (maximum), default `380px` (persisted in `localStorage` as `planner:ai_chat_width`).
- Drag handle: visual border `1px solid token.colorBorderSecondary`, interactive hover hit-area `8px` (`left: -4px`, cursor `col-resize`).
- Mobile touch targets: minimum `44px` touch target size for mobile toggle buttons and drawer close controls.

## Color

| Role | Value (Light / Dark) | Usage |
|------|----------------------|-------|
| Dominant (60%) | `#ffffff` / `#141414` | Drawer background, message stream surface, settings card backgrounds |
| Secondary (30%) | `#fafafa` / `#1f1f1f` | Assistant message bubble background, chat header, input container bar, code block background |
| Accent (10%) | `#1677ff` | User message bubble background, primary action buttons, active scope badge, focus rings |
| Destructive | `#ff4d4f` | Stop generation button, clear context confirmation, API error indicator |

Accent reserved for:
1. User message bubble background (`#1677ff` with `#ffffff` text).
2. Chat Drawer toggle button in AppHeader when drawer is active.
3. Send message button (`SendOutlined` primary button).
4. Active scope badge indicator (`Task` / `Project` / `Milestone` tag in header).
5. Primary action buttons inside message cards ("Thêm vào Checklist", "Mở trong Claude Code").
6. Interactive link text and active model selector outline.

Destructive reserved for:
1. Stop Generation button (`StopOutlined`) during active SSE streaming.
2. Clear Context confirmation action ("Đặt lại ngữ cảnh").
3. Inline API connection error cards and error alerts.

## Component Layout & Visual Specifications

### Focal Point Declaration
- **Primary focal point**: Sticky Chat Input bar at bottom and latest streaming assistant response bubble.
- **Secondary focal point**: Header Scope Chip showing item grounding status (`[Tác vụ: ...]`).

### 1. AppShell Docking & Header Trigger
- **Header Button**: Placed on AppHeader between `ActiveTimerWidget`/`GitHubSyncStatusDot` and `NotificationBell`.
  - Icon: `<RobotOutlined style={{ fontSize: 16 }} />`
  - Tooltip & `aria-label`: `"Trợ lý AI (Cmd+J / Ctrl+J)"`
  - Badge dot when active context item is attached.
- **Docked Side-by-Side (Pinned mode)**:
  - When `isPinned === true` and `isOpen === true`: AppShell `Content` receives `marginRight: {drawerWidth}px` with CSS `transition: margin-right 0.2s ease`. Main view content shrinks without horizontal scroll or table cut-off.
  - When `isPinned === false` (Overlay mode) or on mobile (`screens.md === false`): Drawer behaves as standard Ant Design overlay drawer with backdrop mask (`mask={isMobile}`).
- **Z-Index Hierarchy**:
  - `Content` margin-docked: base level.
  - `AIChatDrawer` (Docked): `z-index: 100` (below modals and inspection drawers).
  - `AIChatDrawer` (Overlay): `z-index: 1000`.
  - `TaskDrawer` & `NotificationDrawer`: `z-index: 1050` (always opens on top of AI Chat Drawer).
  - Modals (`ProjectModal`, `CommandPaletteModal`, `ImportPreviewModal`): `z-index: 1100`.

### 2. AIChatDrawer Structure
- **Width**: Dynamic, bound to state `width` (initialized from `localStorage.getItem('planner:ai_chat_width') || 380`).
- **Drag Handle**:
  - Located on left border of drawer.
  - Visual: `1px solid token.colorBorderSecondary`.
  - On hover / active: `token.colorPrimary` accent line with `col-resize` cursor.
  - Mouse down captures mouse movement with `requestAnimationFrame` clamping width between 320px and 650px.
- **Header Bar**:
  - Left: AI icon, title `"Trợ lý AI"`, and Scope Chip (e.g. `[Tác vụ: Triển khai auth]` or `[Toàn cục / Standalone]`).
  - Middle: Compact Model Selector dropdown (`Select` size `small`, e.g. `gpt-4o`, `claude-3-5-sonnet`, `deepseek-chat`).
  - Right action icons (with explicit accessibility `aria-label` contracts):
    - Clear Context button: `<ClearOutlined />`, tooltip & `aria-label`: `"Đặt lại ngữ cảnh (/clear)"`.
    - Pin/Unpin button: `<PushpinOutlined />` / `<PushpinFilled style={{ color: '#1677ff' }} />`, tooltip & `aria-label`: `"Ghim ngăn trò chuyện bên phải"` (khi bỏ ghim) / `"Bỏ ghim ngăn trò chuyện"` (khi đã ghim).
    - Close button: `<CloseOutlined />`, tooltip & `aria-label`: `"Đóng ngăn trò chuyện"`.
- **Scope Banner (Sub-header)**:
  - When auto-grounded to Task/Project/Milestone: Shows small muted bar (height 28px, background `token.colorFillAlter`) with icon, item title truncated to 1 line, and button `"Tách riêng"` (`type="link"`, size `small`) to detach into global standalone scope.

### 3. Message Stream & Bubbles
- **Message List**: Virtualized or scroll-anchored column with `padding: 16px`, auto-scrolls to bottom on new streaming tokens unless user manually scrolls up.
- **User Message Bubble**:
  - Alignment: Right (`align-self: flex-end`, max-width `85%`).
  - Background: `token.colorPrimary` (`#1677ff`), text `#ffffff`, border-radius `12px 12px 2px 12px`, padding `8px 12px`.
  - Typography: 14px regular, line-height 1.57.
- **Assistant Message Bubble**:
  - Alignment: Left (`align-self: flex-start`, max-width `95%`).
  - Background: `token.colorFillAlter` (`#fafafa` light / `#1f1f1f` dark), border `1px solid token.colorBorderSecondary`, border-radius `12px 12px 12px 2px`, padding `12px 16px`.
  - Content: Rich Markdown render (headings, bold, lists, code fences with syntax highlight, copy code button).
  - Streaming State: Pulse indicator or streaming cursor `▋` appended to text while stream is active.
- **Context Reset Divider**:
  - When `/clear` is executed: Horizontal rule with text badge centered:
    `--- 🔄 Ngữ cảnh đã được đặt lại ---` (color `#8c8c8c`, font size 12px).
- **Action Chips (under Assistant message)**:
  - Flex wrap row with `gap: 4px` (xs token), `margin-top: 8px`.
  - "Thêm vào Checklist" button: `<CheckSquareOutlined />` size `small`, extracts checklist lines from AI reply into Task checklist.
  - "Lưu vào Sticky Note" button: `<FileAddOutlined />` size `small`, creates new note with message content.
  - "Mở trong Claude Code" button (Tauri): `<CodeOutlined />` size `small`, triggers CLI terminal.
  - "Sao chép lệnh CLI" button (Web): `<CopyOutlined />` size `small`, copies formatted `claude "..."` command.

### 4. Chat Input Bar
- **Position**: Sticky bottom of drawer, background `token.colorBgContainer`, border-top `1px solid token.colorBorderSecondary`, padding `12px 16px`.
- **Textarea**: Ant Design `Input.TextArea` with `autoSize={{ minRows: 1, maxRows: 6 }}`.
  - Placeholder: `"Hỏi về tác vụ này hoặc nhập /clear để đặt lại... (Cmd+Enter để gửi)"`.
  - `aria-label`: `"Nội dung tin nhắn trò chuyện AI"`.
- **Action Toolbar (below input)**:
  - Left: Context ground status tag (e.g. `🟢 Đã gắn ngữ cảnh (1.4k tokens)` or `⚪ Toàn cục`).
  - Right:
    - If streaming: "Dừng lại" button (`type="primary"`, `danger`, icon `<StopOutlined />`, visible label `"Dừng"`, `aria-label="Dừng sinh phản hồi"`, tooltip `"Dừng sinh phản hồi"`).
    - If idle: "Gửi" button (`type="primary"`, icon `<SendOutlined />`, visible label `"Gửi"`, `aria-label="Gửi tin nhắn"`, tooltip `"Gửi tin nhắn (Cmd+Enter)"`, disabled if input is empty).

### 5. NineRouterConfigCard (Settings View - AI Tab)
- Located in `SettingsView` under new Tab 5 `"ai"` (label: `<RobotOutlined /> Trợ lý AI`).
- Fields:
  - **API Endpoint**: `Input` (default: `https://api.9router.com/v1`, placeholder: `https://.../v1`).
  - **API Key**: `Input.Password` with show/hide toggle. Encrypted in OS Keychain (Tauri) or Dexie `settings` (Web).
  - **Model mặc định**: `Select` or `AutoComplete` (e.g. `gpt-4o-mini`, `gpt-4o`, `claude-3-5-sonnet`, `deepseek-chat`). Populated automatically after connection test.
  - **Giới hạn ký tự ngữ cảnh (Safe char limit)**: `InputNumber` (default `12000` ký tự, range 2000 - 32000).
- Actions:
  - Button `"Kiểm tra kết nối"` (`type="default"`, icon `<ApiOutlined />`): calls `GET /v1/models` using provided key/endpoint.
  - Connection status alert:
    - Success: `<Alert type="success" showIcon message="Kết nối thành công. Đã tìm thấy {count} mô hình AI." />`
    - Failure: `<Alert type="error" showIcon message="Kết nối thất bại" description="{error details}" />`
  - Button `"Lưu cấu hình"` (`type="primary"`).

## Interaction & Keyboard Contracts

| Shortcut / Action | Scope | Behavior |
|-------------------|-------|----------|
| `Cmd+J` / `Ctrl+J` | Global | Toggle AI Chat Drawer open/closed. |
| `Cmd+Enter` / `Ctrl+Enter` | Chat Input | Send message immediately. |
| `Enter` | Chat Input | Standard newline insertion (preserves multiline formatting). |
| `/clear` command | Chat Input | Executes context reset divider without making LLM call. |
| `Esc` | AI Chat Drawer | Closes drawer IF `isPinned === false`. If pinned, retains focus in main view. |
| Left border drag | Drawer border | Resizes drawer smoothly between 320px and 650px. Saves width on mouse up. |
| Item Click / Inspect | App-wide | When chat is open and auto-follow is active, switches scope to inspected item. |
