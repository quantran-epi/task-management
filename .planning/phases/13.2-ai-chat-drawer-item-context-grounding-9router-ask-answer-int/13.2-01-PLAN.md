<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client → 9router Cloud API | API key and prompts transmitted over HTTPS using native fetch |
| OS Keychain / IndexedDB Settings | API key stored in OS secure storage on desktop or origin-scoped IndexedDB on web |
| Database SCHEMA_V8 | Chat threads and messages stored locally in Dexie IndexedDB |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13.2-01 | Information Disclosure | `nineRouterTokenService.ts` | mitigate | Store API key in OS Keychain via Tauri keyringService on desktop; never store key in localStorage; redact key in errors (`***`). |
| T-13.2-02 | Denial of Service | `nineRouterClient.ts` | mitigate | Handle SSE stream line-buffering properly; listen to AbortController signals to immediately close response stream upon user cancel or unmount. |
| T-13.2-03 | Tampering | `cascadeRepo.ts` | mitigate | Clean up associated `chatThreads` and `chatMessages` in atomic Dexie transactions whenever a task, milestone, or project is deleted. |
| T-13.2-SC | Tampering | npm packages | mitigate | Zero new npm dependencies; use native browser `fetch`, `ReadableStream`, `TextDecoderStream`, and existing Ant Design / Dexie modules. |
</threat_model>
