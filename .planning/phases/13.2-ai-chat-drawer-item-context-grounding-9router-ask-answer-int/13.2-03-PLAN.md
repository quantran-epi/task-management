<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client App → Local Filesystem | Reading local file head for context grounding |
| Client App → OS Terminal Process | Spawning external CLI command with task prompt |
| Local Notes / Content → LLM Prompt | Aggregating unvalidated text into LLM system prompt |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13.2-06 | Denial of Service / Spoofing | `contextGrounding.ts` | mitigate | Strict clamping of context prompt at 12,000 characters maximum; wrap item data in XML tags `<item_context>` to demarcate user data from system instructions. |
| T-13.2-07 | Remote Code Execution / Injection | `claudeCliService.ts`, `src-tauri` | mitigate | Sanitize and escape all prompt strings passed to OS terminal; do not execute arbitrary shell commands; only launch `claude` with escaped prompt argument. |
| T-13.2-05 | Information Disclosure | `contextGrounding.ts` | mitigate | Limit local file ingestion to text files (.txt, .md, .json, source code) and cap at 2,000 lines; do not read binary files or sensitive system paths (.ssh, .env). |
</threat_model>
