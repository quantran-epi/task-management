## Overview

Plan 13.2-03 grounds the AI Chat Assistant in real project, task, and milestone context, while connecting deep work to Claude Code CLI and enabling one-click workflows:

1. **Context Grounding Serializer Engine (`src/services/ai/contextGrounding.ts`):**
   - Formats active Task, Project, or Milestone into structured XML `<item_context>` tags containing status, priority, estimates, checklist items, tags (Ops Owners, BAs), and task notes.
   - Queries attached Sticky Notes (`db.notes`) and screenshot attachments (`db.noteAttachments`), embedding note content and screenshot captions.
   - Inspects `documentLinks`: on Tauri desktop, invokes `read_local_file_text_head` to read the first 2,000 lines of text files (.txt, .md, .json, source files), while leaving binary files as metadata references.
   - Embeds external web URLs as domain metadata without scraping remote HTML.
   - Enforces a strict 12,000 character maximum budget with truncation notice to prevent prompt injection or token bloat (mitigates T-13.2-06).

2. **Native Tauri IPC Commands (`src-tauri/src/jira_proxy.rs`, `src-tauri/src/lib.rs`):**
   - `read_local_file_text_head(file_path, max_lines)`: Safely streams first N lines with validation blocking sensitive directories (`.ssh`, `.gnupg`, `.env`).
   - `launch_claude_terminal(command_str)`: Spawns external OS terminal running `claude` (osascript Terminal.app on macOS, cmd.exe on Windows).

3. **Claude Code CLI Service (`src/services/ai/claudeCliService.ts`):**
   - Formats task goals, pending checklist items, and local file paths into shell-escaped command `claude '...'`.
   - On Desktop Tauri, launches OS terminal directly; on Web/PWA, copies command to clipboard with Ant Design feedback.

4. **Message Action Chips & System Grounding Wiring:**
   - Updated `ChatMessageBubble` to render Action Chips: "Thêm vào Checklist", "Lưu vào Sticky Notes", and "Chạy với Claude Code".
   - Wired `buildItemContextPrompt` inside `AIChatDrawer.tsx` when preparing messages for `streamChatCompletion`, injecting ground-truth item context as system prompt.
