<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Network → Neo4j Database | Neo4j resides inside Kubernetes ClusterIP network; inaccessible outside cluster. |
| Network → knowledge-server | TaskMate reaches knowledge-server via NodePort. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-19.1-01 | Information Disclosure | k8s/*.yaml | mitigate | Zero credentials or Base64 secret strings in committed YAML; use secretKeyRef exclusively (D-05). |
| T-19.1-02 | Elevation of Privilege | k8s/neo4j.yaml | mitigate | Restrict Neo4j service to ClusterIP (D-02); never expose Bolt port (7687) to NodePort or public ingress. |
| T-19.1-03 | Denial of Service | k8s/neo4j.yaml | mitigate | Declare PersistentVolumeClaim with ReadWriteOnce and request limits to avoid unbounded disk consumption. |
| T-19.1-SC | Tampering | knowledge-server/Dockerfile | mitigate | Multi-stage build with non-root runtime container and pinned base image. |
</threat_model>
