# Phase 19.1 Plan 03: Client-Side Fallback Taxonomy & Isolation Summary

Strict error taxonomy and fallback allowlist enforcement in `knowledgeClient.ts` and `groundedTurn.ts` preventing silent degradation to local BM25 for authentication, configuration, and invalid response errors.

## Key Changes

- **Taxonomy Helpers:** Added and exported `isTransportFailure` and `isFallbackAllowed` in `src/services/knowledge/knowledgeClient.ts`.
- **Strict Fallback Gating:** In `src/services/ai/groundedTurn.ts`, verified and enforced that fallback to local BM25 is strictly restricted to transport failures (`NETWORK_ERROR`, `TIMEOUT`, HTTP 5xx, or network disconnection `TypeError`).
