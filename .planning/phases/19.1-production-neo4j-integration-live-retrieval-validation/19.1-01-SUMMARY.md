## Behavior Changes

### WR-01 — Status counts (ActiveGraphView)

`getActiveGraph(setId)` now returns real persistent counts stored on `GraphSnapshot`:

- `nodeCount` — from `candidate.nodes.length`
- `relationCount` — from `candidate.relations.length`
- `factCount` — from `candidate.relations.length`
- `conflictCount` — from `candidate.conflicts.length`
- `quarantineCount` — from `(candidate.quarantines || []).length`
- `approvedFactCount` — from relations filtered to `effectiveClassification === 'BUSINESS_APPROVED'`

Cypher additions:

- `INSERT_GRAPH_SNAPSHOT` now sets `s.nodeCount`, `s.relationCount`, `s.factCount`, `s.conflictCount`, `s.quarantineCount`, `s.approvedFactCount`, `s.quarantinesJson`.
- `GET_ACTIVE_GRAPH` projects all six count columns.

Value conversion uses new `toSafeInt(v)` helper handling Neo4j Integer `toNumber()` and raw number, defaulting to 0 on null.

### WR-02 — Durable quarantines

`getQuarantines(graphSnapshotId)` now reads `s.quarantinesJson` from Neo4j via new parameterized `GET_QUARANTINES_BY_SNAPSHOT` query. In-memory `quarantinesBySnapshot` map retained only as read-through fallback for empty record sets (keeps pre-19.1 same-process semantics intact without breaking persistence guarantee). A new `Neo4jRepository` instance against the same database state retrieves persisted quarantines without needing the write-side state transfer.
