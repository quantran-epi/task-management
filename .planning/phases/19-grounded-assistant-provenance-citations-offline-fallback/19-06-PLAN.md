    Create `src/services/search/localGroundedRetrieval.ts` exporting:

    - Type `LocalEvidenceRange`: `{ documentId: uuid; documentTitle: string; sectionAnchor: string|null; lineStart: int; lineEnd: int; startOffset: int; endOffset: int; rawSnippet: string; contentHash: string; score: number; matchedTerms: readonly string[]; setMemberships: readonly {setId: uuid; setName: string}[] }`.
    - Type `LocalGroundedResult`: `{ ranges: readonly LocalEvidenceRange[]; strongEvidence: boolean; totalScanned: int }`.
    - Function `runLocalGroundedRetrieval(input, deps): Promise<LocalGroundedResult>` where `input = {query: string; resolvedSetIds: readonly uuid[]; maxResults: int (default 5); maxSnippetChars: int (default 1200)}` and `deps = {loadSetMembers(setIds): Promise<MemberEntry[]>; loadNoteBody(documentId): Promise<{title, body, updatedAt}>}`.

    Behavior (D-37/D-39/D-40/D-42):
    1. If `resolvedSetIds` is empty, return `{ranges: [], strongEvidence: false, totalScanned: 0}` and let caller ask clarification instead (D-37).
    2. Call `deps.loadSetMembers(resolvedSetIds)` producing `MemberEntry = {setId, setName, documentId}` entries. Dedupe `documentId` across sets but retain `setMemberships` list per document.
    3. For each unique document load title+body via `deps.loadNoteBody`; skip documents the loader rejects as missing (do not fabricate).
    4. Tokenize query via `src/utils/bm25.ts` tokenize; rank candidates via `rankBM25` with Title ×3, Tags ×2, Body ×1 (existing weighting).
    5. For each top candidate (up to `maxResults`), compute the matching range deterministically:
       - Split body by newline (`trimmed.split('\n')`), find line indices where any `matchedTerm` appears (case/diacritic-insensitive using existing normalization).
       - Compute `lineStart`/`lineEnd` as the smallest contiguous or near-contiguous (window ≤ 6 lines) window around densest match.
       - Compute `startOffset`/`endOffset` via running character sum from body start.
       - Snippet substring from body `[startOffset, endOffset]`, cap at `maxSnippetChars` (never cross document boundary).
       - `sectionAnchor` from nearest preceding Markdown heading (same scan heuristic as existing `extractRelevantSnippet`).
       - `contentHash = computeSha256(normalizeMarkdownForHash(body))` (full-document hash for mismatch comparison in UI).
    6. Dedupe final list by `(documentId, lineStart, lineEnd)` with earliest-score tie-break; attach aggregate `setMemberships` from step 2 (D-39).
    7. Strong-evidence verdict (D-38): `strongEvidence = ranges.length > 0 && (matchedTerms.distinct.size >= 2 || hasExactIdentifierOrTitleMatch) && topScore > 0`. Expose as `strongEvidenceVerdict(result)` helper for testability.
    8. Never consume `AbortSignal` for retrieval; computation is synchronous enough that caller aborts in surrounding turn state machine.

    Export helpers `tokenizeQuery(query): string[]` and `isStrongEvidence(ranges, matchedTerms): boolean`.
  </action>
