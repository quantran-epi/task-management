    - Group `paths` by `snapshotId`. Render ONE Ant `Card` per snapshot (D-14 never concatenates). Card header shows snapshot label (first 7 chars of snapshotId + optional document-set name resolved from citations in that path).
    - Within a card:
      - Determine primary path: if `paths.some(p => p.hasConflict)` within this snapshot → NO primary (D-13); render each path with equal weight. Otherwise primary is the shortest hop count; alternatives collapse behind an `Xem N đường thay thế` affordance.
      - Each path renders as a vertical step list. For each hop: `[sourceURN] → [relation (edgeFactKey)] → [targetURN]` on one row (14px body), classification badge below (Observed / Inferred / Business-Approved), hop citations via `CitationGroup` from Plan 11 using filtered citation lookup for `hopCitationIds[i]`. Use `aria-label` listing full hop path. Hop connector line uses `colorPrimary` (UI-SPEC §Color accent #2).
    - Section heading per `GroundedAnswerCard` collapse: `Xem đường dẫn suy luận (N bước)` where N is total unique hops across all paths.

    Create `src/components/ai/grounded/SourcesPanel.tsx` exporting `SourcesPanel({citations, onOpenCitation}: {citations: readonly PersistedCitation[]; onOpenCitation: (c: PersistedCitation) => void})`:

    - Dedupe by `(documentId, lineStart, lineEnd, publishedContentHash ?? 'local')`.
    - Render Ant `Table` compact mode. Columns: `#` (index number matching citationId numeric suffix), `Document` (documentTitle), `Section` (sectionAnchor or empty), `Range` (`L{startLine}-{endLine}`), `Class` (evidenceClass badge), `Snapshot` (truncated 7-char with full in Tooltip, or `Local` tag for local authority).
    - Rows clickable → calls `onOpenCitation(c)`. Keyboard: Enter on focused row activates. `aria-label` on each row includes full data.
    - Local vs server rows visually distinct via `Local` tag column (no color-only per UI-SPEC Accessibility).

    Create `src/components/ai/grounded/DiagnosticsPanel.tsx` exporting `DiagnosticsPanel({diagnostics, scope, coverageWarnings, fallbackReason, routerSource, promptVersion, schemaVersion, repairs}: props)`:

    - Ant `Collapse` panel titled `Chi tiết chẩn đoán truy xuất`.
    - Render as a `Descriptions` list: modality statuses (fullText/vector/graph each with `ok|degraded|unavailable|stale|truncated` enum), per-modality latency (ms), scope resolution source (`llm|alias|base_default`), `fallbackReason` enum, `coverageWarnings` as bullet list (strings only, pre-written in state machine — no user text here), `promptVersion`, `schemaVersion`, repair count.
    - Content-free per AI-SPEC §7: this component receives ONLY enums/counts/strings produced by the state machine; it must never render user query, source text, model raw output. Add JSDoc comment stating this invariant.
