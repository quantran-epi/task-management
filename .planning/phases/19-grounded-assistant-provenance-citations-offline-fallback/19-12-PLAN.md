      2. Partition paths into three buckets:
         - **Variation bucket** (neutral): `backing.scopeProof.dimension !== 'Unknown'` AND `backing.scopeProof.overrideRelation` ∈ `{'EXTENDS', 'SUPPLEMENTS'}`. These are "sibling" paths that differ only by proven scope.
         - **Conflict bucket** (destructive): `backing` exists AND (`backing.scopeProof.dimension === 'Unknown'` OR `backing.scopeProof.overrideRelation == null`). These are unresolved disagreements.
         - **Normal bucket**: no backing conflict group found.
      3. Render Variation bucket inside a shared **neutral variation container**: Ant `Card` with `type="inner"`, title parameterized by `backing.scopeProof.dimension` (`Khác biệt theo môi trường` for Environment, `Khác biệt theo phiên bản` for Version, `Khác biệt theo hành vi` for Behavior). Container MUST reuse the neutral styling tokens from `ScopeVariationCard` (same gray/info color tokens; NO `role="alert"`, NO destructive color). Add `data-testid="graph-path-variation-container"` + `data-dimension={dimension}` for test assertions. Each path inside renders as a labeled sibling (prefix label `Bối cảnh: {branchLabel}` where `branchLabel` is derived from the backing branch's `scopeFacets` summary).
      4. Render Conflict bucket inside a shared **destructive container**: Ant `Card` with `type="inner"`, `role="alert"`, title `Không có đường chính — cần xác minh` (D-29 "no primary, verify required"). Container uses destructive color tokens. Add `data-testid="graph-path-conflict-container"`.       5. Normal bucket renders inline as before (primary + collapsed alternatives, see rule below).
    - Primary-path rule for the Normal bucket only: if `paths.some(p => p.hasConflict)` within this bucket → NO primary (D-13); render each path with equal weight. Otherwise primary is the shortest hop count; alternatives collapse behind an `Xem N đường thay thế` affordance.
