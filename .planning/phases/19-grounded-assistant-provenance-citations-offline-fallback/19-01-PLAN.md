</objective>

    Export new `OrderedPathSchema` (strict object): `pathId` (regex `^P[1-9][0-9]*$`), `snapshotId` (regex `^gsnap_[0-9a-f]{8,}$`), `nodeUrns` (readonly tuple of URN strings, length 2..4), `edgeFactKeys` (readonly tuple length 1..3), `hopClassifications` (tuple of `EVIDENCE_CLASSIFICATION` same length as edgeFactKeys), `hopCitationIds` (tuple of citation id arrays, outer length === edgeFactKeys.length, each inner non-empty), `hasConflict` boolean, `classification` (effective worst `EVIDENCE_CLASSIFICATION`). Add `superRefine` enforcing `nodeUrns.length === edgeFactKeys.length + 1` and `hopClassifications.length === edgeFactKeys.length` and `hopCitationIds.length === edgeFactKeys.length`.

    Export new `SourceRefSchema` (strict object): `documentId` (uuid), `documentTitle` (string min 1 max 400), `sectionAnchor` (string min 1 max 256 nullable), `lineStart` (positive int), `lineEnd` (positive int, superRefine lineEnd >= lineStart), `publishedContentHash` (regex `^[0-9a-f]{64}$`), `snapshotId` (same pattern as above), `scope` (new `ScopeProofSchema` nullable).

    Export new `ScopeProofSchema` (strict object, D-17/D-25): `dimension` enum `['Version', 'Environment', 'Behavior', 'Unknown']`, `environment` nullable string (max 32), `version` nullable string (max 32), `overrideRelation` enum `['EXTENDS', 'SUPPLEMENTS', 'SUPERSEDES']` nullable. Reject any value for `dimension` outside the allowlist. Per D-15/D-25/D-29 scope MUST originate from structured metadata only; schema has no free-text field.

    Extend `ChunkItemSchema` (do not break existing shape): add required `sourceDocumentTitle` (string min 1 max 400) and `publishedContentHash` (same 64-hex regex). Keep every existing field. Keep per-item `snapshotId` already present.

    Extend `ConflictGroupSchema` (D-15/D-25/D-29): add optional `scopeProof` field typed as `ScopeProofSchema` nullable. If `dimension` is `'Unknown'` and `scopeProof` is non-null, `superRefine` requires every other scope field to be null (no invented explanation).

    Extend `BaseRetrievalResponseSchema`: add new field `paths: z.array(OrderedPathSchema).max(20)` default to empty tuple. Keep every existing field. Add top-level `superRefine` enforcing `paths.every(p => p.hopCitationIds.flat().every(id => citationsById.has(id)))` referencing existing citation ids collected from `items`. Reject when any `OrderedPath.snapshotId` is absent from the per-set `snapshotId` the response already carries.

    Export new `OrderedPath`, `SourceRef`, `ScopeProof` types via `z.infer` for downstream reuse. Do NOT touch `RETRIEVAL_OUTCOMES`. Do NOT add any new outcome enum value.
