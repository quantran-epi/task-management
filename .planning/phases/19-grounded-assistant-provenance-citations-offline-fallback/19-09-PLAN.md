    Create `src/services/ai/groundedTurn.ts` exporting:

    - `GroundedTurnInput` type: `{query: string; recentTurns: readonly {role, content}[]; signal: AbortSignal; capabilities: {serverEnabled: boolean; modelConfigured: boolean}; config: {endpoint, apiKey, model, promptVersion, routerVersion}; catalog: readonly SetCatalogEntry[]; recentSessionId: string;}`.
    - `GroundedTurnResult` type (discriminated union by `kind`):
      - `{kind: 'operational'; routedQuery: string}` — defer to existing operational loop.
      - `{kind: 'clarify_intent'}` — render routing clarification chips (D-09).
      - `{kind: 'clarify_entity'; candidates: readonly CandidateRef[]; outcome: 'NEEDS_CLARIFICATION'}` (D-04).
      - `{kind: 'refine'; outcome: 'NO_EVIDENCE'|'UNSUPPORTED'; refinementChips: readonly string[]}` (D-07).
      - `{kind: 'grounded_answer'; grounding: ChatMessageGrounding}` — fully synthesized READY/DEGRADED/LOCAL_FALLBACK_SYNTHESIS.
      - `{kind: 'local_fallback_results'; grounding: ChatMessageGrounding}` — LOCAL_FALLBACK_RESULTS (D-38 weak snippets).
      - `{kind: 'evidence_only'; grounding: ChatMessageGrounding}` — MODEL_UNAVAILABLE after server READY (D-43).
      - `{kind: 'error'; code: 'ERROR_AUTH'|'ERROR_CONFIG'|'ERROR_INVALID_RESPONSE'|'INVALID_GROUNDED_OUTPUT'; grounding: ChatMessageGrounding}`.

    - `runGroundedTurn(input, deps): Promise<GroundedTurnResult>` where `deps` injects every service created in Waves 2-4: `routeIntent`, `routeScope`, `retrieveFederated` (via knowledgeClient), `runLocalBm25`, `packEvidence`, `synthesizeGroundedAnswer`, `now()`, `generateTurnId()`.

    State machine (D-08/D-09/D-18/D-20/D-36/D-41/D-43/D-45):

    1. **Route intent**. If `operational` → return `{kind: 'operational', routedQuery: query}`. If `clarify` → return `{kind: 'clarify_intent'}`. If `knowledge` or `mixed` → continue.
    2. **Resolve scope** via `routeScope(query, {catalog, completeJson, signal})`. If `capabilities.modelConfigured === false`, pass `completeJson = undefined` so router falls to deterministic alias path (D-20).
    3. **Branch on server availability**:
       - If `capabilities.serverEnabled === false` → **direct to local path** step 6 with `fallbackReason: 'SERVER_DISABLED'`.
       - Else call `knowledgeClient.retrieveFederated({query, setTierAssignments: resolvedScope.setTierAssignments, comparisonMode, budgets}, signal)`.
    4. **Handle retrieve error** (D-41 fallback allowlist):
       - `NETWORK_ERROR` / `TIMEOUT` → fall through to local path step 6 with `fallbackReason: 'NETWORK_ERROR'` / `'TIMEOUT'` and preserve `coverageWarnings` naming unreachable server.
       - `ABORTED` → re-throw (don't persist; caller discards result per turn ownership D-11/AI-SPEC §4b).
       - `INVALID_RESPONSE` → return `{kind: 'error', code: 'ERROR_INVALID_RESPONSE', grounding: {... outcome: 'ERROR_INVALID_RESPONSE'}}` — never fall back silently.
       - `REMOTE_ERROR` with status 401/403 → return `{kind: 'error', code: 'ERROR_AUTH'}` — never fall back (D-41).
       - `REMOTE_ERROR` with status 400 / 404 (config) → return `{kind: 'error', code: 'ERROR_CONFIG'}`.
       - Other `REMOTE_ERROR` 5xx → fall through to local path with `fallbackReason: 'NETWORK_ERROR'` (treat as transport).
    5. **Branch on retrieval outcome** (D-04/D-07/D-43):
       - `NEEDS_CLARIFICATION` → return `{kind: 'clarify_entity', candidates, outcome}`. Zero model calls.
       - `NO_EVIDENCE` / `UNSUPPORTED` → derive refinement chips (first from server suggestions, else deterministic defaults from UI-SPEC Copywriting). Return `{kind: 'refine', ...}`. Zero model calls.
       - `READY` / `DEGRADED` → pack server evidence then step 7.
    6. **Local BM25 path** (D-37/D-38/D-39/D-40):
       - If `resolvedScope.setTierAssignments.length === 0` → scope cannot be resolved safely → return `{kind: 'clarify_intent'}` (D-37 asks user instead of global scan).
       - Call `runLocalBm25({query, resolvedSetIds: resolvedScope.setTierAssignments.map(s => s.setId), ...})`.
       - If `strongEvidence === true` AND `capabilities.modelConfigured === true` → pack local, synthesize, return `grounded_answer` with outcome `LOCAL_FALLBACK_SYNTHESIS`.
       - If `strongEvidence === false` OR `modelConfigured === false` → return `{kind: 'local_fallback_results'}` with grounding carrying ranked ranges and outcome `LOCAL_FALLBACK_RESULTS`.
    7. **Pack + synthesize** (server path):
       - `pack = packEvidence({authority: 'server', serverResponse}, options)`.
       - If `capabilities.modelConfigured === false` AND outcome === `READY`/`DEGRADED` → return `{kind: 'evidence_only', grounding: {outcome: 'MODEL_UNAVAILABLE', authority: 'server', ...}}` (D-43). Grounding carries full citations/paths/conflicts so UI can show ranked evidence.
       - Else `answer = await synthesizeGroundedAnswer({...pack, signal})`.
       - On `GroundedSynthesisError('INVALID_GROUNDED_OUTPUT')` → return `{kind: 'error', code: 'INVALID_GROUNDED_OUTPUT', grounding: {outcome: 'INVALID_GROUNDED_OUTPUT', ...ranked evidence persisted so retry works}}` (D-45).
       - On `GroundedSynthesisError('MODEL_UNAVAILABLE')` → return `{kind: 'evidence_only', ...}` (D-43).
       - On `GroundedSynthesisError('ABORTED')` → re-throw.
       - On success return `{kind: 'grounded_answer', grounding: {outcome: 'READY'|'DEGRADED', authority: 'server', answer, citations, paths, conflicts, scope, modalityDiagnostics, coverageWarnings, fallbackReason: 'NONE', routerVersion, promptVersion, schemaVersion: 1, modelId, createdAt}}`.
    8. **Abort check before return**: if `signal.aborted` throw instead of returning; caller must not persist stale turn.

    Also export `synthesizeFromStoredEvidence(storedGrounding: ChatMessageGrounding, deps): Promise<GroundedTurnResult>`. Logic (D-44):
    - Rehydrate the stored evidence pack from `storedGrounding.citations` + `storedGrounding.paths` + `storedGrounding.conflicts`. Build `promptEvidence` from each citation's `citedExcerpt`.
    - Call `synthesizeGroundedAnswer` with the rebuilt pack and current capability profile. Do NOT re-run retrieval.
    - Return `grounded_answer` on success with same `citations`/`paths`/`conflicts` as the stored grounding (D-46 historical durability). Only `answer` and `modelId`/`createdAt` change.

    Also export `createFreshLookupTurn(prevGrounding, newInput, deps): GroundedTurnInput` helper (D-49). Returns the input to pass to `runGroundedTurn` for a fresh retrieval; caller presents result as a NEW message, preserving `prevGrounding` unchanged. This file does not persist; caller (Plan 10 wiring + Plan 13 chat drawer) owns IndexedDB writes.
