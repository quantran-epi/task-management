    - `'grounded_answer'` / `'local_fallback_results'` / `'evidence_only'` → saveMessage via `chatRepo.saveMessage({..., content: '', grounding: result.grounding})` using signal check per AI-SPEC §4b (confirm `signal.aborted === false` before write).

    - `onAuthRepair` → navigate to Settings → Knowledge Server config.
    - `onConfigRepair` → navigate to Settings.
