  <action>
    Create `src/services/ai/evidencePack.ts` exporting:

    - `EvidencePack` type (readonly): `{ authority: 'server'|'local'; citations: Readonly<Record<string, SourceRecord>>; paths: Readonly<Record<string, ValidatedPath>>; conflicts: readonly ConflictGroup[]; promptEvidence: readonly {id: string; text: string}[]; contextTruncated: boolean; coverageWarnings: readonly string[]; }`.
    - `SourceRecord` type: `{ citationId: string; documentId: uuid; documentTitle: string; sectionAnchor: string|null; lineStart: int; lineEnd: int; authority: 'server'|'local'; evidenceClass: 'OBSERVED'|'INFERRED'|'BUSINESS_APPROVED'|'LOCAL'; snapshotId: string|null; publishedContentHash: string|null; citedExcerpt: string; setMemberships: readonly {setId, setName}[]; evidenceKind?: 'policy_change'|'release_note'|'migration_record'|'other'; }`.
    - `ValidatedPath` type: `{ pathId: string; snapshotId: string; nodeUrns: readonly string[]; edgeFactKeys: readonly string[]; hopClassifications: readonly string[]; hopCitationIds: readonly (readonly string[])[]; classification: string; hasConflict: boolean; }`.
    - `packEvidence(input, options): EvidencePack` where:
      - `input = { authority: 'server'|'local'; serverResponse?: FederatedRetrievalResponse; localResult?: LocalGroundedResult }`
      - `options = { maxEvidenceChars: int (default 8000 server / 6000 local); maxPromptEvidenceCount: int (default 20 server / 5 local); maxPerSnippetChars: int (default 1200); }`

      Logic (AI-SPEC §4 step 4-6 + §4b packing order):
      1. Assign opaque citation ids: scan server `items[]` citations in encounter order; dedupe by `(documentId, lineStart, lineEnd, publishedContentHash)` or by `(documentId, lineStart, lineEnd, 'local')` for local; emit `S1, S2, ...` for server authority and `L1, L2, ...` for local. Merge `setMemberships` across duplicates (D-39).
      2. Assign opaque path ids `P1, P2, ...` for server paths; drop any path whose `hopCitationIds` reference a citation that was dedupe-pruned (closure invariant).
      3. Compute `citedExcerpt` for each citation: use `rawSnippet` from local result OR extract bounded snippet from `item.snippet` for server; cap at `maxPerSnippetChars`.
      4. Enforce packing order (AI-SPEC §4b): emit `promptEvidence` entries ordered as
         - (a) every citation referenced by a conflict branch,
         - (b) exact identifier/title hits (items with `matchType === 'identifier'` or server-marked exact match),
         - (c) citations supporting any complete `ValidatedPath`,
         - (d) remaining ranked items.
      5. Drop whole units when total `promptEvidence` char count would exceed `maxEvidenceChars`. If any drop occurs set `contextTruncated = true` and emit a `coverageWarnings` string naming the dropped category (e.g., `"3 lowest-ranked chunks omitted for budget"`). Never truncate a single snippet mid-range — drop the whole citation (D-03).
      6. Carry conflicts as-is but strip from `promptEvidence` any claim-level conflicting fact; the model receives both branches as separate evidence items but never a merged claim (D-28).
      7. Carry `coverageWarnings` from federated response (partial failure) in addition to budget warnings.
      8. Propagate server `evidenceKind` tag onto `SourceRecord.evidenceKind` when present so the D-26 closure guard (below) can check cited-evidence allowlist.

    - `validateGroundedAnswerClosure(answer: GroundedAnswer, pack: EvidencePack): {valid: boolean; issues: readonly {path: string; code: string; message: string}[]}`:
      Logic:
      1. Every `claim.citationIds[i]` must exist in `pack.citations` (D-01).
      2. Every INFERRED `claim.pathId` must exist in `pack.paths` AND every edge in that path must have at least one citation present in `claim.citationIds` or the path's own `hopCitationIds` closure (D-02).
      3. DIRECT claim must have null `pathId` AND evidenceClass per cited sources (mixed uses weakest: `LOCAL` < `INFERRED` < `OBSERVED` < `BUSINESS_APPROVED`) — compute weakest supporting classification (D-30).
      4. No claim.text may paraphrase a fact that appears in any `pack.conflicts[i].branches` fact field unless it is attributed as "both branches cite" with every branch citationIds included (D-28). Deterministic check: for each claim.citationIds set, assert it is not a strict subset of only one branch of any active conflict group whose `claimTemplate` is covered.
      5. **D-26 override-language guard** (new): define `OVERRIDE_TERMS = /\b(overrides?|supersed(e|es|ed|ing)|replaces?|th(a|ạ|a)y th(ế|e)|ghi đè|thay th(ế|e))\b/iu` and `ALLOWED_EVIDENCE_KINDS = new Set(['policy_change','release_note','migration_record'])`. For each claim whose `text` matches `OVERRIDE_TERMS`:
         - If `claim.pathId` resolves to a `ValidatedPath` AND there exists a `pack.conflicts[k].scopeProof.overrideRelation === 'SUPERSEDES'` where the conflict group's citationIds intersect `claim.citationIds` → accept.
         - Else if every `citationId` in `claim.citationIds` resolves to a `SourceRecord.evidenceKind` in `ALLOWED_EVIDENCE_KINDS` AND `|claim.citationIds| >= 1` → accept.
         - Else → emit issue `{path: 'claims[i].text', code: 'override_language_without_proof', message: 'Claim asserts override/supersede without SUPERSEDES metadata or cited policy_change/release_note/migration_record evidence'}` and set `valid: false`.
         Match is Unicode-aware (`u` flag) and case-insensitive; Vietnamese tokens `thay thế`, `ghi đè` MUST be covered by the regex.
      6. Issue path strings mirror Zod issue path format for parity with downstream error renderer.

    Export helpers `nextCitationId(authority, index)`, `nextPathId(index)`, `computeWeakestClassification(classifications: readonly string[])`, and `claimAssertsOverride(text: string): boolean` (shared with ClaimBlock renderer in Plan 19-11 via re-export).

    No new runtime dependency. Pure functions. No side effects.
