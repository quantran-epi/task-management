<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Web Notification API → Operating System | Local browser Notification constructor sends summary title and body to OS notification center |
| User UI Click → Routing Navigation | Hash route parameter navigation to `/planner?date=YYYY-MM-DD` |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-07 | Information Disclosure | `src/hooks/useDesktopNotification.ts` | mitigate | Use aggregated summary counts in notification body rather than leaking sensitive task names or confidential project descriptions to the OS lock screen |
| T-12-08 | Denial of Service | `src/hooks/useDesktopNotification.ts` | mitigate | Throttle desktop notification to once per browser session via `sessionStorage` key `desktop_notification_shown` to prevent spamming notifications on live query updates |
| T-12-09 | Tampering / Malformed Navigation | `src/components/shell/AppShell.tsx` | mitigate | Sanitize date parameters passed to `onNavigate('planner', { date })` ensuring valid `YYYY-MM-DD` format before routing |
| T-12-SC | Tampering | Existing npm dependencies | mitigate | Zero new dependencies; built with native `window.Notification` and existing Ant Design components |
</threat_model>
