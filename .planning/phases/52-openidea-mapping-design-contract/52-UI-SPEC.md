### Nguyên tắc biên giới (không đàm phán ở Phase 53-56)

1. **API wrapper là hợp đồng** — caller không sửa. Mọi props, event, generic, static subcomponent, hook, controlled/uncontrolled, validation policy, default và accessible name giữ nguyên theo `51-CONTROL-INVENTORY.md` §2/§4 (xem §6).
2. **Metric control lấy từ OpenIDEA** — height 28, radius 4, font 13/12/11, selection radius 5, tab radius 6, popup radius 10, list row 24, popup offset 4, focus ring 2px accent. Không giữ height 30 của AntD cho control.
3. **Palette shell ≠ palette control** — workbench chrome (titlebar 40, statusbar 26, stripe 36, island/shell màu hiện tại) giữ nguyên; control/portal dùng token OpenIDEA nêu ở §4 và §8. Phase 57 đo control, không đo lại chrome.
4. **DOM/class bám source** — dùng cùng cấu trúc `clsx(styles.root, styles[variant])`, class name và thứ tự phần tử như CSS module gốc để parity computed-style; chỉ thêm `data-oi-control` / `data-state` làm hook đo (không đổi API).
5. **Caller style win** — inline `style` của caller luôn áp sau token default; `withoutUndefined()` vẫn bỏ key `undefined` (`exactOptionalPropertyTypes`).
6. **Không copy AntD behavior ngầm** — mọi static API (`message.*`, `notification.*`, `Modal.confirm`) vẫn đi qua holder/hook; realtime notification không reload (memory rule).

## 3. Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, `--space-1` |
| sm | 8px | Compact element spacing, field padding, `--space-2` |
| md | 16px | Default element spacing, card padding, `--space-4` |
| lg | 24px | Section padding, list/tree row height |
| xl | 32px | Layout gaps, icon fallback size |
| 2xl | 48px | Major section breaks, result icon |
| 3xl | 64px | Page-level spacing |

Exceptions (đã có trong source OpenIDEA/proof, không đổi): `--space-0-5: 2px`, `--space-1-5: 6px` (gap giữa icon/chip và `--island-gap`), `--space-3: 12px` (tree indent, titlebar padding), `--list-inset: 6px`, `--popup-offset: 4px`. Các dimension không phải spacing: control height 28, titlebar 40, statusbar 26, stripe 36, tabbar 36, tree icon 16, list row 24, checkbox 16, toggle 42×18, dialog titlebar 32 (mac 28), traffic light 12.

## 4. Typography

Ba kích thước control, đúng OpenIDEA; giữ 16px-only cho legacy Display `typography.tsx` (đã có từ Phase 49, không phát sinh size mới).

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body / UI control (`--fs-ui`) | 13px | 400 regular | 1 (`Button`), 16px (`Tooltip`) |
| Label / compact (`--fs-small`) | 12px | 400 regular | 1.4 |
| Tiny / meta (`--fs-tiny`) | 11px | 600 cho toggle ON/OFF, 400 cho meta | 1.4 |
| Display legacy (chỉ `Typography.Title`) | 16px | 600 semibold | 1.2 |

Font weights tối đa 2: 400 và 600. Cấm fractional font-size trong control; mọi `13.5px` sót thuộc app info surfaces, không thuộc contract này. Font family control: `Inter` + fallback hệ thống; mono: `IBM Plex Mono` (TaskMate) / `JetBrains Mono` (OpenIDEA) — giữ fallback TaskMate để offline, không bundle font mới.

**Accent reserved for (danh sách đóng):** primary button nền; focus ring; checked state của checkbox/radio/switch-on knob track khi dùng accent; active row check SVG/background selection; slider/progress fill; link; spinner indicator; selection highlight của text. **Không dùng accent cho** mọi border, mọi icon, mọi heading, hoặc shell chrome. Status colors success/warning/danger/info của `statusColorMap` (D-12) giữ nguyên cho Tag/Badge/StatusDot/progress status; riêng control-level invalid dùng `--danger` OpenIDEA ở trên.

Quyết định accent: migrate `#2f62d8` (light) và `#6a9bff` (dark) → `#3871e1` cho **mọi mode**, vì PROOF đo `#3871e1` ở cả light lẫn Islands Dark. fileStatusMap (untracked/added/modified/...) giữ nguyên — thuộc domain VCS, không phải control và không nằm trong proof.
