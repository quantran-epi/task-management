# Phase 25.1 Plan 04: SDLC Workflow Hub & Multi-Source Intake UI Summary

Accessible narrow-drawer SDLC 6-step vertical timeline, revision-impact confirmation gate, and independent multi-source intake UI with scoped Note picker, citation closure, and fact conflict detection.

## What Was Built

1. **SDLC Vertical 6-Step Timeline (`SdlcWorkflowHub.tsx`)**
   - Replaced horizontal scrollable chips with an accessible vertical timeline conforming to Ant Design 6 design tokens.
   - Distinct Vietnamese status indicators pairing icons with text (`Đã xong`, `Đang xử lý`, `Cần cập nhật`, `Chưa bắt đầu`, `Lỗi`) so status is never conveyed by color alone.
   - Guaranteed minimum 40px touch targets and full word wrapping without horizontal overflow at 320px narrow drawer widths.
   - Separated timeline inspection (`selectedStep`) from active execution (`currentProcessingStep`), preventing accidental state machine transitions upon row selection.
   - Rendered active cycle expanded and past cycles collapsed/read-only with exact stale warning copy (`Tài liệu cũ (stale) — chỉ đọc để đối chiếu, không dùng làm căn cứ cho bước mới.`).

2. **Revision Impact Confirmation Gate (`RevisionImpactModal.tsx`)**
   - LCS-based line diff showing additions (`+`) and removals (`−`) with token colors.
   - Explicit listing of source identities with short SHA-256 hashes.
   - Impact summary outlining all downstream steps rendered stale (`Cần cập nhật`).
   - Strict confirmation gate: closing the modal via Cancel/Escape discards the draft without committing; only the primary confirm button invokes coordinator transition.

3. **Independent Multi-Source Intake & Local Note Picker (`NoteSourcePickerModal.tsx`, `StepInputDocsModal.tsx`, `sourceMerge.ts`)**
   - Independent selection sets for PL01 (Business Requirements) and PL02 (Functional Specification).
   - Local Note search with Project scope default and Whole System switchable scope.
   - Safe Markdown read-only preview using `renderSafeMarkdown` with 40-line truncation toggle.
   - Stable source records preserving Note ID, version, SHA-256 hash, title, and timestamp.
   - Strict citation closure validating that citations only reference provided source IDs.
   - Conflict detection identifying contradictory key-value claims across source documents.
   - Guaranteed Note immutability across search, preview, selection, and submission.
