# Phase 25.1 Plan 10: Sanitized Diagnostics and Structural D-09 Gate Summary

Drawer close no longer cancels chat or SDLC turns, every AIChatDrawer error log now emits a sanitized descriptor instead of the raw error, and the phase safety gate detects drawer-close aborts structurally with two negative fixtures proving it is strictly stronger than the regex it replaced.

## Accomplishments

- Added `src/components/ai/aiChatDiagnostics.ts` with `describeAiError` and `logAiChatError`; the descriptor contains only `name`, an optional short-string `code`, and optional `issuePaths`.
- Routed all 14 raw error logs in `AIChatDrawer.tsx` through `logAiChatError`, deleted the `JSON.stringify(groundedErr.issues, null, 2)` dump, and kept the D-04 fail-closed `IntentRouterUnavailableError` branch and user-facing `setApiError` copy unchanged.
- Gated the four `[AI Harness]` debug logs (injected prompt, tool call args, tool result, auto-approve tool name) behind `if (import.meta.env.DEV)` so prompts and tool payloads never reach a production console.
- Deleted the `[open]`-dependent abort effect; the unmount cleanup effect, the scope-change effect, and `handleStopGeneration` remain the only abort triggers. The wizard `dispose()` on close is untouched and now carries a comment scoping it as stage-only, never a chat/SDLC turn abort.
- Rewrote grounded-wiring test 2 as a D-09 regression: rerendering with `open={false}` leaves the captured signal un-aborted, and `unmount()` then aborts it.
- Replaced the `[^}]*` regex assertions with `extractUseEffectBodies` (brace-matching, string-aware) plus the single predicate `findOpenEffectAborts`; added removed-shape and nested-abort fixtures, `OLD_D09_REGEX.test(removedShape) === false`, and an unmatched-effect control case.
- Added the D-13 console gate that rejects `console.error`/`console.warn` argument lists containing `err`, `groundedErr`, or `compErr`, plus a fixture proving the gate reports a violation when one exists.
- Existing phase gate assertions (`[Đã dừng]`, localStorage allowlist, no-skip markers, backup invariants, prompt isolation, D-19 merge fixture) all remain green.
