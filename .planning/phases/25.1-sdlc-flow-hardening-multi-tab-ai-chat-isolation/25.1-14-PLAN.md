<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Retry control -> persisted history | A retry must not create a second user row or resurrect failed output. |
| Backup restore -> workflow state | Missing source Notes must block AI steps instead of silently degrading. |
| Legacy localStorage -> per-tab config | A stale global flag must not silently flip per-tab behavior. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-25.1-48 | Tampering | retry identity | mitigate | Explicit `retryUserMessageId` from the runtime; message must exist, be `user`, and match the thread. |
| T-25.1-49 | Information Disclosure | restore recovery | accept | Notice lists only Note ids/titles already stored in the restored workflow. |
| T-25.1-50 | Elevation of Privilege | analysis mode | mitigate | Durable `ChatTab.config.analysisMode` is the only runtime source; global key read once then removed. |
| T-25.1-SC | Tampering | npm/pip/cargo installs | mitigate | No new dependency. |
</threat_model>
