# Phase 25.1 — UI Design Contract

> Visual and interaction contract for multi-tab AI Chat isolation and SDLC flow hardening. Extends the Phase 25 drawer surfaces (`ChatTabBar`, `SdlcWorkflowHub`, `StepInputDocsModal`, `WizardLifecycleBar`, `InlineApiErrorCard`, `ChatMessageList`) with per-tab status, a vertical six-step timeline, a global Note source picker, a revision-impact confirmation, and a per-tab error/interrupted surface. No new design system, no new dependencies, no product-code changes in this document.

Sources: `25.1-CONTEXT.md` D-01…D-35, `25.1-RESEARCH.md`, `25-UI-SPEC.md`, `src/App.tsx:29-36`, `src/components/ai/ChatTabBar.tsx`, `src/components/ai/wizard/SdlcWorkflowHub.tsx`, `src/components/ai/wizard/StepInputDocsModal.tsx`, `src/components/ai/InlineApiErrorCard.tsx`.

## Spacing Scale

Multiples of 4 only.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Badge-to-title gap, icon-to-label gap, timeline indicator to row text |
| sm | 8px | Tab internal padding, timeline row vertical padding, picker row gap |
| md | 16px | Card body padding, modal body padding, error card inset |
| lg | 24px | Gap between timeline and artifact panel, modal section separation |
| xl | 32px | Gap between SDLC header block and timeline |
| 2xl | 48px | Reserved |
| 3xl | 64px | Reserved |

Narrow-drawer exceptions (D-16, D-18):

- Drawer width range is `320px`–`650px` (`MIN_AI_CHAT_WIDTH`/`MAX_AI_CHAT_WIDTH`, `AIChatDrawer.tsx:127-128`). Nothing in this phase may force horizontal scrolling of content; `overflowX: 'auto'` is allowed only on the tab strip itself.
- Timeline row minimum hit height 40px (indicator 20px + `sm` padding); never smaller, even at 320px width. The vertical timeline's current-processing row, marked by the `colorPrimary` spinner, is the primary visual anchor; its single allowed primary CTA is the focal action, while artifact detail remains secondary.
- Step row text wraps to a second line instead of truncating mid-word; long step titles use two lines max, then ellipsis with `title` tooltip.
- Full-screen modals (`NoteSourcePickerModal`, revision-impact modal) use `width: 'min(720px, calc(100vw - 32px))'`; below 480px preview panes stack under the list and the list gets `maxHeight: calc(100vh - 320px)`.
- Touch targets: tab close affordance 16px icon inside a 24px hit area; timeline rows and picker rows minimum 40px.
- Icon-only buttons keep 28px minimum (`25-UI-SPEC.md` precedent).

## Typography

Exactly four sizes, two weights (400 regular, 600 semibold).

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Label (tab title, step state text, badge text, timeline counters, picker metadata, cycle label) | 12px | 600 | 1.4 |
| Body (error card body, interrupted notice, preview excerpt, revision impact rows, helper text) | 14px | 400 | 1.5 |
| Heading (modal title, SDLC header feature name, card title, artifact title) | 16px | 600 | 1.3 |
| Display (Note preview document title, revision diff section title) | 20px | 600 | 1.25 |

Rules:

- Two weights only; Ant `Tag`/`Badge` 500 defaults are overridden to 600 on tab labels and status chips.
- Step state is never font-size-carried: state is icon + text label + color.
- Codes (`CR-001`, `PRC_PROCESS:60000006`, table names, API paths) render verbatim at 12px inside inline `<code>`, `borderRadius: 4`, wrapped not truncated.
- Vietnamese diacritics preserved exactly; no uppercase-transform of Vietnamese copy.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `colorBgContainer` | Drawer body, tab active surface, timeline panel, picker list, modal body |
| Secondary (30%) | `colorFillAlter` / `colorFillTertiary` | Tab strip track, SDLC hub card, cycle header, revision impact summary band, selected picker row hover |
| Accent (10%) | `colorPrimary` `#4f46e5` | Selected tab indicator + active tab label, processing spinner, primary CTA, active step indicator, focus ring |
| Destructive | `colorError` | Error card border/icon, failed step, close-running-tab confirm, reset workflow confirm |

Status semantics (meaning, not accent):

- `colorPrimary` + `Badge status="processing"` — tab request running; step `Đang xử lý`.
- `colorSuccess` — step `Đã xong`, cycle `Hoàn tất`.
- `colorWarning` — step `Cần cập nhật` (stale), tab `Bị gián đoạn`, revision impact notice, read-only stale artifact badge.
- `colorError` — tab error badge, error card, failed step.
- `colorTextQuaternary` — step `Chưa bắt đầu`, tab idle (no badge color).
- `colorInfo` — revision version tags (`v{n}`); read-only cycle tag uses neutral `colorFillTertiary` + text instead.

Accent reserved for (exclusive list):

1. Active tab underline/indicator and active tab label.
2. Per-tab `Badge status="processing"` spinner.
3. Primary CTA buttons in this phase: `Bắt đầu phân tích`, `Áp dụng {n} nguồn`, `Xác nhận cập nhật`.
4. Active step indicator in the vertical timeline and the current cycle header.
5. Keyboard focus ring.

Not accent: `Cập nhật yêu cầu`, `Cập nhật solution`, `Chọn nguồn`, `Tiếp tục thảo luận`, tab close, `Làm mới workflow`, retry. These are default/neutral buttons — a user must never infer "recommended" from color.

Never color-only: every status color is paired with an icon and a Vietnamese text label (accessibility section).

## Interaction Contracts

| Interaction | Trigger | Response |
|-------------|---------|----------|
| Select a tab | Click / Arrow keys + Enter | Switches active tab only. Background tab requests keep running; its badge keeps spinning; drawer never locks. |
| Add chat tab | `+` | Creates a new default chat tab in the current scope and selects it. SDLC tab is never duplicated. |
| Close chat tab (idle/complete) | Close affordance | Immediate close. If it was the last chat tab, an empty default chat tab is created and selected in the same tick. |
| Close chat tab (request running) | Close affordance | Confirmation modal with close-running-tab copy. Confirm → abort → delete thread/tab. Cancel → tab unchanged, request continues. |
| New message in tab B while tab A streams | Send | Tab B submits independently; tab A text/buffer untouched; only tab B's bubble renders in the viewport. |
| Stream completes with valid payload | Stream end | Assistant message commits once; badge returns to idle/complete. |
| Stream aborted / timed out / invalid payload | Runtime error | Nothing committed to history. Error card renders in that tab only. Badge = error. Other tabs unaffected. |
| Retry | `Thử lại` on error card | Re-sends the same user message with a new request ID; no duplicate user bubble; error card is replaced by the new streaming state. |
| Drawer closed while streaming | Drawer close | Request continues (D-09); reopening shows the still-running badge and buffer. No abort. |
| App/process exit mid-request | Exit | Checkpoint written; on reopen tab badge = interrupted and `InterruptedBanner` shows `Tiếp tục`/`Bỏ qua`. |
| Click a timeline step | Row click / Enter | Sets `selectedStep` only; shows that step's artifact/checkpoint + allowed actions. `currentProcessingStep` and state machine unchanged. |
| Timeline step stale | Viewing stale step | Artifact panel is read-only; `Cập nhật lại` shown only for the current processing step; stale step cannot start downstream steps. |
| `Cập nhật yêu cầu` / `Cập nhật solution` | Header action | Opens brainstorm turn in the SDLC tab, then `RevisionImpactModal` when a draft revision exists. No artifact written until confirm. |
| Confirm revision | `Xác nhận cập nhật` | Commits new immutable version, advances active pointer, marks dependent steps stale, updates timeline and cycle. Old versions remain readable. |
| Cancel revision | `Tiếp tục thảo luận` / Escape | Modal closes, nothing changes, conversation continues. |
| Open Note source picker | `Chọn nguồn` (PL01 or PL02) | Modal opens with current selections pre-checked, scope toggle default `Chỉ dự án hiện tại`. |
| Toggle picker scope | `Segmented` | Re-runs the list query; existing selections persist even if out of scope. |
| Search picker | Typing | Debounced local filter over Note titles; no network. |
| Preview a Note | Row selection / focus | Read-only preview in the side/below pane; never editable. |
| Apply sources | `Áp dụng {n} nguồn` | Closes modal, chips render in that block, counts update; PL01 and PL02 sets stay independent. |
| Backup restore with missing sources | Import complete | Workflow checkpoint restored, `RestoredSourceNotice` lists missing notes, no automatic AI run. |
| Reset workflow | `Làm mới workflow` | Popconfirm; on confirm workflow state resets to step 1, Notes preserved. |

## Accessibility

- Tab bar: `role="tablist"` with `aria-label="Thanh tab hội thoại AI"`; each tab `role="tab"` + `aria-selected`; the thread region is `role="tabpanel"` with `aria-labelledby` pointing at the active tab. Roving tabindex with Arrow/Home/End. Close affordance is a real button with `aria-label="Đóng {title}"`, never a clickable `span`.
- Status is never color-only: each tab's accessibility name includes its status text (`… — Đang xử lý`), and the visible badge is accompanied by a visually hidden status span.
- Background-tab streaming announcements are per-tab `aria-live="polite"` regions; a tab that finishes while unfocused must not steal focus. Errors use `role="alert"` once per error occurrence.
- Timeline: the six rows form a list (`role="list"` / `role="listitem"`), not a tab widget; state text is in the DOM, not just an icon; the processing row carries `aria-live="polite"` and is announced once on transition.
- `InterruptedBanner` uses `role="status"` (polite), not `role="alert"` — reopening a drawer should not fire an assertive alert.
- `RevisionImpactModal`: focus trap, initial focus on the title, Escape closes without commit, `Xác nhận cập nhật` is the only commit control, focus returns to the triggering button; diff additions/removals carry `+`/`−` text markers plus color.
- `NoteSourcePickerModal`: search input labelled, checkbox list has multi-select semantics, arrow keys navigate rows, Space toggles selection, preview pane is `aria-live="polite"` so selection changes announce the document title.
- Contrast: 12px label text uses token text colors on token surfaces (`colorTextSecondary` on `colorFillAlter` minimum); never raw hex.
- Respect `prefers-reduced-motion`: no spinner beyond Ant's default reduced-motion handling, no timeline animations, no tab transitions.
