# Phase 25.1 — Manual UAT (Tauri)

> Three manual Tauri gates. Automated gates (vitest, playwright chromium, tsc, safety gates) all green on master `01b2b81f`. These require real Tauri window and local/remote encrypted backup; jsdom/Playwright chromium cannot cover them.

Run via `npm run tauri:dev` on the current master build.

## G1 — Narrow drawer visual fit (D-16 / D-17)

**Setup**
1. Launch Tauri; resize window width to 320 px.
2. Open AI Chat Drawer; switch to SDLC tab.

**Checks**
- [ ] Six-step timeline renders vertically; no horizontal page scroll.
- [ ] Current (processing) step and selected step render as distinct rows — not conflated.
- [ ] Every actionable control (step buttons, "Tiếp tục", "Bỏ qua", source picker trigger, revision confirm) is reachable with Tab + Enter only.
- [ ] Visible focus ring on each focusable control.

**Pass criteria:** all four checked.

## G2 — Process interruption recovery (D-09)

**Setup**
1. Open SDLC tab; start a step that calls the AI (e.g. INTAKE → SOLUTION).
2. While request is in flight, close the Tauri window via native close button.
3. Relaunch via `npm run tauri:dev`.

**Checks**
- [ ] On reopen, the interrupted step shows status `Bị gián đoạn`.
- [ ] Explicit `Tiếp tục` and `Bỏ qua` controls are offered.
- [ ] No AI call fires automatically before user chooses.
- [ ] Choosing `Tiếp tục` issues a fresh request (new request id in debug modal, not a replay of the aborted turn).
- [ ] Choosing `Bỏ qua` discards the aborted turn without persisting it to history.

**Pass criteria:** all five checked.

## G3 — Encrypted reinstall restore (D-28 / D-29 / D-30)

**Setup**
1. On a clean install (fresh IndexedDB), import a pre-25.1 encrypted backup artifact.
2. After restore, open AI Chat Drawer and SDLC Hub.
3. Externally delete one source Note referenced by a wizard checkpoint (e.g. via Dexie dev console).
4. Export a new encrypted backup, uninstall, reinstall, re-import.

**Checks**
- [ ] Step 1: tabs, chat history, and workflow state all appear post-import; no partial-write artifact (no half-populated tab).
- [ ] Step 3→4: missing-source checkpoint shows explicit notice at that step.
- [ ] No empty Note is auto-created to patch the gap.
- [ ] No AI run fires automatically to backfill the missing source.
- [ ] Backup export (step 4) completed without silently dropping the broken checkpoint — it is reported in the export validation summary.

**Pass criteria:** all five checked.
