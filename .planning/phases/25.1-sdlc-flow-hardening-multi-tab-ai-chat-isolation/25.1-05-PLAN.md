<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Dexie tab/config rows → drawer runtime | Durable config and transient runtime cross into UI; secret/global endpoint boundaries must remain separate. |
| SDLC wrapper prompt → existing AI orchestrator | Workflow instructions and source metadata must not mutate shared core prompt or leak to ordinary tabs. |
| Runtime status/error → accessible UI | Untrusted failures must be sanitized and status must remain truthful/non-color-only. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-25.1-16 | Information Disclosure | SDLC prompt assembly | mitigate | Build prompt per request/tab; assert ordinary requests contain no SDLC marker and no module-level prompt mutation. |
| T-25.1-17 | Tampering | active-tab/thread resolution | mitigate | Resolve by durable tab ID/thread ID, scope-check before rendering/writing, and test cross-tab history separation. |
| T-25.1-18 | Denial of Service | background tab lifecycle | mitigate | Do not abort on tab switch/drawer close; only explicit owning-tab close/stop aborts. |
| T-25.1-19 | Information Disclosure | error/interrupted UI | mitigate | Use stable enumerated copy, runtime-only error state, visually hidden status text, and no raw diagnostics. |
| T-25.1-SC | Tampering | npm/pip/cargo installs | mitigate | No package install; all primitives already exist. |
</threat_model>
