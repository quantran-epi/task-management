<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Validated backup envelope → destructive Dexie replacement | Replacement can destroy good local state if new table parity or transaction atomicity is incomplete. |
| Legacy backup threads → generated ChatTab rows | Backfill can misclassify ordinary history as SDLC or create duplicate active/singleton rows. |
| Missing source metadata → restored workflow | Recovery must block safely instead of inventing data or auto-running AI. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-25.1-24 | Tampering | restore transaction | mitigate | Restore only Plan 06 normalized envelope in one Dexie transaction; test injected failure leaves no partial rows. |
| T-25.1-25 | Denial of Service | snapshot rollback | mitigate | Snapshot and rollback include chatTabs/workflow/count parity; equality test covers complete recovery. |
| T-25.1-26 | Spoofing | legacy SDLC classification | mitigate | Recognize only explicit `:sdlc` scope; preserve legacy project scope as ordinary chat and assert singleton uniqueness. |
| T-25.1-27 | Tampering | missing-source recovery | mitigate | Preserve blocked checkpoint/notice; forbid AI call, empty Note creation, and workflow omission. |
| T-25.1-SC | Tampering | npm/pip/cargo installs | mitigate | No package install; existing Dexie/backup stack only. |
</threat_model>
