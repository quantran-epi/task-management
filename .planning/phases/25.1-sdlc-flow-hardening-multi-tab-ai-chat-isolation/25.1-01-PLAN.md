<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Legacy IndexedDB records → SCHEMA_V14 upgrade | Existing threads and messages cross a migration boundary and must not be reclassified or deleted. |
| Dexie ChatTab config → backup/SQLite consumers | Per-tab config is durable data and must never contain endpoint credentials, tokens, passphrases, or raw secret values. |
| Tab deletion request → Dexie transaction | A running request may still own a tab; repository deletion must not create an orphaned request. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-25.1-01 | Tampering | `db.version(14)` upgrade | mitigate | Promote legacy scope keys deterministically, preserve all threads/messages, and assert one SDLC tab per project in fake-indexeddb tests. |
| T-25.1-02 | Information Disclosure | `ChatTabConfig`, SQLite queue | mitigate | Define config without secret fields, retain existing setting exclusions, and test serialized rows for token/key/passphrase absence. |
| T-25.1-03 | Denial of Service | `deleteChatTab` | mitigate | Refuse SDLC deletion and keep abort-before-delete responsibility explicit for the runtime caller. |
| T-25.1-SC | Tampering | npm/pip/cargo installs | mitigate | No package install; verify lockfile and dependency set remain unchanged. |
</threat_model>
