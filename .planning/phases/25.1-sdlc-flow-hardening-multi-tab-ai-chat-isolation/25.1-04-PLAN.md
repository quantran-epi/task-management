<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Stored Note body/title → search and preview UI | User-authored Markdown is untrusted display data and must not execute HTML/script or mutate source. |
| Revision preview → active artifact commit callback | Diff/source/impact data is advisory until explicit confirmation. |
| Timeline click → workflow coordinator | Read-only navigation must not become an implicit state transition or stale baseline execution. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-25.1-12 | Tampering | timeline row selection | mitigate | Local selectedStep only; component tests assert current processing step/callback remain unchanged. |
| T-25.1-13 | Information Disclosure | Note preview | mitigate | Local-only scoped query, safe Markdown renderer, no raw HTML, network, or diagnostic body logging. |
| T-25.1-14 | Tampering | RevisionImpactModal | mitigate | Modal is callback-only; exact preview and explicit confirm are required before coordinator commit. |
| T-25.1-15 | Spoofing | source identity chips | mitigate | Carry stable Note ID/version/SHA-256 hash, not title alone; keep PL01/PL02 collections separate. |
| T-25.1-SC | Tampering | npm/pip/cargo installs | mitigate | Existing Ant Design, React, Dexie, and native crypto only; no package install. |
</threat_model>
