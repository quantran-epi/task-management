## Shared Patterns

### Validation at trust boundaries
**Source:** `src/services/wizard/workflowSchemas.ts` (`z.strictObject`), `src/validation/backupSchemas.ts`
**Apply to:** every new schema (tab, checkpoint, cycle, revision preview).
```ts
const parsed = SdlcWorkflowStateSchema.parse(nextState);   // fail closed, no partial write
```
New fields optional; never widen an existing required field. No secret key fields (`isSafeBackupSetting`, `exportBackup.ts:34-47`).

### Dexie transaction for multi-table writes
**Source:** `chatRepo.ts:219-224`, `artifactRepo.ts` `db.transaction('rw', [db.notes, db.documentSets, db.chatMessages, db.chatThreads], ...)`
**Apply to:** tab create/delete, active-tab switch, artifact version commit. Never call async `blobToBase64` inside a transaction (comment `restoreBackup.ts:44-47`).

### Ant Design + tokens, no new primitives
**Source:** `ChatTabBar.tsx:24`, `SdlcWorkflowHub.tsx:89`, `InlineApiErrorCard.tsx:22`
**Apply to:** all UI files.
```ts
const { token } = theme.useToken();
```
Allowed: `Timeline`, `Badge`, `Tag`, `Modal`, `Alert`, `Card`, `Empty`, `Spin`, `Skeleton`, `Button`, `Checkbox`, `Input.Search`, `Segmented`, `Tooltip`, `Popconfirm`, `Typography`. Vietnamese copy verbatim from UI-SPEC.

### Commit boundary / no error in history
**Source:** `AIChatDrawer.tsx:1911-1925` (valid commit) and `1942-1970` (forbidden abort-commit)
**Apply to:** all assistant turns.
- Commit only after full validated completion.
- Abort/timeout/parse failure: discard buffer; render `InlineApiErrorCard` (`InlineApiErrorCard.tsx:24-88`, `role="alert"`) outside messages.
- `grep -rn "\[Đã dừng\]" src/` must be empty after phase.

### Per-tab abort ownership
**Source:** `AIChatDrawer.tsx:1058-1066` (scope-change abort) shows what NOT to keep
**Apply to:** request lifecycle. Controller lives in registry keyed by `tabId`; only owning tab or explicit close aborts it. Drawer close does not abort (D-09).
