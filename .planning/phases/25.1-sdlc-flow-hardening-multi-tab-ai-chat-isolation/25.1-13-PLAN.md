<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| User-selected Notes -> AI prompt | Untrusted note bodies and titles enter the model prompt with citation identity. |
| Tab title input -> Dexie | Free-text title crosses into `chatTabs` and `chatThreads` rows. |
| ARIA composite widget -> screen reader | Missing listbox roles make multi-select unusable for assistive tech. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-25.1-45 | Tampering | source Notes during merge | mitigate | `buildMergedSdlcInput` clones/parses sources; test asserts byte-identical rows after intake. |
| T-25.1-46 | Spoofing | citation identity in prompt | mitigate | Citations close over supplied source ids only; prompt prints the same id/version/hash triple emitted from `sourceMerge`. |
| T-25.1-47 | Input Validation | tab rename | mitigate | Empty/unchanged titles skipped; `updateChatTab` transaction writes both tab and thread title. |
| T-25.1-SC | Tampering | npm/pip/cargo installs | mitigate | No new dependency; Ant Design `Input` already in use. |
</threat_model>
