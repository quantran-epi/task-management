## STRIDE Threat Register

|-----------|----------|-----------|-------------|-----------------|
| T-32-06 | Elevation of Privilege / Injection | `sdlcPromptComposer.ts::buildExternalResearchSegment` | mitigate | Segment is enclosed in untrusted-data delimiters (`<external_research_evidence>...</external_research_evidence>`); explicit policy instruction forbids external data from superseding internal rules. |
| T-32-07 | Repudiation / False Attribution | Generated SOLUTION.md | mitigate | Every claim in the prompt segment carries an explicit tag (`[EXTERNAL:WEB]` or `[EXTERNAL:REPO:{code}]`) and source URL/filepath, ensuring claims remain attributable in generated solutions. |
