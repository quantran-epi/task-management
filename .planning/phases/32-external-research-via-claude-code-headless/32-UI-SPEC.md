## Component Inventory

### 1. In-Chat Proposal Card (`ResearchProposalCard`)
- **Location:** In-chat message stream (`AiChatWidget` / `StepChatPanel`)
- **Trigger:** AI detects insufficient internal evidence during Step 1/2 turns (D-08)
- **Visuals:**
  - Border: 1px solid `#e9eaee` with light yellow accent border-left (`#faad14`, 3px)
  - Header: Icon `<BulbOutlined />` in `#faad14`, title "Đề xuất nghiên cứu từ bên ngoài (Claude Code)"
  - Body:
    - Target questions list (bullet points)
    - System selector: Checkbox group showing target systems from CR (`targetSystemIds` via `db.systems`) or "Tất cả các hệ thống"
  - Footer / Actions:
    - Button primary (`#3871e1`): "Xác nhận nghiên cứu"
    - Button default: "Bỏ qua"

### 2. Manual Toolbar Trigger & Modal (`ResearchTriggerModal`)
- **Location:** Toolbar of Step 1 (`Step1IntakeView`) and Step 2 (`Step2SolutionView`)
- **Trigger:** User clicks button "Nghiên cứu (Claude Code)"
- **Visuals:**
  - Button: `icon={<SearchOutlined />}`, label "Nghiên cứu (Claude Code)"
  - Modal:
    - Input.TextArea: "Nội dung câu hỏi cần nghiên cứu..." (required)
    - Select / Checkboxes: Target systems (multi-select based on CR subsystems)
    - Switch: "Tìm kiếm Web (WebSearch/WebFetch)" (default: ON)
    - Primary Button: "Bắt đầu nghiên cứu"

### 3. In-Chat Real-Time Streaming Card (`ResearchStreamingCard`)
- **Location:** Directly inside chat thread during execution (D-09)
- **Visuals:**
  - Header: `<SyncOutlined spin />` + "Đang thực thi Claude Code headless trên [SystemCode]..."
  - Metrics row: Elapsed timer badge (`00:35`), Line counter badge (`42 dòng`)
  - Accordion (`<Collapse size="small" />`): "Xem nhật ký stdout theo thời gian thực"
  - Console container: Max height 200px, overflow-y auto, background `#1e1f22`, monospace font 12px, font color `#d1d3d9`
  - Action: Button danger (`#ff4d4f`) `icon={<StopOutlined />}`, label "Hủy nghiên cứu" (triggers D-02 `kill -TERM <pid>`)

### 4. Research Completion Card (`ResearchCompletionCard`)
- **Location:** In-chat message stream upon successful run
- **Visuals:**
  - Header: `<CheckCircleFilled style={{ color: '#52c41a' }} />` + "Hoàn thành nghiên cứu bên ngoài"
  - Summary badges:
    - `<Tag color="blue">[EXTERNAL:WEB] {N} phát hiện</Tag>`
    - `<Tag color="cyan">[EXTERNAL:REPO:{code}] {M} phát hiện</Tag>`
    - Execution time tag (e.g. `28s`)
  - Primary Action: Button type="primary", `icon={<ArrowRightOutlined />}`, copy: "Tiếp tục sinh Solution với bằng chứng này" (D-11)
  - Secondary Action: Button default, `icon={<EyeOutlined />}`, copy: "Xem chi tiết phát hiện"

### 5. Timeout & Disconnect Warning Banner (`ResearchErrorAlert`)
- **Location:** In-chat message stream when execution exceeds 300s or SSH drops (D-03)
- **Visuals:**
  - Alert `type="warning"` with description
  - Action buttons:
    - Button: "Thử lại" (Retry with same parameters)
    - Button: "Bỏ qua, tiếp tục bằng bằng chứng nội bộ" (Proceed with internal evidence alone)

### 6. Summary Card on Step 1 & Step 2 (`ResearchSummaryCard`)
- **Location:** Top of Step 1 (`Step1IntakeView`) and Step 2 (`Step2SolutionView`), placed alongside `ConventionsSummaryCard` (D-10)
- **Visuals:**
  - Card: `background: '#fafbfc'`, `borderColor: '#e9eaee'`, `padding: '8px 14px'`
  - Left:
    - Icon: `<ExperimentOutlined style={{ color: '#3871e1' }} />`
    - Label: "Nghiên cứu bên ngoài:"
    - State Badge:
      - Has research: `<Tag color="processing">RESEARCH v{N}</Tag>` + `<Tag color="blue">Web: {count}</Tag>` + `<Tag color="cyan">Repo: {count}</Tag>`
      - No research: `<Tag color="default">Chưa có dữ liệu</Tag>`
  - Right:
    - Button: `icon={<SearchOutlined />}`, label "Nghiên cứu mới"
    - Button: `icon={<EyeOutlined />}`, label "Xem chi tiết", disabled if no research

### 7. Research Inspection Modal (`ResearchDetailModal`)
- **Location:** Modal popup triggered from `ResearchSummaryCard` or `ResearchCompletionCard`
- **Visuals:**
  - Title: "Chi tiết nghiên cứu bên ngoài — CR {crCode}"
  - Version Selector: Segmented or Select (`RESEARCH v2 (Mới nhất)`, `RESEARCH v1`)
  - Content sections:
    - Tóm tắt tổng quan (Markdown render)
    - Danh sách phát hiện (Findings table or list):
      - Badge: `[EXTERNAL:WEB]` or `[EXTERNAL:REPO:{systemCode}]`
      - Claim: text content
      - Source: clickable link or file path with line number
      - Confidence: Progress bar or tag (e.g. `95%`)
    - Tab "Raw Output": Full JSON / logs for auditing

## Interaction & State Contracts

### State Lifecycle

```
[IDLE]
  │
  ├─► [AI PROPOSAL] ──(User confirms)──┐
  │                                     ▼
  ├─► [MANUAL TRIGGER] ─────────► [STREAMING]
                                        │
                         ┌──────────────┼──────────────┐
                         ▼              ▼              ▼
                    [COMPLETED]     [CANCELED]     [ERROR / TIMEOUT]
                         │                             │
                         ▼                             ▼
                  [PERSIST NOTE]              [RETRY or PROCEED INTERNAL]
                         │
                         ▼
             [INJECT PROMPT SEGMENT]
```

### Cancellation Flow (D-02)
1. User clicks "Hủy nghiên cứu".
2. UI sets button to loading state: "Đang dừng tiến trình...".
3. Tauri sends `ssh_kill_process` (`kill -TERM <pid>`).
4. Remote channel closes, UI transitions to Canceled state: "Tiến trình nghiên cứu đã được hủy bỏ an toàn".
5. No partial corrupt artifact is persisted.

| Element | Copy |
|---------|------|
| Primary CTA (Proposal) | Xác nhận nghiên cứu |
| Primary CTA (Completion) | Tiếp tục sinh Solution với bằng chứng này |

| Error state (Timeout/Drop) | Không thể hoàn thành nghiên cứu qua SSH (quá thời gian 300s hoặc mất kết nối). Kiểm tra lại kết nối mạng hoặc thử lại. |
| Error CTA 1 | Thử lại |
| Error CTA 2 | Bỏ qua, tiếp tục bằng bằng chứng nội bộ |
| Destructive action: Stop | Hủy nghiên cứu: Dừng tiến trình Claude Code đang chạy trên máy chủ từ xa? |
| Cancel confirmation | Tiến trình nghiên cứu đã được dừng an toàn. Không có tệp nào trên remote repo bị thay đổi. |
