<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User Action → Remote SSH Process | User clicks stop/cancel button to terminate remote process |
| UI Rendering → Arbitrary HTML / XSS | External research summary and claims rendering in DOM |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-32-08 | Tampering / XSS | `ResearchDetailModal` in `ResearchSummaryCard.tsx` | mitigate | Use standard React DOM text nodes and sanitized markdown rendering for claims and summary; no `dangerouslySetInnerHTML`. |
| T-32-09 | Denial of Service | `ResearchStreamingCard` in `StepChatPanel.tsx` | mitigate | Limit live log accordion buffer to the latest 500 lines to prevent DOM memory bloat during verbose remote CLI outputs. |
| T-32-12 | Spoofing | `ResearchProposalCard` | mitigate | Proposal questions and system codes come only from the `propose_research` tool result, which already re-resolved ids against `db.systems`; the card never trusts model-supplied names. |
| T-32-SC | Tampering | UI packages | accept | Uses existing bundled `antd` 6.6.5 and `@ant-design/icons`. |
</threat_model>
