  <behavior>
    - `buildResearchPrompt(questions: string[], systemCode: string): string` — instructs strict JSON output `{ summary, findings: [{ claim, scope, source, confidence }] }` per D-04, names the system code, and forbids editing files.
    - `renderResearchMarkdown(payload: ResearchPayload): string` — a Markdown report with a summary section and one row per finding carrying `[EXTERNAL:WEB]` or `[EXTERNAL:REPO:{code}]`, its source, and its confidence.
    - `executeMultiSystemResearch(options): { promise: Promise<ResearchPayload>; cancel: () => Promise<void> }` — the cancel handle is part of the return value, never a side channel.
    - Options: `{ changeRequestId: string; threadId: string; sessionId: string; targetSystemIds: string[]; questions: string[]; includeWeb?: boolean; onLog: (line: string) => void; db?: TaskPlannerDatabase; timeoutMs?: number; now?: () => string }`. Key everything by `changeRequestId` — the same key `assertProjectThread` and `loadLatestResearchArtifact` use.
    - Availability pre-flight via `checkResearchAvailability`; unavailable entries go into `payload.skippedSystems` and each is `onLog`-ed as a Vietnamese line naming the system code and reason.
    - If every target is unavailable, reject with `ResearchRunError('RESEARCH_UNAVAILABLE', ...)`.
    - Per available system, sequentially: `cd <escaped remoteRepoPath> && claude -p <escaped prompt> --output-format json --allowedTools WebSearch,WebFetch,Glob,Grep,Read`. When `includeWeb` is false, drop `WebSearch,WebFetch` from `--allowedTools`.
    - `execRemoteCommandStream` is called with the resolved `SshConfig`; its returned cancel handle is stored so `cancel()` stops the active run.
    - **SSH failure mapping:** if `execRemoteCommandStream` throws, or the stream exit event carries a non-null `error`, reject with `ResearchRunError('RESEARCH_SSH_ERROR', ...)` after cancelling. A dropped connection must never resolve with partial data (D-03).
    - Timeout default 300_000 ms: on expiry call `cancel()` then reject with `ResearchRunError('RESEARCH_TIMEOUT', ...)`; clear the timer on settle.
    - `cancel()` is idempotent and settles the promise with `ResearchRunError('RESEARCH_CANCELLED', ...)`; no artifact is persisted on cancel or error.
    - On success, persist with `saveResearchArtifact({ changeRequestId, threadId, sessionId, inputRevision: 0, draftRevision: 0, inputHash: await defaultSha256(JSON.stringify(payload)), markdown: renderResearchMarkdown(payload), exportPayload: payload, approvedAt: options.now?.() ?? new Date().toISOString() }, db)`.
    - `sessionId` must be a real RFC 4122 v4 UUID — `SdlcArtifactMetadataSchema` validates it with `uuidSchema` (`wizardSchemas.ts:6`), so tests seed a UUID literal.
  </behavior>
