<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Headless CLI Invocation → Remote Shell | Unsanitized prompt text and repo path passed to remote `claude -p` command |
| Remote Web/Repo Output → LLM Context | Untrusted external web content and repo comments entering TaskMate |
| Model tool output → CR scope | `propose_research` system ids proposed by the model |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-32-03 | Tampering / Code Execution | `researchService.ts::escapeShellArg` | mitigate | Strict single-quote escaping applied to both the prompt and `remoteRepoPath` prevents shell metacharacter expansion and subshell injection. |
| T-32-04 | Tampering | Remote git repository | mitigate | Enforce `--allowedTools WebSearch,WebFetch,Glob,Grep,Read`; strictly disallow `Write`, `Edit`, and `Bash` tools during research. |
| T-32-05 | Information Disclosure / Injection | Web search results payload | mitigate | Findings validated via strict `ResearchPayloadSchema` Zod model; raw output sanitized before persistence. |
| T-32-10 | Spoofing / Scope creep | `sdlcArtifactTools.ts::proposeResearch` | mitigate | Every model-supplied `systemId` is re-resolved against `db.systems`; unknown ids are dropped and never echoed back. |
| T-32-SC | Tampering | npm packages | accept | No new npm dependencies; uses existing `zod` and `@tauri-apps/api`. |
</threat_model>
