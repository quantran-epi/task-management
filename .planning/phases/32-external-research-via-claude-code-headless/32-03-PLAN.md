## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Remote Web/Repo Output → LLM Context | Untrusted external content parsed into a payload |
| Prompt text → Remote Shell | Prompt and repo path interpolated into a remote command |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-32-03 | Tampering / Code Execution | `researchService.ts::escapeShellArg` | mitigate | Single-quote wrapping with `'\''` escaping applied to both the prompt and `remoteRepoPath`, so shell metacharacters stay literal. |
| T-32-05 | Information Disclosure / Injection | `researchService.ts::parseResearchOutput` | mitigate | Findings are validated through `ResearchPayloadSchema`; unparseable output degrades to inert `rawOutput` text rather than being treated as structured claims. |
| T-32-SC | Tampering | npm packages | accept | No new npm dependencies; uses existing `zod`. |
</threat_model>
