<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User Action → Remote SSH Process | User clicks stop/cancel to terminate a remote process |
| UI Rendering → Arbitrary HTML / XSS | External research summary and claims rendered in the DOM |
| Step view → Chat panel | Manual trigger payload crossing into the run state machine |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-32-08 | Tampering / XSS | `ResearchDetailModal` in `ResearchSummaryCard.tsx` | mitigate | Claims and summary render as React text nodes; no `dangerouslySetInnerHTML`. |
| T-32-09 | Denial of Service | `ResearchStreamingCard` in `StepChatPanel.tsx` | mitigate | Live log buffer capped at the latest 500 lines to prevent DOM memory bloat. |
| T-32-12 | Spoofing | `ResearchProposalCard` | mitigate | Questions and system codes come only from the `propose_research` tool result, which already re-resolved ids against `db.systems` and `cr.targets`; the card never trusts model-supplied names. |
| T-32-14 | Tampering | `ResearchTriggerModal` target list | mitigate | `targetSystems` is loaded from `db.systems` filtered by the CR's `targets`; the modal cannot submit an arbitrary system id. |
| T-32-SC | Tampering | UI packages | accept | Uses existing bundled `antd` 6.6.5 and `@ant-design/icons`. |
</threat_model>
