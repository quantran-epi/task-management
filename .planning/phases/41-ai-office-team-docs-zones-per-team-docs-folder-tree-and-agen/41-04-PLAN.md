## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| UI input → `createTeam` | Team name and roster ids are user-supplied |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigate / rationale |
|-----------|----------|-----------|-------------|----------------------|
