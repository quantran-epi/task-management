## Color

60-30-10 distribution rules:

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#ffffff` (light) / `#141414` (dark) | Main page background, container surface (`token.colorBgContainer`) |
| Secondary (30%) | `#fafafa` (light) / `#1f1f1f` (dark) | Settings Card surfaces, Modal bodies, Table header row (`token.colorBgElevated`, `token.colorFillAlter`) |
| Accent (10%) | `#1677ff` (Ant Design primary blue) | Primary action triggers only (see explicit list below) |
| Destructive | `#ff4d4f` (Ant Design red) | Dangerous/destructive actions only (Force Overwrite button, Clear Session, invalid/error badge) |

Accent reserved for:
- "Kiểm tra kết nối" (Test connection) button
- "Đẩy lên GitHub" (Push encrypted backup) primary CTA button
- "Tải từ GitHub" (Pull & decrypt) secondary primary CTA button
- Active sync status badge / icon indicator (`<GithubOutlined />` or `<CloudSyncOutlined />`)
- "Tải và xem trước bản remote" (Pull & Preview) choice button in Conflict Modal

Destructive reserved for:
- "Xóa phiên kết nối" (Clear session) button in GitHub Config
- "Ghi đè bản remote" (Force overwrite) confirmation button in Conflict Modal (unlocked only with `OVERWRITE` keyword)
- Validation failure alerts and error tags

## Component Inventory & Interactions

### 1. GitHubConfigCard (`src/components/settings/GitHubConfigCard.tsx`)
- **Mount Location:** `SettingsView` -> tab `Sao lưu & Dữ liệu` (`data`)
- **Fields:**
  - Owner / Organization (`github_owner` - stored in IndexedDB `settings`)
  - Repository (`github_repo` - stored in IndexedDB `settings`)
  - Branch (`github_branch` - stored in IndexedDB `settings`, default `main`)
  - GitHub Token / PAT (Fine-grained token with `contents:read` and `contents:write` - held in memory only, `<Input.Password />`)
  - Passphrase (held in memory only, `<Input.Password />`)
- **Controls:**
  - Button "Lưu cấu hình kho lưu trữ": persists owner/repo/branch to IndexedDB
  - Button "Kiểm tra kết nối": runs preflight GET call to repo and updates session status
  - Button "Xóa phiên kết nối": purges in-memory token and passphrase

### 2. GitHubSyncCard (`src/components/settings/GitHubSyncCard.tsx`)
- **Mount Location:** `SettingsView` -> tab `Sao lưu & Dữ liệu` (`data`)
- **Status Display:**
  - Connection status tag: "Đã kết nối" (success tag) / "Chưa xác thực" (default tag) / "Lỗi kết nối" (error tag)
  - Remote file status: Truncated remote SHA (`sha.slice(0, 7)`), file size (KB), and last updated date
  - In-memory credentials indicator: "Đã nạp vào bộ nhớ tạm" / "Chưa có mật khẩu"
- **Actions:**
  - Primary Button: "Đẩy lên GitHub" (icon: `<CloudUploadOutlined />`)
  - Button: "Tải từ GitHub" (icon: `<CloudDownloadOutlined />`)
  - Diagnostic Button: "Tải tệp mã hóa thô" (shown on decrypt failure)

### 3. GitHubConflictModal (`src/components/settings/GitHubConflictModal.tsx`)
- **Trigger:** Pre-flight SHA mismatch or HTTP 409 Conflict during push
- **Header:** `<WarningOutlined style={{ color: '#faad14' }} /> Xung đột bản sao lưu từ xa`
- **Body:**
  - Remote SHA vs Local known SHA
  - Remote commit message or timestamp
  - Alert message: "Tệp sao lưu trên GitHub đã thay đổi kể từ lần đồng bộ trước."
- **Three explicit choices:**
  1. Primary Button: "Tải và xem trước bản remote" (calls decrypt and opens `ImportPreviewModal`)
  2. Danger Button: "Ghi đè bản remote bằng dữ liệu máy này" (requires exact text `OVERWRITE`)
  3. Default Button: "Hủy bỏ"

### 4. GitHubPassphraseModal (`src/components/settings/GitHubPassphraseModal.tsx`)
- **Trigger:** Fetching remote encrypted backup when passphrase is not yet stored in session memory or when decryption returns `OperationError`
- **Fields:** `<Input.Password placeholder="Nhập mật khẩu giải mã..." />`
- **Actions:** Button "Giải mã & Xem trước" / Button "Hủy"
