## Phase Goal

**As a** personal task planner user, **I want to** configure my GitHub repository and safely hold my token and encryption passphrase in temporary memory, **so that** I can securely encrypt my backup data without leaking credentials to storage, logs, or disk.

## Artifacts this phase produces

### Types & Interfaces
- `EncryptedEnvelope` in `src/services/crypto/types.ts`: JSON structure containing app, format, schemaVersion, exportedAt, crypto params, and Base64 ciphertext per D-10.
- `CryptoConfig` in `src/services/crypto/types.ts`: Parameters interface for PBKDF2 iterations, salt length, and IV length.
- `GitHubAuthContextType` in `src/context/GitHubAuthContext.tsx`: Interface exposing `token`, `passphrase`, `setCredentials`, `setPassphrase`, `clearSession`, `hasToken`, `hasPassphrase`.

### Functions & Utilities
- `bytesToBase64(bytes: Uint8Array): string` in `src/services/crypto/base64.ts`: Binary-safe buffer to Base64 encoder using `btoa`.
- `base64ToBytes(base64: string): Uint8Array` in `src/services/crypto/base64.ts`: Whitespace-tolerant Base64 to binary buffer decoder using `atob`.
- `utf8ToBase64(str: string): string` in `src/services/crypto/base64.ts`: UTF-8 string to Base64 encoder.
- `base64ToUtf8(base64: string): string` in `src/services/crypto/base64.ts`: Base64 to UTF-8 string decoder.
- `deriveKey(passphrase: string, salt: Uint8Array): Promise<CryptoKey>` in `src/services/crypto/webCrypto.ts`: PBKDF2 key derivation (600,000 iter, HMAC-SHA256) per D-11.
- `encryptPayload(payloadJson: string, passphrase: string): Promise<EncryptedEnvelope>` in `src/services/crypto/webCrypto.ts`: AES-GCM-256 authenticated encryption with 96-bit random IV per D-10, D-11.
- `decryptPayload(envelope: EncryptedEnvelope, passphrase: string): Promise<string>` in `src/services/crypto/webCrypto.ts`: AES-GCM-256 authenticated decryption throwing on MAC mismatch or bad passphrase.
- `useGitHubAuth(): GitHubAuthContextType` in `src/context/GitHubAuthContext.tsx`: React hook to access in-memory secrets and clear session control.

### Components
- `GitHubAuthProvider` in `src/context/GitHubAuthContext.tsx`: Root React context provider storing PAT and passphrase in transient component state.
- `GitHubConfigCard` in `src/components/settings/GitHubConfigCard.tsx`: Ant Design card managing non-sensitive repository settings in IndexedDB and session credentials in memory per D-01, D-02, D-03, D-04.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User Input → Memory | Sensitive Personal Access Token and encryption passphrase enter transient React state |
| Memory → IndexedDB | Only non-sensitive repository coordinates (owner, repo, branch) cross into persistent database |
| Plaintext JSON → Web Crypto | Unencrypted task planner database payload is converted into authenticated ciphertext |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-01 | Information Disclosure | `GitHubAuthContext.tsx` | mitigate | Keep PAT and passphrase strictly in React transient memory state; never persist to IndexedDB, Web Storage, cookies, or console (SYNC-01, SYNC-02) |
| T-08-02 | Information Disclosure | `GitHubConfigCard.tsx` | mitigate | Use `Input.Password` masking for token and passphrase; purge inputs immediately on `clearSession` (D-02, D-03) |
| T-08-03 | Tampering | `webCrypto.ts` | mitigate | Use AES-GCM authenticated encryption with 128-bit authentication tag and fresh 96-bit IV per encryption (SYNC-03, D-10) |
| T-08-04 | Elevation of Privilege | `webCrypto.ts` | mitigate | Enforce PBKDF2 with 600,000 iterations of HMAC-SHA256 and 16-byte random salt to prevent brute-force attacks (D-11) |
| T-08-SC | Tampering | npm dependencies | accept | Zero third-party crypto packages installed; native browser `crypto.subtle` only |
</threat_model>
