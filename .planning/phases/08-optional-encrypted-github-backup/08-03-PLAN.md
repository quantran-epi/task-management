## Phase Goal

**As a** personal task planner user, **I want to** pull and decrypt my remote GitHub backup and review the comparative diff before restoring, **so that** I can recover my data on any device without compromising security or overwriting local data accidentally.

## Artifacts this phase produces

### Types & Interfaces
- `PullBackupResult` in `src/services/github/types.ts`: Interface containing `payload: BackupEnvelope`, `remoteSha: string`, `exportedAt: string`, `rawEncryptedJson: string`.

### Functions & Utilities
- `executeGitHubBackupPull(config: GitHubConfig, token: string, passphrase?: string): Promise<PullBackupResult>` in `src/services/github/githubSyncService.ts`: Downloads `.task-management/backup.enc.json`, parses envelope, decrypts with Web Crypto, validates schema with Zod, and returns parsed payload per D-10, D-13, D-14.
- `downloadRawEncryptedBackup(rawJson: string, filename?: string): void` in `src/services/github/githubSyncService.ts`: Browser trigger to download un-decrypted encrypted envelope file for offline diagnostics per D-16.

### Components
- `GitHubPassphraseModal` in `src/components/settings/GitHubPassphraseModal.tsx`: Ant Design modal requesting decryption passphrase when in-memory passphrase is missing or incorrect, with error alert and raw file download button per D-14, D-16.
- `SettingsView` updates in `src/views/SettingsView.tsx`: Full integration coordinating `GitHubConfigCard`, `GitHubSyncCard`, `GitHubConflictModal`, `GitHubPassphraseModal`, and `ImportPreviewModal` in the 'data' tab.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub API → Browser Memory | Untrusted remote ciphertext downloaded from external repository |
| Decrypted JSON → Database | Untrusted plaintext payload must be validated with Zod before touching IndexedDB |
| User Input → Decryption Key | Passphrase input is passed directly to PBKDF2 key derivation |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-09 | Tampering | `githubSyncService.ts` | mitigate | Decryption uses AES-GCM; any bit alteration causes authentication tag check failure and halts immediately (SYNC-03) |
| T-08-10 | Elevation of Privilege | `validateBackup.ts` | mitigate | Decrypted payload must pass strict two-stage structural and referential integrity validation before preview or restore (SYNC-05, D-13) |
| T-08-11 | Denial of Service | `ImportPreviewModal.tsx` | mitigate | Automatic safety snapshot taken into `settings.last_pre_import_snapshot` before multi-table restore; requires typing `RESTORE` keyword (D-15) |
| T-08-12 | Information Disclosure | `GitHubPassphraseModal.tsx` | mitigate | Passphrase entered in `Input.Password`; immediately discarded if dialog is cancelled; never logged or saved to persistent storage (SYNC-01, SYNC-02) |
| T-08-SC | Tampering | npm dependencies | accept | Zero third-party crypto packages installed; native browser `crypto.subtle` only |
</threat_model>
