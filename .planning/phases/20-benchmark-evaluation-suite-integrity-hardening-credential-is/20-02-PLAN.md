  <files>tests/ai/releaseGate.ts</files>

  <action>
1. Create `tests/ai/releaseGate.ts` per D-01, D-02, D-03, and D-04:
   - Define interface `GateThresholds`:
     - `aggregatePassRate: number` (default: 0.90)
     - `categoryPassRate: number` (default: 0.80)
     - `threeHopPassRate: number` (default: 0.90)
     - `pathFidelityRate: number` (default: 1.00)
     - `maxInvariantViolations: number` (default: 0)
   - Export `DEFAULT_GATE_THRESHOLDS: GateThresholds`.
   - Define interface `GateVerdict`:
     - `passedGate: boolean`
     - `aggregatePassRate: number`
     - `passesAggregate: boolean`
     - `categoryScores: Record<string, { total: number; passed: number; passRate: number; passedGate: boolean }>`
     - `passesCategories: boolean`
     - `threeHopScore: { total: number; passed: number; passRate: number; passedGate: boolean }`
     - `passesThreeHop: boolean`
     - `pathFidelity: { totalEvaluated: number; passed: number; fidelityRate: number; passedGate: boolean }`
     - `passesPathFidelity: boolean`
     - `invariantViolations: readonly { caseId: string; violation: string }[]`
     - `passesInvariants: boolean`
   - Export function `evaluateReleaseGate(results: readonly CaseEvaluationResult[], thresholds?: GateThresholds): GateVerdict`:
     - Calculate aggregate rate: total passed / total cases. Check `aggregatePassRate >= thresholds.aggregatePassRate`.
     - Group cases by `category` and calculate per-category pass rate. Check all categories `>= thresholds.categoryPassRate`.
     - Filter `isThreeHop === true` cases and compute 3-hop success rate. Check `threeHopPassRate >= thresholds.threeHopPassRate`.
     - Filter `hasExpectedPaths === true` cases and compute path fidelity rate. Check `pathFidelityRate === thresholds.pathFidelityRate` (1.00).
     - Collect all `invariantViolations`. Check `invariantViolations.length === 0`.
     - If ANY invariant violation exists, or ANY required threshold is missed, mark `passedGate = false`.
     - Never apply retries or mask failures per D-04.
  </action>
  <acceptance_criteria>
    - `tests/ai/releaseGate.ts` exports `evaluateReleaseGate` and `DEFAULT_GATE_THRESHOLDS`.
    - Unit tests or assertions verify that a single invariant violation causes `passedGate: false` even with 100% aggregate pass rate.
    - Verified that path fidelity < 1.00 causes `passedGate: false`.
  </acceptance_criteria>
  <verify>
    <automated>node --experimental-strip-types -e 'import { evaluateReleaseGate, DEFAULT_GATE_THRESHOLDS } from "./tests/ai/releaseGate.ts"; const v = evaluateReleaseGate([]); if (typeof v.passedGate !== "boolean") throw new Error("Invalid verdict");'</automated>
  </verify>
  <done>Release gate evaluator calculates aggregate, category, 3-hop, path fidelity, and zero-tolerance invariant verdicts accurately.</done>
