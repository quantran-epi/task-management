<threat_model>
## Trust Boundaries
| Boundary | Description |
|----------|-------------|
| repo → Dexie | task/milestone writes cross from validated UI input into canonical store |
| CR delete → note detach | cascade removes references across 3+ tables in one transaction |
## STRIDE Threat Register
| ID | Category | Component | Disposition | Mitigation |
|----|----------|-----------|-------------|------------|
| T-52-01 | Tampering | taskRepo.createTask/updateTask/reparentTask | mitigate | assertMilestoneMatchesCr + assertSystemInCrTargets before every write; Zod uuid validation on milestoneId |
| T-52-02 | Tampering | deleteCrMilestoneWithCascade | mitigate | single rw transaction; clear task refs and detach notes before deleting milestone row |
| T-52-03 | Tampering | deleteChangeRequestWithCascade | mitigate | include milestone ids in note detach anyOf and bulkDelete milestones before CR delete |
| T-52-SC | Tampering | package installs | mitigate | no package installs this phase; no new dependencies |
</threat_model>
