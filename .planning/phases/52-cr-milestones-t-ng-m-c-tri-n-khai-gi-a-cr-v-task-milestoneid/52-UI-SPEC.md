# Phase 52 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

## Spacing Scale

Kế thừa `src/styles/tokens.ts` (`sharedTokens.spacing`); không invention giá trị mới. Mọi giá trị là bội của 4:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, padding inline trong row mốc |
| sm | 8px | Khoảng cách control trong section header và ô bảng |
| md | 16px | Section padding, body padding của CR Detail |
| lg | 24px | Section padding lớn (giữ nguyên layout hiện có) |
| xl | 32px | Layout gaps |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Exceptions (đã khóa trong `tokens.ts` / `workbench-tokens.css`, không phải mới):
- `--island-gap: 6px` — khoảng cách island.
- `--gap-1..24` = 1,2,3,4,5,6,7,8,10,12,14,16,24px — legacy gaps, dùng qua biến (`var(--gap-8)`), không literal.
- Fixed metrics: control height 30px (`ui-tokens.css` override 28px cho input/select/button wrapped), table row 24px, table padding 8px, tree indent 12px, section container padding `12px 16px` (giữ nguyên CR Detail hiện tại).
- Không dùng spacing literal trong component mới; mọi khoảng cách đi qua wrapper hoặc CSS var token.

## Typography

4 sizes, 2 weights — lấy từ `tokens.ts` (`--font-size-xs/small/ui` + Heading). Không thêm size step.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| XS / meta | 11px (`--font-size-xs`) | 400 | 1.4 |
| Label / compact / date | 12px (`--font-size-small`; date dùng `--font-mono`) | 400 | 1.4 |
| Body / UI | 13px (`--font-size-ui` / `--font-size-base`) | 400 | 1.5 |
| Heading | 16px | 600 | 1.2 |

- Heading dùng cho tiêu đề section "Mốc triển khai" (nếu tách khỏi luồng header hiện tại) và tiêu đề CR; mọi label field (`Tên mốc`, `Ngày mục tiêu`, `Mốc`) dùng Body/Label 13/12px.
- `targetDate` (`YYYY-MM-DD`) và số lượng mốc/tác vụ render `--font-mono` 12px để căn cột và tránh lệch light/dark.
- Không hardcode `font-size` inline; dùng role token / wrapper default (ADOPT-02).

## Color

Hex lấy trực tiếp từ `src/styles/tokens.ts` (`lightTokens` / `darkTokens`); không thêm hex mới. Tỷ lệ 60/30/10 tính theo diện tích hiển thị.

| Role | Value (light / dark) | Usage |
|------|----------------------|-------|
| Dominant (60%) | `--bg-app` `#ffffff` / `#171d27` | Nền CR Detail, bảng tác vụ, nền section mốc |
| Secondary (30%) | `--bg-island` `#ffffff` / `#1c2330`, `--bg-elev` `#f7f8fa` / `#171d27`, `--surface-sunken` `#e8ecf3` / `#111720` | Card section "Mốc triển khai", group header "Chưa gán mốc", dòng mốc đang chọn (`--bg-selected` `#d0dffe` / `#1e3156`), border `--border` `#e9eaee` / `#2c3646` |
| Accent (10%) | `--accent` `#2f62d8` / `#6a9bff` | Xem "Accent reserved for" |
| Destructive | `--danger` `#d1484f` / `#ff8289` | Chỉ icon/nút "Xóa mốc" và nút "Xóa" trong Popconfirm |

Accent reserved for (danh sách cụ thể):
- Primary button **Thêm mốc** / **Lưu** trong inline editor.
- Mốc đang chọn: viền hoặc thanh chỉ thị 2px + chữ accent (kết hợp `--bg-selected`).
- Focus-visible ring 2px trên mọi control trong section và Select mốc.
- Link/không dùng accent cho text thường, border inactive, disabled control hay decoration.

Semantic khác (không phải accent): `--success` `#338555`/`#4ade80` cho badge số ghi chú đã có; `--warning` `#a56906`/`#e8a13a` cho `targetDate` đã quá hạn (dùng qua `Tag`/`StatusTag`, không tự map màu trong view); `--fg-muted` `#6c707e`/`#9aa8bd` cho nhãn "Chưa gán mốc" và "Chưa có". Mọi map màu đi qua `statusColorMap` / wrapper; CR type badge giữ nguyên (`#1677ff`/`#52c41a`/`#faad14`) — không đổi trong phase này.

## Copywriting Contract

Tiếng Việt cho mọi copy UI (CLAUDE.md). Identifier, tên field kỹ thuật giữ nguyên. Các chuỗi dưới là default soạn tại đây theo discretion D-09; giữ đồng nhất với copy CR Detail hiện tại ("Chưa có", "Thêm link", "Xóa liên kết này?", "Không có tác vụ phù hợp").

| Element | Copy |
|---------|------|
| Primary CTA | **Thêm mốc** (nút thêm trong header section "Mốc triển khai", wrapped Button, right-aligned cạnh tiêu đề). Inline editor dùng **Lưu** / **Hủy**. |
| Empty state heading | **Chưa có mốc triển khai** |
| Empty state body | **Thêm mốc để nhóm tác vụ theo từng đợt triển khai.** kèm CTA **Thêm mốc**. |
| Error state | **Không thể lưu mốc.** → **Thử lại. Nếu lỗi tiếp tục, kiểm tra CR rồi thử lại.** (dùng `message.error` qua `useMessage()`, không static `message.*`). |
| Destructive confirmation | **Xóa mốc «{name}»?** — **Tác vụ trong mốc này sẽ chuyển về «Chưa gán mốc» và ghi chú đính kèm sẽ bị bỏ gắn. Tác vụ và ghi chú vẫn được giữ lại.** Buttons: **Xóa** / **Hủy**, nút Xóa `danger`. |

Copy cố định bổ sung:
- Section header: **Mốc triển khai**, kèm số lượng `(n)` dạng mono 12px.
- Field inline editor: **Tên mốc** (Input, required), **Ngày mục tiêu** (DatePicker, optional, placeholder **Chọn ngày**), giá trị trống ngày hiển thị **—**.
- Nhóm tác vụ chưa gán: **Chưa gán mốc** (đúng chuỗi này, D-02). Nhóm có mốc dùng tên mốc + số lượng.
- Cột bảng: **Mốc**. TaskDrawer field label: **Mốc**; option chưa gán: **Chưa gán mốc**; Tooltip khi chưa chọn CR: **Chọn CR trước**; dropdown rỗng: **CR này chưa có mốc — thêm mốc trong chi tiết CR**.
- EntityNotesSection của mốc kế thừa copy có sẵn (header **Ghi chú**, Empty, "Xóa ghi chú này?"). Không soạn copy notes mới.

## Interaction Contract

### 1. Section "Mốc triển khai" trong CR Detail (D-09)

1. Vị trí: block mới trong `secondaryBlocks` của `ChangeRequestDetailView.tsx`, cạnh block "Ghi chú"/"Links"/"Nhắc nhở"; render qua wrapper `Card`/container island, giữ `padding: 12px` và border `--border` như block hiện tại. `data-testid="cr-detail-milestones"` (và `cr-detail-milestone-add` cho nút) để planner/executor/test bám vào.
2. Layout: compact table (không collapsible cards) — nhất quán với bảng link dạng compact đã duyệt ở commit `261128-d1m`. Cột: **Tên mốc** (Text ellipsis, `title` đầy đủ), **Ngày mục tiêu** (mono 12px, `—` khi trống), **Ghi chú** (số note `entityType='crMilestone'`, qua Badge/Tag), **Thao tác** (IconButton `EditOutlined` + `DeleteOutlined`, mỗi cái có `Tooltip` + `aria-label`: **Sửa mốc** / **Xóa mốc**). Header row dùng muted 11px giữ bảng link hiện tại.
3. Chọn mốc: click vào dòng/tên mốc đặt `selectedMilestoneId`; dòng đó dùng `--bg-selected` + viền accent 2px. Ngay dưới bảng render `<EntityNotesSection entityType="crMilestone" entityId={selectedMilestone.id} db={db} />` (D-05). Khi chưa chọn mốc hoặc danh sách rỗng: không mount notes section, chỉ hiện empty state của section.
4. Inline CRUD (không chuyển trang, không mở Modal riêng):
   - **Thêm mốc** → hiện inline editor row ngay dưới header bảng: `Input` tên (auto-focus) + `DatePicker` ngày mục tiêu + IconButton **Lưu** / **Hủy**.
   - **Sửa mốc** → cùng inline editor row, prefill tên/ngày của mốc đó; Lưu cập nhật tại chỗ, Hủy bỏ không ghi.
   - Validate: tên rỗng hoặc chỉ khoảng trắng → field error **Nhập tên mốc**, không đóng editor; ngày optional. Ký tự tên cắt/giới hạn theo cùng nguyên tắc `LINK_NAME_MAX_LENGTH` nếu planner thấy cần, nhưng không thêm rule mới ngoài required.
   - Mọi write đi qua repository + `useMessage()`; lỗi hiện copy "Không thể lưu mốc." ở trên, editor vẫn mở để thử lại. Không dùng `Modal.confirm` tĩnh.
5. **Xóa mốc** → `Popconfirm` (wrapper) với copy destructive ở trên; `okText="Xóa"`, `cancelText="Hủy"`, `okButtonProps={{ danger: true }}`. Xác nhận → repository xóa trong một transaction: xóa milestone, clear `milestoneId` trên task của nó, detach note `entityType='crMilestone'` + `entityId=id` (D-04). Tasks/notes vẫn tồn tại. Nếu mốc đang chọn bị xóa → reset `selectedMilestoneId`.
6. Không có text field ghi chú trên milestone (D-01). Notes chỉ qua `EntityNotesSection`; không thêm chat scope/reminder/knowledge-link/entity type khác (D-06).

### 2. Cột "Mốc" trong bảng tác vụ (D-09)

1. `TaskTable.tsx` (bảng tác vụ toàn cục) và bảng tác vụ trong CR Detail đều thêm cột `title: 'Mốc'`, `dataIndex: 'milestoneId'`, đặt sau cột **CR**, trước **Subsystem** (thứ tự `CR → Mốc → Task/Subsystem` khớp phân cấp mới).
2. Render: nếu `milestoneId` trỏ tới milestone tồn tại → tên mốc (Text ellipsis, `title` đầy đủ, `--font-size-small`); nếu rỗng/không tìm thấy → **Chưa gán mốc** với `--fg-muted` (không render `undefined`, không `—`). Không dùng accent cho nhãn chưa gán.
3. CR Detail: nhóm dòng theo milestone với group header (tên mốc + số lượng, mono cho số); nhóm **Chưa gán mốc** luôn xếp cuối. SearchInput + status filter hiện tại vẫn lọc trong các nhóm; ẩn nhóm rỗng sau lọc. Giữ nguyên `data-testid` cũ (`cr-detail-task-search`, `cr-detail-status-filter`).
4. Cột mới phải nằm trong `ALWAYS_VISIBLE_COLUMNS` hoặc được thêm vào danh sách cột mặc định `STORAGE_COLUMNS_KEY = 'planner:task_table_columns'` sao cho người dùng không accidentally ẩn cột "Mốc" khi cột lưu từ phiên bản cũ thiếu key — fallback về "hiện" nếu key vắng mặt.

### 3. Select mốc trong TaskDrawer (D-02/D-03/D-09)

1. `FormItem name="milestoneId" label="Mốc"` với wrapped `Select`, `aria-label="Mốc"`, đặt ngay sau field **Change Request (CR)** và trước **Subsystem**, phản ánh `CR → Mốc → Subsystem`.
2. Options = các `crMilestones` có `crId === selectedCrId` (giá trị từ `useWatch('crId', form)`), cộng option đầu **Chưa gán mốc** với value `''` (map tới `undefined` khi submit — giữ `exactOptionalPropertyTypes`, không truyền `undefined` làm key). Không option cross-CR (D-03).
3. Khi `selectedCrId` rỗng: `Select` disabled trong `Tooltip title="Chọn CR trước"` — sao chép pattern Subsystem hiện tại (`TaskDrawer.tsx:496-508`), không hiện lỗi.
4. Trong `handleCrChange`: besides clearing `systemId` như hiện tại, clear `milestoneId` nếu mốc đang chọn không thuộc CR mới (D-02). Invariant D-03 được bảo vệ thêm ở `taskRepo` — UI không phải là nơi duy nhất chặn.
5. Khi CR được chọn nhưng chưa có mốc nào: dropdown chỉ có **Chưa gán mốc** + hint **CR này chưa có mốc — thêm mốc trong chi tiết CR**; không render danh sách rỗng im lặng.
6. Khi mở TaskDrawer cho task đã có `milestoneId`: Select prefill đúng tên mốc; nếu dữ liệu cũ vi phạm invariant (mốc không còn hoặc sai CR) → rơi về **Chưa gán mốc** mà không crash.

### 4. Tuân thủ design system (D-09, ADOPT-01/02, D-10)

- Chỉ import từ `src/components/ui/`; không `from 'antd'` hay `from '@ant-design/icons'` trong các file phase này. Icon lấy từ `icon.tsx`.
- Không inline style mang giá trị token (màu/font/size/spacing). Dùng CSS var (`var(--gap-*)`, `var(--border)`, `var(--font-size-small)`, `var(--fg-muted)`) hoặc wrapper default — kể cả row mốc, group header, inline editor.
- Giữ nguyên 100% công việc chưa commit trên cây (`261128-d1m`: link edit modal + Popconfirm, bảng link compact, nút thêm căn phải). Không revert/stash/overwrite; xếp layer mới lên trên (D-10).
- Light/dark parity: mọi màu từ token; đổi theme cập nhật ngay section mốc, cột "Mốc", Select và notes mà không reload (TOKEN-02). Focus ring accent, disabled control dùng `--control-off`, destructive dùng `--danger` ở cả hai mode.
- A11y: IconButton có `aria-label`; Select/Input/DatePicker có label hoặc aria-label; inline editor auto-focus Input, Esc = Hủy; dòng mốc chọn được bằng click và bàn phím (tabIndex/role phù hợp); `aria-live="polite"` cho thông báo lưu/xóa thành công; tooltip không thay thế accessible name.
