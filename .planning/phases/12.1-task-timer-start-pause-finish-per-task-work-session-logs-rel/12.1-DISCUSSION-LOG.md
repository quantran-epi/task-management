## Timer UI & Active State Display

| Option | Description | Selected |
|--------|-------------|----------|
| Header Bar Widget (Recommended) | Widget gắn cố định góc trên Header của AppShell (cạnh Alert Badge và InstallButton). Khi có timer chạy, hiển thị Tên task rút gọn, thời gian đếm giây (HH:mm:ss) và nút Quick Pause/Stop. Bấm vào mở Drawer chi tiết. | ✓ |
| Floating Bottom Widget | Một thanh nổi (Floating Dock/Pill) neo góc dưới màn hình. Luôn nổi lên trên mọi View, hiển thị task đang chạy và controls. | |
| Embedded Only (Trong Task/Drawer) | Chỉ hiển thị nút Start/Pause/Stop bên trong TaskDrawer và trên dòng Task của các bảng/danh sách. Không có thanh trạng thái toàn cục. | |

**User's choice:** Header Bar Widget (Recommended)
**Notes:** Header Bar gọn gàng, đồng bộ với thiết kế hiện tại của ứng dụng.

## Concurrency Policy & Behavior

| Option | Description | Selected |
|--------|-------------|----------|
| Cho phép chạy đồng thời (Recommended) | Hệ thống cho phép chạy song song nhiều Timer cùng lúc nếu người dùng chủ động bật. Trên Header Bar Widget hiển thị bộ đếm tổng hợp kèm dropdown. | ✓ |
| Tự động tạm dừng timer cũ (Single-active) | Khi bấm 'Start' ở Task B, hệ thống tự động lưu lại và tạm dừng ('Pause') Timer đang chạy ở Task A. | |
| Hỏi xác nhận khi bật task mới | Khi bấm 'Start' Task B trong lúc Task A đang chạy, hệ thống bật modal hỏi xác nhận. | |

**User's choice:** Cho phép chạy đồng thời (Recommended)
**Notes:** Đáp ứng tình huống thực tế của Banking IT: vừa tham gia Meeting/Họp vừa thực hiện hoặc theo dõi task khác.

## Allocation Limits & Feasibility Alerts

| Option | Description | Selected |
|--------|-------------|----------|
| Phân tầng Toast & Drawer & Feasibility (Recommended) | Cảnh báo phân tầng: (1) Toast notification khi Spent chạm 100% Estimate; (2) Đẩy cảnh báo vào Notification Drawer khi tổng Spent vượt 100% Daily Capacity; (3) Cảnh báo tính khả thi trong ngày. | ✓ |
| Chỉ cảnh báo vượt Task Estimate | Chỉ cảnh báo mức Task: Khi timer chạm đúng Estimate (100%), gửi thông báo Desktop/Toast. | |
| Chỉ cảnh báo trực quan (Visual Color Progress) | Cảnh báo sớm từ 80% Estimate và đỏ tại 100% bằng màu sắc thanh tiến độ. | |

**User's choice:** Phân tầng Toast & Drawer & Feasibility (Recommended)
**Notes:** Giúp người dùng theo dõi cả ở cấp độ task cụ thể lẫn toàn bộ kế hoạch ngày.

## Work Session Logs & Spent Aggregation

| Option | Description | Selected |
|--------|-------------|----------|
| Lịch sử phiên + Cho phép CRUD thủ công (Recommended) | Tự động sinh WorkSessionLog khi Pause/Finish. Cho phép xem lịch sử, thêm phiên thủ công, sửa/xóa phiên nhầm. Rollup spent time ở Task, Milestone, Project. | ✓ |
| Chỉ Timer tự động (Read-only logs) | Chỉ ghi nhận tự động từ Timer, không cho phép thêm/sửa/xóa thủ công. | |
| Chỉ cộng dồn spentMinutes vào Task | Không lưu chi tiết từng session nhỏ, chỉ cộng dồn thẳng số phút vào task. | |

**User's choice:** Lịch sử phiên + Cho phép CRUD thủ công (Recommended)
**Notes:** Đảm bảo tính linh hoạt tối đa cho người dùng khi làm việc offline hoặc quên bấm timer.

## Claude's Discretion

- Tần số cập nhật tick timer trên UI: 1 giây (1000ms).
- Định dạng hiển thị thời gian linh hoạt (`< 1m`, `45m`, `2h 15m`).
- Màu sắc thanh tiến độ cảnh báo giới hạn (Xanh, Cam, Đỏ).
