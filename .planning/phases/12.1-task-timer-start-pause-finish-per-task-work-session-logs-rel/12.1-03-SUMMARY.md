# Phase 12.1 Plan 03: Task Timer & Work Sessions UI Summary

Interactive UI components connecting users to time tracking: global `ActiveTimerWidget` in `AppShell`, inline row triggers in `TaskTable`, dedicated `WorkSessionsTab` with `ManualWorkSessionModal` in `TaskDrawer`, and spent time rollups.

## What Was Done

1. **Global ActiveTimerWidget in AppShell Header**:
   - Built `ActiveTimerWidget` rendering null when 0 timers are active per UI-SPEC.
   - Single timer capsule displays running/paused indicator dot, truncated task name, `HH:mm:ss` tabular ticker, and accessible Pause/Resume and Finish buttons.
   - Multi-timer dropdown triggers on badge button (`N timer đang chạy`), listing all running timers with row-level controls.
   - Wrapped `AppShell` with `TimerProvider` and embedded `ActiveTimerWidget`.

2. **TaskTable Inline Timer Actions & Spent Progress**:
   - Integrated inline timer column with compact Start (`PlayCircleOutlined`), Pause/Resume, and Finish actions.
   - Prevented table row selection / drawer opening via `stopPropagation()`.
   - Added spent time vs estimate ratio and dynamic `Progress` bar with color coding (Green <80%, Orange 80-100%, Red >100%).
   - Evaluates Tier 1 toast warning (`evaluateTaskSpentAlert`) on session finish.

3. **TaskDrawer Work Sessions Tab, Manual Modal & Rollups**:
   - Added "Lịch sử làm việc" tab in `TaskDrawer` with live work sessions query.
   - Top banner displays total spent time vs estimate with progress bar and active timer toggle controls.
   - `ManualWorkSessionModal` with FormGuard protection (`manual-work-session-modal`), `TimePicker.RangePicker`, auto-calculated duration, and validation (`endTime > startTime`).
   - Destructive Popconfirm with exact warning text before deleting sessions.
   - Added spent time rollups to `ProjectTable` for both milestones and projects.
