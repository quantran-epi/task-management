## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | #ffffff | App background, container backgrounds, drawer body |
| Secondary (30%) | #f5f5f5 | Header widget capsule, table header rows, card backgrounds |
| Accent (10%) | #1677ff | Active running timer highlight, Start button, primary actions |
| Destructive | #ff4d4f | Stop/Delete work session, over-estimate progress alert (>100%) |

Accent reserved for:
- Start timer button when task timer is idle
- Active running timer indicator dot / badge in AppHeader
- Progress bar under 80% estimate
- Primary save action in manual session modal

Semantic state colors:
- Timer Running / Active: #52c41a (Success green for running ticker)
- Timer Paused: #fa8c16 (Warning orange for paused state)
- Over-allocation / Feasibility Alert: #ff4d4f (Red for >100% estimate and daily overload)

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA (Start) | Bắt đầu tính giờ |
| Primary CTA (Pause) | Tạm dừng |
| Primary CTA (Finish) | Kết thúc phiên |
| Manual Session CTA | Thêm phiên làm việc |
| Header Widget Single Timer | {taskName}: {HH:mm:ss} |
| Header Widget Multi-Timer | {N} timer đang chạy |
| Empty state heading | Chưa có phiên làm việc nào |
| Empty state body | Bấm "Bắt đầu tính giờ" hoặc "Thêm phiên làm việc" để ghi nhận thời gian cho tác vụ này. |
| Error state (Invalid duration) | Thời gian không hợp lệ. Giờ kết thúc phải sau giờ bắt đầu. |
| Error state (Save failure) | Không thể lưu phiên làm việc. Vui lòng thử lại. |
| Destructive confirmation | Xóa phiên làm việc: Bạn có chắc chắn muốn xóa phiên làm việc này không? Thời gian đã ghi nhận sẽ bị trừ khỏi tổng số giờ của tác vụ. |
| Allocation limit warning (Toast) | Tác vụ "{taskName}" đã dùng {spentMinutes}m, vượt quá thời gian ước lượng ({estimateMinutes}m). |
| Daily feasibility alert (Drawer) | Tổng thời gian còn lại của các tác vụ hôm nay ({remainingNeeded}m) vượt quá thời gian làm việc còn lại ({availableCapacity}m). |
