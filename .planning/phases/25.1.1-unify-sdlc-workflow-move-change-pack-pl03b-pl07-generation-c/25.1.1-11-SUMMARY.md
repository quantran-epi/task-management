## Deviations from Plan

- **A real regression was found and fixed, not baselined.** `AIChatDrawerRestoreRecovery.test.tsx` → "refuses Continue while sources are missing and never strands a running checkpoint" is not on the documented baseline list, so it was bisected instead of accepted. Measured failure rate over 20 interleaved runs: HEAD 7/20 vs the pre-phase commit `57d3688e` 1/20. Commit bisect: `37cad244` 0/6, `489d5ca4` 0/6, `e21c4d3a` 3/6 — **introduced by plan 08**. Cause: the guard read `restoredMissingSources`, a `useLiveQuery` value that is `[]` on the first render after a restore, so a fast Continue resumed past the guard and replaced the `interrupted` checkpoint. Fix in `handleSdlcCheckpointContinue`: derive the missing set synchronously from `coordinator.getState()`/`restore()` + `db.notes.bulkGet` before `resumeCheckpoint`. The rendered notice and the send guard still use the live value, so UI behaviour is unchanged. No test was added — the existing D-30 case is the exact subject.
- **`npm run lint` does not exist.** Recorded as skipped with the full script list; `package.json` was not modified.
- **Item 6 of the final sweep is not empty.** `grep -rn "Soạn PL02\|Thanh chọn wizard tài liệu" src e2e` returns 3 lines, all `toHaveCount(0)` assertions inside `e2e/sdlcHubFlow.spec.ts`. Zero production hits. The expectation was recorded as-is rather than edited.
