## Trust Boundaries

| Boundary | Description |

| hub modal → drawer | antd portals must stack above the drawer without trapping focus behind it |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-25.1.1-05 | Tampering | `DriftMatrixView` stacked renderer | mitigate | All values render as React text nodes with `wordBreak: 'break-word'`; no `dangerouslySetInnerHTML`, no markdown-to-HTML for drift content. |
| T-25.1.1-06 | Elevation of privilege | `StepInputDocsModal` portal | mitigate | `zIndex={1300}` keeps the metadata modal actionable above the 1200 drawer so a user cannot be tricked into typing intake metadata into a hidden layer. |
| T-25.1.1-07 | Denial of service | collapse `ResizeObserver` (confirm strip) | mitigate | Observer disconnects on unmount; the fallback when `ResizeObserver` is unavailable is the stacked layout, which is the safe direction. |
| T-25.1.1-08 | Information disclosure | panel copy | accept | Panels render only workflow metadata already visible in the hub; no tokens, endpoints, or notes bodies are surfaced. |
</threat_model>
