# Phase 25.1.1 — UI Design Contract

> Visual and interaction contract for moving change-pack upload, PL03B/PL07 generation, CAB generation, and bank-template `.docx` export into the SDLC Hub, plus a collapse affordance for the timeline and the removal of the wizard entry points. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

This phase adds **no design system, no dependency, and no new surface**. Every pixel it introduces already lives inside `SdlcWorkflowHub`'s step detail panel, the drawer's composer slot, or the existing `src/components/ai/wizard/*` components being relocated. The contract below is about *where* existing pieces render, *which* states they expose, and *what* must disappear.

Exceptions (declared, not accidental):

- **Timeline row height**: `minHeight: 40` retained. The drawer is a desktop/Tauri surface, not a touch surface; 40px keeps six rows plus the detail panel usable at 320×800. Do not grow it.
- **Hub card body padding**: `8px 12px` (existing). 12px is a horizontal-only exception inherited from the antd small `Card` shell; it is not a new scale step.

- **Container width breakpoint `384px`**: the drawer's `MIN_AI_CHAT_WIDTH` is 320px (`AIChatDrawer.tsx:141`). Every layout decision below that says "narrow" means *step-panel content width < 384px*. Narrow mode is not optional at 320px.

## Typography

Exactly four sizes, two weights (400 regular, 600 semibold). **11px is retired everywhere in `src/components/ai/wizard/`** — `SdlcWorkflowHub.tsx` renders 11px at lines 286, 304, and 412; all three must move to 12px. No new `fontSize: 11` may be introduced.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Label — step number ("Bước 4"), row state label, artifact meta ("v2 · a1b2c3d"), pack meta line, cycle rows, button text at `size="small"` | 12px | 600 | 1.4 |
| Body — step title in the row, hint text, dropzone copy, drift cell text, error/success messages, artifact file rows | 14px | 400 | 1.5 |
| Heading — hub card title (`SDLC: {featureName}`), step-panel heading (`Bước 4/6: …`), artifact group heading, drift matrix heading | 16px | 600 | 1.3 |
| Display — not used in this phase | — | — | — |

Rules:

- Two weights only: 400 and 600. Force `fontWeight: 600` on every antd `Tag` used here (antd defaults to 500).
- Codes and identifiers (`MÃ_CR`, branch names, commit SHAs, `change-pack.zip`, `node scripts/change-pack.mjs --cr <MÃ_CR>`, file paths, `SOLUTION.md`, `PL03B`, `PL07`, `CAB`) render verbatim, never translated, never truncated — wrap with `wordBreak: 'break-word'`.
- Vietnamese diacritics preserved exactly in all copy.
- Monospace only for hashes/paths, via existing inline `<code>` treatment; do not introduce a new font stack.
- Drift group headings drop from 16px to **14px/600** so they sit below the 16px panel heading instead of competing with it. The matrix `h2` stays 16px/600.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `colorBgContainer` | Drawer body, timeline row background when unselected, individual artifact rows |
| Secondary (30%) | `colorFillAlter` / `colorFillTertiary` | Hub card body (`colorFillAlter`), selected step row (`colorFillTertiary`), cycle header band, confirm strip, dropzone surface |
| Accent (10%) | `colorPrimary` (`#4f46e5`) | See the reserved list below — nothing else |
| Destructive | `colorError` | `Làm mới workflow` danger button, error alerts, drift group `Ngoài solution` |

Semantic status colors (meaning-carrying, never decorative):

- `colorPrimary` — "Đang xử lý" row state, spinning `SyncOutlined`, active-cycle band.
- `colorSuccess` — "Đã xong" row state, docx export success, `CheckCircleOutlined`.
- `colorWarning` — "Cần cập nhật" row state, stale alert, drift group `Chưa làm`, incomplete-coverage alert, card border when `staleSteps.length > 0`.
- `colorError` — failed pack validation, failed generation, failed export, drift group `Ngoài solution`.
- `colorInfo` — drift group `Làm khác`, artifact version tags.
- `colorTextQuaternary` — "Chưa bắt đầu" rows only.

**Accent reserved for (exhaustive list):**

1. Selected timeline row border (1px `colorPrimary`) — exactly one row at a time.
2. The `SyncOutlined` icon and the 12px state label of the *current processing* row.
3. Primary CTAs inside step panels: `Xác nhận pack`, `Tạo PL03B & PL07`, `Tạo tờ trình CAB`, `Xuất .docx`.
4. Keyboard focus ring on every focusable control in the hub (2px `colorPrimary`, 2px offset).
5. Dropzone drag-over state only (`colorPrimary` dashed border + `colorPrimaryBg` fill).

**Explicitly not accent:** `Chọn pack khác`, `Cập nhật lại`, `Sửa PL01/PL02`, `Cập nhật yêu cầu`, `Cập nhật solution`, `Xuất .docx` secondary repeats (default buttons). A neutral action must never look recommended. `Làm mới workflow` stays `danger` (destructive, not accent).

## Layout Contract — Hub Step Panel (320px)

The hub card is the only container. Its content column at 320px is ~296px wide (drawer 320 − 2×12px card padding).

**Vertical order inside the card body (unchanged except where noted):**

1. Cycle header band (existing).
2. Cycle history rows (existing, read-only).
3. **Timeline list** — `role="list"`, id `sdlc-step-list`, `aria-label="Quy trình 6 bước SDLC"`. Collapsible (see below).
4. **Step detail panel** (the phase's main change). Structure:

```
Bước 4/6: Change Pack & Soi Drift            ← 16px/600, wraps freely
— {hint}                                      ← 14px/400, colorTextSecondary
[stale Alert, if the selected step is stale]
──────────────────────────────────────────────  ← 1px colorBorderSecondary top rule
{step-specific body — see Step Panels below}
```

**Narrow-mode rules (content width < 384px) — all mandatory:**

- No element may have a fixed pixel width. No `white-space: nowrap` on prose. No `overflowX` on the card or the detail panel.
- The detail-panel header row (heading + hint + rerun button) uses `flexWrap: 'wrap'` with the hint block `flex: '1 1 200px'` and the button after it. Never `justifyContent: 'space-between'` with a shrinkable text node (current bug: the hint is squeezed to a one-character column at 320px).
- Action groups stack vertically, full-width, primary first: `display:flex; flexDirection:column; gap:8; alignItems:stretch`.
- The drift matrix renders in **stacked** layout, not `Table` (see below).

Source: `SdlcWorkflowHub.tsx:445-503`, `AIChatDrawer.tsx:3188-3189`.

## Step Panels (the core of this phase)

Each panel renders only for its selected step, replacing the current hint-only body. Panels are pure presentation over `SdlcWorkflowState` plus hub-local draft state (pack validation result, in-flight flags).

### Step 4 — `CHANGE_PACK`

| Sub-state | Condition | Rendering |
|-----------|-----------|-----------|
| `idle` | no pack draft, no committed `artifacts.changePack` | `ChangePackDropzone` (existing component, relocated) |
| `validating` | file selected, validation in flight | Dropzone replaced by a `role="status"` row: `SyncOutlined spin` + `Đang kiểm tra change-pack…`, 14px/400 |
| `invalid` | validation returned an error code | `Alert type="error" showIcon` with the enumerated copy, then a single `Chọn pack khác` default button (narrow: full-width) |
| `pending_confirm` | validated, awaiting confirm | `ChangePackConfirmStrip` (existing) — meta line `CR {cr} · Nhánh {branch} · {commitCount} commit · {fileCount} tệp` at 12px/600, then `Xác nhận pack` (primary) + `Chọn pack khác`; narrow mode stacks them full-width |
| `confirming` | confirm in flight | Strip stays mounted, `Xác nhận pack` gets `loading` + `disabled`, `Chọn pack khác` disabled; new `role="status"` line `Đang đối chiếu với SOLUTION.md…` |
| `confirmed` | `artifacts.changePack` exists | `role="status"` line `Đã nạp change-pack {cr}` (12px/400), then `DriftMatrixView`, then nothing else. A `Chọn pack khác` default button sits below the matrix. |
| `stale` | `staleSteps` includes `CHANGE_PACK` | Existing warning `Alert` at the top of the panel stays; the committed matrix renders read-only. `Cập nhật lại` (existing danger button) clears the *draft* and returns to `idle` while keeping the committed artifact until a new pack is confirmed (data safety). |

`DriftMatrixView` contract:

- Keep the three groups in fixed order: `Ngoài solution` (`error`), `Chưa làm` (`warning`), `Làm khác` (`processing`).
- Keep `h2` `Bảng drift so với SOLUTION.md` at 16px/600, group `h3` at 14px/600.
- **Add `layout?: 'table' | 'stacked'`; hub passes `stacked`, `DocumentPreviewCard` keeps the default `table`.** Stacked renders each tuple as a block: group tag (12px/600), then `Mục` / `SOLUTION.md` / `Thực tế` as three label-value rows (`dl`-like, label 12px/600 `colorTextSecondary`, value 14px/400, `wordBreak: 'break-word'`), separated by `8px` and a `1px colorBorderSecondary` divider. No `Table`, no `scroll={{ x: 640 }}`, no horizontal overflow at any width.
- Empty-group copy stays: clean → `Không phát hiện drift: triển khai khớp với solution đã duyệt.`; otherwise `Không có mục trong nhóm này.`
- Coverage warning `Alert` stays as-is.
- `aria-labelledby` ids must come from `useId()` — the component can mount twice in one drawer (hub + historic message card) and the current hard-coded ids collide.

## DOCX Export Contract

Export lives **inside the owning step's panel**, on the artifact row. There is no global export toolbar and no export entry in the composer.

| Artifact | Step panel | Row label |
|----------|-----------|-----------|
| PL02 (from `artifacts.pl02`) | Step 1 — `INTAKE` | `PL02 — Đặc tả chức năng` |

| CAB | Step 6 — `CAB` | `Tờ trình CAB` |

Export state is keyed by `SdlcArtifactKind`, never by chat message id. One state per kind:

| State | Rendering |
|-------|-----------|
| `idle` | `Xuất .docx` primary button, accessible name `Xuất {KIND} (.docx)` |

## Collapse / Expand Affordance

User asked for it explicitly; the hub is currently a fixed 6×40px block plus panel that dominates a 320px drawer.

| Property | Contract |
|----------|----------|
| Control | A single antd `Button type="text" size="small"` in the hub card title row, right-aligned after the existing action buttons, icon only at narrow width (`UpOutlined` / `DownOutlined`) with the accessible name above. |
| Semantics | Real `<button>` with `aria-expanded={expanded}` and `aria-controls="sdlc-step-list"`. |
| Default state | **Expanded.** Collapsing hides the phase's only navigation, so it is never the initial state. |
| Persistence | Component state for the lifetime of the mounted drawer tab. Not persisted to Dexie or `localStorage` — a remount returns to expanded. No settings entry. |
| Collapsed rendering | The list element stays in the DOM with the `hidden` attribute (so `aria-controls` resolves), replaced visually by one 12px/600 summary line: `Bước {n}/6 — {shortTitle}` + ` · {n} bước cần cập nhật` when stale. The **step detail panel stays visible** — only the six rows collapse. |
| Keyboard | `Enter`/`Space` toggle (native). No shortcut key. `Escape` does **not** collapse (it belongs to modals). |
| Focus management | If focus is inside a step row when the list collapses, focus moves to the toggle button before the rows are hidden. Focus never lands on a hidden element. |
| Selection while collapsed | Not possible (rows hidden). The detail panel keeps showing the last selected step, so the collapse never changes what the user is reading. |

Source: user directive in `25.1.1-CONTEXT.md` scope; `SdlcWorkflowHub.tsx:208-266, 317-442`.

## Interaction Contracts

| Interaction | Trigger | Response |
|-------------|---------|----------|
| Select a step row | Click / `Enter` / `Space` on a row | Updates the viewed step only (D-17). Current processing step and state machine unchanged. Detail panel swaps to that step's panel. |
| Collapse / expand timeline | Toggle button | Hides/shows the six rows, focus moves to the toggle if it was inside the list, detail panel unaffected. |
| Drop or pick a change-pack | Drag-over / drop / click / `Enter` / `Space` on the dropzone | `validating` → `invalid` (enumerated alert, `Chọn pack khác` focused) or `pending_confirm` (confirm strip renders, focus moves to `Xác nhận pack`). The dropzone always leaves the DOM when a result exists, so focus must be re-homed explicitly. |

## Accessibility

- Every focusable control in the hub has a **visible focus ring**: `outline: 2px solid token.colorPrimary; outlineOffset: 2px`. The step rows currently set `outline: 'none'` with no substitute (`SdlcWorkflowHub.tsx:393`) — that must be fixed in this phase, and the same ring applies to the dropzone (currently `tabIndex={0}` with no focus style), the toggle, and every artifact action.
- Step rows keep `aria-label="Bước {n}: {title} — {stateLabel}"`, `aria-selected`, and `aria-current="step"` only on the processing *and* selected row. Distinct "processing" vs "selected" rendering must survive: processing = spinning icon + `colorPrimary` label; selected = `colorPrimary` border + `colorFillTertiary` background. Both may be true at once on the same row.
- The timeline list and the toggle are linked by `id` / `aria-controls`; the collapsed list keeps `hidden`.
- Async transitions announce through `role="status"` (polite) for progress and success, `role="alert"` for errors. Never announce by rendering text alone.
- Focus is moved explicitly whenever a triggering element is removed from the DOM (dropzone → confirm button; confirm strip → drift heading; generation button → artifact export button).
- Headings inside the panel follow h2 (matrix) → h3 (groups) → body; no skipped levels, no heading used purely for size.
- `aria-labelledby` ids are instance-unique (`useId`) because the same component can mount twice.
- Hover-only affordances are forbidden. Every state above is reachable and perceivable by keyboard alone.
- 320px: no horizontal scroll at page level (existing D-16 acceptance test `e2e/sdlcFlowHardening.spec.ts:187`) and — new in this phase — no horizontal scroll inside the step panel either. The drift matrix stacked layout is what makes that possible.
