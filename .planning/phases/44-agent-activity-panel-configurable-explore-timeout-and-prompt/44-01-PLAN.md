<objective>
Make the `explore_repo` exploration deadline a per-call tuning knob: an optional `timeoutSeconds`
argument (integer, clamped 60..900, default 300) that flows from the tool definition through the
handler into the existing JS watchdog, without touching the portable cancel design. (D-01, D-02)

Purpose: a broad exploration can legitimately need more or less than a fixed five minutes. The
deadline must be tunable per call while the Phase-43 watchdog/abort/late-cancel/buffer/cap contract
stays byte-for-byte intact (D-02). This is a tuning knob, never a security boundary (D-01).

Output: a clamp helper and deps seam in `remoteExploreService.ts`, a tool-definition property and
handler wiring in `teamTools.ts`, and focused tests proving the clamp boundaries, the advertised
contract (D-03), and the derived milliseconds reaching the watchdog.
</objective>
