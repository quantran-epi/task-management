  <action>
    Implement graph.ts, register routes in server.ts, and write route tests:
    1. Define routes under `/api/v1/sets/:setId/graph`:
       - `POST /api/v1/sets/:setId/graph/rebuild`: requires bearer auth; validates `setId` uuid; accepts `x-rebuild-key` header for idempotency; returns 202 with build accepted DTO. If a rebuild is already in progress for that set, returns 409 Conflict.
       - `GET /api/v1/sets/:setId/graph/status`: returns `GraphStatusDTO` with active snapshot ID, state ('Never built' | 'Building' | 'Active' | 'Active with warnings' | 'Failed'), current stage ('Preparing' | 'Structured extraction' | 'Prose extraction' | 'Validation' | 'Activation'), node count, fact count, evidence count, conflict count, quarantine count, ontology version, rules version.
       - `GET /api/v1/sets/:setId/graph/facts`: returns paginated list of `FactSummaryDTO` (factKey, subjectUrn, subjectName, subjectKind, relation, objectUrn, objectName, objectKind, effectiveClassification, evidenceCount, hasConflict, qualifiers).
       - `GET /api/v1/sets/:setId/graph/facts/:factKey/evidence`: returns `FactEvidenceDetailDTO` with full list of `EvidenceRecordDTO` (documentId, documentTitle, headingPath, startLine, endLine, startOffset, endOffset, method, classification, quote, environment, conflictBranch).
       - `GET /api/v1/sets/:setId/graph/quarantine`: returns `QuarantineListDTO` (rawIdentifier, documentId, headingPath, startLine, endLine, method, reason, candidateMatches).
    2. Enforce strict error handling: invalid parameters return 400 with content-free error; missing set/snapshot returns 404; unauthorized returns 401; internal errors return 500 without leaking stack traces or credentials.
    3. Register routes in `knowledge-server/src/server.ts` protected by existing origin and bearer authorization hooks.
    4. In graphRoutes.test.ts, test:
       - Unauthorized requests return 401.
       - Rebuild idempotency header handles replays cleanly.
       - Status endpoint returns correct counts and stage progression.
       - Fact and evidence endpoints return valid DTOs conforming to Zod schemas.
  </action>
