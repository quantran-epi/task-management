       - Classification: every validated candidate receives `classification: 'INFERRED'` and `method: 'LLM_PROSE'` (D-13).

       - Uncovered prose segmentation excludes consumed table ranges.
       - Candidate referencing nonexistent URN is quarantined.

       - Exceeding character ceiling safely throws or truncates without leaking secrets.

|----------|-------------|
| Markdown AST → Deterministic extractor | Untrusted markdown content parsed into structural syntax trees |

| LLM JSON output → Graph candidate parser | Untrusted model JSON response crosses into server domain model |
