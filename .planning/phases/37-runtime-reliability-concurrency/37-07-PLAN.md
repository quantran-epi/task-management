## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-37-22 | Denial of Service | double-click retry | medium | mitigate | An in-flight guard per agent rejects a second retry while the first is running, and the ledger's append-only attempt numbering would expose a duplicate as an anomaly in test. |
| T-37-23 | Tampering | retry re-running a completed agent | high | mitigate | `retryAssignment` refuses unless the source row is `stopped`/`error`; the test asserts siblings are invoked exactly once across the flow. |
| T-37-24 | Information Disclosure | retried task text | medium | accept | The retried task is text the same local user already authored and stored; it reaches the same provider the first attempt reached. No new disclosure boundary. |
| T-37-25 | Repudiation | stale synthesis | medium | mitigate | The previous synthesis is marked superseded with a message link, so the transcript always shows which synthesis is current (D-12). |
