# Phase 25.4 Plan 03: Centralized Action Registry & Search Everywhere Summary

Centralized action and shortcut registry with global keyboard shortcut listeners and IntelliJ ExpUI-style Search Everywhere floating modal.

## Key Changes

1. **Centralized Action Registry (`src/workbench/actions/actionRegistry.ts`)**:
   - Implemented singleton action registry with `registerAction`, `executeAction`, `getAllActions`, `getAction`, and `useActionRegistry` observer hook.
   - Pre-registered standard actions for tool window toggling (`Alt+1`..`5`), search everywhere (`Double Shift` / `Ctrl+K`), task creation (`Alt+Insert`), and timer toggle (`Alt+T`).
   - Mitigated T-25.4-05 by dispatching only strictly whitelisted action IDs and preventing arbitrary string evaluation.

2. **Keyboard Dispatchers (`useDoubleShift.ts`, `useGlobalKeymap.ts`)**:
   - `useDoubleShift`: Standalone high-performance Shift double-tap detector with <350ms window. Mitigated T-25.4-06 by guarding against key repetition (`e.repeat`) and input/textarea focus.
   - `useGlobalKeymap`: Listens to `Ctrl+K`/`Cmd+K`, `Alt+1`..`5`, `Alt+T`, and `Alt+Insert` and routes to `actionRegistry`.

3. **Search Everywhere Floating Modal (`src/workbench/search/SearchEverywhereModal.tsx`)**:
   - Centered floating modal with OpenIDEA styling (`--bg-popup`, `--border-strong`, `borderRadius: 3`, box-shadow).
   - Filter tabs: `All` | `Tasks` | `Projects` | `Docs` | `Actions`. Supports switching tabs via `Tab` key.
   - Live query from Dexie DB for tasks, projects, notes + registry actions.
   - Supports direct action mode with `>` prefix (e.g. `> New Task`, `> Toggle Timer`).
   - Arrow `Up`/`Down` selection with highlight (`--bg-selected: #d0dffe`), `Enter` to navigate/execute, `Esc` to close.

4. **Workbench Layout & TitleBar Integration (`WorkbenchLayout.tsx`, `TitleBar.tsx`)**:
   - Mounted `useGlobalKeymap` and `useDoubleShift` in `WorkbenchLayout`.
   - Wired TitleBar search button to open `SearchEverywhereModal`.
   - Listens to `taskmate:open-search-everywhere` custom events from `actionRegistry`.
