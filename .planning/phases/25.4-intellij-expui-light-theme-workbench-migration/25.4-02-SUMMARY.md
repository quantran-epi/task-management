# Phase 25.4 Plan 02: IntelliJ ExpUI View Integration Summary

Tabbed EditorArea center slot and Left/Bottom/Right docked tool windows embedded into resizable Workbench layout without modifying core business logic or views.

## Overview of Work Done

1. **EditorArea & Tab Management (`src/workbench/EditorArea.tsx`)**:
   - Tab bar (32px `--tabbar-height`) with active bottom highlight line (`2px solid var(--accent)`).
   - Dynamic tab switching, tab closing with neighbor activation, and empty state fallback.
   - Wraps active view inside `AntdThemeAdapter`.
   - Supports plug-in views: `TasksView`, `NotesView`, `PlannerView`, `AnalyticsView`, `SettingsView`, and `ProjectsView`.
   - Capped open tabs at 20 (T-25.4-03 mitigation).

2. **Left Tool Window (`src/workbench/toolwindows/LeftToolWindow.tsx`)**:
   - Header with tool window title and collapse button.
   - Reactive tree displaying projects and milestone children from Dexie IndexedDB (`useLiveQuery`).
   - Selecting a project opens or focuses a project tab.

3. **Bottom Tool Window (`src/workbench/toolwindows/BottomToolWindow.tsx`)**:
   - Tabs switching between embedded `AIChatDrawer` and System Logs console.
   - Header with collapse button toggling layoutStore bottomActiveId.

4. **Right Tool Window (`src/workbench/toolwindows/RightToolWindow.tsx`)**:
   - Inspector container ready for detail previews.

5. **WorkbenchLayout Assembly (`src/workbench/WorkbenchLayout.tsx`)**:
   - Connected `LeftToolWindow`, `EditorArea`, `BottomToolWindow`, and `RightToolWindow` to the resizable splitter panels.
