# TASKMATE: INTELLIJ EXPUI (LIGHT THEME) WORKBENCH MIGRATION SPEC

## 1. Mục tiêu (Objective)
- Chuyển đổi giao diện TaskMate sang phong cách **IntelliJ IDEA (ExpUI Islands Light)** tương tự kiến trúc [OpenIDEA](https://github.com/l0ng-ai/openidea).
- Đạt độ mượt mà cao (60fps, low latency, fast docking/switching).
- Giữ nguyên 100% logic nghiệp vụ, Dexie DB, các services và views hiện có của TaskMate.
- Thực hiện trên branch riêng (`feature/intellij-workbench`) theo mô hình **Isolated Shell** để cho phép branch `staging` tiếp tục phát triển song song không gây conflict.

---

## 2. Nguyên tắc triển khai cách ly (Isolation Architecture)

1. **Không sửa ruột business logic**:
   - Không can thiệp `src/db/*`, `src/services/*`, `src/domain/*`.
   - Các views hiện tại (`src/views/*`) giữ vai trò "Plug-in Components" cắm vào các slot của Workbench.
2. **Khu vực code mới**:
   - Toàn bộ shell mới đặt tại `src/workbench/` và `src/styles/workbench-tokens.css`.
   - Tạo file entry riêng: `src/AppIntelliJ.tsx` (chưa ghi đè trực tiếp `src/App.tsx`).
3. **Thư viện giao diện bổ sung**:
   - `react-resizable-panels`: Quản lý panel dock trái/phải/dưới và resizing.
   - `zustand`: Quản lý layout state (active tool windows, slots, collapsed states, panel sizes).
   - `@tanstack/react-virtual`: Ảo hóa danh sách task/logs dài khi render trong panel.

## 3. Cấu trúc Layout IntelliJ Workbench (Islands Style)

```
+-------------------------------------------------------------------------------+
| TITLE BAR (App Logo, Project Switcher, Action Search, Timer Widget, Min/Max/X)|
+----+--------------------------------------------------------------------+----+
| L  | [Tool Window Island: Left]   | [Center Editor Area]                | R  |
| E  | - Projects Tree              | - Tab Bar (Tasks, Timeline, Docs)   | I  |
| F  | - Milestones Outline         | - Active Tab Content View           | G  |
| T  |                              |                                     | H  |
|    |                              +-------------------------------------+ T  |
| S  |                              | [Tool Window Island: Bottom]        |    |
| T  |                              | - AI Chat / Knowledge Search / Logs | S  |
| R  |                              |                                     | T  |
| I  |                              |                                     | R  |
| P  |                              |                                     | I  |
| E  |                              |                                     | P  |
+----+------------------------------+-------------------------------------+----+
| STATUS BAR (Active Task Info, Sync Status, Storage Size, Memory, Notifications)|
+-------------------------------------------------------------------------------+
```

### Thành phần chi tiết:
- **TitleBar (`src/workbench/TitleBar.tsx`)**:
  - Tích hợp Window Drag (Tauri window controls).
  - Quick Project Switcher dropdown.
  - Search Everywhere bar (`Double Shift` / `Ctrl+K`).
  - Mini Task Timer widget (Start/Pause, tên task đang chạy, elapsed time).
- **Tool Window Stripes (`src/workbench/toolwindows/Stripe.tsx`)**:
  - Thanh icon hẹp 32px ở viền trái, phải, đáy.
  - Icon monochrome 16x16.
  - Bấm toggle mở/đóng panel, có badge đếm số lượng (ví dụ: số task quá hạn, số unread chat).
  - Phím tắt: `Alt+1` (Project Tree), `Alt+2` (Tasks List), `Alt+3` (AI Chat), `Alt+4` (Docs/Notes), `Alt+5` (Calendar).
- **Docking Slots / Islands (`src/workbench/toolwindows/ToolWindows.tsx`)**:
  - Hỗ trợ các slot: `left`, `right`, `bottom`.
  - Hỗ trợ resize mượt mà và remember kích thước vào `localStorage`.
- **Editor Area (`src/workbench/EditorArea.tsx`)**:
  - Thanh tab trên cùng với nút đóng tab, reorder tab, tab overflow.
  - Hiển thị view chính được chọn.
- **StatusBar (`src/workbench/StatusBar.tsx`)**:
  - Cao 24px ở đáy.
  - Hiển thị task hiện tại, dung lượng IndexedDB, trạng thái kết nối daemon/sync, phím tắt gợi ý.

## 5. Các hành vi cốt lõi từ OpenIDEA cần tích hợp (Behaviors)

### 1. Search Everywhere Popup (Double Shift / Ctrl+K)
- Popup modal gọn nhẹ, không viền nặng, nổi chính giữa màn hình.
- Các tab filter: All | Tasks | Projects | Docs | Actions.
- Cho phép gõ tìm kiếm theo BM25/fuzzy và thực hiện ngay action:
  - `> New Task`: Mở drawer tạo task.
  - `> Start Timer`: Kích hoạt timer cho task gần nhất.
  - `> Export Backup`: Chạy tiến trình backup.
  - Gõ tên task/doc để nhảy thẳng đến tab làm việc.

### 2. Centralized Action & Keymap Registry (`src/workbench/actions/`)
- Mọi thao tác đều có actionId cố định (ví dụ: `task.create`, `timer.toggle`, `view.toggle-chat`, `window.split-right`).
- Phím tắt tập trung, cho phép điều khiển app 100% bằng bàn phím.

## 6. Kế hoạch triển khai (Roadmap theo Wave)

- **Wave 1: Khung Workbench & Light Theme**
  - Cài đặt `react-resizable-panels`, tạo thư mục `src/workbench/`.
  - Dựng `tokens.css`, `TitleBar`, Left/Right/Bottom Stripes, `StatusBar`.
  - Quản lý trạng thái mở/đóng các panel qua `src/workbench/store/layoutStore.ts` (Zustand).
- **Wave 2: Tích hợp Views hiện có vào các Slots**
  - Slot Left: Nhúng Project Tree / Milestones list.
  - Slot Center: Tabbed Editor Area gắn các view Tasks, Docs, Capacity Planner.
  - Slot Bottom: Gắn AI Chat và System Logs.
  - Bọc các views bằng `AntdThemeAdapter` để áp dụng compact light styling.
- **Wave 3: Search Everywhere & Keymaps**
  - Xây dựng modal Search Everywhere với phím tắt Double Shift hoặc Ctrl+K.
  - Đăng ký các action handlers phổ biến.
- **Wave 4: Tối ưu hiệu năng & Switchover**
  - Ảo hóa danh sách tasks bằng `@tanstack/react-virtual`.
  - Kiểm tra memory leak, render rate (đạt target 60fps).
  - Hoàn thiện test và chuẩn bị PR hợp nhất vào staging.
