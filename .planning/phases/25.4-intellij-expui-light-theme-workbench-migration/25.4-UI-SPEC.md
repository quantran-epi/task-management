# Phase 25.4 — UI Design Contract: IntelliJ ExpUI (Islands Light) Workbench

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (pure CSS custom properties + Ant Design ConfigProvider compact light adapter) |
| Preset | not applicable |
| Component library | none (Ant Design 6.6.5 wrapped in `AntdThemeAdapter`, `react-resizable-panels` 2.1.9) |
| Icon library | `@ant-design/icons` (monochrome 16x16 with tooltips / aria-labels) |
| Font | `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Inter Variable", sans-serif` |

---

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Tool window stripe icon gaps, badge padding, compact table cell padding |
| sm | 8px | TitleBar inline element gaps, button horizontal padding, tab close button margin |
| md | 16px | Tool window island content margins, Search Everywhere popup padding |
| lg | 24px | Major workbench section padding, editor container margins |
| xl | 32px | Tool window stripe width, tabbar height baseline |
| 2xl | 48px | Empty state vertical spacing, wide-screen view headers |
| 3xl | 64px | Maximum page-level breaks, drawer max inset offsets |

Exceptions:
- `34px`: TitleBar height (`--titlebar-height`) — desktop Tauri window drag region and window control button alignment.
- `24px`: StatusBar height (`--statusbar-height`) — compact IDE status footer bar.
- `26px`: Ant Design compact control height (`controlHeight: 26` for Button, Input, Select).
- `3px`: Compact border radius (`borderRadius: 3`) — matching IntelliJ IDEA ExpUI subtle corner rounding.

---

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#ffffff` | Workbench main window background, editor canvas surface, input fields, popup backgrounds |
| Secondary (30%) | `#f7f8f9` | TitleBar surface, tool window stripes, left/bottom tool window island backgrounds, status bar |
| Accent (10%) | `#3871e1` | JetBrains Blue — reserved for specific elements below |
| Destructive | `#c54e58` | Danger badges, close confirmation buttons, reset workbench layout confirmation |

### Status Colors
- Warning: `#a56906`
- Success: `#338555`
- Info: `#3871e1`
- Selection highlight: `#d0dffe` (tree item and menu active background)
- Splitter & Border: `#e9eaee` (standard border), `#d1d3d9` (active splitter / window border)

### Accent Reserved For (Specific Elements Only)
Accent `#3871e1` is strictly reserved for:
1. Active tool window stripe 2px indicator bar (selected tool icon)
2. Active editor tab bottom highlight line (2px underline)
3. Search Everywhere modal active keyboard navigation row cursor
4. Primary dialog CTA button ("Create Task", "Dock Window")
5. Keyboard focus rings on input controls (`:focus-visible`)

---

## Visual Hierarchy & Focal Points

- **Primary Visual Anchor:** Center Editor Area tabbed canvas hosting the active view (`TasksView`, `NotesView`, or `PlannerView`).
- **Secondary Anchors:** 
  1. Top TitleBar (Search Everywhere bar centered with keyboard shortcut hint `Double Shift`).
  2. Left Tool Window Island (Projects Tree and Milestones outline).
  3. Bottom Tool Window Island (AI Chat / System Logs drawer).
- **Accessibility Fallbacks:** All monochrome 16x16 icon buttons in tool window stripes and TitleBar declare mandatory `title` tooltips and `aria-label` attributes (`Alt+1: Projects`, `Alt+2: Tasks`, `Alt+3: AI Chat`, `Alt+4: Docs`, `Alt+5: Calendar`, `Minimize Window`, `Maximize Window`, `Close Window`).

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | "Open Search" (or "Create Task" when in task view) |
| Secondary CTA | "Reset Layout" |
| Empty state heading | "No Tool Window Open" |
| Empty state body | "Press Double Shift to search everywhere, or press Alt+1 through Alt+5 to open tool windows from the stripe." |
| Error state | "Unable to load workbench view: Reset workbench docking layout or reload the window." |
| Destructive confirmation | "Reset Workbench Layout: Are you sure you want to restore default docking slots? Custom panel widths and heights will be reset." |
