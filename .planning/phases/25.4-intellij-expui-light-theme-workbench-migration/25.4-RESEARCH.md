# Phase 25.4: IntelliJ ExpUI (Light Theme) Workbench Migration - Research

**Researched:** 2026-11-04
**Domain:** IntelliJ IDEA ExpUI (Islands Light) Workbench Architecture, Docking Layouts, Isolated Shell Wiring
**Confidence:** HIGH

## Summary

Phase 25.4 transitions the TaskMate UI into an IntelliJ IDEA (ExpUI Islands Light) desktop workbench layout inspired by OpenIDEA. The architecture follows a strict **Isolated Shell** model on branch `feature/intellij-workbench`: zero edits to `src/db/*`, `src/services/*`, or `src/domain/*`. Existing views (`TasksView`, `ProjectsView`, `NotesView`, `PlannerView`, `AnalyticsView`, `SettingsView`, `DashboardView`) are preserved as plug-in components mounted into workbench slots.

The new shell is isolated in `src/workbench/` and `src/styles/workbench-tokens.css`, booted via `src/AppIntelliJ.tsx`. Entrypoint switching in `src/main.tsx` dynamically detects `?ui=intellij` query param or `localStorage.getItem('taskmate_ui') === 'intellij'`, keeping `src/App.tsx` untouched and preventing merge conflicts with parallel branch work.

The standard stack additions are `react-resizable-panels` (docking and splitter management), `zustand` (layout state and persistent window configuration), and `@tanstack/react-virtual` (60fps virtualization for long lists and logs). All three libraries have verified compatibility with React 19.3.0 and Vite 8.3.1.

**Primary recommendation:** Use `react-resizable-panels@^2.1.7` with `zustand@^5.0.0` for panel docking/persistence; wrap views with `AntdThemeAdapter` (compact light theme token overrides); implement `src/workbench/actions/actionRegistry.ts` for centralized keyboard shortcuts (`Double Shift`, `Ctrl+K`, `Alt+1`..`Alt+5`).

### Pattern 1: Isolated Shell Dual-Boot in `main.tsx`
**What:** Allows launching `AppIntelliJ` alongside `App` without editing `App.tsx`.
**When to use:** During branch development and previewing.
```tsx
// src/main.tsx
import React from 'react';
import ReactDOM from 'react-dom/client';
import App from './App';
import { AppIntelliJ } from './AppIntelliJ';
import './styles/markdown.css';
import './styles/workbench-tokens.css';

const searchParams = new URLSearchParams(window.location.search);
const useIntelliJ = 
  searchParams.get('ui') === 'intellij' || 
  localStorage.getItem('taskmate_ui_shell') === 'intellij';

ReactDOM.createRoot(document.getElementById('root') as HTMLElement).render(
  <React.StrictMode>
    {useIntelliJ ? <AppIntelliJ /> : <App />}
  </React.StrictMode>
);
```

### Pattern 2: Resizable Layout with Persistent State
**What:** Manage left, center, right, and bottom tool window panels using `react-resizable-panels` synced with Zustand.
```tsx
import React, { useRef } from 'react';
import { PanelGroup, Panel, PanelResizeHandle, type ImperativePanelHandle } from 'react-resizable-panels';
import { useLayoutStore } from './store/layoutStore';

export const WorkbenchLayout: React.FC = () => {
  const { leftOpen, bottomOpen, rightOpen } = useLayoutStore();
  const leftPanelRef = useRef<ImperativePanelHandle>(null);

  return (
    <PanelGroup autoSaveId="taskmate-workbench-h" direction="horizontal" className="workbench-body">
      {leftOpen && (
        <>
          <Panel ref={leftPanelRef} defaultSize={20} minSize={12} maxSize={35} className="workbench-island">
            <LeftToolWindow />
          </Panel>
          <PanelResizeHandle className="workbench-splitter-v" />
        </>
      )}
      <Panel className="workbench-center">
        <PanelGroup autoSaveId="taskmate-workbench-v" direction="vertical">
          <Panel defaultSize={75} minSize={30}>
            <EditorArea />
          </Panel>
          {bottomOpen && (
            <>
              <PanelResizeHandle className="workbench-splitter-h" />
              <Panel defaultSize={25} minSize={15} maxSize={60} className="workbench-island">
                <BottomToolWindow />
              </Panel>
            </>
          )}
        </PanelGroup>
      </Panel>
      {rightOpen && (
        <>
          <PanelResizeHandle className="workbench-splitter-v" />
          <Panel defaultSize={25} minSize={15} maxSize={40} className="workbench-island">
            <RightToolWindow />
          </Panel>
        </>
      )}
    </PanelGroup>
  );
};
```

### Pattern 3: High-Reliability Double Shift Detection
**What:** Detect standalone Double Shift keystrokes without false positives while typing text.
```tsx
// src/workbench/hooks/useDoubleShift.ts
import { useEffect, useRef } from 'react';

export function useDoubleShift(onDoubleShift: () => void) {
  const lastShiftRef = useRef<number>(0);
  const otherKeyPressedRef = useRef<boolean>(false);

  useEffect(() => {
    const handleKeyDown = (e: KeyboardEvent) => {
      if (e.key !== 'Shift') {
        otherKeyPressedRef.current = true;
      }
    };

    const handleKeyUp = (e: KeyboardEvent) => {
      if (e.key === 'Shift') {
        if (!otherKeyPressedRef.current) {
          const now = performance.now();
          if (now - lastShiftRef.current < 350) {
            onDoubleShift();
            lastShiftRef.current = 0;
          } else {
            lastShiftRef.current = now;
          }
        }
        otherKeyPressedRef.current = false;
      } else {
        otherKeyPressedRef.current = false;
        lastShiftRef.current = 0;
      }
    };

    window.addEventListener('keydown', handleKeyDown);
    window.addEventListener('keyup', handleKeyUp);
    return () => {
      window.removeEventListener('keydown', handleKeyDown);
      window.removeEventListener('keyup', handleKeyUp);
    };
  }, [onDoubleShift]);
}
```

### Anti-Patterns to Avoid
- **Mutating Existing Views:** Do not modify `TasksView.tsx`, `NotesView.tsx`, or `ProjectsView.tsx` to accommodate the workbench shell. Wrap them in `AntdThemeAdapter` inside `EditorArea.tsx` and pass needed `onNavigate` callbacks.
- **Direct Database Mutations in Workbench UI:** Do not bypass existing repositories in `src/db/repositories/*`.
- **Hardcoded RGB Colors in Components:** All styling in `src/workbench/` must reference CSS variables from `workbench-tokens.css` (e.g., `var(--bg-elev)`, `var(--border)`, `var(--accent)`).
- **Polling for Window State:** Use Zustand reactive selectors and `useLiveQuery` from `dexie-react-hooks`.

## Common Pitfalls

### Pitfall 1: Double Shift Triggering During Typing
**What goes wrong:** User types a capital letter or holds Shift while typing, and the Search Everywhere modal pops up unexpectedly.
**Why it happens:** Simply checking `e.key === 'Shift'` on `keyup` triggers if user releases Shift after typing uppercase characters (`Shift+A`).
**How to avoid:** Track `keydown` events. If any non-Shift key is pressed between Shift down and Shift up, flag `otherKeyPressed = true` and disregard the interval check. Only clean, standalone Shift presses count.
**Warning signs:** Search Everywhere opening randomly when typing fast.

### Pitfall 2: `react-resizable-panels` API Version Differences
**What goes wrong:** Build fails with `Export 'PanelGroup' was not found in 'react-resizable-panels'`.
**Why it happens:** v4 renamed components (`PanelGroup` -> `Group`, `PanelResizeHandle` -> `Separator`).
**How to avoid:** Pin `react-resizable-panels@^2.1.7` (or `2.1.9`) in `package.json` to keep the canonical `PanelGroup`, `Panel`, `PanelResizeHandle` API.

### Pitfall 3: Tauri Drag Region Intercepting Button Clicks
**What goes wrong:** Buttons or input fields inside `TitleBar` cannot be clicked or focused on desktop.
**Why it happens:** `data-tauri-drag-region` on a parent container intercepts all mouse events unless children explicitly opt out.
**How to avoid:** Put `data-tauri-drag-region` only on empty spacer divs, or add `data-tauri-drag-region="false"` (or `style={{ WebkitAppRegion: 'no-drag' }}`) on interactive child elements (buttons, inputs, dropdowns).

### Pitfall 4: Sub-pixel Jitter and Layout Thrashing in Resizing Panels
**What goes wrong:** Views embedded in resizable panels re-render 60 times a second during dragging, dropping framerate below 30fps.
**Why it happens:** Parent resizing triggers layout recalculations on deeply nested Ant Design tables.
**How to avoid:** Use CSS `overflow: hidden; contain: layout style;` on panel containers. Do not re-fetch or recalculate complex data on active resize; let flexbox handle DOM geometry.
