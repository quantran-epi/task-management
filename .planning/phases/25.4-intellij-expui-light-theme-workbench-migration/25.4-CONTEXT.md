# Phase 25.4: IntelliJ ExpUI (Light Theme) Workbench Migration - Context

**Gathered:** 2026-11-04
**Status:** Ready for planning
**Source:** PRD Express Path (25.4-SPEC.md)

<domain>
## Phase Boundary

Chuyển đổi giao diện TaskMate sang phong cách IntelliJ IDEA (ExpUI Islands Light) tương tự kiến trúc OpenIDEA.
Đạt độ mượt mà cao (60fps, low latency, fast docking/switching).
Giữ nguyên 100% logic nghiệp vụ, Dexie DB, các services và views hiện có của TaskMate.
Thực hiện trên branch riêng (`feature/intellij-workbench`) theo mô hình Isolated Shell.
</domain>

<decisions>
## Implementation Decisions

### 1. Isolated Shell Architecture
- Không sửa ruột business logic: không can thiệp `src/db/*`, `src/services/*`, `src/domain/*`.
- Các views hiện tại (`src/views/*`) giữ vai trò "Plug-in Components" cắm vào các slot của Workbench.
- Toàn bộ shell mới đặt tại `src/workbench/` và `src/styles/workbench-tokens.css`.
- Entry riêng: `src/AppIntelliJ.tsx` (chưa ghi đè trực tiếp `src/App.tsx`).

### 2. Dependencies
- `react-resizable-panels`: Quản lý panel dock trái/phải/dưới và resizing.
- `zustand`: Quản lý layout state (active tool windows, slots, collapsed states, panel sizes).
- `@tanstack/react-virtual`: Ảo hóa danh sách task/logs dài khi render trong panel.

### 3. Layout & Components
- **TitleBar (`src/workbench/TitleBar.tsx`)**: Tauri window drag/controls, Quick Project Switcher dropdown, Search Everywhere bar (`Double Shift` / `Ctrl+K`), Mini Task Timer widget.
- **Tool Window Stripes (`src/workbench/toolwindows/Stripe.tsx`)**: Thanh icon hẹp 32px viền trái, phải, đáy; monochrome 16x16 icon; badge count; phím tắt `Alt+1`..`Alt+5`.
- **Docking Slots / Islands (`src/workbench/toolwindows/ToolWindows.tsx`)**: Hỗ trợ slots `left`, `right`, `bottom`; resize mượt mà và lưu kích thước vào `localStorage`.
- **Editor Area (`src/workbench/EditorArea.tsx`)**: Thanh tab trên cùng với close, reorder, tab overflow; hiển thị view chính được chọn.
- **StatusBar (`src/workbench/StatusBar.tsx`)**: Cao 24px ở đáy; hiển thị active task, IndexedDB size, daemon/sync connection status, shortcut hints.
- **Theme Tokens (`src/styles/workbench-tokens.css`)**: Áp dụng `:root[data-theme="light"]` với OpenIDEA Islands Light palette (Surfaces, Borders, Typography, Accent JetBrains Blue `#3871e1`).
- **AntdThemeAdapter (`src/workbench/AntdThemeAdapter.tsx`)**: ConfigProvider compact light token theme (controlHeight 26, fontSize 12.5, borderRadius 3).
- **Search Everywhere (`src/workbench/search/SearchEverywhereModal.tsx`)**: Popup modal nổi giữa màn hình, tabs All | Tasks | Projects | Docs | Actions (`Double Shift` / `Ctrl+K`), quick action dispatch (`> New Task`, `> Start Timer`, `> Export Backup`).
- **Centralized Action & Keymap Registry (`src/workbench/actions/`)**: Mọi thao tác có `actionId` cố định, điều khiển 100% bằng bàn phím.

### 4. Wave Roadmap Structure
- Wave 1: Khung Workbench & Light Theme (`react-resizable-panels`, `src/workbench/`, `tokens.css`, `TitleBar`, `Stripe`, `StatusBar`, `layoutStore.ts` Zustand).
- Wave 2: Tích hợp Views hiện có vào các Slots (`AntdThemeAdapter`, Left slot Project Tree, Center Editor Area, Bottom slot AI Chat & Logs).
- Wave 3: Search Everywhere & Keymaps (`Double Shift` / `Ctrl+K`, action registry).
- Wave 4: Tối ưu hiệu năng & Switchover (`@tanstack/react-virtual`, 60fps target, test & verify `AppIntelliJ.tsx`).

### Claude's Discretion
- Chi tiết cấu trúc thư mục con trong `src/workbench/` (components, store, actions, hooks).
- Cơ chế fallbacks khi chạy trên browser dev so với Tauri desktop (window controls drag).

</decisions>
