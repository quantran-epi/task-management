| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-31.2-42 | Tampering / Elevation | `featureBranch` in git commands | mitigate | Branch values are stored on the CR target and every command argument is routed through `escapeShellArg`; the picker only offers names returned by the remote branch list, so a free-typed arbitrary string is not the default path |
| T-31.2-43 | Tampering | `updateChangeRequest` from the picker | mitigate | The write goes through the CR repo, which re-validates targets (existence, subsystem-ness, uniqueness) |
