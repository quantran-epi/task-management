# Phase 31.2 Plan 14: SystemDetailView 4-Tab Restructure Summary

`SystemDetailView` is now a four-tab view whose tabs, header actions and row actions all diverge by node type, with 1-click Git/Terminal on every subsystem row and all four `Git & Branches` states.

## What Was Built

**Tabs (D-33, ENT-NORM-03)** — antd `Tabs size="small"` with `items` built conditionally:

| Tab | Logical Parent | Subsystem |
|-----|----------------|-----------|
| `Tổng quan` | yes | yes |
| `Subsystems` | yes | hidden |
| `Impacted CRs` | yes (union of children) | yes |
| `Git & Branches` | hidden | yes |

The inline `system.type === 'LOGICAL_GROUP' || system.parentId === null` predicate is gone; `isLogicalParent` / `isSubsystem` from `systemRepo` are the only parent/subsystem test.

**Header actions (D-34)** — parent: `Chỉnh sửa` + `Thêm subsystem`, no `Tạo CR` anywhere. Subsystem: `Chỉnh sửa` + primary `Tạo CR cho hệ thống này` opening `ChangeRequestModal` with `initialTargets=[{ systemId }]`.

**Overview** — `Descriptions size="small" bordered`: type badge, description; for a subsystem SSH `user@host:port` (mono, copyable), repo path (mono, copyable), base branch (blue mono tag), connection status dot + text (`Đã kết nối` / `Chưa cấu hình` / `Lỗi kết nối`).

**Subsystems** — child table plus icon-only Git/Terminal per row wired to the shared `useSystemActions` hook (plan 31.2-06). When `disabledReason(row)` is set both buttons render `disabled` with `aria-label` equal to the tooltip copy. Card extra: `Thêm subsystem`.

**Impacted CRs** — subsystem: `getChangeRequestsBySystem`; parent: union over `getSubsystems` deduped by CR id. Columns: CR code tag in type color, name, type tag, status tag, SDLC progress `x/6`, `Mở SDLC Studio` link. Empty copy differs parent vs subsystem; the `Tạo Change Request` CTA renders only for a subsystem.

**Git & Branches** — loads on tab activation through `gitRemoteService`; all four UI-SPEC states rendered verbatim (loading `Spin` with the tip, error `Alert` + `Thử lại`, unconfigured `Empty` + `Chỉnh sửa subsystem`, populated current-branch tag + branch table with 8-char mono SHAs and full-value tooltips).

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Row-action test timed out at 15s**
- **Found during:** Task 1 verification
- **Issue:** `npx vitest run tests/views/SystemDetailView.test.tsx` failed one test with `Test timed out in 15000ms`. Probes showed a single `queryAllByRole('button')` call taking 9.5s after the Subsystems tab mounted, while `queryAllByLabelText` took 2ms. Bisecting the markup isolated it to antd `Space` inside a `Table` cell inside `Tabs`: `Space`'s mount measurement makes jsdom accessible-name resolution ~1s per button.
- **Fix:** Replaced the `Space size={4}` wrapper around the two row action buttons with a plain `display: flex; gap: 4px` div. No visual or behavioural change; test dropped to 11.5s total, all 8 green.
- **Files modified:** `src/views/SystemDetailView.tsx`
