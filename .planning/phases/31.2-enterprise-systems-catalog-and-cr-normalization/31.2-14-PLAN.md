## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| subsystem config → SSH shell | The Git tab passes `remoteRepoPath` into shell commands |
| remote SSH output → rendered table | Branch/commit strings are remote-controlled data |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-31.2-35 | Tampering / Elevation | `Git & Branches` shell calls | mitigate | Every argument is routed through `escapeShellArg`; `remoteRepoPath` is already absolute-validated in Zod and at the repo layer, so a crafted path cannot break out of the command |
| T-31.2-36 | Cross-site scripting | branch/commit rendering | mitigate | Values render as antd `Table` cell text and `Typography.Text`, never `dangerouslySetInnerHTML`; SHAs are truncated to 8 chars with a tooltip |
| T-31.2-37 | Elevation of privilege | parent header actions | mitigate | The parent header renders no `Tạo CR`, matching the repo's rejection of a parent target |
| T-31.2-SC | Tampering | npm/pip/cargo installs | accept | No package installs in this phase |
</threat_model>
