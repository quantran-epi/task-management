# Phase 31.2 — UI Design Contract: Enterprise Systems Catalog & CR Normalization

> Visual and interaction contract for the CR-centric normalization of TaskMate: CR Explorer, ChangeRequestDetailView, tabbed SystemDetailView, SDLC Studio without repo config, per-subsystem packing, and the AI subsystem-proposal gate. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Sources:** `31.2-CONTEXT.md` (D-24..D-53, locked), `31.2-DISCUSSION-LOG.md`, `REQUIREMENTS.md` ENT-NORM-01..06, `src/styles/workbench-tokens.css`, `src/workbench/AntdThemeAdapter.tsx`, and the current implementations of every surface listed below.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (not shadcn) |
| Preset | not applicable |
| Component library | antd@6.6.5 via `ConfigProvider` (`theme.defaultAlgorithm` + `theme.compactAlgorithm`), wrapped by `src/workbench/AntdThemeAdapter.tsx` |
| Icon library | @ant-design/icons@6.3.4 + custom `src/components/icons/JetBrainsIcons.tsx` for stripe glyphs |
| Token source | `src/styles/workbench-tokens.css` (IntelliJ ExpUI "Islands Light") — all new surfaces consume `var(--*)` tokens or `theme.useToken()`, never raw hex |
| Font (UI) | `var(--font-ui, "Inter", -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif)` |
| Font (code / paths / SSH / branch) | `'JetBrains Mono', 'Fira Code', Menlo, Monaco, Consolas, monospace` |
| Control height | 30px (`controlHeight: 30`), border radius 4px (`borderRadius: 4`) |
| Theme mode | Light only. No dark-mode work in this phase. |

**Hard rule:** any new component in this phase reuses antd primitives (`Tree`, `Table`, `Tabs`, `Card`, `Tag`, `Segmented`, `Modal`, `Alert`, `Empty`, `Tooltip`, `Progress`, `Collapse`, `Descriptions`) plus existing tokens. No new CSS framework, no CSS-in-JS library, no third-party UI package.

## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage in this phase |
|-------|-------|---------------------|
| xs | 4px | Tag inner padding (`0 4px`), icon-to-label gap in tree rows, pill gaps |
| sm | 8px | Card body padding, tree row vertical rhythm, button gaps, `Space size={8}` |
| md | 16px | View padding (`16px 20px`), card-to-card gap, modal content gap |
| lg | 24px | Section separation inside CR Detail, tab pane padding |
| xl | 32px | Empty-state vertical padding, workspace column gaps |
| 2xl | 48px | Empty-state container padding (`48px 16px`), page-level breaks |
| 3xl | 64px | Reserved for full-height view wrappers; not used inside tool windows |

Exceptions (pre-existing workbench chrome — do not change, do not propagate to new spacing):

| Value | Justification |
|-------|---------------|
| 6px | `--island-gap`; also ExpUI tab icon gap (`gap: 6px`) |
| 26px | `--statusbar-height` (fixed chrome) |
| 30px | `--tabbar-height` / antd `controlHeight` (compact control) |
| 36px | `--stripe-width` (left tool window stripe) |
| 40px | `--titlebar-height` (fixed chrome) |
| 2px / 1px | Border widths and 1px dividers only — never used as layout spacing |

Tree row geometry is fixed by `workbench-tokens.css`: row height 28px, switcher width 20px, icon slot 16px, title `line-height: 1.2`. New CR Explorer / Systems Explorer nodes must sit inside that geometry — do not introduce a taller row.

## Typography

Declared exactly 4 sizes and 2 weights:

| Role | Size | Weight | Line Height | Family | Usage |
|------|------|--------|-------------|--------|-------|
| Display | 20px | 600 (semibold) | 1.25 | UI | CR Detail title, System Detail title, SDLC step title |
| Heading | 16px | 600 (semibold) | 1.3 | UI | Card titles ("Subsystems & Repos", "Impacted CRs"), modal titles, empty-state heading |
| Body | 13.5px | 400 (regular) | 1.5 | UI | Tree node titles, table cells, form labels, descriptions, alert body |
| Caption / Code | 12px | 400 (regular) | 1.4 | Code font for codes/paths/branches; UI font for tags and metadata | CR code, subsystem code, `user@host:port`, repo path, branch name, tag text, timestamps, counts |

Rules:
- **No fifth size.** Any inline `fontSize: 9`, `9.5`, `10`, `11` found in a file this phase touches (notably `ProjectExplorer.tsx` tag chips, `SystemsExplorer.tsx` code badges, `SdlcSidebar.tsx` type tags) is normalized to **12px Caption** on the rewritten surface.
- **No third weight.** `fontWeight: 500` in `workbench-tokens.css` (`.workbench-expui-tab.active`) is existing chrome and stays; new markup uses only 400 or 600.
- Tree node titles: Body 13.5px / 400; the CR node title may use 600 to mark it as the primary entity, and nothing else in the tree may.
- Monospace text always 12px / 400 / 1.4. Never bold a code string.
- Truncation: single-line `ellipsis` + antd `Tooltip` for codes, paths, branch names, CR names longer than the column. Never wrap a code string.

## Color

60-30-10 distribution over IntelliJ ExpUI Islands Light:

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#ffffff` (`--bg-app`, `--bg-island`) | Editor area, CR Detail canvas, tab panes, card bodies, modal content |
| Secondary (30%) | `#fafbfc` tool-window surface (`--workbench-island-card-toolwindow`), `#f7f8fa` (`--bg-elev`) elevated/read-only panels, `#e9eaee` (`--border`) dividers, `#d1d3d9` (`--border-strong`) card outlines | Left tool windows (CR Explorer, Systems Explorer), SDLC sidebar, "Subsystems & Repos" panel, table headers |
| Accent (10%) | `#3871e1` (`--accent`) | See reserved-for list below |
| Destructive | `#c54e58` (`--danger`) | Delete CR, delete subsystem, remove-subsystem-from-CR, stop-Pack-All, error icons |

### Accent reserved for (exhaustive)

1. Primary CTA buttons: `Mở SDLC Studio` (CR Detail + CR Explorer context menu), `Tạo Change Request` (Systems Explorer subsystem node, SystemDetailView header), `Thêm vào CR` (SubsystemProposalCard), `Đóng gói tất cả` (Step 4), `Lưu cấu hình` (SystemModal).
2. Selected tree node background (`--bg-selected: #d0dffe`) and the 2px active-tab indicator on editor tabs.
3. Selected `Segmented` option in the Subsystem Context Bar and the focused branch `Select` in Step 3.
4. Focus ring / active border on inputs, selects, and the search field in both explorers.
5. Breadcrumb and inline navigation links.

Accent is **never** used for: CR type identity, subsystem identity, status badges, table row striping, or non-primary icon decoration.

### Semantic colors (data identity, not interaction — do not repurpose)

| Meaning | Value | Where |
|---------|-------|-------|
| CR type `NEW_FEATURE` | `#1677ff` | Type tag + icon (`ThunderboltOutlined`) in CR Explorer, CR Detail header, CR table, SDLC sidebar |
| CR type `ENHANCEMENT` | `#52c41a` | Type tag + icon (`ToolOutlined`) |
| CR type `BUGFIX` | `#faad14` | Type tag + icon (`BugOutlined`) |
| Subsystem identity pill | `#13c2c2` (cyan) | Subsystem pill in CR Explorer, CR Detail header, task-table Subsystem column, `SubsystemsReposPanel` rows, proposal card rows |
| Logical Parent | `#722ed1` (purple) | `FolderOutlined` + code badge in Systems Explorer, Parent rows in System Catalog |
| System type badges | `SERVICE` blue / `SCHEMA` cyan / `UI` green / `WORKER` orange | `SYSTEM_TYPES` tag map, unchanged from `SystemDetailView.tsx` |
| Success / connected | `#52c41a` / antd `success` | Git & Branches "Đã kết nối", Pack success |
| Warning / unconfigured | `#faad14` / antd `warning` | Missing SSH/repo, partial Pack All result |
| Error / failed | `#c54e58` / antd `error` | Git tab load failure, Pack failure |

**Two blues are deliberate and must not be merged:** `#3871e1` = interaction accent; `#1677ff` = NEW_FEATURE data identity. A NEW_FEATURE tag never becomes a button, and a primary button never takes `#1677ff`.

### Explicitly forbidden in this phase

- Any new hex literal. New surfaces reference `var(--accent)`, `var(--danger)`, `var(--border)`, `var(--fg-secondary)`, `var(--bg-elev)`, or `token.*` from `theme.useToken()`.
- Gradients (the `--project-color` gradient belongs to workbench chrome, not to CR/System surfaces).
- Colored backgrounds behind table rows or tree nodes other than `--bg-selected`.

## Component Inventory & Interaction Contract

### 1. CR Explorer — left tool window, Alt+1 (`src/workbench/toolwindows/CRExplorer.tsx`, full rewrite)

**Structure:** `CR node` → `Subsystem pill node` → `Task leaf`. No Milestone tier anywhere.

- **CR node title row:** type icon (`#1677ff` / `#52c41a` / `#faad14`) · CR code tag (12px mono, `color="blue"`, `padding: 0 4px`) · CR name (Body 600, ellipsis) · task count (12px, `--fg-muted`, right-aligned). Status shown as a 12px antd `Tag` with `STATUS_TAG_COLORS` (`Open` default, `Pending` gold, `In Progress` processing, `Done` success, `Cancelled` default).
- **Subsystem pill node:** `BranchesOutlined` cyan icon + subsystem code as a cyan `Tag` (12px mono) + subsystem name (Body 400, ellipsis). One pill node per `cr.targets[]` entry.
- **Task leaf:** `CheckSquareOutlined` muted icon + task name (Body 400, ellipsis). Tasks with `systemId === undefined` appear under a synthetic node labelled `Chung (không gắn)` rendered in `--fg-muted`, non-selectable for Git/Terminal actions.
- **Header strip** (8px padding, bottom border `--border`): search `Input` (`placeholder="Lọc CR, subsystem, tác vụ..."`, `size="small"`, `allowClear`) + primary `Button` `Tạo CR` (`icon={<PlusOutlined />}`, height 24, 12px label).
- **Selection:** single click on a CR node opens the `ChangeRequestDetailView` tab (D-31). Single click on a subsystem pill opens the SDLC Studio tab focused on that subsystem's step context. Single click on a task leaf opens the task insight tab.
- **Context menu — CR node** (`Dropdown trigger={['contextMenu']}`): `Mở CR Detail` (`ExportOutlined`), `Mở SDLC Studio` (`RocketOutlined`, accent icon), `Sửa` (`EditOutlined`), divider, `Xóa` (`DeleteOutlined`, `danger: true`).
- **Context menu — Subsystem node:** `Mở Git Explorer` (`CloudServerOutlined`), `Mở SSH Terminal` (`CodeOutlined`), `Mở SDLC tại subsystem này` (`RocketOutlined`), divider, `Gỡ khỏi CR` (`DisconnectOutlined`, `danger: true`).
- **Empty state:** `Empty` with `InboxOutlined` (28px, `--fg-muted`), heading `Chưa có Change Request nào`, body `Tạo CR đầu tiên để bắt đầu vòng đời SDLC.`, CTA `Tạo Change Request`.
- **Empty CR (no tasks):** CR node still renders; its only child is a non-interactive muted row `Chưa có tác vụ` (12px, italic-free, `--fg-subtle`).
- **Empty CR (no targets):** CR node renders with no pill children and a muted row `Chưa gắn subsystem`.
- **Left stripe id:** `cr_explorer` (renamed from `projects`, D-51). Label `CR Explorer`, shortcut `Alt+1`, icon `JetBrainsProjectIcon`. Persist key bumped so a stale `leftActiveId: 'projects'` cannot resolve.

### 2. Systems Explorer — left tool window, Alt+6 (`SystemsExplorer.tsx`, extend)

**Structure:** `Logical Parent` → `Subsystem`. Unchanged tree geometry; action sets diverge by node type (D-30).

- **Parent node:** `FolderOutlined` `#722ed1`, name Body 600, code badge 12px mono on `#f9f0ff` / `#722ed1` / border `#d3adf7`. Context menu: `Xem chi tiết`, `Thêm subsystem`, `Sửa`, divider, `Xóa`. **No `Tạo CR` entry, ever.**
- **Subsystem node:** `BranchesOutlined` `#13c2c2`, name Body 400, code badge 12px mono on `#e6fffb` / `#08979c` / border `#87e8de`. Context menu: `Xem chi tiết`, `Tạo CR` (`RocketOutlined`, accent), `Mở Git` (`CloudServerOutlined`), `Mở Terminal` (`CodeOutlined`), `Sửa`, divider, `Xóa`.
- **`Tạo CR` from a subsystem** opens `ChangeRequestModal` with `targets = [{ systemId, featureBranch: 'feature/{cr.code}' }]` pre-filled; the subsystem field is soft-locked (removable, but pre-selected and visually marked as preselected).
- **`Mở Git` / `Mở Terminal`** are disabled (`disabled` + `Tooltip`) when the subsystem lacks `sshConfigId` or `remoteRepoPath`; tooltip copy is exactly `Chưa cấu hình SSH/Repo — mở System Catalog`, and clicking the tooltip body opens the subsystem edit modal (D-35).
- **Empty state:** unchanged copy `Chưa có hệ thống nào` + CTA `Tạo hệ thống`.

### 3. ChangeRequestDetailView — NEW editor tab (`src/views/ChangeRequestDetailView.tsx`)

Single screen, no sub-tabs (D-32). Vertical stack with 16px gaps, `padding: 16px 20px`, `maxWidth: 1400`.

**3a. Header block** — `#ffffff`, 1px `--border`, radius 8, `padding: 16px 20px`:
- Left: CR code (12px mono `Tag color="blue"`), CR name (Display 20/600), type tag (`#1677ff`/`#52c41a`/`#faad14` + icon + Vietnamese label `Tạo mới` / `Nâng cấp` / `Sửa lỗi`), status tag.
- Below: target subsystem pills — cyan `Tag` with `BranchesOutlined`, 12px mono code, `Tooltip` = `{name} ({type})`. If no targets: muted text `Chưa gắn subsystem` + inline link `Chọn subsystem`.
- Right: primary `Button` `Mở SDLC Studio` (`RocketOutlined`), default `Button` `Sửa`, default `Button` `Xóa` (`danger`).

**3b. SDLC progress strip** — 6 compact steps (`Nạp yêu cầu`, `Giải pháp`, `Coding`, `Change Pack`, `Tài liệu`, `CAB`), 24px tall, connected by 1px `--border` lines. Completed step: `CheckCircleFilled` `#52c41a`. Current step: accent-filled dot + 600 label. Future step: `--fg-faint` dot + 400 label. Clicking any step opens the SDLC Studio tab at that step. Hover raises a `Tooltip` with the step's full title.

**3c. Flat task table** — antd `Table`, `size="small"`, `pagination={false}` (CR-scoped, expected < 50 rows), columns exactly:

| Column | Width | Render |
|--------|-------|--------|
| `Task` | flex | name (Body 400) + status dot |
| `CR` | 120 | CR code tag — present so the table stays consistent with the global Tasks table; same value on every row, still rendered |
| `Subsystem` | 160 | **editable** cyan tag `Select`. Options = subsystems in `cr.targets` + `Chung (không gắn)`. Changing it writes `task.systemId`; clearing writes `undefined`. Never offers a subsystem outside `cr.targets`. |
| `Status` | 110 | antd status tag |
| `Ước lượng` | 100 | hours formatted `Xh Ym` |
| `Hạn` | 110 | `YYYY-MM-DD`, overdue in `--danger` |

Row actions: inline edit (opens `TaskDrawer`), delete (`danger` icon, `Popconfirm`). Header row action: `Thêm tác vụ` (default button, `PlusOutlined`).

**3d. Collapsible secondary blocks** — antd `Collapse` `size="small"`, all collapsed by default, `ghost` variant: `Jira Epic`, `Tài liệu liên kết`, `Nhắc nhở`. Each header shows a count badge when non-empty. Empty block body: muted 12px `Chưa có`.

### 4. SystemDetailView — 4 tabs (`src/views/SystemDetailView.tsx`, convert to `Tabs`)

Header stays (breadcrumb + identity block). Below it, antd `Tabs` with `size="small"`, `items` filtered by node type:

| Tab | Logical Parent | Subsystem | Content |
|-----|----------------|-----------|---------|
| `Tổng quan` | ✅ | ✅ | `Descriptions` `size="small"` `bordered`: type badge, description. Subsystem adds SSH host (`{username}@{host}:{port}` mono, copyable), repo path (mono, `copyable`), base branch (blue mono tag), connection status. |
| `Subsystems` | ✅ | ❌ hidden | `Table` of child subsystems: name (link), code (cyan mono tag), type badge, repo path (mono), 1-click `Git` + `Terminal` icon buttons, `Thêm subsystem` button in the card extra. |
| `Impacted CRs` | ✅ (union of children) | ✅ | `Table`: CR code tag (type color), name, type tag, status tag, SDLC progress (`x/6`), row action `Mở SDLC Studio` (link). |
| `Git & Branches` | ❌ hidden | ✅ | Branch list + recent commits over SSH. |

- **Parent header actions:** `Chỉnh sửa`, `Thêm subsystem`. **No `Tạo CR`.**
- **Subsystem header actions:** `Chỉnh sửa`, primary `Tạo CR cho hệ thống này`.
- **`Git & Branches` states:**
  - *loading:* `Spin` centered, `tip="Đang tải nhánh từ máy chủ SSH..."`, branch list skeleton 3 rows.
  - *error:* `Alert type="error" showIcon` message `Không tải được nhánh từ máy chủ SSH`, description `Kiểm tra cấu hình SSH và đường dẫn repo của subsystem, hoặc thử lại.`, action `Button` `Thử lại`.
  - *unconfigured:* `Empty` (`PRESENTED_IMAGE_SIMPLE`) heading `Subsystem chưa cấu hình SSH/Repo`, body `Cấu hình SSH và đường dẫn repo trong System Catalog để xem nhánh và commit.`, CTA `Chỉnh sửa subsystem`.
  - *populated:* current branch tag (blue mono), branch `Table` (`Tên nhánh`, `Commit gần nhất`, `Tác giả`, `Thời gian`), 12px mono SHAs truncated to 8 chars with full-value tooltip.
- **`Impacted CRs` empty:** heading `Chưa có Change Request nào ảnh hưởng hệ thống này`, body `CR sẽ xuất hiện ở đây khi subsystem này được chọn làm target.` CTA `Tạo Change Request` — **only rendered for a Subsystem**; for a Parent the CTA is omitted and the body reads `CR sẽ xuất hiện ở đây khi subsystem con được chọn làm target.`
- **`Subsystems` empty:** heading `Hệ thống này chưa có subsystem con nào`, body `Subsystem là đơn vị deploy gắn đúng một repo remote SSH. Thêm subsystem để bắt đầu cấu hình.`, CTA `Thêm subsystem`.

### 5. SDLC Studio (`ProjectSdlcView.tsx` → `ChangeRequestSdlcView.tsx`)

Three zones (D-36). `RepoConfigView` is removed from the flow entirely; no sidebar entry, no route, no fallback.

**5a. Sidebar** — CR picker (existing `Select`), CR context card, 6-step list, then the read-only **"Subsystems & Repos"** panel. The existing `Cấu hình` / `Chưa liên kết SSH` chip (`data-testid="sidebar-btn-repo-config"`) is **deleted** — it must not be repurposed.

**5b. `SubsystemsReposPanel`** (`src/components/sdlc/SubsystemsReposPanel.tsx`) — read-only (D-37):
- Container `#f7f8fa`, 1px `--border`, radius 4, 8px padding. Section header: `BranchesOutlined` (`--fg-icon`) + `Subsystems & Repos` (Heading 16/600) + count.
- One row per `cr.targets[]`: subsystem code (cyan mono tag) · name (Body 400, ellipsis) · type badge · SSH `user@host:port` (12px mono) or `Chưa cấu hình` in `--warning` · repo path (12px mono, ellipsis + tooltip) · base branch (mono) · connection dot (8px: `#52c41a` connected / `#faad14` unconfigured / `#c54e58` failed).
- Row actions: icon-only `Git` and `Terminal` buttons (30px, `Tooltip`-labelled, disabled + `Chưa cấu hình SSH/Repo — mở System Catalog` when unconfigured).
- Footer link: `Chỉnh sửa trong System Catalog` (`--link`), opens the subsystem edit modal.
- **Zero inputs.** No `Input`, `Select`, `Switch`, or `Form` may appear inside this panel.
- Empty (CR has no targets): muted 12px `CR chưa gắn subsystem nào` + link `Chọn subsystem`.

**5c. `SubsystemContextBar`** (`src/components/sdlc/SubsystemContextBar.tsx`) — shared Step 3/Step 4 state (D-38):
- Rendered above the step content, only when `cr.targets.length >= 2`. For a single-subsystem CR the bar is **not rendered at all** (no empty container, no reserved height).
- Visual: `#f7f8fa` strip, 1px `--border`, radius 4, `padding: 8px 12px`, single row. Left label `Subsystem đang chọn:` (Body 400, `--fg-secondary`). Center: antd `Segmented` `size="small"`, options `{code} ({name})`, selected option uses accent. Right: connection dot + `featureBranch` (mono tag) + icon-only `Git` / `Terminal`.
- Selecting a subsystem updates the single `selectedSystemId` at SDLC-view level: Step 3 reloads that repo's diff/branch, Step 4 scrolls to and highlights that card. Selection persists across step changes within the same CR session.
- If the selected subsystem has no `featureBranch` on its target, the bar shows a warning-colored tag `Chưa chọn nhánh` and Step 3 renders the branch picker; confirming writes `featureBranch` back to the target (D-38b). Never infer a branch from the CR code.

**5d. Step 2 — solution split per subsystem** (D-39): the rendered solution artifact must show one `### [<SYSTEM_CODE>] <tên subsystem>` section per target, each with its own bullet list. Section headers render as Heading 16/600 with the subsystem code in a cyan mono tag. A subsystem the AI says is unaffected renders an explicit muted line `Không có thay đổi ở subsystem này` — never an empty section. Conventions blocks carry a per-subsystem header; existing `ConventionsSummaryCard` stays at the top of Step 2 unchanged in position.

**5e. Step 4 — per-subsystem pack cards + Pack All** (D-40):
- One `Card size="small"` per target subsystem, 2-column grid at ≥1200px, 1-column below.
- Card header: subsystem code (cyan mono tag) + name (Heading 16/600) + status tag: `Chưa đóng gói` (default) / `Đang đóng gói` (processing, with `SyncOutlined spin`) / `Thành công` (success) / `Thất bại` (error) / `Bỏ qua` (default, when stopped).
- Card body: snapshot/diff summary (base, head, file count) + per-card primary `Button` `Đóng gói` + inline result (pack filename, size, drift count) or inline `Alert type="error"` with the failure reason.
- Above the grid: `Đóng gói tất cả ({n})` primary button. While running it becomes `Dừng đóng gói` (`danger`, `StopOutlined`) and a `Progress` bar shows `{done}/{n}`.
- **Pack All runs sequentially.** Each card shows its own progress; a failing card does not block the remaining cards. On completion a summary `Alert` appears: `type="warning"` if any failed, `type="success"` if all passed, `type="info"` if stopped early.
- **Drift matrix stays one shared table** with an added `Subsystem` column (cyan mono tag). It is not split per card.

### 6. `SubsystemProposalCard` (`src/components/sdlc/common/SubsystemProposalCard.tsx`)

Rendered in-chat in Step 2 (and at Step 2 start when the CR has no targets), following the existing Phase 27 approval-gate pattern (D-41..D-43).

- Container: `#ffffff`, 1px `--border`, 3px left border `#faad14`, radius 4. Header: `BulbOutlined` (`#faad14`) + title `Đề xuất subsystem ảnh hưởng` (Heading 16/600); when the CR already has targets the title becomes `Đề xuất bổ sung subsystem` and a subtitle states `CR đã có {n} subsystem — chỉ liệt kê phần còn thiếu.`
- One row per proposed subsystem: `Checkbox` (checked by default) + subsystem code (cyan mono tag) + name + confidence `Tag` (`high` → success `Cao`, `medium` → warning `Trung bình`, `low` → default `Thấp`) + reason text (Body 400, `--fg-secondary`, max 2 lines with tooltip).
- Evidence list inside a `Collapse` `size="small"`, collapsed by default, label `Bằng chứng ({n})`.
- Footer: primary `Button` `Thêm vào CR` (disabled with `Tooltip` `Chọn ít nhất một subsystem` when nothing is ticked) + default `Button` `Bỏ qua`.
- After `Thêm vào CR`: card collapses to a one-line success strip `Đã thêm {n} subsystem vào CR` (`#52c41a` check icon), non-interactive.
- After `Bỏ qua`: card is removed from the thread and must not reappear in the same CR unless the user explicitly re-runs analysis.
- **Never writes `cr.targets` without an explicit click.** No auto-attach, no pre-checked commit, no silent merge.

### 7. Daily-flow surfaces re-axed (D-46, D-47)

- **`TaskTable` columns:** `Task | CR | Subsystem | Status | Ước lượng | Hạn` as the leading group. CR cell = CR code tag (type color) + name tooltip. Subsystem cell = cyan mono tag or `Chung` in `--fg-muted`. Existing secondary columns (priority, work type, owners, timer, progress) remain after these.

## Interaction & State Contracts

### Disabled 1-click Git / Terminal (D-35)

| Condition | Control state | Copy |
|-----------|---------------|------|
| `sshConfigId` present AND `remoteRepoPath` present | enabled | `Tooltip`: `Mở Git Explorer` / `Mở SSH Terminal tại {repoPath}` |

Disabled buttons must remain in the DOM (not hidden) so the missing configuration is discoverable, and must carry `aria-label` equal to the tooltip text.

### Pack All lifecycle

```
[IDLE] ──(Đóng gói tất cả)──► [RUNNING 1..n]
                                  │  per-card: wait → process → success | error
                                  ├──(Dừng đóng gói)──► [STOPPED]  remaining cards = Bỏ qua
                                  └──(all cards settled)──► [DONE]
[STOPPED] / [DONE] ──► summary Alert (success | warning | info) + per-card results persist
```

- Progress bar reflects settled cards only; the in-flight card shows an indeterminate `Spin` in its own header.
- `Dừng đóng gói` sets the button to `loading` with copy `Đang dừng...` until the current card settles; no card is killed mid-write.
- Summary copy enumerates failures by subsystem code — never a bare count.

## Accessibility & Keyboard

- Every icon-only button (Git, Terminal, copy path, delete, stop) has `aria-label` equal to its tooltip text.
- Disabled Git/Terminal buttons use native `disabled` (removed from tab order) but wrap in an element carrying `aria-label` + `aria-describedby` pointing at the tooltip text, so the reason is announced when the control is reached by pointer or by assistive tech.
- Tree nodes: `role="treeitem"`, `aria-selected` on the active node, `aria-expanded` on CR and Parent nodes.
- Tabs: antd `Tabs` default keyboard behavior (Left/Right arrows, Home/End). Tab order follows visual order.
- Focus ring: 2px `--accent` outline offset 1px. Never remove focus outline.
- Color is never the only signal: connection status dot is paired with text (`Đã kết nối` / `Chưa cấu hình` / `Lỗi kết nối`); CR type tag carries both color and icon + label.
- Contrast: body text `#191b1f` on `#ffffff` and `--fg-secondary #5f6269` on `#ffffff` both pass AA. Do not render `--fg-faint #9fa2a8` text below 12px.
- Minimum hit target for icon-only buttons: 24×24 visual, 30px control height (matches `controlHeight: 30`). Desktop-only runtime (Tauri) — no 44px touch-target requirement.
