### Task 2 — drive `tsc --noEmit` to exit 0 (this commit)

377 → 0. Root causes, in the order they collapsed:

1. **`src/workbench/store/layoutStore.ts` (87 errors).** `consumePendingTerminalTarget` read `useLayoutStore.getState()` inside its own initializer, so `useLayoutStore` was circularly inferred as `any` and every consumer callback lost its parameter types. Switching the initializer to zustand's `get()` and annotating the return type as `PendingTerminalTarget | null` removed the TS7022/TS7023 and collapsed all 83 downstream TS7006s. One fix, not 83.
2. **`branchSnapshots` missing (30).** `SdlcWorkflowState.artifacts` gained a required `branchSnapshots` record. Two *source* files iterated or spread that object assuming every value was an artifact ref:
   - `src/components/ai/wizard/revisionView.ts` typed its key maps as `keyof WorkflowArtifacts`, which now includes `branchSnapshots`/`crSummary`. Narrowed to an explicit `SdlcArtifactKey` union of the eight ref slots.
   - `src/services/backup/validateBackup.ts` used `Object.values(workflow.artifacts)` and `'noteId' in artifact`. Replaced with an explicit list of the eight ref slots so `branchSnapshots` is never treated as an artifact.
   - `src/services/wizard/workflowCoordinator.ts` built `artifacts` without the new required key; now carries `existing?.artifacts.branchSnapshots ?? {}`.
3. **`crId` / `parentId` / `status` / `type` / `targets` missing (180).** Fixture conversion across 90 test files, applied from the compiler's own error list so each insertion landed in the literal the compiler named.
4. **Removed-type references.** `Project` fixtures in six `tests/ai/hub*.test.ts` files became `ChangeRequest` fixtures (they are inserted into `db.changeRequests`). `tests/db.test.ts` `targetSystemIds: []` became `targets: []` plus a `code`. `tests/components/settings/SnapshotRollbackCard.test.tsx` and `tests/services/backup/knowledgeBackupRestore.test.ts` dropped `projects`/`milestones` from backup fixtures — the latter's `legacyEnvelope()` is now typed `unknown` because carrying those tables is precisely what the D-49 guard must reject.
5. **`'project'` scope literals.** `ChatScopeType`/`NotificationEntityType` no longer have a `project` member; the affected fixtures use `'cr'`.
6. **Renamed props.** `SdlcSidebar`, `StepChatPanel` and `Step3CodeGuideView` no longer accept `projectId`/`changeRequestId` where the plan's phase renamed them; the call sites were updated to the current prop names.
7. **Dead imports and dead exports.** `ReminderItem`, `PlusOutlined`, `Popconfirm`, `React`, `ApartmentOutlined`, `handleOpenCatalog`, `waitFor`, `message`, `createSystem`, `createChangeRequest`, `fireEvent`, `loadMultiRepoConventions`, `SCHEMA_V15`, `SystemUpdateSchema`, `ChangeRequestUpdateSchema`, `vi` — all deleted. `ProjectStatus`/`MilestoneStatus` in `src/types/models.ts` had no remaining consumer and were removed with the entities they named.
8. **`exactOptionalPropertyTypes` violations (9).** `TargetSystemsSelector` passes a defined fallback for `onChange`; `ChangeRequestSdlcViewMultiSystem` spreads `repoPath` conditionally; `validateBackup` casts the two optional tables to `NonNullable<…>` (the surrounding spread already guards `undefined`).

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] `layoutStore` circular inference blocked 83 call-site errors**
- **Found during:** Task 2
- **Issue:** `consumePendingTerminalTarget` referenced `useLayoutStore.getState()` inside the store's own initializer, so the store type inferred as `any` and every consumer callback parameter became implicitly `any`.
- **Fix:** Used zustand's `get()` and annotated the action's return type.
- **Files modified:** `src/workbench/store/layoutStore.ts`
- **Commit:** this commit

**2. [Rule 1 - Bug] `validateBackup` treated `branchSnapshots` as an artifact ref**
- **Found during:** Task 2
- **Issue:** `Object.values(workflow.artifacts)` + `'noteId' in artifact` assumed every artifact value is an `SdlcArtifactRef`. With `branchSnapshots` now required, the loop would have iterated a `Record<string, BranchSnapshot>` as if it were one artifact.
- **Fix:** Enumerated the eight ref slots explicitly.
- **Files modified:** `src/services/backup/validateBackup.ts`

**3. [Rule 1 - Bug] `revisionView` key maps widened past the artifact slots**
- **Found during:** Task 2
- **Issue:** `keyof WorkflowArtifacts` now includes non-artifact keys, so `previousArtifactContent` could index a `BranchSnapshot` record.
- **Fix:** Explicit `SdlcArtifactKey` union.
- **Files modified:** `src/components/ai/wizard/revisionView.ts`

**4. [Rule 2 - Missing critical behaviour] `tests/db/taskRepo.test.ts` "requires crId" no longer proved anything**
- **Found during:** Task 2 (a mechanical fixture insertion had satisfied the required field, making the test pass vacuously)
- **Fix:** Pass an empty `crId` so the UUID refinement is what rejects — the runtime form of "required".
- **Files modified:** `tests/db/taskRepo.test.ts`
