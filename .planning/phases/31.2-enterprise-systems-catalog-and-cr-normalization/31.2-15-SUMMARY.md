# Phase 31.2 Plan 15: Subsystems & Repos panel and Subsystem Context Bar Summary

Replaced the deleted repo-config surface with a zero-input read-only "Subsystems & Repos" panel, and lifted the subsystem switcher out of Step 3 into a controlled Context Bar whose selection lives at the SDLC view level.

## What Was Built

### Task 1 — `SubsystemsReposPanel` (commit `e6a1b2eb`)

`src/components/sdlc/SubsystemsReposPanel.tsx` renders one observation row per `changeRequest.targets[]`, resolving each system from the passed `systems` list:

- cyan mono code tag, name (400, ellipsis + title), type badge from a local `SYSTEM_TYPE_TAG` map
- SSH `{username}@{host}:{port}` in 12px mono, or `Chưa cấu hình` in warning colour
- repo path (12px mono, ellipsis + tooltip), base branch (mono), feature branch or `Chưa chọn nhánh`
- 8px connection dot: `#52c41a` connected / `#faad14` unconfigured / `#c54e58` failed
- icon-only Git/Terminal from `useSystemActions`, disabled with `aria-label` equal to the tooltip copy `Chưa cấu hình SSH/Repo — mở System Catalog`
- footer link `Chỉnh sửa trong System Catalog` → `onEditSubsystem`; empty state `CR chưa gắn subsystem nào` + `Chọn subsystem` → `onChooseSubsystem`

Zero form controls — `container.querySelectorAll('input,select,textarea').length === 0` is asserted.

### Task 2 — `SubsystemContextBar` + view-level selection (commit `5ed20e95`)

`src/components/sdlc/SubsystemContextBar.tsx` is fully controlled: `{ targets, systems, selectedSystemId, onSelect }`, returns `null` when `targets.length < 2`, holds no `useState`. It renders the UI-SPEC §5c strip with the `Subsystem đang chọn:` label, an antd `Segmented`, the selected target's `featureBranch` mono tag (or the `Chưa chọn nhánh` warning tag), and icon-only Git/Terminal.

`src/views/ChangeRequestSdlcView.tsx` now owns `selectedSystemId`, initialises it to the first target, resets it when the CR changes or the id is no longer a target (T-31.2-40), and forwards `crTargets` / `crTargetSystems` / `selectedSystemId` / `onSelectSystem` into `SdlcWorkspace`, which renders the bar above the step node.

`src/components/sdlc/SdlcSidebar.tsx` renders `SubsystemsReposPanel` below the 6-step list with `SystemModal` (edit) and `ChangeRequestModal` (attach subsystems) handoffs.
