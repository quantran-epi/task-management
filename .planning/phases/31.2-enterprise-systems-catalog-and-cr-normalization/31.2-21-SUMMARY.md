- **Found during:** Task 1 and Task 2 first `vitest list`
- **Issue:** `tests/services/wizard/`, `tests/services/ai/` and `tests/workbench/` are two levels below `src/`, so `../../src/...` failed to resolve and aborted collection.

**2. [Rule 1 - Bug] antd v6 DOM selectors in the first draft did not match the rendered markup**
- **Found during:** Task 2 while proving `TargetSystemsSelector` was RED for the right reason
- **Issue:** `.ant-select-selector` no longer exists in antd v6 (it is `.ant-select-content`), and `aria-disabled` is not set on a `selectable: false` tree node. The first draft failed on a missing element rather than on the classification bug.
- **Fix:** Drive the dropdown through `getByRole('combobox')` and discriminate selectable nodes with `aria-selected` (present only when `selectable !== false`). Verified against a dumped DOM that the current component renders an unparented `SERVICE` as a folder header — the real regression.
- **Files modified:** `tests/components/changeRequests/TargetSystemsSelector.test.tsx`
- **Commit:** `1acf5422`

**3. [Rule 1 - Bug] `ChangeRequestTable` zero-task branch renders `0 tác vụ`, not `0/0 Done`**
- **Found during:** Task 2
- **Issue:** The progress column short-circuits when `total === 0`.
- **Fix:** Assert the actual placeholder string so the test pins real behaviour rather than a guess.
- **Files modified:** `tests/components/changeRequests/ChangeRequestTable.test.tsx`
- **Commit:** `1acf5422`

**4. [Rule 1 - Bug] `crId`/`systemId` fixture rows rejected by the current `Task` type**
- **Found during:** Task 2 typecheck of `CRExplorer.test.tsx`
- **Issue:** `Task.crId`/`systemId` arrive in plan 01, so a literal fixture fails `tsc` today.
