## Test Infrastructure

| Property | Value |

| **Estimated runtime** | ~5–20s per scoped file; serial (`fileParallelism: false`) |

---

## Sampling Rate

- **After every task commit:** Run the single scoped test file for that task (e.g. `npx vitest run tests/db/systemRepo.test.ts`)
- **After every plan wave:** Run the union of that wave's scoped files, passed explicitly
- **Before `/gsd-verify-work`:** Every file listed below, in small batches, plus a manual Tauri smoke test on a real SSH host
- **Never:** `npx vitest run` bare (full suite >1 hour)
- **Max feedback latency:** 30 seconds
