## Interaction Patterns & States

### 1. Settings Tab: Jira Configuration (`JiraConfigCard`)
- **Fields:**
  - Jira Domain (`Input`, placeholder: `my-org.atlassian.net`, suffix `.atlassian.net` optional helper)
  - Jira Email (`Input`, placeholder: `user@example.com`)
  - API Token (`Input.Password`, placeholder: `••••••••••••••••`)
  - CORS Proxy URL (`Input`, optional, placeholder: `https://my-proxy.workers.dev/?url=`)
  - Default Project Key (`Input`, optional, placeholder: `SHB`)
  - Default Issue Type (`Select`, default: `Task`, options: `Task`, `Bug`, `Story`, `Sub-task`)
- **States:**
  - *Chưa cấu hình:* Form rỗng, nút "Kiểm tra kết nối" disable nếu thiếu domain/email/token.
  - *Đang kiểm tra:* Nút loading, disable form.
  - *Thành công:* Alert type `success` hiển thị tên hiển thị và email tài khoản Jira.
  - *Lỗi CORS:* Alert type `warning` hướng dẫn điền URL CORS Proxy.
  - *Lỗi xác thực:* Alert type `error` thông báo token hoặc email không đúng.

### 2. Task Details Section: Jira Integration (`TaskJiraSection`)
- **Vị trí:** Section riêng trong `TaskDrawer`, đặt ngay dưới thông tin tiến độ / mô tả.
- **Trạng thái chưa liên kết (`jiraKey` rỗng):**
  - Khối tạo mới: Nút "Tạo Jira Issue mới" mở `CreateJiraIssueModal`.
  - Khối liên kết thủ công: Input nhập Jira Key (regex `^[A-Z][A-Z0-9]+-[0-9]+$`), nút "Gắn Jira Key".
- **Trạng thái đã liên kết (`jiraKey` có giá trị):**
  - Header: `Tag` màu `processing` (xanh dương `#1677ff`) hiển thị `jiraKey` kèm icon `<LinkOutlined />`. Click mở `https://{domain}.atlassian.net/browse/{jiraKey}` tab mới (`target="_blank" rel="noopener noreferrer"`).
  - Nút "Hủy liên kết" (dạng text nguy hiểm hoặc secondary button với confirmation Popconfirm/Modal).
  - Khối Workflow Transition:
    - Hiển thị Trạng thái Jira hiện tại (`Spin` khi đang fetch).
    - `Select` dropdown danh sách transition lấy từ Jira REST API v3.
    - Nút "Thực hiện chuyển trạng thái" (loading khi đang gọi API).
    - Tự động map trạng thái Jira về trạng thái Task cục bộ (Open, In Progress, In Review, Resolved, Done, Cancelled) theo bảng Smart Status Mapping.

### 3. Modal Tạo Jira Issue (`CreateJiraIssueModal`)
- **Fields:**
  - Project Key (mặc định lấy từ Settings, cho phép sửa)
  - Issue Type (mặc định lấy từ Settings, cho phép chọn)
  - Summary (điền sẵn từ `task.name`, bắt buộc)
  - Description (điền sẵn từ `task.description`, tự động serialize thành Minimal ADF v3)
- **Footer:** Nút "Hủy" và nút primary "Tạo Jira Issue".
- **Hành động sau thành công:** Gắn `jiraKey` vừa tạo vào Task hiện tại, đóng modal, thông báo thành công.

### 4. Hiển thị trên TaskTable & PlannerView
- **TaskTable:** Render Jira Key dưới dạng `Tag` màu `#1677ff` ngay cạnh tên tác vụ. Bấm vào tag gọi `e.stopPropagation()` và mở URL Jira trong tab mới.
- **PlannerView (TaskAllocationCard):** Render micro-badge Jira Key nhỏ (font size 12px theo token Label) để tra cứu nhanh khi xem lịch làm việc.
- **TaskFilterBar:** Bổ sung option lọc "Trạng thái Jira": Tất cả (`all`) / Đã liên kết Jira (`linked`) / Chưa liên kết Jira (`unlinked`).
