<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User Input → Task Model | Manual Jira Key entry in drawer |
| Task Model → Jira API payload | Local task title and description transmitted to Jira Cloud |
| Jira Transitions Response → Task Status | External status categories altering local task state |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-04 | Tampering | `TaskJiraSection.tsx` | mitigate | Enforce strict regex `^[A-Z][A-Z0-9]+-[0-9]+$` on manual key input before saving or constructing URLs to prevent URL injection. |
| T-11-05 | Information Disclosure | `CreateJiraIssueModal.tsx` | mitigate | Sanitize all error responses from Jira issue creation and transition endpoints via `sanitizeErrorMessage` to prevent token leakage. |
| T-11-06 | Denial of Service / State Desync | `TaskJiraSection.tsx` (Status Sync) | mitigate | Status mapping uses safe fallback: if Jira status does not match known rules, local status remains unchanged without throwing errors. |
| T-11-SC | Supply Chain | Build / Dependencies | mitigate | Zero new dependencies; minimal custom ADF converter avoids importing vulnerable or heavy external serializers. |
</threat_model>
