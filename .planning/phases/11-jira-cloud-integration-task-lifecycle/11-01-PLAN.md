<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → Jira Cloud / CORS Proxy | Basic Auth token and user request payload transmitted across network |
| Storage → Memory | Jira API Token persisted in local IndexedDB `db.settings` |
| UI Rendering → Logs | Error messages and exceptions thrown during Jira network operations |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-01 | Information Disclosure | `jiraApi.ts` & `JiraConfigCard.tsx` | mitigate | Sanitize all error messages via `sanitizeErrorMessage` replacing `apiToken` with `[REDACTED]`. Use `Input.Password` to prevent shoulder-surfing. Persist only in origin-isolated IndexedDB `db.settings`. |
| T-11-02 | Tampering | `schemas.ts` & `Task` | mitigate | Validate Jira issue keys strictly with regex `^[A-Z][A-Z0-9]+-[0-9]+$` preventing injection or malformed keys. |
| T-11-03 | Elevation of Privilege / SSRF | `jiraApi.ts` (CORS proxy) | mitigate | Disallow external proxies without explicit user configuration. Restrict default destination to `https://{domain}.atlassian.net`. Validate URL scheme to http/https only. |
| T-11-SC | Supply Chain | Build / Dependencies | mitigate | Zero new npm dependencies introduced. Use native browser `fetch`, `btoa`, and Web Crypto APIs only. |
</threat_model>
