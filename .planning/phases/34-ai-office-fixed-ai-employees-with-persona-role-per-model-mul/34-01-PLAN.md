<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| persisted row → runtime | Data read from IndexedDB is re-hydrated into typed objects; a malformed or legacy row must not be trusted |
| backup payload → restore | A user-supplied backup file crosses into the canonical store |
| renderer → local SQLite mirror | Every domain write is mirrored to disk by an allowlisted table name |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-34-01 | Tampering | `src/db/index.ts` `version(17)` | mitigate | Purely additive `.stores(SCHEMA_V17)` with no `.upgrade()` and no changes to existing store index specs; `tests/db/schemaV17Migration.test.ts` proves V16 rows survive |
| T-34-02 | Information disclosure | `src/types/aiOffice.ts` persisted records | mitigate | No `systemPrompt`/`prompt`/`token`/`secret` field names; `persona` and `body` are the only free-text carriers, so `backupSchemas.ts` `FORBIDDEN_BACKUP_KEYS` cannot be tripped later |
| T-34-03 | Elevation of privilege | `ChatScopeType` widening + `threadScopeParts` | mitigate | `'team'` is a first-class enum member (D-31) **and** a member of the `threadScopeParts` whitelist, so a team thread can never be resolved as the shared `global` thread — neither when created nor when rehydrated from a bare scope key |
| T-34-04 | Tampering | `src/validation/aiOfficeSchemas.ts` | mitigate | Zod schemas at the repo boundary enforce length caps and the two-member role enum before any row is written (ASVS V5) |
| T-34-05 | Information disclosure | `src/services/localSqlitePersistence.ts` + Rust `ALLOWED_TABLES` | accept | The mirror writes the same domain rows to a local file the user already owns; no secret-bearing field exists on any new record |
| T-34-SC | Tampering | npm/pip/cargo installs | mitigate | Zero packages installed this phase; `git diff --stat package.json package-lock.json` must stay empty. No legitimacy checkpoint required because no install task exists |
