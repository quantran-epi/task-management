Create `src/services/ai/office/budgetGate.ts` — no React, no Dexie, no imports beyond types.

`createBudgetGate()` returns `{ close(), open(), isClosed(), wait(signal?) }`. `wait` resolves immediately when open; when closed it returns a promise that stores a single resolver slot and rejects with `new DOMException('Aborted', 'AbortError')` on signal abort (the abort listener must be registered with `{ once: true }` and removed on resolve so a long-lived signal does not accumulate listeners). `open()` clears the slot and resolves. Opening an already-open gate is a no-op.

`bucketOf(used, budget)` returns `Math.floor((used / budget) * 10)` and returns 10 when `budget <= 0` (a zero budget is fully consumed, not a division by zero).

`shouldNotifyPause(previousBucket, currentBucket)` returns `currentBucket >= 8 && previousBucket < 8`. This is the whole D-20 rule with zero stored state: after a top-up the budget grows, the bucket drops below 8, and the next crossing notifies again.

`normalizeUsageTotal(usage)` returns `usage.totalTokens ?? (usage.promptTokens ?? 0) + (usage.completionTokens ?? 0)` — some providers omit `total_tokens`.

Then create `tests/services/ai/office/budgetGate.test.ts` covering the seven behaviors. For the abort case, park on a closed gate, call `controller.abort()`, and assert the rejection's `name` is `'AbortError'` and that `getStatus`-equivalent state is not left pending (assert the promise settles within a short timeout).

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| skill body / note body / transcript row → system prompt | Retrieved text is attacker-influenced data entering an instruction channel |
| budget state → turn execution | A paused scope must not silently continue spending |
| agent runtime → agent runtime | Concurrent turns must not share a controller |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-34-16 | Tampering / Elevation | `teamPrompts.wrapUntrusted` | mitigate | Every retrieved body is wrapped in a delimited block that states it is data, never instructions; the read-only policy and write-authority rules are emitted before any retrieved content so later text cannot redefine them |
| T-34-17 | Denial of service (cost) | `buildEmployeeTurnRequest` | mitigate | Skill body withheld (progressive disclosure), assignment history capped at `ASSIGNMENT_HISTORY_CAP`, recent window capped at `RECENT_WINDOW_TURNS` |
| T-34-18 | Information disclosure | `buildLeadTurnRequest` roster | mitigate | Roster exposes name + role + capability only; employee personas and skill bodies never reach the lead (D-04) |
| T-34-19 | Denial of service | `budgetGate.wait` | mitigate | Abort listener registered `{ once: true }` and removed on resolve; aborting while parked rejects with `AbortError` so a Stop cannot leave a hung turn (Pitfall 8) |
| T-34-20 | Elevation of privilege | `teamRunRegistry` | mitigate | One runtime per agentId means one `AbortController` per agent, so a per-agent Stop cannot abort a sibling and a global Stop reaches all of them (D-14) |
| T-34-SC | Tampering | npm/pip/cargo installs | mitigate | No packages installed; `git diff --stat package.json package-lock.json` must stay empty |
</threat_model>
