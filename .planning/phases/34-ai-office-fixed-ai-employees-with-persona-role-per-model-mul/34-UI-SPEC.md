# Phase 34 — UI Design Contract: AI Office

> Visual and interaction contract for the AI Office: employee/lead/skill management surfaces, the team page, the shared agent-attributed transcript, the assignment-plan card, the token-budget surfaces, and the paused/stopped states. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (no shadcn, no Tailwind — confirmed: no `components.json`, no `tailwind.config.*`) |
| Preset | not applicable |
| Component library | `antd@6.6.5`, consumed through `src/workbench/AntdThemeAdapter.tsx` (`defaultAlgorithm + compactAlgorithm`, `colorPrimary: #5b4fe8`, `fontSize: 13.5`, `borderRadius: 4`, `controlHeight: 30`) |
| Icon library | `@ant-design/icons@6.3.4` (import individually; no icon barrels) |
| Font (UI) | `var(--font-ui, "Inter", -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif)` |
| Font (code / skill body / diff) | `ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas, "Liberation Mono", "Courier New", monospace` |
| Styling rule | Inline `style` objects + `theme.useToken()` values, matching every existing AI component. No new CSS file, no CSS-in-JS library. |

**Hard rule:** every color used in this phase comes from `theme.useToken()` or a `var(--…)` workbench token. No new raw hex literals except where this document names one explicitly.

## Spacing Scale

Declared values (multiples of 4, matching the IntelliJ ExpUI workbench):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gap, tag inner padding, avatar-to-name gap |
| sm | 8px | Button gaps, card internal gaps, list row gaps, `margin: '8px 0 16px'` card stack |
| md | 16px | Card padding, transcript container padding, drawer body padding, grid gap |
| lg | 24px | Section breaks inside drawer, splitter panel padding |
| xl | 32px | Empty-state vertical padding (`32px 16px`), page-level gaps |
| 2xl | 48px | Empty-state block padding (`48px 16px`) in list surfaces |
| 3xl | 64px | Not used in this phase (no full-page marketing layout) |

Exceptions (existing-project conventions, must not be "fixed"):
- `6px` — `--island-gap` workbench token; island gaps and icon micro-gaps. Also the sanctioned value for three avatar/row micro-gaps in this phase: `marginLeft: -6` (roster avatar overlap), `gap: 6` (transcript attribution row), `padding: '6px 0'` (assignment-plan row).
- `10px` — antd `Space` default wrap gap.
- `12px` — chat bubble padding `12px 16px` (existing `ChatMessageBubble`).
- `22px` — icon-only control footprint (`width/height: 22`, matches `ChatTabToolbox` and `ActiveAiTurnIndicator`).
- `28px` — tree/list row height in the workbench left tool window.

Touch/click targets: every icon-only button in this phase is at least `22 × 22` and carries an `aria-label`. Primary buttons keep antd `controlHeight: 30`.

## Typography

Declared 4 sizes, 2 weights (no others permitted in new code):

| Role | Size | Weight | Line Height | Family |
|------|------|--------|-------------|--------|
| Display (page title, team name in workspace header) | 20px | 600 | 1.3 | UI |
| Heading (card title, drawer section title, employee name in list) | 14px | 600 | 1.4 | UI |
| Body (transcript text, form text, descriptions) | 13.5px | 400 | 1.5 | UI |
| Caption (role, model tag, timestamps, budget numbers, help text) | 12px | 400 | 1.4 | UI |

Exceptions:
- `11px` — micro metadata already used by `ChatMessageBubble` (timestamp, `⏱`, `🪙`). Reuse it only for the same class of metadata; never for readable copy. The role text in the §6 attribution row and the §10 `@mention` options is **not** micro metadata — it uses the 12px Caption size.
- `14px / 1.57` — chat bubble body inside `ChatMessageBubble`. Do not change it; agent attribution wraps around the existing bubble, it does not restyle it.
- Skill body textarea and diff/preview panes use the code family at `12px / 1.5`.

Weights: **400 and 600 only**. No 500, no 700. `fontWeight: 500` appears in legacy code — do not copy it into new components.

60-30-10 distribution over the IntelliJ ExpUI Islands Light palette:

| Role | Value | Usage |
|-------|-------|-------|
| Dominant (60%) | `#ffffff` (`token.colorBgContainer`) / `#f7f8fa` (`token.colorBgElevated`, `--bg-elev`) | Editor island surface, drawer body, workspace background |
| Secondary (30%) | `#e9eaee` / `#d1d3d9` borders (`token.colorBorder`, `token.colorBorderSecondary`), `#f7f8fa` fills (`token.colorFillAlter`), `#5f6269` (`token.colorTextSecondary`) | Cards, list rows, toolbar strip, roster panel, budget panel, tool badges |
| Accent (10%) | `#5b4fe8` (`token.colorPrimary`, `--accent`) | See reserved list below |
| Destructive | `token.colorError` (`#c54e58` workbench `--danger`) | Delete employee/lead/skill/team, per-agent Stop icon, global Stop |

Semantic colors (always via antd token, never raw hex):

| Meaning | Token | Where |
|---------|-------|-------|
| Running | `token.colorPrimary` + `<SyncOutlined spin />` | Running agent badge, team "Đang chạy" badge |
| Success / done | `token.colorSuccess` (`#338555`) | Completed agent badge, budget under 80% |
| Warning / paused / 80% budget | `token.colorWarningBg` / `colorWarningBorder` / `colorWarningText` | Paused-agent banner, budget bar at ≥80%, assignment-plan card is **not** warning-colored |
| Error | `token.colorError` | Failed agent badge, validation errors |
| Neutral / stopped | `token.colorTextSecondary` + `colorFillAlter` | "Đã dừng giữa chừng" badge, idle team badge |

Accent reserved for (exhaustive — nothing else may use `colorPrimary` as a fill):
1. Primary button "Tạo nhân viên" / "Tạo lead" / "Tạo kỹ năng" / "Tạo nhóm" (one per surface header).
2. Primary button "Chấp thuận kế hoạch" on the assignment-plan card.
3. Primary button "Cấp thêm token" in the budget top-up modal.
4. Primary button "Kích hoạt nhóm" on an idle team card.
5. Active `Segmented` option (Nhân viên / Lead / Kỹ năng) and the active editor tab indicator (already `--accent`).
6. The 3px left border of the assignment-plan card and the `TeamOutlined` icon in its header.
7. Lead crown icon (`CrownOutlined`) in the transcript name row and on lead cards.

Explicitly **not** accent: employee avatars (see §Avatar), team roster chips, budget progress bar fill (uses success → warning), any transcript bubble background.

### 6. Agent attribution in the transcript (D-07, D-09, D-14)

Extend, do not replace:
- `ChatMessageList` gains optional `agentDirectory?: Map<string, {name, role, isLead, color}>` and passes `agent` into `ChatMessageBubble`.
- `ChatMessageBubble` gains optional `agent?: {name, role, isLead, color}` and optional `onStopAgent?`, `agentStatus?`.
- Render order for an agent message: **attribution row → existing bubble → status/stop row**.
- Attribution row (above the bubble, left-aligned, `marginBottom:4`, `gap:6`): `<Avatar size={24} shape={isLead?'square':'circle'}>` + name (12/600) + role (11 secondary) + lead crown.
- Bubble: unchanged (`maxWidth:'95%'`, `colorFillAlter`, radius `12px 12px 12px 2px`, border `colorBorderSecondary`). Agents never get a colored bubble — identity is carried by the avatar and name, not the surface.
- Status/stop row (below the bubble, `marginTop:4`, `gap:8`):
  | Status | Badge | Stop button |
  |--------|-------|-------------|
  | running | `<Tag color="processing" icon={<SyncOutlined spin/>}>Đang làm việc</Tag>` | yes |
  | paused (budget) | `<Tag color="warning" icon={<PauseCircleOutlined/>}>Tạm dừng — cần cấp thêm token</Tag>` | yes |
  | stopped | `<Tag icon={<StopOutlined/>}>Đã dừng giữa chừng</Tag>` | no |
  | error | `<Tag color="error">Lỗi</Tag>` | no |
  | done | no badge (row collapses to the existing timestamp/token footer) | no |
- Stop button: `Button type="text" size="small" danger icon={<StopOutlined/>}` at `22×22`, `aria-label={`Dừng ${name}`}`, `data-testid={`agent-stop-${agentId}`}`. No confirmation — the transcript is preserved and the partial result is explicitly marked.
- User messages keep the existing right-aligned accent bubble. Lead messages are left-aligned like employees.
- `@mention` rendering: extend `renderUserMessageWithMentions` with an `agent:` target, rendered as a pill using the same `Tag` style as task/doc pills but with the agent's avatar color as background at 100% and white text.
- **Liveness (FLAG 6c):** a streaming agent bubble carries `aria-live="polite"` on its text region so new text is announced without stealing focus; the bubble's status badge is the visual affordance and the `ActiveAiTurn` capsule (§11) **stays visible with its elapsed ticker running** during `WAITING FOR TOKENS` — the paused state is never a silent screen.
- `data-testid`: `agent-attribution-{agentId}`, `agent-status-{agentId}`.

## Interaction & State Contracts

### Employee / lead / skill lifecycle
```
[LIST] ──"Tạo …"──► [DRAWER: create] ──Lưu──► [LIST]
   └────"Sửa"────► [DRAWER: edit] ──Lưu──► [LIST]
   └────"Xóa"────► [Popconfirm] ──Xác nhận──► [LIST]
```
- Save is disabled until required fields are valid; validation messages appear inline under the field (antd `Form.Item` `help`), never as a toast.
- Deleting an entity that is referenced by a team is allowed but the Popconfirm names the consequence (see §Copywriting). No blocked-delete path in this phase.

### Team run lifecycle (UI-visible states)
```
[IDLE] ─Kích hoạt/Mở nhóm─► [READY]
[READY] ─user sends─► [LEAD THINKING]
[LEAD THINKING] ─plan emitted─► [AWAITING PLAN] ─approve─► [BATCH RUNNING]
[AWAITING PLAN] ─reject─► [READY]
[BATCH RUNNING] ─all agents done─► [LEAD SYNTHESIZING] ─► [READY]
[BATCH RUNNING] ─agent hits 80%─► [WAITING FOR TOKENS] ─top-up─► [BATCH RUNNING]
[BATCH RUNNING] ─lead mutation─► [AWAITING MUTATION APPROVAL] ─decision─► [BATCH RUNNING]
[any] ─per-agent stop─► agent bubble = "Đã dừng giữa chừng", run continues
[any] ─global stop─► [READY] with all running agents marked stopped
```
- `WAITING FOR TOKENS` **must** render the paused banner; it must never render a spinner or an empty gap.
- Leaving the tab does not change state (D-22). Returning re-renders from the persisted transcript.

### Budget threshold rule (D-20)
- Bar and numbers turn `token.colorWarning` at `used >= 0.8 * total` for both the team and each agent.
- Crossing 80% again after a top-up re-notifies (banner re-appears); nothing auto-stops.

## Accessibility Contract

- Every icon-only control has `aria-label` in Vietnamese (Stop, remove link, expand).
- **Focus order in the team workspace:** sidebar controls → workspace header actions → transcript region → composer. The transcript region is one focus stop with `tabIndex={0}` and roving focus for per-agent Stop buttons, so a keyboard user reaches them without tabbing through every bubble.
- **Streaming liveness:** an agent bubble streams under `aria-live="polite"`; the paused banner and the assignment-plan decision line use `role="status"`. Nothing announces the whole transcript on each token.
- Status is never color-only: each state carries a text `<Tag>` (running / paused / stopped / error / done).
- The paused banner uses `role="status"` so it is announced; the assignment-plan decision result uses `role="status"`.
- Avatar color is decorative; the name is always adjacent text.
- Focus ring: `outline: 2px solid token.colorPrimary` on keyboard focus for the transcript region and diff-like scroll areas (existing `ArtifactDiffApprovalCard` pattern).
- `@mention` popup keeps antd `Mentions` keyboard behavior; the option label includes the role as text so the lead is distinguishable without color.
