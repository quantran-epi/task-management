<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user composer input → coordinator | `@agent` text decides which runtime is started |
| team settings → budget gate | A budget edit changes when a scope pauses |
| linked item selection → lead context | A link widens what the lead can read |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-34-50 | Elevation of privilege | `TeamWorkspace` composer | mitigate | `@[Name](agent:<id>)` resolves only against the team roster; an unknown id falls back to the lead, so a crafted mention cannot start an agent outside the team |
| T-34-51 | Tampering | `TeamSettingsDrawer` budget table | mitigate | Per-row budgets are written through `aiTeamMembers` single-row updates; the drawer recomputes the remainder onto the lead row so rows always sum to the total |
| T-34-52 | Information disclosure | `LinkedItemPicker` | mitigate | Only the five declared item types are offered, and `get_linked_context` re-checks membership server-side, so a link cannot widen the lead's reach beyond what the user selected |
| T-34-53 | Denial of service (cost) | activate/pause controls | mitigate | Activation is blocked at 3 teams and pause is blocked on the last active team, so the user cannot leave the run surface without a confirmation path |
| T-34-54 | Repudiation | global stop from the workspace | mitigate | `onStop={coordinator.abortAll}` is routed through the same `abortAll` the capsule's confirmed Popconfirm uses, so both paths behave identically |
| T-34-55 | Tampering | `renderViewContent` switch | mitigate | Both cases land in one edit, so the switch is never left referencing an unbuilt module or a stale view |
| T-34-SC | Tampering | npm/pip/cargo installs | mitigate | No packages installed; `git diff --stat package.json package-lock.json` must stay empty |
</threat_model>
