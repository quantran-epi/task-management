## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client → Remote SSH Git CLI | User input (branch names, commit SHAs, file paths) crosses into remote shell commands |
| Remote Files → JSZip Memory | Remote file contents streamed into client RAM for zip compression |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-30-01 | Tampering | `runGitCommand` in `changePackPackager.ts` | high | mitigate | Wrap all remote shell arguments with `escapeShellArg` to prevent command injection |
| T-30-02 | Denial of Service | `createChangePackFromSnapshot` JSZip in-memory generation | medium | mitigate | Check individual entry sizes against `maxEntryBytes` (10MB) and total entries against `maxEntries` (1000) |
| T-30-03 | Information Disclosure | `entryPolicy` file filtering | medium | mitigate | Exclude `.env`, `package-lock.json`, and `node_modules` from zip packaging per D-07 |
| T-30-SC | Tampering | npm packages | high | mitigate | Package Legitimacy Audit verified 100% existing packages (jszip, zod, antd) |
