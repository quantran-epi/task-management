## UI Considerations

Applicable state considerations resolved: 7 covered, 1 backstop, 0 unresolved.

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| empty | Snapshot Card | ✅ covered | Khi chưa có `branchSnapshot`, ẩn nút đóng gói, hiển thị Alert warning với CTA "Quay lại Bước 3: Duyệt nhánh" và tự động mở Collapse Fallback Manual |
| populated | Snapshot Card | ✅ covered | Hiển thị Base Branch, Target Branch, Head Commit SHA rút gọn (8 ký tự), số lượng commit và số lượng tệp thay đổi kèm nút Primary CTA |
| loading | Packaging Progress Stepper | ✅ covered | Hiển thị Ant Design Steps 4 pha: (1) Kiểm tra remote & tạo diff.patch → (2) Thu thập tệp mới & SQL → (3) Nén JSZip in-memory → (4) Đối soát Drift Matrix |
| partial | Remote Drift Warning | ✅ covered | Khi `remoteHeadSha !== snapshot.headSha`, hiển thị Alert warning màu vàng với 2 nút: "Quay lại Bước 3 duyệt lại" hoặc "Tiếp tục với commit đã duyệt" |
| partial | Dirty Working Tree Warning | ✅ covered | Khi remote có uncommitted files, hiển thị Alert info màu vàng với thông báo làm rõ đóng gói dựa trên commit range đã duyệt |
| error | SSH Failure Banner | ✅ covered | Khi SSH timeout hoặc kết nối thất bại, hiển thị Alert error với nút "Thử lại kết nối" và tự động bung mở Accordion "Nạp Change Pack thủ công (.zip)" |
| overflow | MultiPack Table & File Lists | ✅ covered | Bảng MultiPack phân trang 5 bản ghi/trang; danh sách tệp dài trong Drift Matrix hiển thị cuộn tối đa 400px với thanh cuộn chuẩn |
| long-text | Commit Message / File Path | 🧪 backstop | Text quá dài trên 40 ký tự tự động cắt `text-overflow: ellipsis` kết hợp Ant Design `Tooltip` hiển thị toàn bộ nội dung khi hover |
