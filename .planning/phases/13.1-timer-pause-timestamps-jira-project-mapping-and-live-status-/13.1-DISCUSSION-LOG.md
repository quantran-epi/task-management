## Timer Lifecycle

| Decision | Alternatives considered | Selected |
|---|---|---|
| Pause/Resume history | Running segments; event stream; latest `pausedAt` only | Running segments ✓ |
| Status automation | Open-only Start; Start+Finish; always In Progress; none | Start/Resume changes `Open` only ✓ |
| Finish while paused | Last Pause timestamp; button-click timestamp; ask each time | Last Pause timestamp ✓ |
| Hierarchy subtitle | `Project › Milestone`; Project only; full metadata; runtime-specific | `Project › Milestone` ✓ |

**User's choice:** Preserve every running segment; automate only `Open → In Progress`; use final Pause timestamp; show Project and Milestone context.
**Notes:** Multiple concurrent timers remain supported. Finish never auto-completes task.

## Jira Live Sync

| Decision | Alternatives considered | Selected |
|---|---|---|
| Project mapping | Local Project ↔ Jira Project; Local Project ↔ Jira Epic | Local Project ↔ Jira Epic ✓ |
| Epic lifecycle | Link only; auto-create only; link and create | Link existing + Create Epic from Project ✓ |
| Status authority | Jira authoritative; bidirectional automatic; local authoritative; independent | Local authoritative ✓ |
| Mapping cardinality | One-to-one; keyword guessing; one-to-many | One local status → many Jira statuses ✓ |
| Unmapped Jira status | Guess via category; prompt immediately; preserve local + warning | Preserve local + warning ✓ |
| Refresh cadence | Polling; global manual; refresh-on-open/manual | Refresh-on-open/manual ✓ |
| Runtime API route | Custom proxy everywhere; fallback chain; Tauri built-in + Web configured proxy | Tauri built-in + Web configured proxy ✓ |

**User's choice:** Project in app represents Jira Epic. Local status remains authoritative. Mapping may associate one local status with several Jira status IDs; user selects target when needed.
**Notes:** Jira status changes only update cached Jira status. Local change prompts before Jira Transition. Tauri opens Jira links in system browser.

## Sticky Notes

| Decision | Alternatives considered | Selected |
|---|---|---|
| Entity relation | One entity; multiple entities; entity-only; standalone-or-one-entity | Standalone or one entity ✓ |
| Main UI | Entity-only; global drawer; spatial board; Notes view + entity sections | Notes view + entity sections ✓ |
| Attachment storage | Data URL; OCR; filesystem path; Blob + caption | Blob + filename/caption ✓ |
| Image limits | Unlimited; compression; larger limits; 5 images × 5 MB | 5 images × 5 MB ✓ |
| Content format | Plain text; Markdown; rich text; checklist-only | Markdown ✓ |
| Markdown safety | Raw HTML; source-only; Common Markdown without raw HTML | Common Markdown without raw HTML ✓ |
| Pop-out model | One window/note; Tauri-only; in-app panel; one Notes list window | One Notes list window ✓ |
| Entity deletion | Cascade; prompt; broken reference; detach | Convert notes to standalone ✓ |
| Note pinning | Window-only; color; entity-local; global note pin | `isPinned` per note ✓ |

**User's choice:** Support standalone notes plus notes attached to one Task/Project/Milestone. One searchable Notes window, not one window per note.
**Notes:** Tauri window supports Always on Top; Web uses reusable popup. No OCR, raw HTML or automatic image compression.

## Worklog & Sync

| Decision | Alternatives considered | Selected |
|---|---|---|
| Worklog layout | Day-only; timesheet grid; calendar timeline; weekly planned-vs-actual | Weekly planned-vs-actual ✓ |
| Default rows | All active; Actual-only; required Project filter; Planned-or-Actual | Planned-or-Actual + Add Task ✓ |
| Cross-midnight work | Start day; end day; ask user; split running segments | Split at local midnight ✓ |
| Manual entry | Full modal only; aggregate field; timer-only; quick minutes + detail | Quick minutes + optional detail ✓ |
| Variance | Percentage; both; none; signed neutral delta | Signed neutral delta ✓ |
| Jira Worklog | Manual push; auto push; export; local only | Local only; never push ✓ |
| Secret persistence | Plaintext; encrypted vault; Tauri-only; OS keychain + browser manager | OS keychain + browser manager ✓ |
| Legacy Jira token | Keep copy; erase/re-enter; manual; move/verify/purge | Move, verify, then purge ✓ |
| Credential controls | Show/copy; clear all; none; status/replace/forget | Status + Replace + Forget ✓ |
| Retry policy | Fixed interval; online-only; none; exponential backoff | Exponential backoff ✓ |
| Conflict handling | Auto-pull/merge; force push; retry; pause | Pause and require resolution ✓ |
| Sync visibility | Settings only; notifications; none; Settings + header | Settings + compact header indicator ✓ |

**User's choice:** Weekly local Worklog with one Actual source (`WorkSession`), persistent credentials without repeated Tauri entry, and auto-sync that recovers predictably.
**Notes:** Auth/conflict failures do not retry automatically. Missed daily sync catches up only when dirty. No Jira Worklog integration.
