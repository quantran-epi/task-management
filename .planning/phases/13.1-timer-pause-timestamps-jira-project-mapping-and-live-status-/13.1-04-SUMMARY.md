# Phase 13.1 Plan 04: Actual Worklog Planner Summary

Weekly Planned vs Actual Worklog Planner with midnight segment splitting, color-coded variance calculation, inline quick minute entry, and full WorkSession detail editing.

## Overview

Delivered the complete Actual Worklog subview inside PlannerView. The view features:
1. Deterministic partitioning of discrete running segments across calendar midnight boundaries with DoS protection (`splitSegmentByMidnight` capped at 30 days).
2. Live reactive aggregation of Planned vs Actual hours per task and weekday from IndexedDB using Dexie `useLiveQuery`.
3. 7-day matrix table with weekly total column, color-coded variance tags (`+Xm` warning in orange, `-Xm` neutral in gray, `0m` success in green).
4. Searchable Add Task combobox to add unallocated tasks to the week.
5. Inline popover for fast minutes logging and `WorkSessionDetailModal` for fine-grained editing of timestamps, segments, and notes.
6. Seamless `Segmented` subview toggle in `PlannerView` ('Kế hoạch' vs 'Thực tế') sharing `WeekNavigator` state and keyboard shortcuts.

## Key Changes

### Utilities & Repositories
- `src/utils/worklog.ts`:
  - `splitSegmentByMidnight`: Splits ISO time intervals crossing local midnight into individual calendar days (`YYYY-MM-DD`) and integer minutes.
  - `aggregateTaskActualMinutesByDate`: Aggregates WorkSession records per task and date without double counting paused intervals.
  - `computeVariance` & `formatVariance`: Calculates signed difference and assigns semantic status.
- `src/db/repositories/workSessionRepo.ts`:
  - Added `getWorkSessionsForWeek` query helper.

### UI Components
- `src/components/planner/WorkSessionDetailModal.tsx`:
  - Lists existing sessions for a specific task and date with start/end times, durations, and discrete segments.
  - Allows editing or deleting sessions and logging new manual work sessions.
- `src/components/planner/ActualWorklogPlanner.tsx`:
  - Ant Design Table rendering 7 weekdays + Total column.
  - Toolbar with Searchable Task Selector and week total summary tags.
  - Interactive cell Popover with quick minutes entry and navigation to detail modal.
- `src/views/PlannerView.tsx`:
  - Segmented toggle (`Kế hoạch` / `Thực tế`) integrated into top toolbar.
  - Reuses existing `WeekNavigator`, keyboard shortcuts, and date synchronization.

### Automated Tests
- `tests/actualWorklog.test.ts`:
  - Verified midnight segment splitting across date boundaries.
  - Verified aggregation treating WorkSession as single source of truth without double-counting pause intervals.
  - Verified variance calculations for positive, zero, negative, and zero-planned cases.
