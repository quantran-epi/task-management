## Key Decisions Made

- Made `ActiveTimer.segments` optional (`segments?: TimerSegment[] | undefined`) on the TypeScript model level to maintain backwards compatibility with existing unit test mocks while ensuring runtime operations in `TimerContext` always populate and persist segment arrays.
- Ensured finishing a paused timer uses `lastSegment.endTime` rather than `Date.now()`, eliminating idle wall-clock drift from logged work sessions when a user finishes a timer hours after pausing.
- Enforced safe status automation strictly inside the Dexie transaction: only tasks in `Open` status transition to `In Progress`, leaving terminal and review statuses untouched.
