  - Enforced 5MB size limit and 5-image cap per note at repository and upload component levels.
  - Cascade deletion of tasks, milestones, or projects detaches associated notes into standalone notes without losing content or attachments.

## Overview
Implemented offline-first Sticky Notes with entity association (Task/Project/Milestone), safe Common Markdown rendering, screenshot attachments with backup serialization, top-level Notes view, and a single reusable floating pop-out window with Always on Top on desktop.
