## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, note card metadata gaps, dense pop-out row gaps |
| sm | 8px | Button groups, tag gaps, thumbnail gaps, compact form controls |
| md | 16px | Page/card gaps, drawer sections, Settings card internal spacing |
| lg | 24px | Modal body spacing, major form groups, Actual Worklog header separation |
| xl | 32px | Empty state vertical padding, major section breaks |
| 2xl | 48px | Large empty-state top/bottom breathing room |
| 3xl | 64px | Page-level bottom padding and max separation between unrelated groups |

Exceptions:
- Mobile and touch icon-only controls: `44px` min-width and min-height.
- Desktop pop-out dense icon-only controls: `28px` min-width and min-height, only inside Timer/Notes pop-out windows.
- Screenshot thumbnails: `96px × 72px`, preserving 4px grid.
- Notes pop-out default window: `420px × 640px`, min `360px × 480px`; clamp restored position to visible screen.

## Color

60-30-10 distribution based on Ant Design tokens:

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | #ffffff (light) / #141414 (dark) | Main canvas, modal/drawer bodies, Notes editor surface, Actual Worklog table background |
| Secondary (30%) | #fafafa (light) / #1f1f1f (dark) | Cards, sidebar/nav, form section backgrounds, table headers, pop-out row backgrounds |
| Accent (10%) | #1677ff | Primary CTAs, active navigation/segmented state, Jira key/Epic tags, selected note row, active refresh/open actions |
| Destructive | #ff4d4f | Destructive actions only: delete note, delete attachment, delete work session, forget credential, force push, unlink Jira relation |

Accent reserved for:
1. Primary buttons: `Thêm ghi chú`, `Lưu ghi chú`, `Lưu thời gian`, `Đồng bộ ngay`, `Lưu ánh xạ`.
2. Active navigation item: `Ghi chú`; active Planner segmented tab: `Thực tế`.
3. Jira `jiraKey` / `jiraEpicKey` tags and selected Jira transition target.
4. Selected note row/card in Notes view and Notes pop-out.
5. Header indicator for pending sync only; error/conflict use semantic colors.

Semantic state colors:
- Success `#52c41a`: running timer dot, stored credential, in-sync Jira status, sync success tag in Settings only.
- Warning `#faad14`: paused timer dot, positive variance (`Actual > Planned`), Jira/local mismatch, retry backoff, unsupported Jira transition screen.
- Neutral `#8c8c8c`: negative variance (`Actual < Planned`), standalone note entity, disabled/unknown status.
- Destructive/error `#ff4d4f`: failed sync/auth, conflict paused, validation error, destructive action buttons.

Do not rely on color alone. Pair every semantic color with text, icon, or tag label.

## Feature Interaction Contracts

### 1. Timer pause timestamps, status automation and hierarchy context

| Element | Contract |
|---------|----------|
| Header single timer capsule | Show task name first line, subtitle `{Project} › {Milestone}` second line when available. Omit missing project or milestone. Truncate both with Tooltip. |
| Header multi-timer dropdown | Each row shows status dot, task name, subtitle, elapsed ticker, Pause/Resume, Finish. Dropdown width min `280px`, max row title one line. |
| Timer pop-out | Same subtitle contract as header. Dense layout may use 12px label text. Pin button keeps existing Tauri Always on Top behavior. |
| Running segment visibility | No raw segment timeline in header. Segment details appear only in WorkSession detail modal as read-only rows unless user opens advanced edit. |
| Pause | Button label/aria-label: `Tạm dừng`. Pause closes current segment and changes status dot to warning. No task status change. |
| Resume | Button label/aria-label: `Tiếp tục`. Resume opens new segment. If task is `Open`, show one success message `Đã chuyển tác vụ sang Đang làm.` and set local status to `In Progress`. Do not overwrite other statuses. |
| Finish while running | Button label/aria-label: `Kết thúc phiên`. Close current segment at click timestamp and create WorkSession. |
| Finish while paused | Use last pause timestamp as visible end time. Confirmation not required. Success copy: `Đã lưu phiên làm việc.` |
| Error | `Không thể cập nhật bộ đếm. Vui lòng thử lại.` via `message.error`; timer row remains visible with prior state. |

| Element | Contract |
|---------|----------|
| Project modal Jira section | Add section title `Jira Epic` below project status/deadline. If no `jiraEpicKey`, show buttons `Liên kết Jira Epic` and `Tạo Jira Epic`. If linked, show `Tag` with `jiraEpicKey`, `Open in Jira`, `Refresh`, `Hủy liên kết`. |
| Project table | Show Jira Epic tag under/next to project name when present. Clicking tag stops row click and opens Jira safely. |
| Create Jira Issue modal | Default Epic field from parent Project `jiraEpicKey`. Allow override with searchable Select/Input. Display helper: `Issue mới sẽ được gắn vào Epic này nếu Jira cho phép.` |
| Jira status cache | Task Jira section shows two status rows: `Local status` and `Jira status`. Jira status row includes `statusName`, `statusCategory`, and `syncedAt` formatted `DD/MM HH:mm`. |
| Refresh behavior | Refresh on TaskDrawer open and when user clicks `Refresh`. No polling text or background spinner outside open task. |
| Mapping settings | Settings Jira card adds `Ánh xạ trạng thái Jira`. Use table rows for local statuses: Open, In Progress, In Review, Resolved, Done, Cancelled. Each row has multi-select Jira status IDs/names. Save with `Lưu ánh xạ`. |
| Unmapped Jira status | Show warning Alert in Task Jira section. Do not guess by keyword. Offer `Mở trên Jira` and `Cấu hình ánh xạ`. |
| Local status change with Jira target | Before API call show confirmation Modal with selected reachable target. If one target, preselect it. If multiple targets, user must choose one. |

| External links | Tauri opens Jira links in system browser. Web/PWA opens new tab with `noopener,noreferrer`. |

## Visual Hierarchy & Focal Points

1. **Primary anchor:** Notes view and Actual Worklog table use Ant Design Cards/Table with clear headings and current-week context. Do not create decorative dashboards.
2. **Secondary anchor:** Jira mismatch and sync conflict Alerts use warning/error semantic styles with explicit recovery CTAs.
3. **Tertiary anchor:** Header timer/sync indicators stay compact; they must not compete with main task planning workspace.
4. **Pop-out windows:** Use dense but readable layout. One task/note row per line; no large illustrations or empty-state artwork.

## Accessibility Contract

| Requirement | Contract |
|-------------|----------|
| Icon-only buttons | Every icon-only Button must have `aria-label`: pause/resume/finish/open pop-out/pin/delete/refresh/open in Jira. |
| Keyboard | Ant Design default keyboard behavior must work for Select, Segmented, Modal, Upload and Table controls. Notes search receives focus when Notes view or pop-out opens. |
| Focus restoration | Modals and pop-out launchers restore focus to triggering control on close when still mounted. |
| Screen reader status | Save, sync, credential migration, Jira transition and upload validation results announce via existing `AriaLiveRegion` where action changes persistent state. |
| Color independence | Running/paused/mismatch/variance/sync states include Tag text or icon plus color. |
| Motion | No custom animations for ticker, notes pop-out or sync indicators. Ant Design default transitions only. |
| Touch | Mobile icon-only controls use 44px minimum target. Desktop pop-out dense controls are allowed at 28px only because pointer window is compact. |
| Markdown links | Preview links are keyboard-focusable and open safely. Raw HTML never becomes focusable DOM. |
