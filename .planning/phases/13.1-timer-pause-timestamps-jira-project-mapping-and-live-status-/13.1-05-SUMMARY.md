# Phase 13.1 Plan 05: Native OS Keychain, Zero-Secret Boundaries & Auto-Sync Hardening Summary

Desktop OS Keychain credential persistence via Rust keyring crate with zero-secret SQLite/IndexedDB boundaries and exponential backoff auto-sync recovery.

## What Was Done

1. **Native OS Keychain Integration & Rust Commands (D-33)**:
   - Added `keyring = "4.2"` dependency in `src-tauri/Cargo.toml`.
   - Created `src-tauri/src/keyring_store.rs` exposing `store_credential`, `get_credential`, and `delete_credential` commands.
   - Registered commands in `src-tauri/src/lib.rs`.
   - Created `src/services/keyringService.ts` for type-safe Tauri IPC credential operations.

2. **Zero-Secret Boundary Enforcement (D-34, D-35)**:
   - Extended `EXCLUDED_SETTING_KEYS` in `src/services/localSqlitePersistence.ts` to strictly exclude `jira_api_token`, `github_pat`, `github_token`, `github_passphrase`, `backup_passphrase`, and `tauri_keyring_migrated`.
   - Updated `src/context/GitHubAuthContext.tsx` to automatically load PAT and Passphrase from OS Keychain on Tauri desktop boot, keeping Web/PWA memory-only.

3. **Safe Legacy Jira Token Migration & UI Controls (D-36, D-37)**:
   - Created `src/services/jiraTokenService.ts` implementing read-back verification before purging legacy `jira_api_token` from IndexedDB and SQLite queue.
   - Updated `JiraConfigCard.tsx` and `GitHubConfigCard.tsx` with "Stored" / "Not stored" status badges and separate "Thay đổi" (Replace) and "Xóa" (Forget) modals without exposing secret plaintext.
   - Integrated token lookup in `ProjectModal`, `CreateJiraIssueModal`, and `TaskJiraSection`.

4. **GitHub Auto-Sync Backoff & Catch-Up (D-38, D-39, D-40, D-41)**:
   - Implemented `BACKOFF_MINUTES = [1, 5, 15, 30, 60]` progression in `useGitHubAutoSync.ts`.
   - Added window `online` event listener that immediately resets failure count and retries if local state is dirty.
   - Paused auto-sync on HTTP 401/403 errors and cleared dirty state upon sync success without desktop notification.
   - Created comprehensive unit test suite in `tests/syncBackoff.test.ts`.

5. **SHA Conflict Pausing & Status Visibility (D-42, D-43)**:
   - Caught `GitHubSyncConflictError` to pause auto-sync scheduler with `pauseReason: 'conflict'`.
   - Displayed prominent conflict alert with "Tải về từ GitHub (Pull)" and "Ghi đè lên GitHub (Force Push)" buttons in `GitHubSyncCard.tsx`.
   - Added sync dashboard in `GitHubSyncCard.tsx` showing sync status, next run, dirty since timestamp, and last error.
   - Added compact `GitHubSyncStatusDot.tsx` in `AppShell` header with green (synced), orange (dirty), and red (conflict/error) status badges.
