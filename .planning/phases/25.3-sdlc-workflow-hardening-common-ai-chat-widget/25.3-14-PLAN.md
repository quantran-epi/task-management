## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Intake submission -> AI turn | A user action authorizes one artifact turn; the host must not amplify it |
| Thread bootstrap -> queued request | A request can arrive before its thread identity is known |
| Step/CR navigation -> delayed callback | A pending callback can target a step the user already left |
