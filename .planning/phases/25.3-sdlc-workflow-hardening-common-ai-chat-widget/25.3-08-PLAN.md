## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| AI output → transcript DOM | Model text and tool results are untrusted |
| Host → widget | Typed callbacks cross the component boundary |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-25.3-26 | Tampering | Markdown rendering | mitigate | All model/artifact text goes through `renderSafeMarkdown`; no raw HTML in `ArtifactEventCard` or the approval card (Task 1 asserts) |
| T-25.3-27 | Elevation | Mutation approval UI | mitigate | Approval card has explicit approve/reject and no auto-dismiss; runtime guard order is owned by plan 25.3-07 |
| T-25.3-28 | Repudiation | Clear thread | mitigate | `onClearThread` receives the active `scope.scopeKey`; widget never clears workflow state and Test 6 pins that |
| T-25.3-29 | Information disclosure | Reasoning leakage | mitigate | `onReasoningChunk` is never subscribed; Test 2 asserts reasoning text never reaches the DOM |
| T-25.3-30 | Spoofing | Artifact card status | mitigate | Card renders `draft` vs `approved` from the host event, never infers approval from content presence |
| T-25.3-43 | Tampering | Persisted artifact event | mitigate | `hash` and `version` validated before write (`INVALID_ARTIFACT_EVENT`); only metadata persisted, never the artifact body |
</threat_model>
