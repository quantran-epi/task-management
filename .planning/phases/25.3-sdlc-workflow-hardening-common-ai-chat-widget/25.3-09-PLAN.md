## Trust Boundaries

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-25.3-31 | Tampering | Draft vs approved artifact | mitigate | Step chat draft callbacks only update editor draft state; no commit path is reachable from a chat turn (Task 1, Task 2 draft handling) |
| T-25.3-32 | Elevation | Step navigation | mitigate | `navigateToStep` only persists `currentStep`; test asserts navigation never sends a chat message |
| T-25.3-33 | Information disclosure | Guard error surfacing | mitigate | Raw codes are mapped through `formatGuardMessage`; no exception text with internal detail reaches the user |
| T-25.3-34 | DoS | Restore rejection | mitigate | A failed restore renders prerequisite guards instead of throwing during render; race-guarded effect with `cancelled` flag |
| T-25.3-46 | Tampering | Historical artifact open | mitigate | `readOnly` forced when the version is not active or the CR is closed; editor approve controls disabled (Task 3 Tests 5-6) |
| T-25.3-47 | Repudiation | Artifact event provenance | mitigate | Each card records `kind`/`version`/`hash` from the committed artifact ref at write time; cards are never rewritten (Task 3 Tests 1-4) |
</threat_model>
