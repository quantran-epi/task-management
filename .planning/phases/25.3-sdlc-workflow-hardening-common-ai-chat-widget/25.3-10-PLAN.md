| Drawer tabs → runtime | Each tab's request state must stay isolated |
| Host callbacks → widget | Drawer business actions cross into the shared renderer |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-25.3-35 | Tampering | Cross-tab leakage | mitigate | Per-tab runtime instances in a ref-backed registry; isolation suite asserts independent transcripts and requests, and the registry suite asserts no shared state |
| T-25.3-36 | Repudiation | Retry duplication | mitigate | Retry identity owned by the runtime and re-asserted in the Drawer suite |
| T-25.3-37 | Tampering | Partial commit on abort | mitigate | Abort path persists nothing; abort/commit suite unchanged in intent |
| T-25.3-38 | Elevation | Host callbacks | accept | Drawer callbacks are local single-user actions; no privilege boundary changes |
</threat_model>
