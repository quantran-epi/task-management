# Phase 25.3 Plan 05: Step 5 Evidence-Only Tech Docs Summary

Step 5 now emits evidence-only PL03B drafts, a verdict-free PL07 checklist, and commits nothing until the user clicks `Lưu & Phê duyệt`.

## What was built

**Task 1 — PL03B stripped to the implemented system (D-14).**

- `Pl03bDocxPayload.reconciliation: ReconciliationResult` → `reconciliationEvidence: Pl03bReconciliationEvidence`, carrying only `actualImplementation`, `coverage`, `dbChangesRollback`, `regressionMatrix`.
- `reconciliationChildren` no longer emits `THIẾT KẾ NHƯ ĐÃ DUYỆT`, `BẢNG DRIFT`, or `Trạng thái đối soát`; `THỰC TẾ TRIỂN KHAI`, the coverage table, `THAY ĐỔI DB VÀ ROLLBACK`, and `MA TRẬN REGRESSION TEST` stay.
- `toPl03bDocxPayload` derives purpose/overview from `proposalData.actualImplementation` instead of `approvedDesign`.
- `pl03bMarkdown` drops the `Drift:` bullet.
- `toPl07DocxPayload` maps every mark to `unknown` — the declared `PASS`/`FAIL`/`NOT_APPLICABLE` is discarded before the schema parse, so no verdict survives even with citations present.
- `pl07Markdown` lists `PL07_BASELINE` question text and section-VI findings as `Cần review:`, never a status word.
- New `generateHubTechDocDraft(input)` runs both stages and returns payloads + markdown with zero Note writes; `generateHubTechDocs` now calls it and only then persists via `saveApprovedArtifact` (3 occurrences: 1 import + 2 calls).
- `reconciliation.ts` exports `DbChangesRollbackSchema`, `RegressionMatrixRowSchema` and their types; `wizardDocx.ts` composes `reconciliationEvidence` from those shared schemas (no `z.unknown()`, no duplicate declarations).

**Task 2 — Step 5 view generates drafts, approval is separate (D-16, D-17, D-18, D-20).**

- New optional props: `onNavigateToStep`, `draftPl03b`, `draftPl07`, `onDraftChange`, `wizardRuntime`, `generateDrafts`.
- Deleted `handleGenerateTechDocs`'s fabricated payload, the literal `'Đã triển khai code trong change pack.'`, the `Kết quả đối chiếu với Change Pack` section, and the loop stamping every PL07 item `status: 'pass'` with `ev-verified-pack`.
- Generate button reads `Tạo bản nháp` → `Tạo lại bản nháp`; success message says a draft was created.
- Review tag reads `Bản nháp` until `workflowState.artifacts.pl03b`/`pl07` exists, then `Đã duyệt (v{n})`.
- Per-document `Lưu & Phê duyệt` primary button is the only caller of `onCommitTechDoc`; disabled without prerequisites or non-empty draft.
- Missing SOLUTION/Change Pack renders `formatGuardMessage('SOLUTION_AND_PACK_REQUIRED_FOR_TECH_DOCS')` with a `Chuyển đến Bước 4: Kiểm soát Change Pack` action.
- No runtime and no `generateDrafts` → disabled button plus the Settings configuration Alert.
