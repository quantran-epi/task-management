## Chat thường vs tạo artifact

| Question | Option | Description | Selected |
|---|---|---|---|
| Artifact trigger | Action hoặc yêu cầu rõ | Dedicated action or explicit natural-language request may create/update a draft; ordinary Q&A does not alter artifacts. | ✓ |
| | Chỉ action tường minh | Only explicit UI action may create/update artifact. | |
| | Tự động extract mọi lúc | Any document-shaped output in an artifact step updates editor automatically. | |
| Explicit SOLUTION edit | Cập nhật draft | Clear edit request updates editor draft immediately; prior approved version stays unchanged until user saves/approves. | ✓ |
| | Preview rồi áp dụng | Show preview/diff before applying to draft. | |
| | Chỉ nút cập nhật | Chat text never updates editor. | |
| PL03B/PL07/CAB | Draft rồi duyệt | Generate draft, then user reviews and explicitly approves/saves. | ✓ |
| | Commit ngay | Commit immediately after AI turn. | |
| | Chỉ nút action | Chat cannot generate artifact. | |
| Update shape | Toàn bộ artifact | Return complete document on every create/update. | ✓ |
| | Chỉ phần thay đổi | Return partial section and merge patch. | |
| | Diff trước | Always produce a diff before a complete artifact. | |

**User's choice:** Distinguish ordinary Q&A from explicit artifact intent; artifact-generating turns produce full drafts and never bypass user approval.  
**Notes:** Explicit natural-language editing is an explicit trigger, not a mount/remount auto-trigger. This carries forward Phase 25.2's no-remount-trigger and explicit analysis action guarantees.
