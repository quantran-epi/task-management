# Phase 25.3 Plan 12: Production SDLC Wizard Runtime Summary

A single production constructor now supplies the `WizardModel`, evidence collector, and real published set ids that Step 5/6 PL03B/PL07/CAB generation needs, with credentials read only from persisted router settings.

## What Was Built

**`src/services/wizard/sdlcWizardRuntime.ts`** (195 lines) — exports `createSdlcWizardRuntime`, `SdlcWizardRuntime`, and `wizardModelUnconfiguredError`.

- `createSdlcWizardRuntime({ db, knowledgeBaseUrl?, knowledgeToken? })` returns `{ model, collectEvidence, resolveSetIds }` — exactly the three fields `HubTechDocsInput`/`HubCabInput` declare.
- `model` = `{ endpoint: config.endpoint, apiKey?, model: config.defaultModel }` from `getNineRouterConfig(db)` + `getNineRouterApiKey(db)`. No `import.meta.env` anywhere (T-25.3-49); the key is user-entered at runtime and, in Tauri, keyring-backed.
- `resolveSetIds` reads `listDocumentSets(db)`, keeps the one project SDLC set (`sdlc.projectId === projectId && purpose === 'sdlc'`), throws `DUPLICATE_PROJECT_SDLC_SET` on duplicates, then appends base sets (deduped via `Set`). It returns real ids, so an empty result reaches `collectWizardEvidence` as `EMPTY_SCOPE` rather than being masked (T-25.3-50).
- `collectEvidence` delegates to `collectWizardEvidence(input, deps)`. `deps.runLocalBm25` mirrors `localBm25Deps` from `createDefaultGroundedTurnDeps`: set membership from `db.documentSets.where('id').anyOf(...)`, bodies from `db.notes` unwrapped with `readNoteMarkdown`.
- `retrieveRemote` maps only `type: 'chunk'` federated items to `WizardEvidenceItem` (`source: 'remote'`, id namespaced `remote-${setId}-${chunkId}`). Chunk payloads carry line ranges but no character offsets, so `startOffset`/`endOffset` are `0` rather than invented positions.
- No `saveApprovedArtifact`, no `db.notes.add` — the module is pure wiring (T-25.3-54).

**`tests/ai/sdlcWizardRuntime.test.ts`** (167 lines, 6 tests) — persisted-config mirroring; `WIZARD_MODEL_UNCONFIGURED` when settings are absent; real set-id resolution excluding another project's set; `EMPTY_SCOPE` with no sets then real local BM25 grounding on the resolved ids (asserting the artifact JSON envelope is unwrapped); local-only degradation (`REMOTE_DISABLED`, `MCP_UNAVAILABLE`, no `mcp` items); router-default endpoint when only a model is persisted.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Router defaults would have made the "unconfigured" check unreachable**
- **Found during:** Task 1
- **Issue:** The plan's "if no endpoint or key is configured, throw" cannot be read literally: `getNineRouterConfig` always returns `DEFAULT_NINEROUTER_ENDPOINT` (`http://localhost:20128`) and `DEFAULT_NINEROUTER_MODEL` (`gpt-4o`) when nothing is persisted, so an endpoint always exists and `WIZARD_MODEL_UNCONFIGURED` would never fire. Generation would instead post to a guessed localhost endpoint and fail with an opaque transport error.
- **Fix:** "Configured" is defined as at least one persisted `ninerouter_endpoint` / `ninerouter_default_model` / API key row; router defaults still fill the gaps once one of them exists.
- **Files modified:** `src/services/wizard/sdlcWizardRuntime.ts`
- **Commit:** `1f13f6b9`

**2. [Rule 2 - Missing critical functionality] Local-only coverage assertion corrected**
- **Found during:** Task 1 test run
- **Issue:** A first draft expected `coverage: 'COMPLETE'` for local-grounded evidence. `collectWizardEvidence` marks every absent optional seam as degraded, so omitting `retrieveMcp` (required by the plan) always yields `PARTIAL`.
- **Fix:** The test now asserts `PARTIAL` and documents why; no runtime change, since the degradation list is the honest signal the stage needs.
- **Files modified:** `tests/ai/sdlcWizardRuntime.test.ts`
- **Commit:** `1f13f6b9`

No architectural (Rule 4) changes. No authentication gates.
