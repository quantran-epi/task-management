# Phase 25.3 Plan 17: Resizable SDLC Chat Lane

**SDLC Studio chat lane now supports bounded pointer and keyboard resizing, accessible splitter controls, and persisted device layout preference.**

## Accomplishments

- Added keyboard resize behavior to `ResizeSplitter`: Arrow keys move by 16px with side-aware direction; Home/End jump to bounds; unrelated keys remain untouched.
- Added optional `ariaLabel`, `ariaControls`, visible focus indication, and preserved existing pointer/double-click behavior.
- Added `SdlcWorkspace` constants `SDLC_CHAT_WIDTH_MIN`, `SDLC_CHAT_WIDTH_DEFAULT`, `SDLC_CHAT_WIDTH_MAX`, and exact key `planner:sdlc_chat_width`.
- Wired chat lane to `ResizeSplitter` with 320..480px bounds and 380px reset/default.
- Added safe `localStorage` read/write, malformed-value fallback, clamping, `minWidth: 0` step pane, and flexible chat pane sizing.
- Added focused tests for keyboard direction, bounds, labels, pointer clamping, reset, remount persistence, and malformed values.
