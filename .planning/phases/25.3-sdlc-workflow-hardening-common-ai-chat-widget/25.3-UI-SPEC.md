## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge padding, compact inline tags |
| sm | 8px | Button gaps, compact element padding, toolbox control gaps |
| md | 16px | Card body padding, transcript message spacing, header margin |
| lg | 24px | Section padding, modal content gutter, SDLC view margin |
| xl | 32px | Layout gaps, split workspace division padding |
| 2xl | 48px | Major container breaks |
| 3xl | 64px | Page-level spacing |

Exceptions:
- Touch target minimum for interactive icon-only buttons: 32px (Ant Design default compact controlHeight) or 36px (standard controlHeight token).
- Tool detail drawer/popover min-width: 260px.
- Chat drawer / step panel width bounds: 320px minimum, 380px default, 480px maximum.

## UI Component Contract Specifications

### 1. `AiChatWidget` Common Layout & Extension Points
- **Container Structure**:
  - `Header`: Contextual scope identifier (`SDLC: [CR-CODE] - [Tên bước]` or `General Chat: [Scope]`), status indicators (Streaming, Waiting for Approval, Analysis Mode).
  - `Toolbox`: Compact horizontal bar hosting `ChatTabToolbox` (Model Select, Analysis Mode switch, Auto-approve switch, MCP Popover, Clear Context icon).
  - `Transcript`: Scrollable message area with virtualized/efficient rendering, auto-scroll anchored to bottom on active turn.
  - `Composer`: Auto-resizing textarea (`minRows: 1`, `maxRows: 6`), keyboard shortcuts (Enter to send, Shift+Enter for newline), Send / Stop Generation toggle button.
- **Host Adapters**:
  - `SDLC Host Adapter`: Supplies step-scoped prompt templates, step quick prompt arrays, solution extraction callback, and mutation approval dispatching.
  - `Drawer Host Adapter`: Supplies global/task/project context grounding, item quick prompts, and popout window triggering.

### 2. Staged Loading & Tool Event Cards (D-04, D-19)
- **Staged Progress Indicator**:
  - Replaces raw reasoning blocks with a 4-state indicator:
    1. *Chuẩn bị ngữ cảnh* (Preparing context & grounding)
    2. *Truy xuất công cụ* (Tool execution with badge tag)
    3. *Đang phản hồi* (Streaming token synthesis)
    4. *Chờ phê duyệt* (Waiting for explicit mutation decision)
- **Tool Event Cards**:
  - Compact collapsible Ant Design card with status badge (`sync` spinning for running, `check-circle` for success, `close-circle` for error).
  - Title format: `[Công cụ] {toolName}`.
  - Detailed arguments and output hidden by default; expanded via single-click toggle.

### 3. Prerequisite Guards & Actionable Disabling (D-20)
- **Visual Pattern**:
  - Step 3 (Coding Guide): Action card displays target-repo command `node scripts/change-pack.mjs --cr <CR>` with one-click copy. Obsolete checklist removed.
  - Step 4 (Change Pack): Dropzone disabled with inline `Alert` if `SOLUTION.md` is unapproved. Direct action button: `Chuyển đến Bước 2: Thiết kế giải pháp`.
  - Step 5 (Tech Docs): Generation CTA disabled with inline `Alert` if `SOLUTION.md` or validated `Change Pack` is missing. PL03B displays actual implementation only (drift matrix remains in TaskMate inspection view). PL07 rendered as un-checked reviewer questions (no auto-PASS).
  - Step 6 (CAB): Generation CTA disabled with inline `Alert` if PL02, PL03B, or PL07 missing. GoLive summary separated from internal TaskMate CR summary.

### 4. Mutation Approval Wait State (D-22)
- Distinct dedicated card inside chat transcript:
  - Header: `Yêu cầu xác nhận thay đổi dữ liệu` with `ExclamationCircleOutlined` in `#faad14`.
  - Body: Diff/summary table showing Entity Type, Action (Create/Update/Delete), Target Fields.
  - Actions: Primary Button `Chấp thuận` (`#4f46e5`), Default Button `Từ chối` (`#ef4444`).
