## Decisions Made

- No mount-driven analysis. Successful explicit intake submission authorizes the automatic artifact turn; generation remains a draft and does not approve or save artifacts.
- `selectCr` clears timers on actual identity changes only. Active-CR initialization can reselect the newly created CR after intake; cancelling on this redundant selection would silently drop its authorized analysis.
- Tests hold only the analysis timer while actual IndexedDB/form promises settle, then test callback scope guards and controlled 150ms advancement without racing database setup.
