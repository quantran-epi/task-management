<objective>
Keep the complete SOLUTION artifact on the SDLC side: extract the whole document across nested fences, tighten the output contract so the model does not wrap the document in an ambiguous outer fence, and make sure a length-truncated artifact is never stored. The host sets no completion cap of its own. The router and model configuration decide the output limit.

Purpose: The observed artifact stops at "Kiến trúc giải pháp mục tiêu". The primary defect is first-fence extraction (a non-greedy regex stops at the first inner fence). Plan 25.3-15 already rejects provider-truncated output at the runtime layer. This plan fixes extraction, the prompt contract, and the SDLC host's handling of that rejection.
Output: Fence-aware parser, summary removal, contract update, and context-window forwarding with truncated-artifact handling in `StepChatPanel`.
</objective>
