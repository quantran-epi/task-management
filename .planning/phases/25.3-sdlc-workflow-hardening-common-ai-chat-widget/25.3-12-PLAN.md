    `model` comes from `getNineRouterConfig(db)` + `getNineRouterApiKey(db)`: `{ endpoint: config.endpoint, ...(apiKey ? { apiKey } : {}), model: config.defaultModel }`. Do not read `import.meta.env` — the project forbids `VITE_*` secrets and the key is already user-entered at runtime. If no endpoint or key is configured, throw `WIZARD_MODEL_UNCONFIGURED` so the step surfaces an actionable error rather than silently generating nothing.
    `resolveSetIds` returns the ids from `listDocumentSets(db)` filtered to sets the project can publish from; when the project SDLC set exists include it first. It must never return `[]` silently — an empty scope strips every citation, so return the real set list and let `collectWizardEvidence` report `EMPTY_SCOPE`.
    `collectEvidence` delegates to `collectWizardEvidence(input, deps)` where `deps` is built exactly as `createGroundedTurnDeps` builds `localBm25Deps` (load set members from `db.documentSets`, load note bodies from `db.notes`); provide `retrieveRemote` only when `knowledgeBaseUrl`/`knowledgeToken` are supplied, and omit `retrieveMcp` (the wizard stage must not call MCP tools — `WIZARD_STABLE_SYSTEM_PREFIX` forbids tool requests).
    Export nothing that writes Notes. This module is pure wiring.
    Add `tests/ai/sdlcWizardRuntime.test.ts`: Test 1 asserts `model` mirrors the persisted router config; Test 2 asserts `WIZARD_MODEL_UNCONFIGURED` when settings are absent; Test 3 asserts `resolveSetIds` returns seeded set ids (not `[]`) for a project with sets; Test 4 asserts `collectEvidence` yields `EMPTY_SCOPE` coverage when no sets exist and calls the local BM25 seam with the resolved ids.
