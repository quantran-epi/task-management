## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Pack/diff/Note text → prompt | Untrusted document content is concatenated into a model prompt |
| Model output → artifact state | Model-generated artifact text is later parsed and offered as a draft |

| T-25.3-08 | Elevation | `composeSdlcTurn` grounding segment | mitigate | Policy is emitted first and grounding is enclosed in explicit untrusted-data delimiters; a step contract cannot precede or replace policy (Task 2 Tests 1, 3, 6) |
