<objective>
Make `workflowCoordinator` self-healing: any lifecycle or action call restores persisted state before inspecting artifacts, and every missing-prerequisite failure returns a stable code that the UI can turn into actionable guidance.

Purpose: Success criteria 1 and 3 both bottom out here. Without a restore-before-action path, every step UI keeps throwing `WORKFLOW_NOT_INITIALIZED` after reload. Without a code→copy registry, each step invents its own error text (D-20 requires one actionable explanation per guard).
Output: `ensureState()` in the coordinator, `workflowGuards.ts` registry, extended coordinator tests, new guard tests.
</objective>
