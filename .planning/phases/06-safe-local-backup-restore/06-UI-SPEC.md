## Visual Hierarchy & Focal Points

1. **Primary Navigation Anchor (`SettingsView` Tab Organization)**:
   - Top-level segmented `Tabs` container (`type="line"`) cleanly separating:
     - **Tab 1: Công suất làm việc** (`WeeklyCapacityForm`, `OverridesTable`) — daily capacity rules.
     - **Tab 2: Sao lưu & Dữ liệu** (`BackupExportCard`, `BackupImportCard`, `SnapshotRollbackCard`, `DatabaseResetCard`) — data operations.
   - Eliminates vertical clutter and isolates high-risk data management workflows into a dedicated workspace.

2. **Secondary Operational Anchor (`BackupExportCard` & `BackupImportCard`)**:
   - Stacked cards in Tab 2 with clear functional grouping:
     - **Export Card**: Prominent primary button `Xuất bản sao lưu (JSON)` with download icon, metadata display showing latest export timestamp (`Lần sao lưu gần nhất: ...`), and record count summary badges.
     - **Import Card**: Ant Design `Upload.Dragger` dropzone area (dashed border, 32px vertical padding, inbox icon, 50MB file limit indicator, clear call-to-action button `Chọn tệp sao lưu`).

3. **Critical High-Stakes Anchor (`ImportPreviewModal`)**:
   - Centered modal dialog (`width: 700px`, masked, closable via Cancel only) triggered immediately upon file selection.
   - 3-tier vertical hierarchy:
     1. *Envelope Header*: App marker tag, schema version tag, export timestamp formatted as human-readable date-time.
     2. *Comparison Table*: 4 columns (`Bảng dữ liệu`, `Hiện tại trong máy`, `Tệp nhập vào`, `Chênh lệch (+/-)`) displaying counts across all 6 domain tables.
     3. *Safety & Confirmation Gate*:
        - If valid: Safety notice about pre-import snapshot creation, warning Alert, explicit input requiring typing keyword `RESTORE`, and danger button `Xác nhận khôi phục`.
        - If invalid: Error banner and scrollable error table listing Table, Record ID, Invalid Field, and validation message. Restore button disabled.

4. **Safety Net Anchor (`SnapshotRollbackCard` & Post-Restore Banner)**:
   - **Post-Restore Success Banner**: Persistent top-level Alert displayed following restore with direct rollback CTA `Hoàn tác về bản trước đó` and snapshot download CTA `Tải snapshot về máy`.
   - **Snapshot Management Card**: Dedicated card in Settings Tab 2 showing current local pre-import snapshot state (`Thời điểm tạo`, `Tổng bản ghi`), with one-click rollback trigger and physical JSON download option.

## Component Inventory & Interaction Contracts

### 1. Reorganized Settings View (`src/views/SettingsView.tsx`)
- Container: Max width 1000px, centered, standard padding `16px 24px`.
- Header: Title `Cài đặt` with back button to previous view.
- Sub-navigation: Ant Design `Tabs` with 2 items:
  - **Tab 1: Công suất làm việc** (`key="capacity"`, icon `<ScheduleOutlined />`): Contains `WeeklyCapacityForm` and `OverridesTable`.
  - **Tab 2: Sao lưu & Dữ liệu** (`key="data"`, icon `<DatabaseOutlined />`): Contains data management cards.
- Default active tab: `'capacity'`. Retains query-based deep link if provided (`/#/settings?tab=data`).

### 2. Backup Export Card (`src/components/settings/BackupExportCard.tsx`)
- Surface: Ant Design `Card` with header `<CloudDownloadOutlined /> Sao lưu dữ liệu`.
- Description: Informative paragraph explaining that backup includes the 6 core business tables (`projects`, `milestones`, `tasks`, `capacityRules`, `capacityOverrides`, `plannedAllocations`) while preserving local device UI preferences.
- Metadata Status:
  - Displays last export timestamp from `backupMetadata` table: e.g., `Lần sao lưu gần nhất: 14:30 27/09/2026 (48 bản ghi)` or `Chưa có lịch sử sao lưu`.
- Action Trigger: Primary `Button` (`type="primary"`, icon `<DownloadOutlined />`, label `Xuất bản sao lưu (JSON)`).
- Interaction Contract:
  1. User clicks `Xuất bản sao lưu (JSON)`.
  2. Button enters loading state (`loading={true}`).
  3. Headless backup service queries all 6 domain tables and constructs standard envelope (D-01, D-02).
  4. Triggers browser file download using filename convention `task-planner-backup-YYYY-MM-DD-HHmmss.json` (D-03).
  5. Inserts log into `backupMetadata` (D-04).
  6. Displays `notification.success` ("Đã tải tệp sao lưu về máy").
  7. Screen reader region announces completion. Button loading state released.

### 3. Backup Import Card (`src/components/settings/BackupImportCard.tsx`)
- Surface: Ant Design `Card` with header `<CloudUploadOutlined /> Nhập & Khôi phục dữ liệu`.
- Subtitle: Clear instruction about replacing current data and automatic snapshot protection.
- Dropzone: Ant Design `Upload.Dragger` configured with:
  - `accept=".json,application/json"`
  - `multiple={false}`
  - `showUploadList={false}`
  - File size check: Rejects files > 50MB before parsing with explicit error message.
- Content inside Dragger:
  - Inbox icon (`<InboxOutlined style={{ fontSize: 36, color: '#1677ff' }} />`)
  - Primary text: `Nhấp hoặc kéo thả tệp sao lưu JSON vào khu vực này`
  - Secondary hint: `Chỉ chấp nhận tệp .json tối đa 50MB xuất từ Personal Task Planner`
  - Explicit action button: `Chọn tệp sao lưu` (`<FileSearchOutlined />`)
- Interaction Contract:
  1. User selects or drops file.
  2. Dragger reads file as text asynchronously using `FileReader`.
  3. JSON parses text; if syntax error occurs, displays error `notification.error` ("Tệp chứa định dạng JSON không hợp lệ") without opening preview modal.
  4. File is passed to `ImportPreviewModal` which runs headless validation.

### 4. Import Preview & Confirmation Modal (`src/components/settings/ImportPreviewModal.tsx`)
- Container: Ant Design `Modal`, `width: 720px`, `centered: true`, mask non-dismissable (`maskClosable={false}`).
- Header: Title `Xem trước & Khôi phục dữ liệu`.
- File Envelope Metadata Section:
  - Clean card/tag summary displaying:
    - App marker badge: `personal-task-planner` (Green tag if match, Red error tag if mismatch).
    - Schema version: `v{schemaVersion}`.
    - Export timestamp: Formatted date-time (`DD/MM/YYYY HH:mm:ss`).
    - File size: Formatted KB/MB.
- Comparison Table:
  - Ant Design `Table` (`size="small"`, `pagination={false}`).
  - Columns:
    1. `Bảng dữ liệu` (Vietnamese table name + technical key in muted text).
    2. `Hiện tại trong máy` (Current local Dexie count).
    3. `Tệp nhập vào` (Incoming file count from envelope/records).
    4. `Chênh lệch` (Delta badge: Green `+X`, Red `-X`, Grey `=0`).
  - Rows for the 6 domain tables:
    - Dự án (`projects`)
    - Cột mốc (`milestones`)
    - Tác vụ (`tasks`)
    - Quy tắc công suất tuần (`capacityRules`)
    - Ngoại lệ ngày (`capacityOverrides`)
    - Phân bổ kế hoạch (`plannedAllocations`)
  - Summary row: `Tổng cộng` records current vs incoming vs net delta.
- Validation Check State:
  - **State A (Valid)**:
    - Displays `Alert` (`type="warning"`, `showIcon`): Explains replacement of local data and automatic snapshot creation.
    - Confirmation prompt: Text `Nhập "RESTORE" để xác nhận:`.
    - Input field: `Input` (`placeholder="RESTORE"`, value controlled, autoFocus).
    - Modal Footer:
      - `Button` `Hủy` (closes modal, resets file).
      - `Button` `Xác nhận khôi phục` (`type="primary"`, `danger={true}`, disabled unless input strictly equals `'RESTORE'`).
  - **State B (Invalid / Corrupted)**:
    - Displays `Alert` (`type="error"`, `showIcon`): Explains validation failure and that local database remains unchanged.
    - Error details container: Max-height 200px scrollable table/list showing:
      - `[Vị trí]` (Table name / Record ID)
      - `[Trường lỗi]` (Field name)
      - `[Mô tả]` (Zod error or foreign key missing error)
    - Modal Footer:
      - Single `Button` `Đóng` (closes modal). Confirm button completely hidden or disabled.
- Execution Contract:
  1. User enters `RESTORE` and clicks `Xác nhận khôi phục`.
  2. Button enters loading state. Modal controls disabled.
  3. Single atomic Dexie readwrite transaction opens:
     - Reads current 6 domain tables and saves snapshot to `settings` (`last_pre_import_snapshot`) + logs to `backupMetadata`.
     - Clears 6 domain tables (`db.projects.clear()`, etc.).
     - Bulk adds incoming records (`db.projects.bulkAdd(...)`, etc.).
  4. If transaction succeeds:
     - Modal closes.
     - `useLiveQuery` automatically triggers UI refresh across all views.
     - `notification.success` appears with total imported count.
     - Screen reader announces completion.
     - Global Post-Restore Banner appears at top of screen with snapshot rollback CTA.
  5. If transaction fails:
     - Dexie automatically aborts; local data intact.
     - Displays error alert with error message. Modal stays open or displays error.

### 5. Snapshot Rollback Card (`src/components/settings/SnapshotRollbackCard.tsx`)
- Surface: Ant Design `Card` with header `<HistoryOutlined /> Bản sao lưu an toàn gần nhất (Snapshot)`.
- Content:
  - If snapshot exists in `settings`:
    - Information block:
      - `Thời điểm tạo`: Formatted date-time.
      - `Tổng số bản ghi`: Total records preserved in snapshot.
      - Breakdown tags: Projects count, Tasks count, Allocations count.
    - Actions:
      - `Button` `Khôi phục từ bản an toàn này` (`danger`, opens confirmation dialog).
      - `Button` `Tải bản snapshot về máy` (downloads JSON file `task-planner-snapshot-YYYY-MM-DD-HHmmss.json`).
  - If no snapshot exists:
    - Ant Design `Empty` state with compact image and text `Chưa có bản snapshot an toàn`.
    - Subtitle: `Bản snapshot an toàn sẽ tự động được tạo trước mỗi lần khôi phục hoặc thay thế dữ liệu.`
- Rollback Confirmation:
  - Uses standard Ant Design `Modal.confirm`:
    - Title: `Xác nhận hoàn tác về bản snapshot?`
    - Content: `Thao tác này sẽ thay thế dữ liệu hiện tại bằng bản dữ liệu được lưu trước lần khôi phục gần nhất ({snapshotTime}).`
    - `okText`: `Hoàn tác dữ liệu` (`okButtonProps={{ danger: true }}`)
    - `cancelText`: `Hủy`
  - On confirm: Restores snapshot atomically, announces via screen reader, updates view reactively.

### 6. Accessible Screen Reader Status Region (`src/components/common/AriaLiveRegion.tsx`)
- Container: Off-screen visually hidden container placed in `AppShell` root:
  - Style: `position: 'absolute', width: 1, height: 1, padding: 0, margin: -1, overflow: 'hidden', clip: 'rect(0, 0, 0, 0)', whiteSpace: 'nowrap', border: 0`
  - Attributes: `role="status"`, `aria-live="polite"`, `aria-atomic="true"`
- Hook/Service: `useAriaAnnounce()` or event dispatcher emitting status announcements for all async operations (exporting, validating, importing, rolling back).
