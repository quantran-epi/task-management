<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| IndexedDB → Export Payload | Local database tables serialized to user-downloaded JSON file |
| Component → Browser DOM Download | Blob URL generated and clicked to prompt browser download |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-01 | Information Disclosure | `exportBackupPayload` | mitigate | Explicitly query only the 6 core business domain tables (`projects`, `milestones`, `tasks`, `capacityRules`, `capacityOverrides`, `plannedAllocations`). Exclude `settings` table (which may contain theme preferences, device tokens, or session secrets) and `backupMetadata`. |
| T-06-02 | Denial of Service | `triggerDownload` | mitigate | Stream payload via standard browser Blob and revoke object URL immediately after synthetic anchor click to prevent browser memory leaks. |
| T-06-SC | Tampering | npm packages | mitigate | Zero new dependencies installed; audit confirms existing core packages (`antd`, `dexie`, `zod`, `dayjs`) are trusted and approved. |
</threat_model>
