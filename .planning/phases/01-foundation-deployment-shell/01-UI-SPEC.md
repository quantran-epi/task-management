## Visual Hierarchy & Focal Point

| Layout Context | Focal Anchor | Visual Weight |
|----------------|--------------|---------------|
| Desktop Shell | Header title + Active Route Segment | Medium weight, high contrast |
| Sider Navigation | Active Menu Item (Accent #1677ff background tint) | Primary interaction anchor |
| Notification Bar | Service worker update alert ("Reload Page") | Top-level high-visibility focal banner |
| Mobile Shell | Collapsed header bar + Hamburger trigger | Compact 44px min touch anchor |

---

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge padding, compact inline tag margins |
| sm | 8px | Button inline gaps, input padding, list item compact margin |
| md | 16px | Default content padding, card body margin, standard form item gap |
| lg | 24px | Section padding, container outer margins on desktop |
| xl | 32px | Major layout gaps, header-to-content separation |
| 2xl | 48px | Drawer top offsets, modal vertical gutters |
| 3xl | 64px | Page-level spacing, full-viewport empty state vertical center |

Exceptions:
- Mobile touch targets: minimum 44px height for header toggle buttons and drawer navigation links (accessibility baseline).

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | #ffffff (Dark: #141414) | Page background, shell content surface, drawer canvas |
| Secondary (30%) | #f5f5f5 (Dark: #1f1f1f) | Sider background, header surface, card background, modal surface |
| Accent (10%) | #1677ff | Active nav link indicator, primary modal action ("Reload"), input focus border |
| Destructive | #ff4d4f | Database reset modal confirmation action, fatal error states |

Accent reserved for:
- Primary CTA action button ("Reload Page")
- Active sidebar navigation item highlight indicator
- Form input focus border and focus ring
- Active tab / active route badge indicator

Status colors:
- Success (Online): #52c41a (Header network status badge dot)
- Warning (Offline): #faad14 (Header network status badge dot)
- Destructive: #ff4d4f (Database reset modal trigger and confirmation button)
