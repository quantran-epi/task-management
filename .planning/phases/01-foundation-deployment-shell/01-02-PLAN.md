## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser Hash URL → Application Route | Untrusted URL fragment parsed into application navigation state |
| User Input → Reset Action | Text input driving destructive database reset |
| Multi-Tab IndexedDB Version Conflict | Competing tab connections initiating incompatible schema migrations |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|

| T-01-04 | Denial of Service | src/components/shell/UpgradeModal.tsx | mitigate | Listen to db-upgrade-blocked and db-version-changed events, display blocking modal and offer reload CTA |
| T-01-05 | Spoofing / Tampering | src/hooks/useHashRoute.ts | mitigate | Sanitize hash input against explicit route whitelist ('tasks', 'projects', 'planner', 'settings') with safe fallback |
