## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Local Codebase → GitHub Actions Runner | CI/CD automation executing build and test commands |
| Build Pipeline → GitHub Pages CDN | Static artifacts published to public CDN hosting |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-06 | Elevation of Privilege | .github/workflows/deploy.yml | mitigate | Grant least-privilege workflow permissions (contents: read, pages: write, id-token: write) and use official pinned GitHub actions |
| T-01-07 | Information Disclosure | dist/ bundle | mitigate | Client bundle is strictly static with zero environment variables, API secrets, or private keys included |
| T-01-SC | Tampering | npm dependencies in CI | mitigate | Use npm ci in workflow to guarantee reproducible dependency installation matching package-lock.json |
</threat_model>
