## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client Code → IndexedDB Storage | Local in-browser storage layer receiving entity models and schema updates |
| Runtime Input → Date & ID Utilities | Untrusted strings passing into date validation and UUID helpers |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Tampering | src/utils/date.ts | mitigate | Strict regex check ^\d{4}-\d{2}-\d{2}$ and dayjs strict parsing to prevent timezone-shifted date strings entering storage |
| T-01-02 | Denial of Service | src/db/seeds.ts | mitigate | Wrap database purge and reseed inside a single atomic Dexie readwrite transaction across all tables |
| T-01-SC | Tampering | npm dependencies | mitigate | All packages verified through registry audit table with [OK] disposition and clean postinstall scripts |
</threat_model>
