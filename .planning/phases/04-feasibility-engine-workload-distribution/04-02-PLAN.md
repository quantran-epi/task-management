## Phase Goal

**As a** solo planner, **I want to** evaluate task estimates against capacity and preview deterministic lowest-load distributions, **so that** I know before scheduling whether my work fits available time and can commit allocations with one click.

<objective>
Build the interactive user review interface and modal container for task feasibility and workload distribution. The modal houses parameter controls (dual range mode, strategy selector, daily cap), feasibility status banners with surplus/deficit and earliest feasible date shortcuts, an interactive candidate review table allowing 15-minute adjustments, and a collapsible date breakdown panel. Proposed allocations stay strictly in memory until explicit confirmation, at which point an atomic Dexie transaction merges them into IndexedDB.

Purpose: Deliver the core interactive review workflow (CALC-06, CALC-03, CALC-04, CALC-05) satisfying the UI Design Contract and security constraints.
Output: `CandidateAllocationsTable.tsx`, `DateInspectionBreakdown.tsx`, `FeasibilityModal.tsx`, `FeasibilityModal.test.tsx`.
</objective>
