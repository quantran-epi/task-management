<objective>
Switch every live client surface to the query-only wire contract while proving that existing AI-engine flows keep working unchanged.

Purpose: after 28-01 the server accepts query-only requests, but three independent client gates still block a fresh device — the strict mirrored schema, the `groundedTurn` empty-scope `clarify_intent` branch, and `fetchSetCatalog`-derived IDs in the tool, drawer and Telegram. Fixing only one leaves the other surfaces broken. Equally, changing these seams risk breaking offline local fallback, MCP merge and genuine intent clarification, so each preserved behavior gets its own regression test.

Output: mirrored wire schema, catalog-free default retrieval in grounded/drawer/Telegram paths, attributed tool JSON, and regression-proof preservation of existing flows.

Per D-01, D-05, D-06, D-07, D-08.

Non-regression contract (absolute): the existing grounded-turn routing flags, MCP merge branch, local BM25 fallback with its local-only label, error taxonomy and existing copy must remain unchanged. The only behavior changes allowed are (a) a server-enabled default request no longer requires a non-empty local scope, (b) the wire body uses the thin shape, and (c) the tool adds attribution fields while keeping every previous key.
</objective>
