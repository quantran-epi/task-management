<objective>
Make the trust guarantees real for query-only requests: bounded budgets that actually bound, per-set coverage attribution that distinguishes contribution from silence from failure, and citation/path identity that survives packing and rendering across multiple sets and snapshots.

Purpose: query-only federates over an unknown number of sets, so every previously latent aggregation defect becomes a live correctness problem — a queued set can outlive the deadline, one oversized chunk can defeat the character budget, all-failed looks like empty success, identical document ranges in two snapshots collapse into one citation, and an orphan path can reach the client. Each is a D-03/D-04/D-09/D-11 violation once retrieval is federated by default.

Output: deadline-aware scheduling, a populated coverage ledger, truthful no-success outcomes, server-side federated path closure, snapshot-aware client dedupe, and citation inspection that works with no local document.

Per D-03, D-04, D-08, D-09, D-10, D-11.
</objective>
