    - Test 2: tokenize extracts alpha-numeric word tokens with length > 1, stripping punctuation
    - Test 3: rankBM25 returns empty array when query is empty or doc list is empty
    - Test 4: rankBM25 ranks documents matching in Title higher than documents matching only in Body due to Title x3 weighting
    - Test 5: rankBM25 ranks documents matching in Tags higher than documents matching only in Body due to Tags x2 weighting
    - Test 6: rankBM25 matches non-diacritic query terms to documents containing diacritics ('bao cao' matches 'Báo cáo')

  </behavior>
  <action>
    1. Create `src/utils/bm25.ts` containing:
       - `normalizeVietnamese(text: string): string` using Unicode NFD decomposition: `text.normalize('NFD').replace(/[̀-ͯ]/g, '').replace(/đ/g, 'd').replace(/Đ/g, 'D').toLowerCase().trim()`
       - `tokenize(text: string): string[]` splitting on `/[^a-z0-9_]+/i` and filtering tokens of length > 1.
       - Interface `BM25Document`: `{ id: string; title: string; tags: string[]; body: string; updatedAt?: string; }`
       - Interface `BM25ScoredResult`: `{ doc: BM25Document; score: number; matchedTerms: string[]; }`
       - `rankBM25(query: string, docs: BM25Document[], options?: { k1?: number; b?: number; limit?: number }): BM25ScoredResult[]`:
         * Field weighting per D-10: Title tokens replicated 3x, Tag tokens replicated 2x, Body tokens replicated 1x.
         * Calculate doc length with weighted tokens.
         * Calculate inverse document frequency: `IDF = Math.log((N - df + 0.5) / (df + 0.5) + 1)`.
         * Compute Okapi BM25 score per term and sum across query tokens.
         * Filter results with `score > 0` and sort descending by score.
       - `extractRelevantSnippet(body: string, query: string, maxChars = 1500): string` per D-11:
         * Find first paragraph or heading containing the most query terms.
         * Include heading context plus preceding and succeeding lines.
         * Truncate safely at word boundary if exceeding `maxChars`.
    2. Create `tests/utils/bm25.test.ts` covering normalization, tokenization, field weighting, Vietnamese tolerance, snippet extraction, and edge cases.
  </action>
