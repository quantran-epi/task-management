| Boundary | Description |
|----------|-------------|
| External Markdown Paste → Regex Parser | Untrusted strings from Claude/ChatGPT/Obsidian parsed for hashtags and headings |
| Wiki-link token → Rendered HTML Chip | Dynamic entity IDs and labels injected into document preview |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-14-03 | Tampering / XSS | `src/utils/markdown.ts` | mitigate | Strict `escapeHtml` applied to wiki-link display labels and attributes; reject non-alphanumeric entity IDs. |
| T-14-04 | Denial of Service | `src/utils/smartIngestion.ts` | mitigate | Avoid polynomial regular expressions (ReDoS); use simple token loops with bounded input slice length for title and tag extraction. |
| T-14-SC | Tampering | npm dependencies | mitigate | Zero new npm packages added; builds on top of existing project utilities and regex primitives. |
</threat_model>
