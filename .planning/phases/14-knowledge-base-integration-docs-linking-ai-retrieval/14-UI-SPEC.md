## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, tag inline padding, metadata badge padding |
| sm | 8px | Compact element spacing, tree node indent, toolbar action gaps |
| md | 16px | Default element spacing, card padding, editor gutter, doc list item gap |
| lg | 24px | Section padding, drawer content spacing, modal body padding |
| xl | 32px | Layout column gaps, document header separator |
| 2xl | 48px | Major section breaks, empty state padding |
| 3xl | 64px | Page-level boundary padding |

Exceptions:
- Mobile touch targets: minimum 44px height for icon-only action buttons.
- Form controls: 36px standard `controlHeight` matching existing Ant Design theme configuration.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#ffffff` (Light) / `#141414` (Dark) | Primary canvas, document editor surface, reader pane, preview drawer background |
| Secondary (30%) | `#fafafa` (Light) / `#1f1f1f` (Dark) | 3-column navigation sidebar (folder tree), doc list middle column, card containers, table headers |
| Accent (10%) | `#4f46e5` | Interactive highlights reserved strictly for items declared below |
| Destructive | `#ff4d4f` | Delete document, Move to Trash, Permanent Delete, Unlink confirmation |

Accent reserved for:
1. Primary action buttons: "Tạo tài liệu", "Lưu thay đổi", "Áp dụng tất cả"
2. Active folder and tag selection indicators in the navigation tree
3. Selected document card border and background tint in the middle Doc List
4. Interactive Wiki-link chips `[[...]]` and Clickable Citation Chips `[📄 ...]`
5. Active tab bar indicators in NotesView, TaskDrawer, and ProjectsView

Semantic Colors:
- Warning (`#faad14`): Backlink impact alert banner, unsaved draft indicator
- Success (`#52c41a`): Auto-save synced indicator, 1-Click link application confirmation
- Muted Text (`#8c8c8c`): Metadata labels, dates, character counts, backlink counts

## Component Layout & Interaction Contracts

### 1. 3-Column Docs View (`NotesView.tsx`)
- **Column 1: Navigation & Folders (~220px, collapsible)**
  - Top action: "Tạo tài liệu" (Primary button) + "+" quick folder button.
  - Section 1 (Quick Filters): Inbox (Hộp thư), Pinned (Đã ghim), All Docs (Tất cả tài liệu), Sticky Notes (Ghi chú nhanh), Trash (Thùng rác).
  - Section 2 (Folder Tree): Ant Design `Tree` component supporting drag-and-drop hierarchy, badge with document count.
  - Section 3 (Tags): Tag cloud / list with search, filtered on click.
- **Column 2: Document List (~300px, resizable 260-400px)**
  - Header: Search input with instant debounce (200ms) + Sort dropdown (Thời gian cập nhật, Tiêu đề, Ngày tạo).
  - List items: Card-style rows with Title (14px semibold), preview snippet (12px muted, 2 lines max), tag chips (12px), relative updated timestamp.
  - Selected state: Border left 3px `#4f46e5`, light background tint (`#f0f2ff` / `#1a2035`).
- **Column 3: Editor / Reader Main Content (Flex: 1)**
  - Top Toolbar: View switcher (Chỉnh sửa / Xem trước / Song song), Fullscreen button, Popout window button, "Hỏi AI về tài liệu" button, More options dropdown (Di chuyển, Nhân bản, Thùng rác).
  - Smart Ingestion Banner: Positioned at top of editor when external Markdown is pasted.
  - Editor area: Split view with synced scroll or single tab preview.
  - Outline (ToC): Collapsible right rail or floating popover showing H1/H2/H3 headings with smooth scroll navigation.
  - Footer: Word/character count, auto-save status indicator ("Đã lưu lúc HH:mm:ss"), Backlinks section.

### 2. Smart Ingestion Flow & Link Suggestions
- **Paste Detection:**
  - Auto-extracts first `# Heading 1` as document title if title is untitled.
  - Detects inline `#hashtags` and suggests adding them to document tags.
- **Suggestion Banner ("💡 Gợi ý liên kết liên quan"):**
  - Surface: Ant Design `Alert` (banner style) with info theme.
  - Content: List of detected entities (Task key/title, Project name, Milestone name).
  - Checkbox per item to include/exclude.
  - Primary button: "Áp dụng tất cả" (Applies 2-way links in 1 click).
  - Dismiss button: "Bỏ qua".

### 3. Wiki-link & Citation Chips
- **Autocomplete Trigger:** Typing `[[` inside editor opens inline popup with tabs (Tất cả, Tài liệu, Tác vụ, Dự án).
- **Rendered Format:**
  - Doc link: `[[doc:id|Title]]` renders as `📄 [Title]` pill chip. Click opens document in viewer.
  - Task link: `[[task:id|Title]]` renders as `✅ [Title]` pill chip. Click opens `TaskDrawer`.
  - Project link: `[[project:id|Title]]` renders as `📁 [Title]` pill chip. Click opens project view.
- **AI Citation Chip:** `[📄 {DocTitle} §{Heading}]` rendered inside AI chat messages. Hover shows preview tooltip; click slides out `QuickPreviewDrawer`.

### 4. Quick Preview Drawer (`QuickPreviewDrawer.tsx`)
- Slide-out drawer on the right side (`width: 480px`, `zIndex: 1100`).
- Allows reading referenced documents directly from `TaskDrawer`, `ProjectsView`, or AI Chat citations without losing primary workflow context.
- Header: Document title, "Mở trong Docs" button (navigates to full NotesView), Close button.
- Body: Rendered Markdown viewer with syntax-highlighted code blocks and clickable inner links.

### 5. Backlinks Footer ("🔗 Được liên kết từ")
- Placed at the bottom of the document viewer.
- Displays accordion or card list of referencing entities:
  - Tác vụ (Tasks) referencing this doc via `[[doc:...]]` or entity link.
  - Dự án (Projects) referencing this doc.
- Click on any item immediately navigates to or inspects the entity.
