## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User UI → Validation Schemas | User inputs (hours, minutes, dates, notes) enter domain model |
| Domain Repository → IndexedDB | Validated capacity rules and overrides persist to Dexie |
| Date Resolver → Calendar Math | Date calculations determine weekday without timezone offset corruption |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering | CapacityRuleInputSchema / CapacityOverrideInputSchema | mitigate | Validate bounded integer minutes (0-1440), reject negative numbers and non-integers, validate canonical YYYY-MM-DD format using isValidCalendarDate |
| T-03-02 | Denial of Service | OverridesTable | mitigate | Limit note strings to 200 characters, bound date overrides table pagination, prevent memory bloat |
| T-03-03 | Information Disclosure / Drift | getEffectiveDailyCapacity | mitigate | Keep all dates as canonical YYYY-MM-DD strings; extract dayOfWeek via Dayjs UTC or ISO week parser to prevent timezone shifts across midnight |
| T-03-SC | Tampering | npm packages | mitigate | Zero new npm packages installed; all dependencies already approved in standard stack |
</threat_model>
