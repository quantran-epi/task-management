## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL Hash Route → App Router | Route navigation between tasks, projects, planner, settings |
| User Date Navigation → ISO Week Math | Week shifting across month/year boundaries without date corruption |
| Day Column Rendering → Accessible DOM | Load indicators must satisfy WCAG 2.1 AA dual-encoding |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-03 | Information Disclosure / Drift | WeekNavigator / ISO Week Math | mitigate | Strictly use dayjs.startOf('isoWeek') and canonical YYYY-MM-DD strings; avoid local Date timezone shifts |
| T-03-04 | Denial of Service | PlannerView / useWeeklyPlanner | mitigate | Limit weekly query to 7 calendar dates [weekStart, weekEnd]; batch-fetch task entities by ID to avoid N+1 queries |
| T-03-05 | Accessibility / Compliance | DayColumnHeader | mitigate | Enforce dual-encoding (icon + text + color) on all 4 load states so colorblind users can distinguish states (WCAG 2.1 AA) |
| T-03-SC | Tampering | npm dependencies | mitigate | Zero external package additions; native Web Crypto and existing libraries used exclusively |
</threat_model>
