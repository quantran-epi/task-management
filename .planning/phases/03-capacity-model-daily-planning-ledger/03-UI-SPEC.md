## Component Layout & Interactions

### 1. Planner View (`/#/planner`)

#### Navigation Toolbar
- **Week Navigator**:
  - `Button` icon `<LeftOutlined />` ("Previous Week")
  - `Button` label "Today" (sets view to current calendar week)
  - `Button` icon `<RightOutlined />` ("Next Week")
  - `DatePicker` picker="week" showing selected week range (e.g. `2026-W39: Sep 21 - Sep 27, 2026`)
- **View Controls**:
  - `Switch` label "Show Completed" (default: `false`). When `true`, shows Done/Cancelled tasks with 50% opacity and strikethrough styling.
  - `Button` icon `<SettingOutlined />` label "Capacity Settings" (opens Capacity Settings Modal).

#### Weekly Grid Board
- 7 day columns (Monday through Sunday) formatted side-by-side on desktop (min-width per column: 140px, scrollable horizontally if viewport < 1100px); stacked vertically into single-column cards on mobile (< 768px).
- **Day Column Header**:
  - Top row: Day of week name (e.g., "Monday") [Heading: 16px 600], Date string (e.g., "Sep 21") [Body: 14px 400].
  - Current calendar day highlighted with `token.colorPrimary` accent border or pill.
  - Status Tag: Available (green), Busy (orange), Overloaded (red), No Capacity (grey). Displays icon + text.
  - Context Switching Warning Tag: Appears when allocated task count > 4 (`WarningOutlined` "5 tasks").
  - Metrics row:
    - `Capacity: {capacityHours}h {capacityMinutes}m` (clickable Popover to quickly add/edit date override)
    - `Allocated: {allocatedHours}h {allocatedMinutes}m`
    - `Balance: +{remHours}h {remMinutes}m` (green text) or `Balance: -{overHours}h {overMinutes}m` (red text)
  - Accessible Load Progress Bar:
    - Ant Design `Progress` component percent calculated as `Math.min(100, Math.round((allocated / capacity) * 100))`.
    - Status color mapped to load state (`success` for <80%, `warning` for 80-100%, `exception` for >100%).
- **Day Column Body**:
  - Vertical list of task allocation cards.
  - Card elements:
    - Task title [Body: 14px 600, truncate with tooltip].
    - Project / Milestone tag [Label: 12px 400].
    - Planned duration badge: `{hours}h {minutes}m` [Label: 12px 600].
    - Status dot / InlineStatusTag.
    - Quick actions on hover / focus: Edit duration (inline Popover), Move date (inline DatePicker), Delete allocation (`DeleteOutlined` with Popconfirm).
  - Empty state when 0 tasks allocated: displays subtle grey dashed placeholder with "No tasks allocated".
- **Day Column Footer**:
  - Compact button: `+ Allocate` spanning column width. Opens Allocation Modal / Popover pre-filled with this column's date.

### 2. Task Allocation Modal / Popover (`+ Allocate`)
- Triggered from Day Column footer button OR TaskDrawer Planning tab.
- Form fields:
  - **Task Select**: Searchable `Select` dropdown listing active tasks (Open, In Progress, In Review, Resolved). Shows task name, priority tag, and `Est: Xh Ym | Alloc: Zh Wm`.
  - **Date**: `DatePicker` default to selected column's date.
  - **Hours & Minutes**: Dual `InputNumber` controls: Hours (0-24, step 1), Minutes (0-59, step 15 quick steppers).
  - **Estimate vs Allocation Preview**:
    - Displays `Total Allocated: {currentAlloc + newAlloc} / Estimate: {taskEstimate}`.
    - Shows alert if exceeding estimate: `Allocated time exceeds estimate by {surplus}` (warning style, non-blocking).
- Primary button: "Record Allocation"
- Cancel button: "Discard Allocation"

### 3. Capacity Settings View (`/#/settings`) & Modal
- **Section 1: Weekly Base Capacity Template**:
  - Grid / Form of 7 weekdays (Monday through Sunday).
  - For each day:
    - Weekday label [Heading: 16px 600].
    - Paired inputs: `InputNumber` Hours (0-24) + `InputNumber` Minutes (0-59).
    - Quick preset button group: `0h` (off), `4h` (half), `8h` (full).
    - Live computed weekly total: `Total weekly capacity: Xh Ym`.
- **Section 2: Date-Specific Overrides**:
  - Button: `+ Add Override` (opens inline drawer or popover with Date, Hours, Minutes, and Note).
  - Interactive Table:
    - Columns: Date (`YYYY-MM-DD`), Day of Week, Override Capacity (`Xh Ym`), Note (e.g., "National Holiday", "Vacation", "Overtime"), Actions.
    - Action: `Popconfirm` with "Reset to Default" / Delete.
- **Section 3: Planning Preferences**:
  - `InputNumber` "High Context Switching Threshold" (default: 4 tasks/day, range: 1-20).

### 4. TaskDrawer Planning Tab (`/#/tasks` integration)
- Embedded section inside `TaskDrawer.tsx`:
  - Summary row: `Estimate: {estHours}h {estMinutes}m` | `Total Allocated: {allocHours}h {allocMinutes}m` | `Remaining: {remHours}h {remMinutes}m`.
  - Mini allocation table listing existing allocations:
    - Columns: Date, Planned Time (`Xh Ym`), Day Load Status, Action (`DeleteOutlined`).
  - Inline row to quickly add allocation: DatePicker + Hours + Minutes + `+ Add Allocation` button.
