## UAT Contract — 6 luồng × Light/Dark Parity (ADOPT-03)

Quan sát được trên **Chrome thật** (DevTools tay) + **Playwright smoke** lặp lại được. Không chấp nhận "đọc code" hay "build xanh" làm bằng chứng (50 D-12, C-15). Thêm spec Playwright cho 6 luồng vào `e2e/*.spec.ts` (dùng `playwright.config.ts` hiện có).

| # | Luồng | Bề mặt | Kiểm tra parity light/dark |
|---|-------|--------|----------------------------|
| U1 | Task quick-add | tasks/planner | Input/Button/Tag: height 30, font 13, radius 4; accent chỉ ở primary Button; focus ring 2px đúng token |
| U2 | Settings CRUD | settings | Form/Input/Select/Drawer/Modal: error/disabled state, footer policy, width scale; không control nào lệch màu/font/size giữa 2 theme |
| U3 | CR detail actions | CR/notes | StatusTag/Badge map màu trạng thái đúng `statusColorMap`; action Button loading/danger |
| U4 | Modal forms | CR/notes + mọi nơi | `useTaskMateModal()` footer/close/mask; `message.*` qua hook hiện đúng vị trí; không `Modal.confirm` tĩnh |
| U5 | Toolbar icon buttons | shell/tool windows | IconButton có accessible name (`aria-label`), size mặc định; tree row/chip selected đúng `--accent-soft`; resize handle hover |
| U6 | AI chat controls | AI Office/chat | Composer/controls + notification hook; toggle theme đổi tức thì không reload, giữ lựa chọn user |

**Parity rule (SC4):** cùng một control ở hai theme **chỉ khác giá trị token** — không control nào lệch color/font/size/spacing. Mọi phát hiện lệch là defect, ghi vào `50-UAT.md` kèm cách sửa.

**Accessibility preservation (SC3):** trên mọi control thuộc 6 luồng, quan sát và ghi trạng thái:
- **Focus**: focus ring 2px đúng token, tab order không bị migration làm đứt.
- **Keyboard nav**: Tab/Shift+Tab, Enter activate, Escape đóng overlay vẫn hoạt động.
- **Accessible name**: mọi IconButton có `aria-label`; control không tên phải được bổ sung qua wrapper, không sửa tại view bằng inline.

## Copywriting Contract

Phase 50 **không thêm copy mới**. Migration phải giữ nguyên toàn bộ copy tiếng Việt hiện có (xưng "sếp"; identifier/command giữ nguyên hình thức gốc — CLAUDE.md). Đây là interaction contract: chuyển API tĩnh → hook không được đổi nội dung thông báo/xác nhận.

| Element | Copy |
|---------|------|
| Primary CTA | Không có CTA mới; giữ nguyên mọi CTA hiện hữu. |
| Empty / Error state | Giữ nguyên copy hiện có của từng tính năng; không thêm/sửa. |
| Notification/modal copy | `message.*`, `notification.*`, `Modal.confirm` → hook: **giữ byte-for-byte** nội dung tiếng Việt; chỉ đổi cơ chế gọi. |
| Destructive confirmation | Giữ nguyên copy xác nhận của từng tính năng; wrapper Modal/Popconfirm chỉ áp policy (footer/close/mask), không sửa chữ. |
