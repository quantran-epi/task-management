  <name>Task 1: Add remote repository convention candidate probing and loading in conventionService</name>
  <files>src/services/conventionService.ts</files>
  <behavior>
    - Probe candidate paths in order: 'CONVENTIONS.md', '.github/CONVENTIONS.md', 'docs/CONVENTIONS.md' (per D-05)
    - If project has no SSH binding or invalid config, return null without throwing (per D-08)
    - If candidate file exists, read its full content via readRemoteFile and return { content, foundPath, loadedAt } (per D-06, D-07)
    - If no candidate exists (exitStatus !== 0), return null gracefully (per D-08)
    - If SSH execution throws or disconnects, catch error, log warning, and return null (per D-08)
  </behavior>
  <action>
    Update `src/services/conventionService.ts`:
    - Define and export `CONVENTION_CANDIDATE_PATHS = ['CONVENTIONS.md', '.github/CONVENTIONS.md', 'docs/CONVENTIONS.md'] as const;` (per D-05).
    - Define and export `interface RepoConventionResult { content: string; foundPath: string; loadedAt: string; }`.
    - Implement `loadRepoConventions(projectId: string, db = defaultDb): Promise<RepoConventionResult | null>`:
      1. Check `isTauriApp()`. If false (web browser context), return `null` immediately.
      2. Call `getProjectRepoSshBinding(projectId, db)`. If missing or incomplete (`!sshConfigId || !remoteRepoPath`), return `null`.
      3. Call `getSshConfigById(binding.sshConfigId, db)`. If not found, return `null`.
      4. Call `getSshSecret(config.id)`.
      5. Construct single-roundtrip probe shell script using `test -f`:
         `for p in CONVENTIONS.md .github/CONVENTIONS.md docs/CONVENTIONS.md; do if [ -f "${binding.remoteRepoPath}/$p" ]; then echo "$p"; exit 0; fi; done; exit 1`
         Execute via `execRemoteCommand(config, probeCmd, secret ?? undefined)`.
      6. If probe exitStatus !== 0 or stdout is empty, return `null`.
      7. Extract first line of stdout as `foundPath`. Construct full remote path: `${binding.remoteRepoPath.replace(/\/+$/, '')}/${foundPath}`.
      8. Call `readRemoteFile(config, fullPath, secret ?? undefined)` to get full content (per D-12: no truncation).
      9. Return `{ content, foundPath, loadedAt: new Date().toISOString() }`.
      10. Wrap in try/catch: on any network/SSH failure, console.warn and return `null` (strictly honoring D-08 graceful degradation).
  </action>
  <verify>
    <automated>npx vitest run tests/services/conventionService.test.ts</automated>
  </verify>
  <done>conventionService exports CONVENTION_CANDIDATE_PATHS and loadRepoConventions with robust probe and error handling.</done>

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-31-04 | Remote Code Execution | `execRemoteCommand` probe command | mitigate | Candidate paths are statically hardcoded array literals; remoteRepoPath is trimmed and quoted safely |
| T-31-05 | Denial of Service | `readRemoteFile` loading large files | mitigate | Desktop SSH file reader has native size limit safeguards; read is read-only without modifying remote worktree |
| T-31-06 | Information Disclosure | SSH secret credential handling | mitigate | Secrets retrieved exclusively via native keyring (`getSshSecret`) and never logged or written to storage |
</threat_model>
