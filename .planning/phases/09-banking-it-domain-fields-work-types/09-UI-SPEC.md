# Phase 9 — UI Design Contract

> Visual and interaction contract for Banking IT domain fields (Ops Owner / BA tags), inheritance display, and 7-value work type badges. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

## Design System

| Property | Value |
|----------|-------|
| Tool | none (Ant Design 6 is the fixed UI system per CLAUDE.md; shadcn/tailwind not used and new UI libs are forbidden) |

**Theme source of truth:** `src/App.tsx` `ConfigProvider` with `token.colorPrimary = '#1677ff'` and `algorithm` switching `defaultAlgorithm` / `darkAlgorithm` via `useThemeMode()` (system `prefers-color-scheme`). All colors below MUST read from `theme.useToken()` at runtime — never hardcode hex except the categorical work-type palette (Ant preset color names). Dark mode is a first-class requirement (CR-01 precedent).

**Reuse mandates (from CONTEXT.md `code_context`):**
- Clone `src/components/shell/StatusBadge.tsx` / `src/components/tasks/InlineStatusTag.tsx` Tag+color pattern for new `WorkTypeBadge`.
- Wrap new form fields with `useRegisterActiveForm` (FormGuardContext) in `TaskDrawer`, `ProjectModal`, `MilestoneModal` to prevent dirty-form loss on PWA update.
- Use `createFocusRestorer()` (`src/utils/focus.ts`) — already active in these modals/drawers; new fields must not break focus restoration.

Exceptions:

## Color

60/30/10 split reads from Ant Design theme tokens (light values shown; dark resolved by `darkAlgorithm`):

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `token.colorBgContainer` (`#ffffff` light / `#141414` dark) | Page/table/modal/drawer surfaces |
| Secondary (30%) | `token.colorFillAlter` (`#00000005` light) + Sider nav | Filter bar, cards, nav rail, tag input backgrounds |
| Accent (10%) | `token.colorPrimary` `#1677ff` | See reserved list below |
| Destructive | `token.colorError` (`#ff4d4f`) | Not triggered this phase (no new destructive action) |

Accent reserved for: primary form submit button (`Lưu`), active tag-input focus ring, the on-the-fly "press Enter to add tag" affordance, and focused `Select` control border. NOT applied to work-type badges, inherited-tag borders, or table rows.

**Categorical work-type palette (data encoding — exempt from the 10% accent rule):** Work-type badges encode 7 distinct categories, so they use Ant Design preset color names as a categorical palette, not accent color. This is a deliberate exception: categorical data-viz encoding requires distinguishable hues. Values (D-10):

| workType | Ant preset color | Icon | VN label |
|----------|------------------|------|----------|
| `code` | `blue` | `<CodeOutlined />` | Lập trình |
| `document` | `green` | `<FileTextOutlined />` | Tài liệu |
| `meeting` | `purple` | `<TeamOutlined />` | Họp hành |
| `support_testing` | `orange` | `<CheckCircleOutlined />` | Hỗ trợ SIT / UAT |
| `investigate` | `magenta` | `<BugOutlined />` | Điều tra lỗi / R&D |
| `configuration` | `cyan` | `<SettingOutlined />` | Cấu hình hệ thống |
| `review_code` | `gold` | `<EyeOutlined />` | Review code |

Each badge pairs icon + text + color (triple encoding) so meaning never relies on color alone (WCAG 1.4.1). Verified count: 7 hues are Ant presets with sufficient distinction; icons disambiguate adjacent hues (blue/cyan, orange/gold, purple/magenta).

**Inherited-tag visual treatment (D-08, Claude discretion on exact values):**
- Border: `1px dashed token.colorBorder`; opacity `0.75` on the tag.
- Leading origin glyph: `<LinkOutlined />` at 12px, `token.colorTextTertiary`.
- Tooltip on hover/focus states exact origin: `Kế thừa từ Milestone: {name}` or `Kế thừa từ Dự án: {name}`.
- Explicitly-assigned tags: standard solid Ant `Tag` (default fill, no dashed border, opacity 1).
- Contrast: dashed-border ghost style must still meet 3:1 non-text contrast against surface; `colorBorder` token satisfies this in both light and dark.

## Interaction States

- **Tag input:** typing filters autocomplete suggestions (ordering = Claude discretion, recommend frequency-desc then alphabetical); Enter commits; duplicate (case-insensitive) is silently merged, not added twice; exceeding 10 blocks add and shows `Tối đa 10 thẻ cho mỗi trường` inline error.
- **Inheritance → override transition:** empty field shows inheritance placeholder; first committed tag flips record to explicit override (inherited tags no longer shown as active); clearing all explicit tags reverts to inheritance display.
- **Focus/keyboard:** `Select` fully keyboard operable (Ant default); focus ring uses `colorPrimary`; modal/drawer focus restoration preserved via existing `createFocusRestorer()`.
- **Hover/focus reveal:** inherited-tag origin Tooltip and `+N` overflow Popover trigger on both hover AND keyboard focus (accessibility — not hover-only).
- **Dark mode:** all tokens resolve through `darkAlgorithm`; categorical preset colors auto-adapt via Ant; verify dashed-border contrast in dark.
