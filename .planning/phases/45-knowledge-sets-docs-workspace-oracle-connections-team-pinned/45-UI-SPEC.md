## Interaction & State Contracts

### Deleting a document set (D-01/D-02)
```
[user: Xóa bộ tài liệu]
   └─ DocumentSetDeleteDialog
        ├─ unpublished → [Hủy | Xóa cục bộ]  (local only, no remote)
        └─ published   → warning Alert + type-to-confirm Input
                          ├─ full delete (default): purge remote → delete local → success toast
                          └─ local-only: ENABLED only on exact name match → delete local only
```
- Local-only is never the default and never reachable without the typed name.
- A failed remote purge keeps local metadata and shows an error; it never silently falls through to local-only.

### Server-side set cleanup (D-03)
```
[Settings > Quản lý set] → listPublishedSets() (daemon required)
   ├─ daemon off/unreachable → info/warning Alert, table not shown
   └─ reachable → Table → "Dọn set này" → Popconfirm → purgeDocumentSet() → reload list
```
- Manual and explicit; no automatic reconciliation, no GC, no retrieval-scope filtering. Do not re-run the D-05 cleanup.

### Opening a Docs set
```
[Docs workspace] → click set → openTab('doc_set', { setId })
   → doc_set tab (persisted, MAX_OPEN_TABS) → bounded document list → "Xóa bộ tài liệu" → shared delete dialog
```
- No browser/system tab. Multiple sets → multiple tabs. Offline works without the daemon.

### Oracle connection selection (D-10..D-12)
```
[oracle_query / oracle_describe with optional selector]
   → resolve: exact id → case-insensitive name/environment → active fallback
   ├─ found    → execute under unchanged read-only guard
   └─ not found → error listing available names ONLY (no connection strings)
```
- `oracle_list_connections` lets the model discover valid selectors; it is advertised under the same team gating as the other Oracle read tools.

### Pinned context lifecycle (D-16..D-19)
```
[Team Settings] → edit Pinned Team Context → save to team
   → every leader/member turn: buildPinnedContextSegment(pin) → wrapped segment in both builders
   → team chat: badge + tooltip shows current content
```
- No pin → no segment, no badge. Pin content never mutates the global Oracle active connection.

### Loading / busy states (no new spinner idioms)
- Set list loading → antd `Table` spinner; empty state suppressed while loading.
- Purge/delete in flight → the specific row's action shows antd loading; all dialog controls disabled.
- Oracle test in flight → the tested row's `Test` shows loading; result banner appears after.
- Docs set list loading → bounded list spinner; no full-array mount.

- Preserve existing accessible names verbatim on controls this phase does not change. New controls use Vietnamese `aria-label`s: `Làm mới danh sách set`, `Xóa bộ tài liệu {name}`, `Gõ đúng tên bộ tài liệu "{name}" để xóa cục bộ`, `Mở bộ tài liệu {name}`.

- Oracle connection strings are `Input.Password`; redaction applies to every displayed/test message. No secret is exposed via `title`, `aria-label`, or `Tooltip`.
- Destructive confirmations keep `okType: 'danger'` semantics and an explicit cancel; focus does not land on a deleted row after purge/delete.
- Tab order in the chat header and settings cards changes only by inserting the new badge/section — no focus trap, no skipped stop.
- Respect `prefers-reduced-motion` for any entrance/transition (existing `team-chat.css` pattern); this phase adds no mandatory animation.
- `doc_set` tabs follow the existing `ChatTabBar` accessible-name style (`Đóng {title}`) where that pattern is reused.
