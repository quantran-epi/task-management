## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Daemon attempt resource -> local cache | Untrusted terminal status and activeSnapshotId drive local projection metadata |
| Frozen submitted snapshot -> IndexedDB metadata | User content is reduced to content-free IDs/hashes before persistence |
| Network observation -> server state | Observer loss must not fabricate terminal failure or cancel accepted work |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-16-21-02 | Information Disclosure | `publishedDocuments` | mitigate | Persist IDs, SHA-256 hash, timestamps, and state only; no body/title/tag/token/excerpt |
| T-16-21-03 | Repudiation | async attempt cache | mitigate | Preserve server attempt ID, timestamps, bounded metrics, and terminal status in newest-10 history |

| T-16-21-05 | Tampering | failed candidate | mitigate | Never delete or replace active metadata unless explicit `In sync` with activeSnapshotId per D-14 |
