## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| NotesView UI -> Knowledge Server | Document set publishing preview and candidate POST crosses client/network boundary |
| PublishPreviewModal -> DLP Scanner | Untrusted local markdown text is scanned for sensitive credentials/PII before egress |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-16-GAP1-01 | Information Disclosure | `PublishPreviewModal.tsx` | mitigate | Require explicit pre-send DLP scan; block publish button until findings are reviewed and fresh nonce is confirmed per D-15 - D-19 |
| T-16-GAP1-02 | Spoofing | `knowledgeClient.ts` | mitigate | Validate HTTPS or loopback HTTP URL; enforce session-only Bearer token; redact secrets from error envelopes per D-05, D-07 |
| T-16-GAP1-03 | Denial of Service | `NotesView.tsx` | mitigate | Disable preview action during ongoing scan/publish; deduplicate requests via idempotency key (`attemptKey`) per D-09, D-11 |
| T-16-SC | Tampering | npm dependencies | mitigate | Use existing zero-dependency stdlib/installed packages; no new dependencies added |
</threat_model>
