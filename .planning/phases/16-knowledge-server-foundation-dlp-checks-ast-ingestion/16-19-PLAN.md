<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Daemon error response -> client decision | Untrusted status/envelope controls whether remote state may be treated as absent |
| Active manifest -> local preview | Content-free remote document/chunk hashes drive destructive removal classification |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-16-19-01 | Tampering | `KnowledgeClientError` classification | mitigate | Trust absent state only from strict error envelope with 404 plus `SNAPSHOT_NOT_FOUND` |
| T-16-19-02 | Information Disclosure | client errors | mitigate | Keep messages fixed/bounded and redact bearer token; retain no raw body or headers |
| T-16-19-03 | Elevation of Privilege | `NotesView` preview gate | mitigate | Authentication/origin/protocol errors cannot fall through to publishable preview |
| T-16-19-04 | Tampering | removal preview | mitigate | Use authoritative manifest so remote-only documents require explicit D-03 removal consent |
| T-16-19-SC | Tampering | npm supply chain | mitigate | Use existing client, Zod, React, and Vitest stack; add no dependency |
</threat_model>
