|-----------|----------|-----------|-------------|-----------------|

| T-16-GAP2-02 | Information Disclosure | `exportBackup.ts` | mitigate | Enforce `isSafeBackupSetting` filter; ensure `dlpAudits` records store only document IDs, hashes, and finding counts without sensitive cleartext excerpts per D-18 |

| T-16-SC | Tampering | npm dependencies | mitigate | Use existing zod and Dexie primitives; no new dependencies added |
</threat_model>
