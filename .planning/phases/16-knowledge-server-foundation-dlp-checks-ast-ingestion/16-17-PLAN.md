| Settings form -> root React context | Bearer token enters ephemeral application memory |
| Docs set form -> IndexedDB | User-entered set name and explicit document UUID membership become local records |
| Docs preview -> daemon | Token may leave memory only as Authorization header after user starts guarded flow |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-16-17-01 | Information Disclosure | `KnowledgeConfigProvider` consumers | mitigate | Keep one root provider and assert token never reaches storage, backup, DOM diagnostics, or logs per D-07 |
| T-16-17-02 | Tampering | `DocumentSetDrawer` create mode | mitigate | Route save through existing strict `DocumentSetSchema` and stable UUID repository per D-01 |
| T-16-17-03 | Repudiation | local set save | accept | Personal local-only set edit has no external side effect; createdAt/updatedAt remain persisted metadata |
| T-16-17-04 | Information Disclosure | create flow | mitigate | Creation performs no daemon request; DLP remains mandatory later at publish service boundary |
| T-16-17-SC | Tampering | npm supply chain | mitigate | Use existing React, Ant Design, Dexie, and test stack; add no dependency |
</threat_model>
