## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Async daemon status -> React progress | Validated remote terminal/uncertain state controls user-visible result |
| IndexedDB attempt manifest/metadata -> drawer badges | Content-free durable cache drives offline status and resumed reconciliation |
| Mutable Notes -> set/document state | Current hashes may indicate Local changes but cannot become submitted remote truth |
| Reopen reconciliation -> daemon | Retained attempt ID crosses authenticated exact-origin API boundary |
