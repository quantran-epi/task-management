## Trust Boundaries

| Boundary | Description |
|---|---|
| Frozen API payload → async worker | Mutable caller data becomes daemon-owned immutable attempt input. |
| Candidate → active snapshot | Partial projection must never activate. |
| Concurrent requests → set state | Replay/race requests contend for one set. |
